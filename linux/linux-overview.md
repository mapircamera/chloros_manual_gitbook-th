# Linux ภาพรวม

Chloros 1.1.0 นำการรองรับ Linux ดั้งเดิมสำหรับ **CLI**และ**Python SDK** ช่วยให้สามารถประมวลผลภาพหลายสเปกตรัมแบบ headless บนเวิร์คสเตชั่น Linux เซิร์ฟเวอร์ และอุปกรณ์ NVIDIA Jetson Edge

{% hint style="info" %}
**ไม่มี GUI บน Linux** Chloros Desktop GUI มีเฉพาะบน Windows เท่านั้น ผู้ใช้ Linux โต้ตอบกับ Chloros ผ่าน [CLI](../CLI.md) และ [Python SDK](../api-python-sdk.md)
{% endhint %}

| สถาปัตยกรรม | คำอธิบาย | วิธีการติดตั้ง |

| **arm64 (aarch64)** | โปรเซสเซอร์ที่ใช้ ARM โดยส่วนใหญ่เป็น NVIDIA Jetson | `.deb` แพ็คเกจ (JetPack 6) |

* **NVIDIA JetPack 6** (arm64 — แพลตฟอร์ม Jetson)***

## สิ่งที่ผู้ใช้ Linux ได้รับ

* **Chloros CLI** — อินเทอร์เฟซบรรทัดคำสั่งเต็มรูปแบบสำหรับการประมวลผลเป็นชุด ระบบอัตโนมัติ และการเขียนสคริปต์
* **Chloros Python SDK** — อินเทอร์เฟซ Python แบบเป็นโปรแกรม (`pip install chloros-sdk`) สำหรับการผสานรวมเข้ากับไปป์ไลน์การวิจัยและเครื่องมือที่กำหนดเอง
* **การเร่งความเร็วของ GPU** — การประมวลผลที่เร่งด้วย CUDA บน NVIDIA GPU (เดสก์ท็อปและ Jetson)
* **การปรับการประมวลผลแบบไดนามิก** — การตรวจจับฮาร์ดแวร์อัตโนมัติและการเพิ่มประสิทธิภาพกลยุทธ์การประมวลผล
* **คุณสมบัติการประมวลผลทั้งหมด** — ไปป์ไลน์การประมวลผลหลายสเปกตรัมแบบเดียวกับ Windows (การปรับเทียบ การแก้ไขขอบมืด ดัชนีพืชพรรณ รูปแบบการส่งออกทั้งหมด)
* **คุณสมบัติ Chloros+** — การประมวลผลแบบมัลติเธรด, การดีบาย Texture Aware, ดัชนีที่กำหนดเอง (พร้อมใบอนุญาต Chloros+)

## สิ่งที่ผู้ใช้ Linux ไม่ได้รับ

* **GUI เดสก์ท็อป** — ไม่มีอินเทอร์เฟซแบบกราฟิก การโต้ตอบทั้งหมดผ่านทาง CLI หรือ Python SDK
* **โปรแกรมดูรูปภาพ** — ไม่มีโปรแกรมดูรูปภาพแบบโต้ตอบ มุมมองตาราง หรือเครื่องหมายแผนที่
* **การจัดการโครงการด้วยภาพ** — โครงการได้รับการจัดการผ่านคำสั่ง CLI และการเรียก SDK***

## เริ่มต้นใช้งาน Linux

1. **ติดตั้ง Chloros** — ดู [การติดตั้ง Linux](linux-installation.md) สำหรับการติดตั้งแพ็คเกจ `.deb`
2. **ติดตั้ง Python SDK** (อุปกรณ์เสริม) — `pip install chloros-sdk`
3. **เปิดใช้งานใบอนุญาตของคุณ** — `chloros-cli login your@email.com 'password'`
4. **ประมวลผลชุดข้อมูลแรกของคุณ** — `chloros-cli process ~/datasets/flight001`

สำหรับผู้ใช้ NVIDIA Jetson โปรดดู [NVIDIA Jetson Guide](nvidia-jetson-guide.md) โดยเฉพาะสำหรับการตั้งค่าและการเพิ่มประสิทธิภาพเฉพาะแพลตฟอร์ม
