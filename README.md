## สิ่งใหม่ในChloros

1.2.0

* **การควบคุมกล้องแบบเรียลไทม์ — แท็บ Cameras ใหม่** เชื่อมต่อกล้อง LATTICE ได้ทั้งแบบทีละตัวหรือเป็นกลุ่มกล้องหลายตัวที่ซิงโครไนซ์ (การซิงค์เวลา PTP, การจับภาพที่ทริกเกอร์โดยฮาร์ดแวร์) พร้อมด้วยภาพพรีวิวสดแบบโอเวอร์เลย์, ฮิสโตแกรมตามแต่ละแบนด์, การปรับแสงอัตโนมัติอัจฉริยะ, เครื่องคำนวณดัชนีแบบสด และการอัปเดตเฟิร์มแวร์กล้องภายในแอป
* **เซ็นเซอร์แสง — แท็บ Light Sensors ใหม่** เชื่อมต่อเซ็นเซอร์ DAQ-U (USB), DAQ-M (Bluetooth) และ DAQ-E (Ethernet); ดูสเปกตรัมที่ปรับเทียบแล้วแบบเรียลไทม์ (W/m²/nm), บันทึกไฟล์ `.daq` ลงในโครงการของคุณ, เลือกโปรไฟล์การปรับแก้ cap, และอัปเดตเฟิร์มแวร์ DAQ-E ผ่านเครือข่าย
* **โหมดการจับภาพและเครื่องบันทึก** โหมดการจับภาพแบบเดี่ยว / ต่อเนื่อง / ตามช่วงเวลา พร้อมโหมดการจับภาพเร็วที่สุด (Fastest Capture) ที่บันทึกเฉพาะข้อมูลดิบ; การเลือกกล้องและประเภทการส่งออกที่ &quot;Capture All&quot; จะสร้างขึ้นตามแต่ละโครงการ; เครื่องบันทึกแบบอาร์เรย์สำหรับวิดีโอแบบดัชนีระดับการเฝ้าติดตาม และชุดข้อมูลดิบแบบบัร์สต์ระดับการวิเคราะห์ พร้อมการสร้างวิดีโอแบบออฟไลน์
* **ท่อประมวลผล LATTICE** นำเข้าโฟลเดอร์การจับภาพ LATTICE และแยกแต่ละเฟรมดิบออกเป็นผลิตภัณฑ์ที่ผ่านการถอดเบย์เออร์, ภาพตัวอย่าง, ค่าความสว่างแบบ float32 (W/m²/sr/nm), และค่าการสะท้อน พร้อมตัวเลือกเปิด/ปิดสำหรับแต่ละผลิตภัณฑ์ ค่าการสะท้อนสามารถมาจากเป้าหมายการปรับเทียบในเฟรมหรือการวัดแสงลงจาก DAQ; การจัดแนวอาร์เรย์จะถูกนำไปใช้กับไฟล์ที่ส่งออก; การปรับเทียบจากโรงงานที่ขาดหายไปจะถูกดาวน์โหลดอัตโนมัติตามหมายเลขซีเรียลของกล้อง
* **โครงการจะจดจำอุปกรณ์ฮาร์ดแวร์** กล้องและเซ็นเซอร์แสงที่เชื่อมต่อจะถูกบันทึกไว้กับโครงการ (`cameras.json` / `sensors.json`) และจะเชื่อมต่อใหม่ด้วยตั้งค่าที่บันทึกไว้เมื่อเปิดโครงการอีกครั้ง ดู [GUI : Projects](projects.md).
* **การอัปเกรดโปรแกรมดูภาพ** การแสดงค่าพิกเซล/ดัชนีของเคอร์เซอร์พร้อมการปรับสเกลการสะท้อนแสงที่ถูกต้องตามไฟล์แต่ละไฟล์, ฮิสโตแกรมชั้น, สไลเดอร์การรวม GSD, โหมดกริด Per Trigger / Per Camera, มุมมองผลิตภัณฑ์ LATTICE, และการส่งออกดัชนี/LUT แบบแซนด์บ็อกซ์ไปยังดิสก์
* **การขยายฟังก์ชันCLI

และSDK

อย่างมาก** กลุ่มคำสั่งใหม่ `lattice`, `daq pool-*`, `project` และ `time-sync`; ตัวเลือก `process` ใหม่ (`--input-level`, สวิตช์สำหรับแต่ละผลิตภัณฑ์, `--reflectance-source`, ธงการจัดแนวอาร์เรย์);SDK

ตัวจัดการ smart-connect (`connect_camera` / `connect_array` / `connect_daq_sensor`) ที่เริ่มต้นระบบหลังบ้านโดยอัตโนมัติ; `open_project()` การทำงานอัตโนมัติ; ไลบรารีSDK

ถูกบรรจุรวมกับตัวติดตั้งและเผยแพร่บน PyPI ในชื่อ `chloros-sdk`.
* **เซมานติกส์ความล้มเหลวที่ตรงไปตรงมา** การรัน `chloros-cli process` ที่ขอผลิตภัณฑ์แต่ไม่เขียนอะไรเลย จะล้มเหลวอย่างชัดเจนและออกค่าไม่เท่ากับศูนย์; การรันที่สำเร็จจะรายงานจำนวนผลิตภัณฑ์ภาพที่เขียน
* **รูปแบบผลลัพธ์ใหม่** ผลิตภัณฑ์จะถูกจัดเก็บในโฟลเดอร์ `<project>/<camera>/<format>/<Product>_Images/` และรักษาชื่อไฟล์ต้นฉบับไว้ — โฟลเดอร์ (ไม่ใช่ส่วนท้ายของชื่อไฟล์) เป็นตัวระบุผลิตภัณฑ์ ดู [รูปแบบภาพผลลัพธ์](output-image-formats.md).
* **ข้อมูลนำเข้า แผน และภาษาเพิ่มเติม** รองรับข้อมูลนำเข้า `.dng`; ภาษาอินเทอร์เฟซทั้ง 38 ภาษาได้รับการจัดเตรียมครบถ้วน; ข้อจำกัดฮาร์ดแวร์ตามแผน โดยสามารถใช้ฟรี (ไม่ต้องเข้าสู่ระบบ) ได้สูงสุด 4 กล้องและ 2 เซ็นเซอร์แสง
* **ความน่าเชื่อถือ** การหยุดการประมวลผล (Stop Processing) จะหยุดอย่างสมบูรณ์พร้อมสรุปการทำงานที่ชัดเจน โครงการที่มีหลายกล้องจะส่งออกข้อมูลจากทุกกล้อง และโปรแกรมติดตั้ง (installer) ที่อัปเกรดจะไม่ทำให้คุณถูกออกจากระบบอีกต่อไป***
