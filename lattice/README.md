# กล้อง LATTICE

LATTICE เป็นระบบกล้องมัลติสเปกตรัมแบบโมดูลาร์ของMAPIR สำหรับการถ่ายภาพทางการเกษตรและวิทยาศาสตร์ กล้อง LATTICE ทุกตัวถูกสร้างขึ้นบนเซ็นเซอร์ Sony IMX265 แบบ global-shutter (**

3.1 MP, 3.45 µm พิกเซล**) และเชื่อมต่อผ่าน Ethernet ในฐานะอุปกรณ์**GigE Vision**

Chloros 1.3.0 ควบคุมกล้อง LATTICE แบบเรียลไทม์ — การค้นหา, การดูตัวอย่างแบบเรียลไทม์, การถ่ายภาพ, และระบบกล้องหลายตัวที่ทำงานพร้อมกัน — จากสามอินเทอร์เฟซ:

| อินเทอร์เฟซ    | ที่                                                          | แพลตฟอร์ม                                                |
| ---------- | -------------------------------------------------------------- | -------------------------------------------------------- |
| GUI        | แท็บ **Cameras** ในแถบด้านข้างของ Chloros                         | Windows 10/11 x64                                        |
| CLI        | กลุ่มคำสั่ง `chloros-cli lattice`                           | Windows 10/11 x64, Linux x86\_64, Linux aarch64 (Jetson) |
| Python SDK | `chloros_sdk.connect_camera()` / `chloros_sdk.connect_array()` | Windows 10/11 x64, Linux x86\_64, Linux aarch64 (Jetson) |

> **กำลังหาอุปกรณ์ฮาร์ดแวร์อยู่ใช่ไหม?**โมดูลกล้อง, เลนส์, ฟิลเตอร์และแถบความยาวคลื่น, กรอบและอุปกรณ์ติดตั้ง, สายเคเบิล, PoE และสายทริกเกอร์ ได้รับการบันทึกไว้ใน [**คู่มือผู้ใช้ LATTICE**](https://mapir.gitbook.io/lattice-camera). บทนี้อธิบายวิธีการควบคุมกล้องจากChloros

ไฟล์ที่ LATTICE บันทึกเป็นไฟล์ `.tif`/`.tiff` มาตรฐาน และChloros จะประมวลผลไฟล์เหล่านี้เสมอโดยเริ่มจากข้อมูลดิบที่บันทึกมา ดู [CLI Reference](../reference/cli-reference.md) และ [SDK Reference](../reference/sdk-reference.md) เพื่อดูคำสั่งและAPI ทั้งหมด

## สองรูปแบบการตั้งค่าเซ็นเซอร์

| รูปแบบการตั้งค่า | เซ็นเซอร์       | ตัวกรอง                                | ข้อมูลที่กล้องหนึ่งตัวส่งมา                                          |
| ------------- | ------------ | ------------------------------------- | ----------------------------------------------------------------- |
| **M3C**| สี Bayer | ตัวกรองผ่านแถบสามชั้น                |**สามแถบที่ปรับเทียบแล้วจากการถ่ายภาพครั้งเดียว**                 |
| **M3M**| ขาวดำ   | ตัวกรองแทรกสอดแถบแคบเดี่ยว |**แถบที่ปรับเทียบแล้วหนึ่งแถบ**; รวมกล้อง M3M หลายตัวเพื่อสร้างดัชนี |

เนื่องจากกล้อง M3M เป็นกล้องขาวดำที่อยู่หลังตัวกรองเดียว แต่ละแถบจึงได้รับการถ่ายภาพแยกกัน กล้อง M3C ครอบคลุมทั้งสามแถบด้วยกระบวนการถ่ายภาพด้วยเซ็นเซอร์เพียงครั้งเดียว

## สายตัวอักษรแบบจำลองและการตั้งชื่อ

กล้องทุกตัวเก็บข้อมูลระบุตัวตนไว้ใน GenICam `DeviceUserID` ในรูปแบบสายตัวอักษรแบบจำลอง:

```
<sensor>-<lens>-F<filter>       e.g.  M3C-L41-FRGN,  M3M-L87-F450
```

Chloros แสดงมันด้วยคำนำหน้า `LATT-` (เช่น `LATT-M3M-L87-F450`) สตริง `LATT-…` เดียวกันนี้จะถูกเขียนลงในแท็ก EXIF `Model` ของการส่งออกทุกครั้ง และถูกใช้เป็นชื่อโฟลเดอร์ผลลัพธ์ของกล้องในโครงการที่ผ่านการประมวลผล

| ส่วนประกอบ | ค่า                                                   | ความหมาย                                                                                            |
| --------- | -------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| เซ็นเซอร์    | `M3C` / `M3M`                                            | ระบบสี Bayer / ขาวดำ                                                                          |
| เลนส์      | `L41` / `L87`                                            | ตัวเลขนี้คือ **มุมมองแนวนอนเป็นองศา**: L41 = แคบ (41°), L87 = กว้าง (87°)    |
| ฟิลเตอร์    | `FRGB` / `FRGN` / `FOCN` / `FNGB` (M3C) หรือ `F<nm>` (M3M) | ดู [ตัวกรองและแถบสเปกตรัม](https://mapir.gitbook.io/lattice-camera/hardware/filters-and-bands) |

สตริงรุ่นกำหนดทุกสิ่งในขั้นตอนต่อไป: Chloros จะกำหนดโปรไฟล์เซ็นเซอร์ การจัดวางแถบสเปกตรัม และการปรับเทียบจากโรงงาน จาก `DeviceUserID` + `DeviceSerialNumber`. ไม่จำเป็นต้องตั้งค่าอะไรสำหรับกล้องแต่ละตัว — ดู [การเชื่อมต่อกล้อง](connecting.md).

## ฟิลเตอร์และแถบสเปกตรัม

จุดศูนย์กลางของแถบสเปกตรัม ขอบFWHM และแคตตาล็อก M3M ทั้งหมด 23 SKU เป็นข้อมูลจำเพาะของผลิตภัณฑ์ ดังนั้นจึงอยู่ในคู่มือฮาร์ดแวร์: [**ฟิลเตอร์และแถบสเปกตรัม**](https://mapir.gitbook.io/lattice-camera/hardware/filters-and-bands).

สิ่งที่สำคัญด้านซอฟต์แวร์: รหัสฟิลเตอร์ในสตริงรุ่นจะกำหนดว่า Chloros สามารถสร้างผลิตภัณฑ์ใดได้ กล้องที่มีตัวกรอง RGB (`FRGB`) ส่งออกเฉพาะผลิตภัณฑ์ที่ผ่านการถอดเบย์เออร์และภาพตัวอย่างเท่านั้น — ค่าความส่องสว่างและค่าการสะท้อนแสงต่อแถบความถี่ไม่มีความหมายสำหรับเซ็นเซอร์แถบกว้าง ดังนั้น Chloros จึงข้ามค่าเหล่านี้และระบุไว้อย่างชัดเจน ส่วนตัวกรองอื่น ๆ ทั้งหมดจะให้ชุดข้อมูลครบถ้วนตั้งแต่ความส่องสว่าง → การสะท้อนแสง → ดัชนี

## การสอบเทียบเรดิโอเมตริกในภาพรวม

กล้อง LATTICE ทุกตัวได้รับการสอบเทียบเป็นรายตัวที่โรงงานตามห่วงโซ่ที่สามารถตรวจสอบย้อนกลับได้ถึง NIST และมาพร้อมกับใบรับรองสำหรับกล้องแต่ละตัว รายละเอียดเกี่ยวกับสิ่งที่การปรับเทียบครอบคลุม วิธีการวัด และความแม่นยำที่คุณสามารถอ้างอิงได้ มีอยู่ในคู่มือฮาร์ดแวร์: [**การปรับเทียบรังสีในโรงงาน**](https://mapir.gitbook.io/lattice-camera/calibration/factory-radiometric-calibration).

ด้านซอฟต์แวร์ สิ่งสำคัญคือ Chloros จะกำหนดการปรับเทียบที่ถูกต้องเมื่อกล้องเชื่อมต่อ และล็อกค่าสัมประสิทธิ์ที่ใช้ลงในทุกการส่งออก — ดู [การเชื่อมต่อกล้อง](connecting.md).
