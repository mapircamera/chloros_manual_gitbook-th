# การเชื่อมต่อกล้อง

<figure><img src="../.gitbook/assets/image (37).png" alt=""><figcaption><p>แท็บ &quot;กล้อง&quot; ก่อนที่จะเชื่อมต่ออุปกรณ์ใดๆ</p></figcaption></figure>

Chloros
จะตรวจพบกล้อง LATTICE บนลิงก์โดยอัตโนมัติ — จากแท็บ Cameras ใน GUI, จาก `chloros-cli lattice` หรือจาก Python
SDK
สตริงรุ่นของกล้องจะกำหนดทุกสิ่งในขั้นตอนต่อไป: Chloros
จะกำหนดโปรไฟล์เซ็นเซอร์, การจัดวางแถบความถี่ และการปรับเทียบจากโรงงาน จากไฟล์ `DeviceUserID` + `DeviceSerialNumber` ของกล้อง ดังนั้น **ไม่จำเป็นต้องตั้งค่าใดๆ สำหรับกล้องแต่ละตัว**.

ก่อนเชื่อมต่อ ให้แน่ใจว่าเครือข่ายโฮสต์ได้รับการตั้งค่าเรียบร้อยแล้ว — การกำหนดที่อยู่แบบ link-local, เฟรมจัมโบ้ และสำหรับอาร์เรย์ ให้ตั้งค่าบัฟเฟอร์รับของ NIC นี่คือการตั้งค่าด้านฮาร์ดแวร์ ซึ่งระบุไว้ในคู่มือ LATTICE: [**Network Setup**](https://mapir.gitbook.io/lattice-camera/setup/network-setup).

## การเชื่อมต่อจาก GUI

เปิดแท็บ **Cameras** ในแถบด้านข้างของChloros
(แท็บฮาร์ดแวร์จะปรากฏขึ้นเมื่อระบบหลังบ้านเริ่มต้นเสร็จสิ้น) หรือใช้เมนูหลัก → **Connect to Camera**ทั้งสองวิธีจะเปิดกล่องโต้ตอบ**Connect Camera(s)**

### กล่องโต้ตอบ Connect Camera(s)

กล่องโต้ตอบนี้จะสแกนเครือข่ายทันทีที่เปิดขึ้น (&quot;Scanning network...&quot;) และแสดงรายชื่อกล้องทุกตัวที่พบ แต่ละแถวจะแสดง **รุ่น**ของกล้อง (เช่น `LATT-M3M-L41-F550`),**หมายเลขซีเรียล**และ**ที่อยู่ IP*** **คลิกแถวเพื่อเลือก**(มีสีเขียวเน้น) คุณสามารถเลือก**กล้องหลายตัว** และเชื่อมต่อพวกมันพร้อมกัน — Chloros
จะเชื่อมต่อพวกมันตามลำดับ
* แถวที่มีป้าย **&quot;Connected&quot;** หมายถึงกล้องนั้นได้เชื่อมต่อแล้วและไม่สามารถเลือกซ้ำได้
* แถวที่มีป้าย **&quot;In Array&quot;** หมายถึงกล้องนั้นเป็นส่วนหนึ่งของกลุ่มกล้องที่เชื่อมต่ออยู่ปัจจุบัน ต้องตัดการเชื่อมต่อกลุ่มกล้องก่อน เพื่อใช้กล้องนั้นแบบอิสระ
* **Connect** — เชื่อมต่อกล้องที่เลือกไว้; ปุ่มจะแสดงจำนวน เช่น &quot;Connect (3)&quot; เมื่อเลือกมากกว่าหนึ่งตัว
* **Rescan** — ดำเนินการค้นหาอีกครั้ง
* **ปิด** — ปิดหน้าต่างสนทนา
* หากการสแกนเสร็จสิ้นโดยไม่มีผลลัพธ์ หน้าต่างสนทนาจะแสดง **&quot;ไม่พบกล้องใดในเครือข่าย&quot;** — ดู [การแก้ไขปัญหา](connecting.md#troubleshooting) ด้านล่าง

<figure><img src="../.gitbook/assets/image (38).png" alt=""><figcaption><p>หน้าต่าง Connect Camera(s) — แสดงที่นี่โดยไม่มีกล้องใดในเครือข่าย</p></figcaption></figure>

### การเชื่อมต่อครั้งแรก: ดาวน์โหลดแพ็กเกจการปรับเทียบ

**ครั้งแรก** ที่กล้องตัวใดตัวหนึ่งถูกเชื่อมต่อกับเครื่อง Chloros
จะดึงแพ็กเกจการปรับเทียบจากโรงงานของกล้อง (~3.8 MB) จากตัวกล้องเองผ่าน GigE ระหว่างที่กระบวนการนี้กำลังทำงาน หน้าต่างสนทนาจะแสดงแผงสีเขียว **&quot;กำลังดาวน์โหลดข้อมูลการปรับเทียบจากกล้อง&quot;**พร้อมแถบความคืบหน้าตามหมายเลขซีเรียล — คาดว่าจะใช้เวลาประมาณ**70 วินาที** ต่อกล้องหนึ่งตัว หากมีกล้องมากกว่าหกตัว แถบความคืบหน้าจะเลื่อนภายในแผง แพ็กเกจนี้จะถูกเก็บไว้ในแคชของเครื่องโฮสต์ ดังนั้นการเชื่อมต่อกล้องตัวเดียวกันในครั้งต่อไปจะข้ามขั้นตอนการดาวน์โหลดไปโดยสิ้นเชิง (และจะไม่แสดงแผงนี้อีก)

### วิเคราะห์ระบบ

ปุ่ม **วิเคราะห์ระบบ** ในหน้าต่างจะตรวจสอบเครื่องโฮสต์และเครือข่าย (จะมีข้อความ &quot;กำลังวิเคราะห์...&quot; ขณะทำงาน) และแสดงรายงานการวินิจฉัย:

* **เครื่องโฮสต์** — จำนวนคอร์ CPU และ RAM; ชื่อ GPU และหน่วยความจำ หรือ &quot;GPU: ไม่พบ&quot;
* **อินเทอร์เฟซเครือข่าย** — ชื่อ NIC แต่ละตัว, ความเร็วการเชื่อมต่อ, MTU (พร้อมแท็ก &quot;jumbo&quot; หากเปิดใช้งาน), สถานะการส่ง/รับข้อมูล, และว่ามันอยู่บนบัส USB หรือไม่
* **กล้อง**— หมายเลขซีเรียล, รุ่น, IP, และ**NIC ที่กล้องแต่ละตัวเชื่อมต่ออยู่**.
* **ประสิทธิภาพ** — fps ปัจจุบันเทียบกับ fps ที่เหมาะสมต่อกล้องสำหรับรูปแบบพิกเซล พร้อมด้วยบรรทัดสีเขียว &quot;Potential: N× improvement possible&quot; เมื่อค่าที่เหมาะสมสูงกว่าค่าปัจจุบัน.
* **คำเตือนและคำแนะนำที่มีหมายเลข** — หรือ &quot;ระบบดูดีสำหรับจำนวนกล้องปัจจุบัน&quot; เมื่อไม่มีสิ่งใดที่ต้องแก้ไข

เรียกใช้โปรแกรมนี้เมื่อการค้นหาหรือการสตรีมมีพฤติกรรมผิดปกติ — โปรแกรมนี้จะระบุปัญหาส่วนใหญ่ด้าน NIC (MTU ผิด, กล้องอยู่บนอินเทอร์เฟซผิด, ข้อจำกัดของอะแดปเตอร์ USB) โดยไม่ต้องออกจากหน้าต่างสนทนา

### การเชื่อมต่ออาร์เรย์

เพื่อเชื่อมต่อกล้องสองตัวหรือมากกว่าเป็น **อาร์เรย์ที่ซิงโครไนซ์**ให้ใช้ตัวช่วยการเชื่อมต่ออาร์เรย์ (**Connect Camera Array**) แทน: ตัวช่วยนี้จะนำคุณผ่านขั้นตอนการเลือกมาสเตอร์/สเลฟ (ถูกกรอกข้อมูลล่วงหน้าโดยตัวตรวจจับสายซิงค์ — กล้องใดก็ตามที่ต่อสายสามารถเป็นมาสเตอร์ได้, และกล้องRGB
`-FRGB` จะถูกเลือกไว้ล่วงหน้าเมื่อต่อสาย), การเลือกโหมดแสดงผล (Separate vs. Combined tiles), และฉากการตั้งค่าอาร์เรย์พร้อมการแสดงผลสดของ fps ที่สามารถบรรลุได้และ bandwidth ของสาย ก่อนที่คุณจะยืนยันการตั้งค่า ขั้นตอนการทำงานของตัวช่วยสร้างและระบบกล้องหลายตัวถูกอธิบายไว้ในส่วนระบบกล้องหลายตัวของคู่มือนี้; ส่วนที่เทียบเท่าใน CLI
คือ &quot;LATTICE Camera First-Connect Workflow&quot; ใน [CLI
Reference](../reference/cli-reference.md).

และ SDK
การเข้าถึงผ่าน

CLI
และ SDK
จำเป็นต้องมีแพ็กเกจ Chloros
+ แบบเสียค่าใช้จ่ายและต้องเข้าสู่ระบบแล้ว; ข้อกำหนดนี้ถูกบังคับใช้จากฝั่งเซิร์ฟเวอร์ (`401 AUTH_REQUIRED` เมื่อยังไม่ได้เข้าสู่ระบบ, `403 PLAN_UPGRADE_REQUIRED` สำหรับแพ็กเกจฟรี)

```bash
# List cameras on the network (vendor, model, serial, IP, MAC)
chloros-cli lattice info

# Single-camera smoke test: capture one frame (saves every applicable export type)
chloros-cli lattice capture -o output/

# Connect a synchronized array — same smart-prep flow as the GUI
chloros-cli lattice array-connect --serials 213800234,214000533
```

```python
import chloros_sdk

# Persistent live-camera session through the backend
with chloros_sdk.connect_camera("213800234") as cam:
    ...

# Array session (smart-prep: network probe, tier auto-pick, PTP, AE seeding, trigger config)
with chloros_sdk.connect_array(["213800234", "214000533"]) as array:
    ...
```

ลายเซ็นเต็ม ตัวเลือก และขั้นตอนการทำงานในการจับข้อมูล: [คู่มือ CLI
](../reference/cli-reference.md) § `chloros-cli lattice`, [คู่มือ SDK
](../reference/sdk-reference.md) § `connect_camera()` / `connect_array()`.

## วิธีแก้ไขการปรับเทียบเมื่อเชื่อมต่อ

กล้อง LATTICE ทุกตัวมีชุดการปรับเทียบจากโรงงาน **ในตัวกล้อง** และChloros
ยังตรวจสอบคลาวด์ของMAPIR
เมื่อกล้องเชื่อมต่อ:

| สถานการณ์   | สิ่งที่Chloros
ใช้                                                                                                                                                                                                          |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ออนไลน์**|**ข้อมูลการปรับเทียบล่าสุดที่เผยแพร่สำหรับหมายเลขซีเรียลนั้น** — ข้อมูลในคลาวด์จะมีความสำคัญเหนือกว่าข้อมูลในตัวกล้อง ดังนั้นกล้องที่ได้รับการปรับเทียบใหม่หรืออัปเดตโดยMAPIR
จะอัปเดตตัวเองโดยอัตโนมัติ; ไม่จำเป็นต้องมีการดำเนินการจากผู้ใช้ |
| **ออฟไลน์**|**แพ็กเกจในกล้อง** ตามเดิม กระบวนการทำงานแบบออฟไลน์เต็มรูปแบบยังคงทำงานได้ปกติ; เพียงแต่จะไม่รับการปรับเทียบที่ใหม่กว่าจนกว่ากล้องจะเชื่อมต่อออนไลน์อีกครั้ง (หรือถูกแฟลชใหม่ตามค่าโรงงาน)                                                  |

เมื่อถ่ายภาพ ค่าสัมประสิทธิ์ที่ใช้จริงจะถูก **บันทึกไว้ในข้อมูลเมตาดาต้า XMP ของภาพแต่ละภาพ** การอัปเดตการปรับเทียบในภายหลังจะไม่เปลี่ยนแปลงภาพที่คุณถ่ายไว้แล้วโดยอัตโนมัติ — การประมวลผลภาพเก่าจะใช้ค่าสัมประสิทธิ์ที่บันทึกไว้ใน XMP ของภาพนั้น ไม่ใช่ค่าที่ใหม่ที่สุดในปัจจุบัน

## การแก้ไขปัญหา

* **&quot;ไม่พบกล้องใดในเครือข่าย&quot;**— ตรวจสอบการตั้งค่า link-local ใน [Network Setup](https://mapir.gitbook.io/lattice-camera/setup/network-setup): NIC ของโฮสต์ตั้งค่าแบบคงที่ `169.254.x.x/16`, กล้องอยู่บนลิงก์เดียวกัน, ไม่ใช้ DHCP/เกตเวย์ จากนั้นใช้**Analyze System**ในหน้าต่างเชื่อมต่อเพื่อตรวจสอบว่ากล้องแต่ละตัวปรากฏ (หรือไม่ปรากฏ) บน NIC ใด**Rescan** หลังจากเปลี่ยนสายหรือ NIC ใดๆ
* **ระบบที่เคยทำงานได้ปกติแต่ตอนนี้ไม่สามารถเชื่อมต่อได้** (แผงอาร์เรย์มีข้อผิดพลาดกับ `FRAMES WILL DROP` / `Reduce ROI to enable`) — การอัปเดตไดรเวอร์ NIC ได้รีเซ็ตการตั้งค่าวงรับสัญญาณโดยไม่ได้แจ้งเตือน ตั้งค่าใหม่หรือเรียกใช้ `chloros-cli lattice network --fix` จากเทอร์มินัลที่มีสิทธิ์ผู้ดูแลระบบ; ดู [การตั้งค่าเครือข่าย](https://mapir.gitbook.io/lattice-camera/setup/network-setup).
* **กล้องแสดง &quot;In Array&quot;** — กล้องนี้อยู่ในเซสชันอาร์เรย์ที่เชื่อมต่ออยู่ ให้ตัดการเชื่อมต่ออาร์เรย์เพื่อใช้กล้องแบบสแตนด์อโลน
