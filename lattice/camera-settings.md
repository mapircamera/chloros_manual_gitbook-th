# การตั้งค่ากล้อง

แท็บ **กล้อง** เป็นหน้าควบคุมแบบสดของChloros

สำหรับกล้อง LATTICE: พื้นที่แสดงภาพหลักที่แสดงกล้องทุกตัวที่เชื่อมต่อไว้ในรูปแบบไทล์สด และแถบข้างที่สามารถเลื่อนระหว่างสามหน้า — **รายชื่อกล้อง**,**แผงตั้งค่า**(การตั้งค่าต่อกล้องแต่ละตัว, การตั้งค่าแบบอาร์เรย์ หรือการตั้งค่าการจับภาพ — ครั้งละหนึ่งหน้า) และ**เครื่องคำนวณดัชนี**หน้านี้อธิบายทุกตัวควบคุมใน**รายชื่อกล้อง**,**หน้าต่างการตั้งค่าต่อกล้อง**และ**หน้าต่างการตั้งค่าแบบอาร์เรย์**โหมดการจับภาพ การเลือกประเภทการส่งออก และขั้นตอน**Capture All** อยู่ในหน้าคู่ [การตั้งค่าและโหมดการจับภาพ](capture.md).

แท็บ “กล้อง” จะปรากฏในแถบด้านข้างเมื่อระบบหลังบ้านChloros

พร้อมใช้งานแล้ว ทุกปุ่มควบคุมด้านล่างนี้สื่อสารกับระบบหลังบ้านท้องถิ่นผ่าน `127.0.0.1:5000`; การเปลี่ยนแปลงจะมีผลกับกล้องสดทันที เว้นแต่จะระบุไว้เป็นอย่างอื่น

### ช่องแสดงภาพ

กล้องแต่ละตัวจะแสดงช่องแสดงภาพสดแบบรวม; กล้องยังสามารถแสดงช่องแสดงภาพแบบ **แบ่งตามช่องสัญญาณ** ในโทนสีเทาได้อีกสามช่อง (ดู [Channel Splits](#display-overlays-drawn-over-the-live-feed)), ส่วนอาร์เรย์จะแสดงช่องแสดงภาพแบบรวม ไทล์ที่กำลังใช้งานอยู่จะมีวงแหวนเลือกสีตามสีของกล้อง (หรืออาร์เรย์)

เมื่อนำเมาส์ไปวางเหนือไทล์ จะปรากฏปุ่มปิด **X**:

* การปิดไทล์ **รวม** ในขณะที่การแบ่งช่องสัญญาณยังคงอยู่ จะเพียงแต่ซ่อนไทล์รวมเท่านั้น
* การปิด **ไทล์สุดท้ายที่มองเห็นได้ของกล้องเดี่ยว** จะทำให้กล้องนั้นถูกตัดการเชื่อมต่อ
* **ไทล์แบ่งช่องของสมาชิกในอาร์เรย์รวม**จะไม่**ตัดการเชื่อมต่อ** กล้อง — แต่จะซ่อนเพียงเท่านั้น

เมื่อปลดล็อกกริดแล้ว ให้ลากไทล์ใดก็ได้ไปยังช่องใดก็ได้; การจัดวางจะถูกบันทึกพร้อมกับโครงการ

## แถบด้านข้าง — รายการ

<!-- SCREENSHOT-NEEDED: sidebar camera list pane showing a standalone camera row and an ARRAY group with indented member rows, the DAQ on/off pill visible on the array row, plus the Connect Camera / Connect Array / Capture All buttons at the top. -->

กล้อง หน้าแรกของแถบด้านข้างแสดงรายการกล้องและอาร์เรย์ที่เชื่อมต่อทั้งหมด:

* **เชื่อมต่อกล้อง**(สีเขียว) /**เชื่อมต่ออาร์เรย์** (สีน้ำเงิน, แสดง &quot;กำลังตรวจหา...&quot; ระหว่างการสแกน). ทั้งสองถูกปิดใช้งานเมื่อมีหน้าต่างเชื่อมต่อเปิดอยู่
* **บันทึกทั้งหมด** (สีแดง) — บันทึกภาพจากกล้องทุกตัวที่แสดงในรายการด้วยประเภทการส่งออกที่เลือกไว้ใน [การตั้งค่าการบันทึก](capture.md) ต้องมีโครงการที่เปิดอยู่ มีเอกสารอธิบายอย่างละเอียดใน [การตั้งค่าการบันทึกและโหมด](capture.md).
* **ไอคอนรูปเฟืองการตั้งค่าการจับภาพ**(ข้าง**จับภาพทั้งหมด**) — เปิด [หน้าต่างการตั้งค่าการจับภาพ](capture.md#the-capture-settings-pane) จะถูกปิดใช้งานหากไม่มีโครงการหรือขณะกำลังจับภาพ

### แถวกล้อง

แต่ละแถวกล้องแสดงขอบที่ระบุด้วยสี (สีที่กำหนดเองของกล้อง), ป้าย &quot;CAM&quot; — พร้อมตัวอักษร **M**(master) หรือตัวอักษร**S** (slave) สีเขียว สำหรับสมาชิกในอาร์เรย์ — และชื่อที่แสดง ชื่อเริ่มต้นคือ `LATTICE-MODEL (serial)`; สามารถเปลี่ยนชื่อได้จากหน้าต่างการตั้งค่าของแต่ละกล้อง ปุ่มในแถว:

| ปุ่ม | ผล |
| --- | --- |
| **ตา**| เปิด/ปิดการแสดงผล กล้องที่ซ่อนจะออกจากตารางและ**ไม่ถูกรวมใน Capture All** |
| **เกียร์** | เปิดหน้าต่างการตั้งค่าสำหรับกล้องแต่ละตัว (ส่วนถัดไป) |
| **หยุดชั่วคราว / เล่น**| หยุดภาพสด**เฉพาะด้านหน้าจอ** — การจับภาพจากระบบหลังยังคงทำงานต่อไป กล้องที่หยุดชั่วคราวไม่สามารถจับภาพได้ |
| **X** | ตัดการเชื่อมต่อ UI จะอัปเดตทันที (แบบคาดการณ์); การตัดการเชื่อมต่อของระบบหลังอาจใช้เวลา 10–30 วินาทีเพื่อเสร็จสิ้น |

### แถวของอาร์เรย์

แถวของอาร์เรย์จะแสดงป้าย &quot;ARRAY&quot; ในสีของอาร์เรย์ ชื่ออาร์เรย์ (สามารถเปลี่ยนชื่อได้ในตั้งค่าอาร์เรย์) และปุ่ม **DAQ · เปิด/ปิด**—**เปิด** เมื่อเซ็นเซอร์แสงระดับอาร์เรย์ถูกตั้งค่า *หรือ* สมาชิกใดก็ตามมีเซ็นเซอร์เฉพาะกล้อง; คำอธิบายเครื่องมือจะแสดงอย่างชัดเจนว่าเซ็นเซอร์ใดส่งข้อมูลไปยังส่วนใด กล้องสมาชิกจะแสดงอยู่ด้านล่างด้วยช่องว่างถอยร่นในแถวของตัวเอง ปุ่มในแถวอาร์เรย์: **ตา**(ซ่อน/แสดงสมาชิกทั้งหมดพร้อมกัน),**เกียร์**(หน้าต่างการตั้งค่าอาร์เรย์),**X**(ตัดการเชื่อมต่ออาร์เรย์ทั้งหมด)

สถานะของเซ็นเซอร์แสง (DLS) ที่ใช้ในแถวของอาร์เรย์และหน้าต่างการตั้งค่าอาร์เรย์มีสี่สถานะ:**ปิด**,**รอ**(ยังไม่มีสเปกตรัม),**กำลังทำงาน**(มีสเปกตรัมเข้ามาภายใน 3 วินาทีที่ผ่านมา), และ**เก่า** — ไม่มีสเปกตรัมใหม่ใน 3 วินาที แต่ค่าอ่านล่าสุด *ยังคงถูกใช้* (ค่าอ่านจาก DAQ ไม่หมดอายุบนเส้นทางจับภาพ)

คุณสามารถลากกล้องเดี่ยวและกลุ่มอาร์เรย์ทั้งชุดผ่านกันในแถบด้านข้างเพื่อจัดลำดับรายการใหม่; สมาชิกในอาร์เรย์ไม่สามารถลากแยกกันได้

เปิดด้วย **ไอคอนรูปเกียร์** บนแถวกล้อง แผงนี้จะเลื่อนมาทับรายการกล้อง

**ส่วนหัว**:**ตัวอย่างสี**ของกล้อง (คลิกเพื่อเปิดเครื่องมือเลือกสีในตัว — ใช้กำหนดสีขอบแถบด้านข้างและสีวงแหวนเลือกไทล์),**ชื่อ**พร้อมปุ่ม**เปลี่ยนชื่อ**รูปดินสอ (การบันทึกชื่อว่างจะกลับสู่ค่าเริ่มต้น `MODEL (serial)`), และ**×** เพื่อปิด

### ฮิสโตแกรมแบบเรียลไทม์

ส่วนบนของหน้าต่างมีฮิสโตแกรมลูมาแบบเรียลไทม์ ที่คำนวณจากภาพตัวอย่างJPEG

ที่ความถี่ประมาณ 8 Hz ค่าเฉลี่ยถูกถ่วงน้ำหนักแบบ Bayer — (R+2G+B)/4 — เพื่อให้สอดคล้องกับระบบวัดแสงอัตโนมัติ (AE) ของกล้องเอง

* **Orange

เส้นประ**= เป้าหมาย AE**ลากเส้นนี้ตามแนวนอนเพื่อปรับเป้าหมายใหม่** — เมื่อปล่อยมือจะส่งคำสั่งหนึ่งครั้ง และการลากจะเปลี่ยนโหมดเป้าหมาย AE เป็นโหมดแมนนวล
* **เส้นทึบGreen** = ค่าเฉลี่ยลูมาจริง (สิ่งที่ระบบ AE กำลังส่งออกมาในขณะนี้)
* **ปุ่มRGB** (มุมขวาบน): สลับการแสดงฮิสโตแกรมซ้อนทับตามแต่ละแบนด์ โดยใช้สีตามฟิลเตอร์ของกล้อง (เช่น บน FRGN: สีเทาNIR

, สีเขียว, สีแดง) สำหรับกล้องโมโน (M3M) ปุ่มจะแสดงเป็น &quot;MONO&quot; และถูกปิดใช้งาน — โหมดโมโนจะแสดงฮิสโตแกรมลูมาแบบแถบเดียวเสมอ
* ป้ายกำกับแกน X ขึ้นอยู่กับความลึกของบิตเซ็นเซอร์ของรูปแบบพิกเซลปัจจุบัน: 0..255, 0..1023, 0..4095 หรือ 0..65535.

* **Linear** — สัญญาณมืด + ฟิลด์แบน + สมดุลสีขาว; ไม่มีเมทริกซ์สี ไม่มีแกมมา
* **Natural** *(ค่าเริ่มต้น)* — Linear บวกเมทริกซ์การแก้ไขสีที่วัดได้ และเส้นโค้งโทนที่ปรับตามฉาก
* **Enhanced**— Natural บวกความสดใส (Vibrance) และความคมชัดท้องถิ่น CLAHE ค่าใช้จ่ายเพิ่มเติมนี้ใช้กับ**การดูตัวอย่างแบบสดเท่านั้น** — ภาพที่บันทึกไว้จะได้รับการปรับแต่งอย่างสมบูรณ์เสมอ ไม่ว่าใช้โปรไฟล์ใด
* **Custom Temperature** — Natural โดยตั้งค่าสมดุลสีขาวให้คงที่ตามค่า Kelvin ที่คุณเลือก

{% hint style="warning" %}
สำหรับโหมด Natural, Enhanced และ Custom Temperature ช่องแสดงผลจะแสดงหมายเหตุเกี่ยวกับโทนสี: ภาพจะถูกปรับให้สว่างขึ้นตามฉากของแต่ละเฟรม ดังนั้นภาพที่บันทึกไว้บน *หน้าจอ* จึงไม่สามารถเปรียบเทียบระหว่างเฟรมได้ **ส่งออกค่า radiance หรือ reflectance เพื่อการวัด**
{% endhint %}

### Spot Meter

* **คลิกเพื่อสุ่มตัวอย่าง**ช่องทำเครื่องหมาย: คลิกที่ภาพสดเพื่อสุ่มตัวอย่างพิกเซลเดียว (มีเส้นกากบาทแสดงตำแหน่ง) หรือคลิกและลากพื้นที่เพื่อคำนวณค่าเฉลี่ยพิกเซล**ล้าง**ลบตัวอย่างและเส้นกากบาท ไม่สามารถใช้ร่วมกับโหมด**Aim** ของ AE-ROI ได้
* **แสดง**เมนูแบบเลื่อนลง:**Raw (bit depth)**— ค่าตัวเลขดิจิทัลต้นฉบับตามความลึกของบิตของเซ็นเซอร์ (เช่น 12-bit → 0..4095) — หรือ**Display (8-bit)** (ค่าเริ่มต้น) เมื่อดัชนีแบบเรียลไทม์ถูกเปิดใช้งาน Display จะแสดงค่าดัชนีที่คำนวณได้ (เช่นNDVI

) แทน
* แผงแสดงผลจะแสดงพิกัดพิกเซล ขนาดเฟรม รูปแบบพิกเซล ความลึกของบิต และตารางช่อง (Chan / Value / %) พร้อมป้ายชื่อแถบและช่วงความยาวคลื่น; คู่สีเขียวแบบ Bayer จะถูกเฉลี่ย; ตัวอย่างพื้นที่แสดง &quot;N px avg&quot;

### การปรับแสงอัตโนมัติแบบคาดการณ์ (ขับเคลื่อนด้วย DLS)

ส่วนนี้จะปรากฏขึ้นเฉพาะเมื่อ **มีเซ็นเซอร์แสง DAQ อย่างน้อยหนึ่งตัวที่เชื่อมต่อ** — ตัวแก้ปัญหาต้องการสเปกตรัมแสงที่ส่องลงแบบเรียลไทม์เพื่อขับเคลื่อนมัน

| การควบคุม | ช่วง | ค่าเริ่มต้น | หน้าที่ |
| --- | --- | --- | --- |
| **เปิดใช้งาน** | ช่องทำเครื่องหมาย | เปิด (กล้องแบบสแตนด์อโลน) | ตัวแก้ปัญหาแบบสูตรปิดใช้สเปกตรัม DLS ร่วมกับค่าสเกลาร์จากชุดปรับเทียบของกล้อง เพื่อปรับแถบที่สว่างที่สุดให้อยู่ใกล้จุดอิ่มตัว ในขณะที่รักษาแถบที่มืดที่สุดให้อยู่เหนือระดับ SNR ขั้นต่ำ — เขียนข้อมูลการเปิดรับแสงครั้งเดียวต่อการแก้ปัญหาหนึ่งครั้ง ไม่มีวงจรปรับสมดุล ออกแบบมาสำหรับถ่ายไทม์แลปส์ที่ใช้พลังงานแสงอาทิตย์ ซึ่งทุกภาพต้องได้รับการเปิดรับแสงอย่างถูกต้อง ระบบหลังจะเปลี่ยนไปใช้ AE แบบตอบสนองโดยอัตโนมัติเมื่อค่า DLS ล้าสมัย/ขาดหายไป หรือแพ็กเกจการปรับเทียบยังไม่ถูกโหลด |

{% hint style="info" %}
**การเชื่อมต่อแบบอาร์เรย์จะปิด AE แบบคาดการณ์โดยค่าเริ่มต้น** — สำหรับอาร์เรย์,Chloros

&#x27; ระบบ AE อัจฉริยะร่วมกับระบบปรับแสงอัตโนมัติของกล้องจะจัดการการเปิดรับแสง (พร้อมการป้องกันการอิ่มตัว) และการประมาณค่าการสะท้อนของฉากแบบเดียวของ AE แบบคาดการณ์ไม่ปลอดภัยเมื่อใช้กับฉากที่ผสมกัน คุณสามารถเปิดใช้งานใหม่ได้สำหรับกล้องแต่ละตัวที่นี่ หากคุณต้องการการเปิดรับแสงแบบรังสีที่ขับเคลื่อนด้วย DLS โดยเฉพาะ
{% endhint %}

**ขีดจำกัดการเปิดรับแสงที่ขับเคลื่อนโดย DAQ และ AE ที่ยึดตามแสงตกกระทบ** โดยไม่ขึ้นกับช่องทำเครื่องหมายข้างต้น เมื่อเซ็นเซอร์แสง DAQ ถูกกำหนดให้กับกล้องRGB

,Chloros

จะคำนวณ — จากค่าความเข้มแสงลงสู่พื้นผิวที่วัดได้ — ค่าการเปิดรับแสง×อัตราขยายสูงสุดที่พื้นผิวสะท้อนแสง 100% จะอยู่ต่ำกว่าจุดคลิป และนำไปใช้เป็น **ขีดจำกัด**สำหรับการเปิดรับแสงอัตโนมัติ ขณะที่ขีดจำกัดนี้ทำงานอยู่ กล้องจะอยู่ในโหมด**ยึดตามแสงตกกระทบ**: กล้องจะทำงานในโหมดวงเปิด (open-loop) ที่ระดับการเปิดรับแสงตามการวัดแสงตกกระทบ โดยค่าเกนอยู่ที่ 0 dB — การเปิดรับแสงจะติดตามแสงที่วัดได้ ไม่ใช่เนื้อหาของฉาก เนื่องจาก**เพดาน**สามารถลดระยะเวลาการเปิดรับแสงได้เท่านั้น จึงไม่สามารถก่อให้เกิดการตัดสัญญาณ (clipping) ได้เอง**เพดาน** จะถูกปิดโดยอัตโนมัติ — และการเปิดรับแสงอัตโนมัติ (AE) ของฉากปกติจะกลับมาทำงาน — เมื่อใดก็ตามที่ค่าการอ่านจาก DAQ ขาดหายไป, ข้อมูลเก่า (&gt;30 วินาที), หรือมืด, หรือหาก ≥15 % ของเฟรมเกิดการตัดสัญญาณที่การเปิดรับแสงที่ถูกตรึง (หมายความว่าเซ็นเซอร์และกล้องกำลังรับรู้ระดับแสงที่แตกต่างกัน) ไม่มีสวิตช์ใน GUI; นี่เป็นพฤติกรรมมาตรฐานเมื่อใดก็ตามที่กล้องRGB

| การควบคุม | ตัวเลือก / ช่วง | หน้าที่ |

| **รูปแบบพิกเซล** | BayerRG8 / BayerRG10 / BayerRG12 / BayerRG16 / Mono8 | รูปแบบเซ็นเซอร์ที่สม่ำเสมอสำหรับทุกสมาชิก |
| **การรวมพิกเซล (Binning)** | 1x1 / 2x2 / 4x4 | การรวมพิกเซลด้วยฮาร์ดแวร์ — รักษาพื้นที่มุมมองเต็มไว้พร้อมทั้งเพิ่มอัตราส่วนสัญญาณต่อสัญญาณรบกวน (SNR) และอัตราเฟรม การเปลี่ยนแปลงนี้จะรีเซ็ตฟิลด์ ROI ให้สอดคล้องกับพื้นที่มุมมองเต็มใหม่ |
| **ความละเอียด** (ตั้งค่าล่วงหน้า) | Full / Half / Quarter | ขึ้นอยู่กับ binning; เติมช่อง ROI ด้วยภาพที่ตัดส่วนกลาง |
| **ROI crop (px)**| ช่องตัวเลข W / H / X / Y | การตัดภาพจากเซ็นเซอร์ ความกว้าง/ความสูงจะปรับให้ตรงกับจำนวนเท่าของ 16 (ขั้นต่ำ 64); ค่าออฟเซ็ตจะปรับให้ตรงกับจำนวนเท่าของ 4. คำแนะนำ &quot;max WxH&quot; แสดงค่าสูงสุด และ**Reset** จะกลับสู่มุมมองเต็ม | ระหว่างการแก้ไข กล่องตัวอย่างการตัดภาพสีส้มแบบเรียลไทม์จะถูกวาดขึ้นบนไทล์ของอาร์เรย์ (รวมถึงแผนผังเซ็นเซอร์เต็มเมื่อขยายการตัดภาพออกไปด้านนอก) |
| **อัตราการทริกเกอร์**| สลับระหว่างอัตโนมัติ / มือถือ + fps 0.5–10, ขั้นละ 0.5 |**อัตโนมัติ**(ค่าเริ่มต้น): ระบบหลังบ้านคำนวณอัตราการทริกเกอร์จากความละเอียดและแบนด์วิดท์ — ช่องป้อนข้อมูลถูกปิดใช้งานและแสดงค่าที่คำนวณได้**มือถือ**: กำหนดค่าของคุณเมื่อกด Apply |

หมายเหตุในหน้าต่าง: &quot;การเปลี่ยนแปลงรูปแบบ/ความละเอียดจะทำให้กล้องทั้งหมดรีสตาร์ทชั่วคราว อัตราการทริกเกอร์มีผลทันที&quot; ปุ่ม **Apply / Cancel** อยู่ด้านล่างของหน้าต่าง

### การจัดแนว (การลงทะเบียนร่วม) *(เฉพาะเมื่อรวมกล้อง)*

<!-- SCREENSHOT-NEEDED: array settings Alignment section after a successful calibration — green "RMS x.xx px" residual pill, "✓ All cameras aligned (N)" summary, the per-camera table with px error / match count / NCC columns, the Recalibrate alignment button and the "Auto-expose cameras for alignment" checkbox. -->



* **ค่าความคลาดเคลื่อน**: &quot;RMS x.xx px&quot; — สีเขียวหากต่ำกว่า 1 px, สีเหลืองอำพันหากต่ำกว่า 3 px, สีแดงในกรณีอื่นหรือหากกล้องใดล้มเหลว; &quot;ไม่มีโปรไฟล์&quot; ก่อนการแก้ปัญหาครั้งแรก.
* บรรทัดสรุป: &quot;✓ กล้องทั้งหมดจัดแนวแล้ว (N)&quot; / &quot;⚠ p/N กล้องจัดแนวแล้ว —  <serial (filter)="">ล้มเหลว&quot; / &quot;โหมดครอปกำลังทำงาน — ปรับเทียบใหม่เพื่อจัดแนว (ใช้เซ็นเซอร์เต็ม)&quot; / &quot;กำลังรอให้ค่าการเปิดรับแสงคงที่…&quot;.
* ตารางตามกล้อง: กล้อง (4 ตัวเลขสุดท้ายของหมายเลขซีเรียล + ฟิลเตอร์), ความผิดพลาดในการฉายกลับใน px พร้อมจำนวนการจับคู่ (&quot;ref&quot; สำหรับกล้องหลัก), และคะแนนความสัมพันธ์ไขว้ที่ปรับมาตรฐานแล้วของพื้นที่ทับซ้อนเทียบกับค่าขั้นต่ำ 0.35 pass floor.
* **ปุ่ม &quot;ปรับเทียบการจัดแนวใหม่&quot;** (แสดงข้อความ &quot;ปรับเทียบการจัดแนว&quot; ก่อนโปรไฟล์แรก) — ดำเนินการจัดแนวร่วมใหม่บนเฟรมที่ยังไม่ถูกประมวลผล
* **ช่องทำเครื่องหมาย &quot;ปรับการเปิดรับแสงอัตโนมัติของกล้องเพื่อการจัดตำแหน่ง&quot;** (ถูกทำเครื่องหมายไว้โดยค่าเริ่มต้น) — เพิ่มความสว่างชั่วคราวให้กับกล้องที่มืดหรือภาพแบน (ปรับการเปิดรับแสงก่อน แล้วปรับเกน) เพื่อให้มีพื้นผิวสำหรับจับคู่ จากนั้นคืนค่า AE กลับสู่ปกติ

การดูตัวอย่างแบบรวมจะจัดตำแหน่งอัตโนมัติเมื่อเปิด; ปรับเทียบใหม่หากโฟกัสหรือความลึกของฉากเปลี่ยนแปลง การจัดตำแหน่ง **ถูกออกแบบให้เป็นเฉพาะเซสชันเท่านั้น** — ไม่ถูกบันทึกไว้ในโปรไฟล์เลย เนื่องจากขึ้นอยู่กับการระยะห่างของฉากในขณะนั้น ภาพที่ถ่ายยังสามารถส่งออกได้โดยมีการลงทะเบียนพิกเซล (ดู [Aligned exports](capture.md#per-array-controls))

### Smart Vignette

* **เปิดการแก้ไข**— ใช้การประมาณค่า vignette ของแต่ละกล้องกับโซ่รังสี (ทั้งแบบสด**และ** การส่งออก)
* **ปรับเทียบจากมุมมองปัจจุบัน**— ชี้อาร์เรย์ไปยังเป้าหมายที่มีพื้นผิวเรียบสม่ำเสมอ (แผงเรียบ, ผนัง หรือท้องฟ้า) ก่อน; กล้องแต่ละตัวจะถูกปรับให้เรียบแยกกัน และรายงานสถานะจะแสดง &quot;n/N cams · −x.x %&quot; การปรับปรุงความเรียบ****Clear** ลบการประมาณค่า
* ปรับแต่งละเอียดสำหรับแต่ละกล้องด้วยแถบเลื่อน **Vignette** ของแต่ละกล้องใน [Live Preview](#live-preview)

### Live Preview *(รวมเท่านั้น)** **Index**: เปิดกล่องเลือก + ไอคอนเฟือง — เปิด [Index Calculator](#index-calculator-pane) ที่ใช้ร่วมกัน โดยแสดงแถบที่วาดจาก**ทุก** กล้องสมาชิก แถวแสดงตัวอย่างนิพจน์ด้านล่างจะแสดงนิพจน์ปัจจุบัน (&quot;ยังไม่ได้ตั้งนิพจน์ — เปิดเครื่องคำนวณเพื่อสร้างนิพจน์&quot;) ซึ่งอัปเดตทุกวินาที
* **ความละเอียดการเรนเดอร์**เมนูแบบเลื่อนลง (ตั้งค่าล่วงหน้าเหมือนต่อกล้องแต่ละตัว, ค่าเริ่มต้น 720p): ความสูงของสตรีมภาพสด**และ** ขนาดการส่งออกภาพรวมที่บันทึกไว้ หมายเหตุในหน้าต่าง: &quot;ขนาดภาพตัวอย่าง + ขนาดภาพรวมที่บันทึกไว้ ภาพต่อกล้องแต่ละตัวจะส่งออกด้วยความละเอียดเต็มเสมอ&quot;

### ชั้นแสดงผล *(รวมกันเท่านั้น)** **เปิด** ช่องทำเครื่องหมาย (ค่าเริ่มต้นปิด — กล้องหลักแสดงตรง; เปิด = ภาพรวมแบบชั้น)
* **Foreground**/**Background**เมนูแบบเลื่อนลง: กล้องสมาชิกแต่ละตัว (ตามชื่อ) หรือ**Index** เมื่อ Foreground เป็น Index พิกเซลนอกช่วง LUT Min/Max จะแสดงชั้น Background

### Split View *(รวมเท่านั้น)*

**&quot;แสดงกล้องสมาชิก&quot;**— ปุ่ม**แบ่ง / ซ่อนกล้องสมาชิก** ที่เพิ่มภาพสดของแต่ละกล้องสมาชิกเป็นไทล์กริดแยกต่างหากข้างภาพรวม ไทล์เหล่านี้อ่านเฟรมบัฟเฟอร์ที่มีอยู่ของอาร์เรย์ (ไม่ต้องเชื่อมต่อกล้องเพิ่มเติม) แสดงเฉพาะในมุมมองกริด; บันทึกตามอาร์เรย์พร้อมกับโครงการ

### ความสามารถ

แผงข้อมูลแบบอ่านอย่างเดียวที่อัปเดตทุก 5 วินาที:

* **ป้ายระดับ**: &quot;การจับภาพพร้อมกัน&quot; (สีเขียว) · &quot;การจับภาพพร้อมกัน (การส่งสัญญาณแบบ FTD-staggered)&quot; (สีเขียว) · &quot;การจับภาพแบบสลับกัน (ความคลาดเคลื่อน 100 ms)&quot; (สีเหลือง) · &quot;การกำหนดค่าใหญ่เกินไป&quot; (สีแดง).
* **สภาพเฟรม**: &quot;x.xx % ไม่สมบูรณ์&quot; — สีเขียวเมื่อต่ำกว่า 1 %, สีเหลืองเมื่อต่ำกว่า 5 %, สีแดงเมื่อ 5 % หรือมากกว่า
* **เส้นลิงก์**: &quot;NIC {mbps} Mbps - ความเร็วคงที่ {MB/s} MB/s&quot;.

นี่คืองบประมาณแบนด์วิธแบบเรียลไทม์ของอาร์เรย์ สำหรับโมเดล fps และเครือข่ายพื้นฐาน — รวมถึงสิ่งที่ควรปรับเปลี่ยนเมื่อระดับเปลี่ยนเป็นสีเหลืองหรือสีแดง — ดู [Multi-Camera Arrays](arrays.md) และ [CLI Reference](../reference/cli-reference.md).



<!-- SCREENSHOT-NEEDED: array settings Capabilities panel showing a green "Simultaneous capture" tier, the frame-health percentage, and the NIC/sustained-throughput line. -->## แผง Index Calculator

หน้าแถบด้านข้างที่สาม ซึ่งใช้ร่วมกันระหว่างเกียร์ Index ของกล้องแต่ละตัวและเกียร์ Index ของอาร์เรย์รวม (ทีละหนึ่ง — หัวข้อจะแสดงเป็น &quot;Index Calculator — <camera name="">&quot; หรือ &quot;Index Calculator — <array name="">&quot;). หน้านี้รับรายการแถบ (แถบธรรมชาติของฟิลเตอร์กล้อง หรือทุกแถบของสมาชิกในอาร์เรย์), นิพจน์ปัจจุบัน และการตั้งค่า LUT (เปิด/ปิด, ระดับ — ค่าเริ่มต้น 3, ขั้นต่ำ — ค่าเริ่มต้น 0.2, สูงสุด — ค่าเริ่มต้น 1) พร้อมด้วยฮิสโตแกรมดัชนีแบบเรียลไทม์ **Apply** จะยืนยันการแสดงผล; การเปลี่ยนแปลง LUT จะถูกนำไปใช้แบบเรียลไทม์กับภาพตัวอย่าง



<!-- SCREENSHOT-NEEDED: Index Calculator pane open for a combined array — band buttons for all member cameras, an NDVI-style expression in the editor, LUT controls, and the live index histogram. -->## การตั้งค่าตามกล้องแต่ละตัว vs การตั้งค่าที่จัดการโดยอาร์เรย์

คู่มืออ้างอิงอย่างรวดเร็วเกี่ยวกับตำแหน่งของข้อมูลเมื่อกล้องเป็นสมาชิกของอาร์เรย์:

| จัดการโดยอาร์เรย์ (อ่านอย่างเดียวในหน้าต่างกล้อง) | ยังคงตั้งค่าตามกล้องแต่ละตัวภายในอาร์เรย์ |
| --- | --- |
| รูปแบบพิกเซล, ความละเอียด, การรวมพิกเซล | การเปิดรับแสงอัตโนมัติ (การเปิดรับแสง, การเพิ่มสัญญาณ, ค่าเป้าหมาย, การปรับเรียบ, ROI) |
| โหมด/แหล่งทริกเกอร์, อัตราเฟรม | การลดสัญญาณรบกวน, ความคมชัด, วิเนตต์ |
| | ทิศทาง (สะท้อน/หมุน), ชั้นทับซ้อนบนหน้าจอ, เครื่องวัดแสงจุด |
| | ดัชนี (อาร์เรย์แสดงแยก), การผูกมัดเซ็นเซอร์แสง |

พฤติกรรมข้ามส่วนอื่นๆ:

* **การแสดงผลรวม vs แยก** ถูกเลือกเมื่อเชื่อมต่ออาร์เรย์: รวม = แผ่นภาพรวมที่จัดเรียงเป็นหนึ่งเดียว (ข้อมูลจากสมาชิกส่งผ่าน Split View เท่านั้น); แยก = แต่ละสมาชิกแสดงแผ่นภาพของตัวเองที่ซิงโครไนซ์กัน กล้องจะไม่แสดงทั้งข้อมูลแบบสแตนด์อโลนและแผ่นภาพอาร์เรย์พร้อมกัน
* **การเชื่อมต่ออัตโนมัติ**: การเปิดโครงการที่บันทึกไว้จะกู้คืนกล้องและอาร์เรย์ของโครงการนั้น และนำการตั้งค่าที่บันทึกไว้ทั้งหมดไปใช้กับระบบหลังบ้านก่อนที่สตรีมจะเริ่มทำงานอีกครั้ง
* **การจำกัดการบันทึก**: กล้องที่ถูกซ่อนหรือหยุดชั่วคราวจะไม่ถูกรวมในการบันทึกทั้งหมด (Capture All); อาร์เรย์จะถูกบล็อกอย่างสมบูรณ์ก็ต่อเมื่อสมาชิกทั้งหมดถูกซ่อน/หยุดชั่วคราว ดู [การตั้งค่าและโหมดการบันทึก](capture.md).

## วิธีที่การตั้งค่าถูกเก็บรักษา

สถานะของแท็บกล้องถูกบันทึก **ร่วมกับโครงการ** ไม่ใช่ในเบราว์เซอร์:

* ทุกการเปลี่ยนแปลงแบบรีแอคทีฟจะบันทึกภาพกล้องและอาร์เรย์ลงใน `cameras.json` ของโครงการ (มีช่วงหน่วง 500 ms). ซึ่งรวมถึงชื่อและสีของกล้อง, การตั้งค่าการเปิดรับแสง/การเพิ่มสัญญาณ/AE, รูปแบบพิกเซล/ความละเอียด/การรวมพิกเซล, อัตราการทริกเกอร์, การตั้งค่าการดูตัวอย่าง (ความละเอียดการเรนเดอร์, การลดสัญญาณรบกวน, ความคมชัด, วิเนตต์, โปรไฟล์สี, ความอิ่มตัว/ความคมชัด), ทิศทาง, การซ้อนทับ, การแบ่งช่องสัญญาณ, การกำหนดค่าดัชนี, การตั้งค่า AE แบบคาดการณ์, AE ROI, ชื่ออาร์เรย์, โหมดแสดงผล, การตั้งค่าการจับภาพอาร์เรย์ (รวมถึงตำแหน่งการครอป ROI), และบล็อกกริด (การซูมฟีด, โหมดมุมมอง, การล็อกกริด, ลำดับไทล์แบบมือ, กล้องที่ซ่อน, ไทล์ที่ปิด, กล้องที่ใช้งานอยู่).
* การตั้งค่าการผูกเซ็นเซอร์แสงจะถูกบันทึกไว้ในไฟล์ `sensors.json` ของโครงการ
* การเปิดโครงการใหม่จะเชื่อมต่ออุปกรณ์ใหม่และนำการตั้งค่าทั้งหมดมาใช้ใหม่
* **ไม่มีโครงการเปิด = เฉพาะเซสชัน**: หากไม่มีโครงการ ข้อมูลใดๆ จะไม่ถูกเก็บไว้เมื่อปิดChloros
* เฉพาะเซสชัน ไม่ว่าจะมีโครงการหรือไม่: สถานะพัก, ตัวอย่างการวัดจุด, ช่องทำเครื่องหมาย Calibration Target สำหรับกล้องแต่ละตัว (เปิดไว้เสมอ), และโปรไฟล์การจัดแนวอาร์เรย์ (ถูกคำนวณใหม่ทุกเซสชันตามการออกแบบ)
* มีข้อยกเว้นหนึ่งข้อ: **การตั้งค่าการจับภาพ** (Capture Settings) ที่เลือกไว้สำหรับการส่งออกและโหมดการจับภาพจะคงอยู่ตามแต่ละโครงการในพื้นที่จัดเก็บข้อมูลท้องถิ่นของแอป แทนที่จะอยู่ใน `cameras.json` — ดู [การตั้งค่าและโหมดการจับภาพ](capture.md).</array></camera></serial>
