# การตั้งค่ากล้อง

แท็บ **กล้อง** เป็นหน้าควบคุมแบบสดของChloros

สำหรับกล้อง LATTICE: พื้นที่แสดงภาพหลักที่แสดงกล้องทุกตัวที่เชื่อมต่ออยู่ในรูปแบบไทล์สด และแถบข้างที่สามารถเลื่อนระหว่างสามหน้า — **รายชื่อกล้อง**,**แผงการตั้งค่า**(การตั้งค่าต่อกล้องแต่ละตัว, การตั้งค่าแบบอาร์เรย์ หรือการตั้งค่าการจับภาพ — ครั้งละหนึ่งหน้า) และ**เครื่องคำนวณดัชนี**หน้านี้อธิบายทุกตัวควบคุมใน**รายชื่อกล้อง**,**หน้าต่างการตั้งค่าต่อกล้อง**และ**หน้าต่างการตั้งค่าแบบอาร์เรย์** โหมดการจับภาพ, การเลือกประเภทการส่งออก และกระบวนการ Capture All อยู่ในหน้าคู่ [Capture Settings &amp; Modes](capture.md).

แท็บ Cameras จะปรากฏในแถบด้านข้างเมื่อระบบหลังบ้านของChloros

พร้อมใช้งานแล้ว ทุกปุ่มควบคุมด้านล่างนี้สื่อสารกับระบบหลังบ้านท้องถิ่นผ่าน `127.0.0.1:5000`; การเปลี่ยนแปลงจะมีผลกับกล้องสดทันที เว้นแต่จะระบุไว้เป็นอย่างอื่น

### แถบด้านบน

| การควบคุม | หน้าที่ |
| --- | --- |
| **สลับโหมดแสดงผล**| สลับระหว่าง**มุมมองกริด**(ทุกไทล์เป็นเซลล์) และ**มุมมองรายการ**(แถวความกว้างเต็ม: แต่ละอาร์เรย์รวมกันเป็นแถวเดียวที่รวมกัน แต่ละสมาชิกของ**อาร์เรย์แยก** เป็นแถวของตัวเองพร้อมสตรีมและตาราง Calibration Target ของตัวเอง แล้วตามด้วยกล้องอิสระหนึ่งตัว — กล้องที่กำลังใช้งาน — ด้านล่าง). ข้อความช่วย: &quot;เปลี่ยนเป็นมุมมองตาราง&quot; / &quot;เปลี่ยนเป็นมุมมองรายการ&quot;. |
| **ล็อคตาราง**(รูปกุญแจ) | ตั้งค่าเริ่มต้น**ล็อค** — ช่องถูกตรึงไว้ที่เดิม ปลดล็อคเพื่อลากและจัดเรียงช่องใหม่ในช่องใดก็ได้ (ช่องว่างจะถูกรักษาไว้) กริดจะล็อคอัตโนมัติทุกครั้งที่มีกล้องใหม่เชื่อมต่อเข้ามา คำอธิบายเครื่องมือ: &quot;ปลดล็อคกริด (เปิดการลากไทล์)&quot; / &quot;ล็อคกริด (ตรึงไทล์ไว้ที่เดิม)&quot;. |
| **สไลเดอร์ซูมฟีด** | ขนาดไทล์ ตั้งแต่ 60 พิกเซล จนถึงความกว้างเต็มของคอนเทนเนอร์ เซลล์จะรักษาอัตราส่วน 4:3 เมื่อความกว้างของเซลล์ต่ำกว่า 200 px ชื่อและชั้นทับซ้อน fps จะถูกซ่อนเพื่อรักษาความสะอาดของไทล์ |

### ไทล์ฟีด

กล้องแต่ละตัวจะเรนเดอร์ไทล์สดแบบรวม; กล้องยังสามารถแสดงไทล์ **แบ่งตามช่องสัญญาณ** แบบสีเทาได้อีกสามไทล์ (ดู [Channel Splits](#display-overlays-drawn-over-the-live-feed)) และอาร์เรย์จะแสดงไทล์รวม ไทล์ที่กำลังใช้งานอยู่จะมีวงแหวนเลือกสีตามสีของกล้อง (หรืออาร์เรย์)

เมื่อนำเมาส์ไปวางเหนือไทล์ จะปรากฏปุ่มปิด **X**:

* การปิดไทล์ **รวม** ในขณะที่ไทล์แบ่งช่องสัญญาณยังคงอยู่ จะเพียงซ่อนไทล์รวมเท่านั้น
* การปิด **ไทล์สุดท้ายที่มองเห็นได้ของกล้องเดี่ยว** จะตัดการเชื่อมต่อกล้องนั้น
* **ไทล์แบ่งช่องสัญญาณของสมาชิกในอาร์เรย์รวม** ไม่เคยตัดการเชื่อมต่อกล้อง — มันเพียงซ่อนเท่านั้น

เมื่อปลดล็อกกริดแล้ว ให้ลากไทล์ใดก็ได้ไปยังสล็อตใดก็ได้; การจัดวางจะถูกบันทึกไว้กับโครงการ

## แถบด้านข้าง — รายการ

<!-- SCREENSHOT-NEEDED: sidebar camera list pane showing a standalone camera row and an ARRAY group with indented member rows, the DAQ on/off pill visible on the array row, plus the Connect Camera / Connect Array / Capture All buttons at the top. -->

กล้อง หน้าแรกของแถบด้านข้างแสดงรายการกล้องและอาร์เรย์ที่เชื่อมต่อทั้งหมด:

* **Connect Camera**(สีเขียว) /**Connect Array** (สีน้ำเงิน, แสดง &quot;Detecting...&quot; ขณะสแกน). ทั้งสองถูกปิดใช้งานเมื่อหน้าต่างเชื่อมต่อเปิดอยู่
* **Capture All** (สีแดง) — บันทึกภาพจากกล้องทุกตัวที่แสดงในรายการด้วยประเภทการส่งออกที่เลือกใน Capture Settings ต้องมีโครงการเปิดอยู่ มีเอกสารอธิบายอย่างละเอียดใน [การตั้งค่าและโหมดการจับภาพ](capture.md)
* **ไอคอนรูปเฟืองการตั้งค่าการจับภาพ**(ข้าง**จับภาพทั้งหมด**) — เปิด [หน้าต่างการตั้งค่าการจับภาพ](capture.md#the-capture-settings-pane) เปิดขึ้นได้เมื่อไม่มีโครงการหรือระหว่างการจับภาพ

### แถวกล้อง

แต่ละแถวกล้องแสดงขอบที่มีรหัสสี (สีที่กำหนดเองของกล้อง) ป้าย &quot;CAM&quot; — พร้อมตัวอักษร **M**(master) หรือตัวอักษร**S** (slave) สีเขียว สำหรับสมาชิกในอาร์เรย์ — และชื่อที่แสดง ชื่อเริ่มต้นคือ `LATTICE-MODEL (serial)`; สามารถเปลี่ยนชื่อได้จากหน้าต่างการตั้งค่าของแต่ละกล้อง ปุ่มในแถว:

| ปุ่ม | ผล |
| --- | --- |
| **Eye**| สลับการแสดงผล กล้องที่ซ่อนจะออกจากตารางและ**ไม่ถูกรวมใน Capture All** |
| **Gear** | เปิดหน้าตั้งค่าสำหรับกล้องแต่ละตัว (ส่วนถัดไป) |
| **Pause / Play**| หยุดภาพสด**เฉพาะด้านหน้าจอ** — การจับภาพจากระบบหลังยังคงทำงานต่อไป กล้องที่หยุดชั่วคราวไม่สามารถจับภาพได้ |
| **X** | ตัดการเชื่อมต่อ UI จะอัปเดตทันที (ตามการคาดการณ์); การตัดการเชื่อมต่อของระบบหลังอาจใช้เวลา 10–30 วินาทีเพื่อเสร็จสิ้น |

### แถวของอาร์เรย์

แถวของอาร์เรย์จะแสดงป้าย &quot;ARRAY&quot; ในสีของอาร์เรย์ ชื่ออาร์เรย์ (สามารถเปลี่ยนชื่อได้ในตั้งค่าอาร์เรย์) และปุ่ม **DAQ · เปิด/ปิด**—**เปิด** เมื่อเซ็นเซอร์แสงระดับอาร์เรย์ถูกตั้งค่า *หรือ* สมาชิกใดก็ตามมีเซ็นเซอร์เฉพาะกล้อง; คำอธิบายในเครื่องมือแสดงอย่างชัดเจนว่าเซ็นเซอร์ใดส่งข้อมูลไปยังส่วนใด กล้องของสมาชิกจะแสดงอยู่ด้านล่างด้วยช่องว่างและแถวของตัวเอง ปุ่มในแถวของอาร์เรย์: **ตา**(ซ่อน/แสดงสมาชิกทั้งหมดพร้อมกัน),**เกียร์**(หน้าต่างการตั้งค่าอาร์เรย์),**X**(ตัดการเชื่อมต่ออาร์เรย์ทั้งหมด)

สถานะของเซ็นเซอร์แสง (DLS) ที่ใช้ในแถวของอาร์เรย์และหน้าต่างการตั้งค่าอาร์เรย์มีสี่สถานะ:**ปิด**,**รอ**(ยังไม่มีสเปกตรัม),**ทำงาน**(สเปกตรัมมาถึงภายใน 3 วินาทีที่ผ่านมา), และ**เก่า** — ไม่มีสเปกตรัมใหม่ใน 3 วินาที แต่ค่าอ่านล่าสุด *ยังคงถูกใช้* (ค่าอ่านจาก DAQ ไม่หมดอายุบนเส้นทางจับภาพ)

จนกว่าคุณจะจัดเรียงใหม่ รายการจะแสดงอาร์เรย์ก่อน แล้วตามด้วยกล้องเดี่ยว โดยกล้อง (และสมาชิกของแต่ละอาร์เรย์) จะอยู่ใน **ลำดับกล้อง**: M3C (Bayer) ก่อน M3M (mono); ในกลุ่ม M3C, FRGB, FRGN, FOCN, แล้ว FNGB; M3M ตามความยาวคลื่นของฟิลเตอร์ โดยเริ่มจากค่าต่ำสุดก่อน การจัดวางเริ่มต้นของกริดจะตามลำดับเดียวกัน คุณสามารถลากกล้องเดี่ยวและกลุ่มอาร์เรย์ทั้งชุดผ่านกันในแถบด้านข้างเพื่อจัดลำดับรายการใหม่; ส่วนสมาชิกของอาร์เรย์ไม่สามารถลากแยกกันได้

**ส่วนหัว**:**ตัวอย่างสี**ของกล้อง (คลิกเพื่อเปิดเครื่องมือเลือกสีในตัว — ใช้เพื่อกำหนดสีขอบแถบด้านข้างและสีวงเลือกไทล์),**ชื่อ**พร้อมปุ่ม**เปลี่ยนชื่อ**(รูปดินสอ) (การบันทึกชื่อว่างจะกลับสู่ค่าเริ่มต้น `MODEL (serial)`), และ**×** เพื่อปิด

### ฮิสโตแกรมแบบเรียลไทม์

ส่วนบนของหน้าต่างมีฮิสโตแกรมลูมาแบบเรียลไทม์ที่คำนวณจากภาพตัวอย่างJPEG

ที่ ~8 Hz ค่าเฉลี่ยถูกถ่วงน้ำหนักแบบ Bayer — (R+2G+B)/4 — เพื่อให้ตรงกับระบบวัดแสงอัตโนมัติ (AE) ของกล้องเอง

* **เส้นประสีOrange**= เป้าหมาย AE **ลากเส้นนี้ตามแนวนอนเพื่อปรับเป้าหมายใหม่** — เมื่อปล่อยมือจะส่งคำสั่งหนึ่งครั้ง และการลากจะเปลี่ยนโหมดเป้าหมาย AE เป็นโหมดมือ
* **เส้นทึบสีGreen** = ค่าเฉลี่ยความสว่างจริง (ค่าที่ระบบ AE กำลังส่งออกมาในขณะนี้)
* **ปุ่ม RGB** (มุมบนขวา): สลับการแสดงฮิสโตแกรมซ้อนทับตามแต่ละแบนด์ โดยใช้สีตามฟิลเตอร์ของกล้อง (เช่น บน FRGN: สีเทาสำหรับ NIR

, สีเขียว, สีแดง) สำหรับกล้องโมโน (M3M) ปุ่มนี้จะแสดงข้อความ &quot;MONO&quot; และถูกปิดใช้งาน — กล้องโมโนจะแสดงฮิสโตแกรมลูมาแบบแบนด์เดียวเสมอ
* ป้ายกำกับแกน X ขึ้นอยู่กับความลึกของบิตเซ็นเซอร์ของรูปแบบพิกเซลปัจจุบัน: 0..255, 0..1023, 0..4095 หรือ 0..65535

#### ตารางเป้าหมายการปรับเทียบ

ตารางนี้เป็น **การแสดงผลเพื่อการตรวจสอบความถูกต้องเท่านั้น** (&quot;เพื่อการตรวจสอบความถูกต้องเท่านั้น — ไม่แก้ไขการปรับเทียบ&quot;). ส่วนหัวของตารางระบุหมายเลขซีเรียลของกล้อง, ตัวกรอง, หมายเลขเป้าหมาย และขนาดมาร์กเกอร์ในพิกเซล และมีหนึ่งแถวต่อหนึ่งแผง:

* **แผง**, ตามด้วยหนึ่งคอลัมน์ต่อหนึ่งแถบ พร้อมค่าของแผง — กล้อง Bayer แสดงสามแถบตามชื่อและความยาวคลื่น (เช่น FRGN: Red

660 nm / Green

550 nm / NIR

850 nm); **กล้องโมโน (M3M) แสดงแถบเดียว** (เช่น `F750`) และไม่มีคอลัมน์ NDVI


* **Sat** — สัดส่วนของพิกเซลในแผงที่อิ่มตัว (สีเหลืองอำพันตั้งแต่ 1 % สีแดงตั้งแต่ 5 %).
* **NDVI

Meas**,**NDVI

Theo** (NDVI

ค่าสะท้อนแสงอ้างอิงของแผง) และ **Δ**— เฉพาะกล้องมัลติสเปกตรัมแบบ Bayer เท่านั้น เครื่องหมายเล็กหลัง &quot;NDVI

Meas&quot; ระบุว่าค่า NDVI

เท่านั้นที่สามารถเปรียบเทียบกับ NDVI

Theo ได้: สำหรับ L และ DN คอลัมน์ Δ จะถูกทำให้เป็นสีเทา และมีหมายเหตุระบุว่า (&quot;ไม่มีค่าอ่านจากเซ็นเซอร์แสง: NDVI

มาจาก radiance ดังนั้น Δ จึงไม่ใช่การตรวจสอบการปรับเทียบ&quot; / &quot;NDVI

มาจากค่าดิบของกล้อง ดังนั้น Δ จึงไม่ใช่การตรวจสอบการปรับเทียบ&quot;). สำหรับ ρ, Δ จะแสดงเป็นสีเขียวเมื่อต่ำกว่า 0.02, สีเหลืองอำพันเมื่อต่ำกว่า 0.05, และสีแดงในกรณีอื่น ๆ

**วิธีการทำงานของระบบการเปิดรับแสงอัตโนมัติ (1.3.0)**

* การตั้งค่าการเปิดรับแสงแบบแมนนวลจะคงค่าเกนไว้ที่โหมดอัตโนมัติจนกว่าคุณจะเปลี่ยนค่าเกน
* จุดสว่างเล็กๆ ไม่ทำให้ฉากมืดลง: แสงสะท้อนที่มากถึง 1 % ของเฟรมจะถูกเพิกเฉย และในแผงของเป้าหมายการปรับเทียบที่ทราบค่าแล้ว จะเพิกเฉยได้ถึง 0.5 % ของแผง
* ค่าเพดานการรับแสง DAQ ใช้ได้เฉพาะเมื่อเป้าหมายการปรับเทียบอยู่ในมุมมองเท่านั้น; เมื่อไม่เห็นแผงใดๆ กล้องจะรับแสงตามฉาก
* การเปิดรับแสงจะคงที่เมื่อแสงคงที่ และปรับตัวให้คงที่ภายในไม่กี่วินาทีหลังการเปลี่ยนแปลงครั้งใหญ่ การตัดส่วนเกิน (clip) จะไม่จำกัดการเปิดรับแสงอย่างถาวรอีกต่อไป และการเปลี่ยนแปลงพื้นที่สนใจ (ROI) จะปรับการเปิดรับแสงให้เหมาะสมอีกครั้ง
* เป้าหมายความสว่างจะไม่เกินขีดจำกัดของกล้องดังนั้น แสงที่กลับมาจะไม่ทำให้เฟรมเกิดแฟลร์
* กล้องที่ระบบปรับแสงอัตโนมัติหยุดตอบสนองในแสงแดดจ้า จะถูกรักษาไว้ที่ระดับแสงที่กล้องอยู่ ซึ่งอ่านจากเซ็นเซอร์แสง หรือหากไม่มีการเชื่อมต่อเซ็นเซอร์แสง จะอ่านจากเฟรมของกล้องเอง และปล่อยเมื่อแสงเปลี่ยนแปลง เซ็นเซอร์แสงที่มืดหรือถูกปิดบังจะไม่รบกวนกระบวนการนี้
{% endhint %}

### Spot Meter

* **คลิกเพื่อเก็บตัวอย่าง**ช่องทำเครื่องหมาย: คลิกที่ภาพสดเพื่อเก็บตัวอย่างพิกเซลเดียว (มีเส้นกากบาทแสดงตำแหน่ง) หรือคลิกและลากเพื่อเลือกพื้นที่เพื่อคำนวณค่าเฉลี่ยของพิกเซล**ล้าง**ลบตัวอย่างและเส้นกากบาท ไม่สามารถใช้ร่วมกับโหมด**Aim** ของ AE-ROI ได้
* **Show**เมนูแบบเลื่อนลง:**Raw (bit depth)**— ค่าตัวเลขดิจิทัลต้นฉบับตามความลึกของบิตของเซ็นเซอร์ (เช่น 12-bit → 0..4095) — หรือ**Display (8-bit)**(ค่าเริ่มต้น) เมื่อดัชนีแบบเรียลไทม์ถูกเปิดใช้งาน ตัวเลือก**Display** จะแสดงค่าดัชนีที่คำนวณได้ (เช่น NDVI

) แทน
* แผงแสดงผลแสดงพิกัดพิกเซล ขนาดเฟรม รูปแบบพิกเซล ความลึกของบิต และตารางช่อง (Chan / Value / %) พร้อมชื่อแถบและช่วงความยาวคลื่น; คู่สีเขียวแบบ Bayer ถูกรวมค่าเฉลี่ย; ตัวอย่างพื้นที่แสดง &quot;N px avg&quot;

### การปรับแสงอัตโนมัติแบบคาดการณ์ (ขับเคลื่อนด้วย DLS)

**ขีดจำกัดการเปิดรับแสงที่ขับเคลื่อนโดย DAQ และ AE ที่ยึดตามแสงตกกระทบ.** ไม่ว่ากล่องเลือกข้างบนจะถูกเลือกหรือไม่ เมื่อเซ็นเซอร์แสง DAQ ถูกกำหนดให้กับกล้องRGB

, Chloros

จะคำนวณ — จากค่าความเข้มแสงลงสู่พื้นผิวที่วัดได้ — ค่าการเปิดรับแสง×อัตราขยายสูงสุด ที่พื้นผิวที่มีค่าการสะท้อนแสง 100% จะอยู่ต่ำกว่าจุดตัด (clipping) และนำไปใช้เป็น **ขีดจำกัด**สำหรับการปรับแสงอัตโนมัติ ตั้งแต่เวอร์ชัน 1.3.0 ขีดจำกัดนี้จะถูกใช้เฉพาะเมื่อมีเป้าหมายการปรับเทียบอยู่ในมุมมองของกล้องนั้น (ปรากฏในเฟรมของกล้องภายใน 10 วินาทีที่ผ่านมา); เมื่อไม่มีเป้าหมายในมุมมอง ระบบการปรับแสงอัตโนมัติปกติของกล้อง — พร้อมระบบป้องกันส่วนสว่างเกิน — จะทำงานแทน ดังนั้นส่วนที่เหลือของฉากจะไม่ถูกทำให้มืดกว่าที่จำเป็น เมื่อเพดานกำลังทำงาน กล้องจะ**ถูกตรึงตามแสงตกกระทบ**: กล้องทำงานในโหมดวงเปิด (open-loop) ที่การเปิดรับแสงตามการวัดแสงที่ตกกระทบ (incident-metered exposure) ด้วยค่าเกน (gain) ที่ 0 dB — การเปิดรับแสงจะตามค่าแสงที่วัดได้ ไม่ใช่ตามเนื้อหาของฉาก เนื่องจากขีดจำกัดการเปิดรับแสงสูงสุด (ceiling) สามารถลดระยะเวลาการเปิดรับแสงได้เท่านั้น จึงไม่สามารถก่อให้เกิดการตัดแสง (clipping) ได้เอง ตั้งแต่เวอร์ชัน 1.3.0 ค่าเพดานถูกคำนวณโดยใช้ค่าคงที่การเปิดรับแสงของกล้องเองจากชุดการปรับเทียบ (ค่าเฉลี่ยของกลุ่มกล้องจะใช้ก็ต่อเมื่อชุดการปรับเทียบไม่มีค่าดังกล่าว) ค่าเพดานจะปิดการทำงานอัตโนมัติ — และระบบ AE ของฉากปกติจะกลับมาทำงาน — เมื่อไม่มีเป้าหมายการปรับเทียบอยู่ในมุมมอง, การอ่านค่า DAQ ขาดหายไป, ล้าสมัย (&gt;30 วินาที), หรือมืด, หรือหาก ≥15 % ของเฟรมเกิดการคลิปที่การเปิดรับแสงที่ถูกตรึง (หมายความว่าเซ็นเซอร์และกล้องกำลังรับรู้ระดับแสงที่แตกต่างกัน) ไม่มีสวิตช์ใน GUI; นี่เป็นพฤติกรรมมาตรฐานเมื่อกล้องRGB

| **อัตราการทริกเกอร์**| สลับระหว่าง Auto / Manual + fps 0.5–10, ขั้น 0.5 |**Auto**(ค่าเริ่มต้น): ระบบหลังบ้านจะคำนวณอัตราการทริกเกอร์จากความละเอียดและแบนด์วิดท์ — ตัวเลือกการป้อนข้อมูลถูกปิดใช้งานและแสดงค่าที่คำนวณได้**Manual**: กำหนดค่าของคุณเมื่อกด Apply อัตราที่ถูกกำหนดไว้ซึ่งขนาดเฟรมใหม่ไม่สามารถรองรับได้ จะถูกปรับเป็นอัตราสูงสุดที่ขนาดนั้นอนุญาต และจะกลับสู่ค่าเดิมเมื่อขนาดเฟรมใหม่สามารถรองรับได้อีกครั้ง |

หมายเหตุในหน้าต่าง: &quot;การเปลี่ยนแปลงรูปแบบ/ความละเอียดจะทำให้กล้องทั้งหมดรีสตาร์ทชั่วคราว อัตราการทริกเกอร์มีผลทันที&quot; ปุ่ม **Apply / Cancel** อยู่ด้านล่างของหน้าต่าง

#### ตัวแก้ไข ROI

ใหม่ในเวอร์ชัน 1.3.0 แถวการตัด ROI และแผนที่ด้านล่างทำงานร่วมกัน:

* **ROI on / ROI off**— เปิดหรือปิดการตัดเซ็นเซอร์**ทันที**(กล้องจะรีสตาร์ทชั่วคราว; แผงแสดงผลจะแสดง &quot;กำลังปรับใช้การตั้งค่า…&quot;)**ปิด**จะอ่านข้อมูลจากเซ็นเซอร์ทั้งหมดและ**จดจำการตัดภาพของคุณ**— ช่องข้อมูลจะยังคงแสดงผลนั้น;**เปิด** จะนำไปใช้ใหม่ การเปิด ROI โดยไม่มีการตั้งค่าการตัดภาพจะนำไปใช้การตัดภาพขนาดครึ่งหนึ่งที่อยู่ตรงกลาง (&quot;ไม่มีการตั้งค่าการตัดภาพ จึงนำไปใช้การตัดภาพขนาดครึ่งหนึ่งที่อยู่ตรงกลาง ปรับด้วยช่องข้อมูล&quot; )
* **Select**— วาดกรอบตัดบนแผนที่: ลากผ่านพื้นที่ที่ต้องการ หรือคลิกสองมุมที่ตรงข้ามกัน (กด Esc เพื่อยกเลิก) สี่เหลี่ยมผืนผ้าจะถูกวางลงในช่อง W/H/X/Y, และถูกจัดให้ตรงกับขั้นตอนข้างต้น; ไม่มีการปรับใช้ใดๆ จนกว่าคุณจะกด**Apply** ดังนั้นคุณจึงสามารถปรับแต่งให้ละเอียดด้วยลูกศรในช่องข้อมูลก่อนได้ หนึ่งรูปสี่เหลี่ยมต่อการกด Select หนึ่งครั้ง
* **แผนที่**แสดงการครอปบนเซ็นเซอร์ทั้งหมด ดังนั้นคุณจึงสามารถขยายกลับออกไปได้: &quot;เซ็นเซอร์เต็ม, แบบสด&quot; ในขณะที่กล้องอ่านเซ็นเซอร์เต็ม, หรือ &quot;ภาพถ่ายเต็มเฟรมจาก {เวลา}&quot; ขณะที่กล้องกำลังอ่านเฉพาะส่วนที่ถูกตัดกรอบ หากอาร์เรย์นี้เคยส่งข้อมูลเฉพาะส่วนที่ถูกตัดกรอบเท่านั้น แผนที่จะแสดงข้อความ &quot;ยังไม่มีมุมมองเต็มเฟรม: อาร์เรย์นี้ส่งข้อมูลเฉพาะส่วนที่ถูกตัดกรอบเท่านั้น&quot;&quot; พร้อมปุ่ม**แสดงภาพเต็มเฟรม** ซึ่งจะปิด ROI ลง ป้าย `W×H @ X,Y` ของส่วนที่ถูกครอปจะอยู่ด้านนอกกรอบ (ด้านบน หรือด้านล่างเมื่อกรอบสัมผัสกับขอบบน) ทั้งบนแผนที่และบนไทล์สด
* **Apply**จะบันทึกค่าของฟิลด์: การครอปจะเปิด ROI; โหมดเฟรมเต็ม (หลัง**Reset**) จะปิด ROI โดยยังคงจดจำการครอปครั้งก่อนไว้; ROI ที่ปิดอยู่และฟิลด์ยังคงแสดงการครอปที่จดจำไว้จะยังคงปิดอยู่เมื่อคุณใช้การเปลี่ยนแปลงอื่น (รูปแบบ, binning, อัตรา)
* **บนอาร์เรย์ที่จัดแนวแล้ว หน้าต่างการครอปของแต่ละสมาชิกจะถูกจัดวางตามการจัดแนว** ดังนั้นกล้องทุกตัวจะจับภาพส่วนเดียวกันของฉาก อาร์เรย์ที่ถูกครอปก่อนการจัดแนวจะถูกจัดแนวบนเซ็นเซอร์เต็มก่อน (การครอปจะถูกยกเลิก การจัดแนวถูกแก้ไข และการครอปถูกคืนค่าด้วยหน้าต่างเฉพาะกล้องแต่ละตัว)
* หลังจากการเปลี่ยนแปลงการครอป การปรับแสงอัตโนมัติจะปรับตัวใหม่ให้สอดคล้องกับกรอบภาพใหม่ แม้ในระหว่างการครอป การปรับแสงของสมาชิกแต่ละตัวยังสามารถทำงานได้จนถึงช่วงเวลาทริกเกอร์
* สถานะเปิด/ปิดของ ROI และการครอปที่บันทึกไว้จะถูกเก็บไว้กับโครงการ

### การจัดแนว (การลงทะเบียนร่วม)

แสดงสำหรับ **ทั้งอาร์เรย์ที่รวมกันและแยกกัน** (เวอร์ชัน 1.2.0 แสดงเฉพาะสำหรับอาร์เรย์ที่รวมกัน); หัวข้อกลุ่มระบุว่า &quot;Alignment&quot;



<!-- SCREENSHOT-NEEDED: array settings Alignment section after a successful calibration — green "RMS x.xx px" residual pill, "✓ All cameras aligned (N)" summary, the per-camera table with px error / match count / NCC columns, the Recalibrate alignment button and the "Auto-expose cameras for alignment" checkbox. -->

* **ค่าความคลาดเคลื่อน**: &quot;RMS x.xx px&quot; — สีเขียวเมื่อต่ำกว่า 1 px, สีเหลืองอำพันเมื่อต่ำกว่า 3 px, สีแดงในกรณีอื่นหรือหากมีกล้องใดล้มเหลว; &quot;ไม่มีโปรไฟล์&quot; ก่อนการแก้ปัญหาครั้งแรก
* บรรทัดสรุป: &quot;✓ กล้องทั้งหมดจัดแนวแล้ว (N)&quot; / &quot;⚠ p/N กล้องจัดแนวแล้ว — <serial (filter)="">ล้มเหลว&quot; / &quot;การครอปกำลังทำงาน — ปรับเทียบใหม่เพื่อจัดแนว (ใช้เซ็นเซอร์เต็ม)&quot; / &quot;รอให้การรับแสงคงที่…&quot; / &quot;กำลังปรับตั้งค่า…&quot; (กล้องกำลังรีสตาร์ท) / &quot;อาร์เรย์หยุดส่งเฟรม — เชื่อมต่ออาร์เรย์ใหม่&quot;.
* ตารางต่อกล้อง: กล้อง (4 ตัวเลขสุดท้ายของหมายเลขซีเรียล + ฟิลเตอร์), ความผิดพลาดในการฉายกลับใน px พร้อมจำนวนการจับคู่ (&quot;ref&quot; สำหรับกล้องหลัก), และคะแนนความสัมพันธ์ไขว้ที่ปรับมาตรฐานแล้วจากการทับซ้อน เทียบกับเกณฑ์ผ่านขั้นต่ำ 0.35
* **ปรับเทียบการจัดแนวใหม่** ปุ่ม (แสดงข้อความ &quot;Calibrate alignment&quot; ก่อนโปรไฟล์แรก) — ดำเนินการลงทะเบียนร่วมใหม่บนเฟรมที่ยังไม่ถูกประมวลผล
* **ช่องทำเครื่องหมาย &quot;ปรับการเปิดรับแสงอัตโนมัติของกล้องเพื่อการจัดแนว&quot;** (ถูกทำเครื่องหมายไว้โดยค่าเริ่มต้น) — เพิ่มความสว่างชั่วคราวให้กับกล้องที่มืดหรือภาพแบน (ปรับการเปิดรับแสงก่อน แล้วปรับเกน) เพื่อให้มีพื้นผิวที่ตรงกัน จากนั้นคืนค่า AE กลับสู่ค่าเดิม

Chloros จะจัดแนวทุกอาร์เรย์โดยอัตโนมัติหลังการเชื่อมต่อ ในทั้งสองโหมดแสดงผล เมื่อการปรับความเปิดรับแสงอัตโนมัติของสมาชิกคงที่แล้ว (ระบบจะพยายามต่อไปสูงสุด 5 นาที); การแสดงตัวอย่างรวมจะจัดแนวเมื่อเปิดขึ้นด้วย อาร์เรย์ที่แยกต่างหากไม่มีไทล์รวม ดังนั้นส่วนนี้จะตรวจสอบสถานะการจัดแนวและเรียกใช้ Recalibrate ด้วยตัวเอง ให้เรียกใช้ Recalibrate หากโฟกัสหรือความลึกของฉากเปลี่ยนแปลง การจัดแนว **ถูกออกแบบให้เป็นเฉพาะเซสชัน** — ไม่เคยถูกบันทึกไว้ในโปรไฟล์ เนื่องจากขึ้นอยู่กับระยะห่างของฉากในขณะนั้น ภาพที่ถ่ายยังสามารถส่งออกได้โดยมีการลงทะเบียนพิกเซล (ดู [การส่งออกที่จัดแนวแล้ว](capture.md#per-array-controls)).

### Smart Vignette

* **กล่องเลือก &quot;เปิดการแก้ไข&quot;**— ใช้การประมาณค่า vignette ของแต่ละกล้องกับห่วงโซ่รังสี (ทั้งแบบสด**และ** การส่งออก)
* ****ปรับเทียบจากมุมมองปัจจุบัน**— ชี้อาร์เรย์ไปยังเป้าหมายที่มีพื้นผิวเรียบสม่ำเสมอ (แผงแบน ผนัง หรือท้องฟ้า) ก่อน; กล้องแต่ละตัวจะถูกปรับให้เรียบเป็นรายตัว และสถานะจะรายงาน &quot;n/N cams · −x.x %&quot; การปรับปรุงความเรียบ**ล้าง** จะลบการประมาณค่า
* สถานะ: &quot;Calibrated&quot;, &quot;Not calibrated&quot;, หรือ &quot;Partially calibrated — re-run&quot; เมื่อการประมาณค่าของสมาชิกบางตัวเท่านั้นที่ยังคงใช้ได้กับกรอบภาพปัจจุบัน (เช่น หลังจากที่การ Recalibrate ได้ย้ายหน้าต่างครอปของสมาชิกตัวหนึ่ง) — ดำเนินการ Calibrate อีกครั้ง
* ปรับแต่งละเอียดสำหรับแต่ละกล้องโดยใช้แถบเลื่อน **Vignette** สำหรับแต่ละกล้องใน [Live Preview](#live-preview).

### Live Preview

* **Histogram**ช่องทำเครื่องหมาย + ตัวเลื่อนความกว้าง (0.10–0.90 ของเฟรม) — แถบฮิสโตแกรมบนฟีดที่แสดงพร้อมกันบนไทล์ของสมาชิกทุกคน (รวมถึงไทล์ช่องแยก) และ [Histogram overlay](#display-overlays-drawn-over-the-live-feed) ที่ตั้งค่าไว้สำหรับทั้งอาร์เรย์ จะแสดงว่าเปิดอยู่เมื่อสมาชิกทุกคนมีอยู่แล้ว ในอาร์เรย์**แยกต่างหาก** แถวนี้จะเป็นแถวเดียวในกลุ่ม
* *เฉพาะเมื่อรวม:* **ดัชนี**: ช่องทำเครื่องหมายเปิดใช้งาน + ไอคอนเฟือง — เปิด [เครื่องคำนวณดัชนี](#index-calculator-pane) ที่ใช้ร่วมกัน โดยแสดงแถบที่คำนวณจาก**ทุก** กล้องของสมาชิก แถวตัวอย่างนิพจน์ด้านล่างจะแสดงนิพจน์ปัจจุบัน (&quot;ยังไม่ได้ตั้งนิพจน์ — เปิดเครื่องคำนวณเพื่อสร้างนิพจน์&quot;) ซึ่งอัปเดตทุกวินาที
* *เฉพาะโหมดรวม:* เมนูแบบเลื่อนลง **ความละเอียดการเรนเดอร์**(ตั้งค่าล่วงหน้าเหมือนโหมดต่อกล้องแต่ละตัว, ค่าเริ่มต้น 720p): ความสูงของสตรีมภาพสด**และ** ขนาดการส่งออกภาพรวมที่บันทึกไว้ หมายเหตุในหน้าต่าง: &quot;ขนาดภาพตัวอย่าง + ขนาดภาพรวมที่บันทึกไว้ ภาพต่อกล้องแต่ละตัวจะส่งออกด้วยความละเอียดเต็มเสมอ&quot;

### ชั้นแสดง *(เฉพาะแบบรวม)** **เปิด** ช่องทำเครื่องหมาย (ค่าเริ่มต้นปิด — กล้องหลักแสดงแบบตรง; เปิด = ภาพรวมแบบชั้น)
* ****Foreground**/**Background**: เลือกกล้องสมาชิกแต่ละตัว (ตามชื่อ) หรือ**Index** เมื่อ Foreground เป็น Index พิกเซลที่อยู่นอกช่วง LUT Min/Max จะแสดงชั้น Background

### Split View *(เฉพาะแบบรวมเท่านั้น)*

**&quot;Show member cameras&quot;**— ปุ่ม**แบ่ง / ซ่อนกล้องสมาชิก** ที่เพิ่มภาพสดของกล้องสมาชิกแต่ละตัวเป็นช่องกริดแยกกันข้างๆ ภาพรวม ช่องกริดเหล่านี้อ่านจากบัฟเฟอร์เฟรมที่มีอยู่ของอาร์เรย์ (ไม่ต้องเชื่อมต่อกล้องเพิ่มเติม) แสดงในโหมดกริดเท่านั้น; บันทึกตามอาร์เรย์พร้อมกับโครงการ

### ความสามารถ

แผงข้อมูลแบบอ่านอย่างเดียวที่อัปเดตทุก 5 วินาที:

* **ป้ายระดับ**: &quot;การบันทึกพร้อมกัน&quot; (สีเขียว) · &quot;การบันทึกพร้อมกัน (FTD-staggered emit)&quot; (สีเขียว) · &quot;การบันทึกแบบสลับกัน (100 ms drift)&quot; (สีเหลือง) · &quot;การกำหนดค่าใหญ่เกินไป&quot; (สีแดง).
* **สภาพเฟรม**: &quot;x.xx % ไม่สมบูรณ์&quot; — สีเขียวเมื่อต่ำกว่า 1 %, สีเหลืองอำพันเมื่อต่ำกว่า 5 %, สีแดงเมื่อ 5 % หรือมากกว่า.
* ****ความเร็วการเชื่อมต่อ**: &quot;NIC {mbps} Mbps - ความเร็วคงที่ {MB/s} MB/s&quot;.

## หน้าต่าง Index Calculator

หน้าแถบด้านข้างที่สาม ซึ่งใช้ร่วมกันระหว่างเกียร์ Index ของกล้องแต่ละตัวและเกียร์ Index ของอาร์เรย์รวม (แสดงทีละหนึ่ง — หัวข้อจะแสดงว่า &quot;Index Calculator — <camera name="">&quot; หรือ &quot;Index Calculator — <array name="">&quot;) หน้าต่างนี้รับรายการแบนด์ (ทั้งแบนด์ธรรมชาติของตัวกรองกล้อง-ธรรมชาติของกล้อง หรือทุกแถบของสมาชิกในอาร์เรย์), สมการปัจจุบัน และการตั้งค่า LUT (เปิด/ปิด, ระดับ — ค่าเริ่มต้น 7-stop, ขั้นต่ำ — ค่าเริ่มต้น 0.2, สูงสุด — ค่าเริ่มต้น 1), พร้อมด้วยฮิสโตแกรมดัชนีแบบเรียลไทม์ **Apply** จะบันทึกสมการ; การเปลี่ยนแปลง LUT จะถูกนำไปใช้กับภาพตัวอย่างแบบเรียลไทม์



<!-- SCREENSHOT-NEEDED: Index Calculator pane open for a combined array — band buttons for all member cameras, an NDVI-style expression in the editor, LUT controls, and the live index histogram. -->## การตั้งค่าตามกล้องแต่ละตัว vs การตั้งค่าที่จัดการโดยอาร์เรย์

คู่มืออ้างอิงด่วนเกี่ยวกับตำแหน่งที่ตั้งค่าต่างๆ เมื่อกล้องเป็นสมาชิกของอาร์เรย์:

| จัดการโดยอาร์เรย์ (อ่านได้เท่านั้นในหน้าต่างกล้อง) | ยังคงตั้งค่าตามกล้องแต่ละตัวภายในอาร์เรย์ |
| --- | --- |
| รูปแบบพิกเซล, ความละเอียด, การรวมพิกเซล | การเปิดรับแสงอัตโนมัติ (การเปิดรับแสง, การเพิ่มสัญญาณ, ค่าเป้าหมาย, การปรับเรียบ, ROI) |
| โหมด/แหล่งทริกเกอร์, อัตราเฟรม | การลดสัญญาณรบกวน, ความคมชัด, vignette |
| | ทิศทาง (สะท้อน/หมุน), ชั้นทับซ้อนบนหน้าจอ (การตั้งค่ากลุ่ม → Live Preview ตั้งค่าฮิสโตแกรมบนทุกสมาชิกพร้อมกัน), การวัดแสงจุด |
| | ดัชนี (กลุ่มที่มีหน้าจอแยก), การผูกเซ็นเซอร์แสง |

พฤติกรรมอื่นที่ข้ามส่วนต่าง ๆ:

* **การแสดงผลรวม vs แยก** ถูกเลือกเมื่อเชื่อมต่ออาร์เรย์: รวม = แผ่นภาพรวมที่จัดเรียงให้ตรงกัน (ข้อมูลจากสมาชิกส่งผ่าน Split View เท่านั้น); แยก = แต่ละสมาชิกแสดงแผ่นภาพของตัวเองที่ซิงโครไนซ์กัน กล้องจะไม่แสดงทั้งข้อมูลแบบสแตนด์อโลนและแผ่นภาพอาร์เรย์พร้อมกัน
* **การเชื่อมต่ออัตโนมัติ**: การเปิดโครงการที่บันทึกไว้จะกู้คืนกล้องและอาร์เรย์ และนำการตั้งค่าที่บันทึกไว้ทั้งหมดไปใช้กับระบบหลังบ้านก่อนที่สตรีมจะเริ่มทำงานอีกครั้ง
* **การจำกัดการบันทึก**: กล้องที่ถูกซ่อนหรือหยุดชั่วคราวจะไม่ถูกรวมในการบันทึกทั้งหมด (Capture All); อาร์เรย์จะถูกบล็อกอย่างสมบูรณ์ก็ต่อเมื่อสมาชิกทั้งหมดถูกซ่อน/หยุดชั่วคราว ดู [การตั้งค่าและโหมดการบันทึก](capture.md).

## วิธีที่การตั้งค่าถูกเก็บรักษา

สถานะของแท็บกล้องถูกบันทึก **ร่วมกับโครงการ** ไม่ใช่ในเบราว์เซอร์:

* ทุกการเปลี่ยนแปลงแบบตอบสนองจะบันทึกภาพกล้องและอาร์เรย์ลงใน `cameras.json` ของโครงการ (มีช่วงเวลาหน่วง 500 ms). ซึ่งรวมถึงชื่อและสีของกล้อง, การตั้งค่าการเปิดรับแสง/การเพิ่มสัญญาณ/AE, รูปแบบพิกเซล/ความละเอียด/การรวมพิกเซล, อัตราการทริกเกอร์, การตั้งค่าการดูตัวอย่าง (ความละเอียดการเรนเดอร์, การลดสัญญาณรบกวน, ความคมชัด, วิเนตต์, โปรไฟล์สี, Highlights, ความอิ่มตัว/ความคมชัด), ทิศทาง, การซ้อนทับ, การแบ่งช่องสัญญาณ, การกำหนดค่าดัชนี, การตั้งค่า AE แบบคาดการณ์, AE ROI, ชื่ออาร์เรย์, โหมดแสดงผล, การตั้งค่าการจับภาพอาร์เรย์ (รวมถึงการครอป ROI, การเปิด/ปิด ROI และการครอปที่บันทึกไว้เมื่อปิด), Wire Budget ของอาร์เรย์ และบล็อกกริด (การซูมฟีด, โหมดแสดงผล, การล็อกกริด, ลำดับไทล์แบบแมนนวล, กล้องที่ซ่อน, ไทล์ที่ปิด, กล้องที่ใช้งานอยู่).
* การตั้งค่าการผูกเซ็นเซอร์แสงจะถูกบันทึกไว้ในไฟล์ `sensors.json` ของโครงการ
* การเปิดโครงการใหม่จะเชื่อมต่ออุปกรณ์ใหม่และนำการตั้งค่าทั้งหมดมาใช้ใหม่
* **ไม่มีโครงการเปิด = เฉพาะเซสชัน**: หากไม่มีโครงการ ข้อมูลใดๆ จะไม่ถูกเก็บไว้เมื่อปิดChloros
* เฉพาะเซสชัน ไม่ว่าจะมีโครงการหรือไม่: สถานะพัก, ตัวอย่างการวัดจุด, ช่องทำเครื่องหมาย Calibration Target สำหรับกล้องแต่ละตัว (เปิดไว้เสมอเมื่อปิด), และโปรไฟล์การจัดแนวอาร์เรย์ (คำนวณใหม่ทุกเซสชันตามการออกแบบ)
