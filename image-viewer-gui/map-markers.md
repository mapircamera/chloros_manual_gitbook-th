# จุดหมายบนแผนที่

แท็บแผนที่จะแสดงภาพของคุณบนแผนที่ 2D แบบโต้ตอบ โดยใช้พิกัด GPS ของภาพเหล่านั้น มันช่วยให้คุณเห็นภาพรวมทางภูมิศาสตร์ของเซสชันการถ่ายภาพ และเป็นวิธีที่รวดเร็วที่สุด (ทันทีหลังการนำเข้า) เพื่อลบภาพที่คุณไม่ต้องการประมวลผล

<figure><img src="../.gitbook/assets/chloros_map_markers.gif" alt=""><figcaption></figcaption></figure>

## การเข้าถึงแท็บแผนที่

1. เปิดหรือสร้างโครงการใน Chloros
2. นำเข้าภาพที่มีข้อมูลเมตาดาต้า GPS
3. คลิกแท็บ **แผนที่** <img src="../.gitbook/assets/image (3) (1).png" alt="" data-size="line"> ในแถบด้านซ้าย
4. แผนที่จะแสดงเครื่องหมายที่ตำแหน่ง GPS ของภาพแต่ละภาพ

{% hint style="info" %}
**จำเป็นต้องมี GPS**: ภาพที่มีพิกัด GPS ในข้อมูลเมตาดาต้า EXIF เท่านั้นที่จะปรากฏบนแผนที่ ภาพที่ไม่มีพิกัดจะยังคงอยู่ในโครงการและยังคงถูกประมวลผลตามปกติ — เพียงแต่ไม่มีจุดหมาย
{% endhint %}

***

## ปรับภาพจากแท็บแผนที่

แท็บ **แผนที่**<img src="../.gitbook/assets/image (3) (1).png" alt="" data-size="line"> มีปุ่มเพิ่ม <img src="../.gitbook/assets/image (3).png" alt="" data-size="line"> <img src="../.gitbook/assets/image (1) (1).png" alt="" data-size="line"> และลบ <img src="../.gitbook/assets/image (2) (1).png" alt="" data-size="line"> ไฟล์ เช่นเดียวกับแท็บ [**ตัวเรียกดูไฟล์**](../processing-images-gui/adding-files-to-a-project.md) <img src="../.gitbook/assets/icon_file-browser.JPG" alt="" data-size="line"> มันแสดงรายการไฟล์โครงการเดียวกัน พร้อมด้วยคอลัมน์ทางภูมิศาสตร์:

| คอลัมน์        | เนื้อหา                                                           |
| ------------- | ------------------------------------------------------------------ |
| **ชื่อ**      | ชื่อไฟล์ตามที่ถ่ายจากกล้อง                             |
| **ละติจูด**  | องศาทศนิยม 6 ตำแหน่ง                                |
| **ลองจิจูด** | องศาทศนิยม 6 ตำแหน่ง                                |
| **ความสูง**  | เมตร, หนึ่งตำแหน่งทศนิยม — `-` เมื่อภาพไม่มีความสูง |

{% hint style="info" %}
คลิกที่หัวคอลัมน์ใดก็ได้เพื่อจัดเรียงตามคอลัมน์นั้น; คลิกอีกครั้งเพื่อกลับลำดับ
{% endhint %}

{% hint style="warning" %}
**ความสูงคือความสูงเหนือระดับน้ำทะเล ไม่ใช่ความสูงเหนือพื้นดิน** ค่านี้มาจากแท็ก EXIF `GPSAltitude` ของภาพ ซึ่งอ้างอิงถึงระดับน้ำทะเลเฉลี่ย นี่ไม่ใช่ความสูงการบินเหนือพื้นดิน และChlorosจะไม่คำนวณระยะตัวอย่างพื้นดินจากค่านี้ — เหนือทุ่งนาที่อยู่สูง 300 ม. เหนือระดับน้ำทะเล โดรนที่บินอยู่ที่ความสูง 100 ม. AGL จะบันทึกค่าประมาณ 400 ม. ที่นี่ ใช้คอลัมน์นี้เพื่อตรวจหาค่าผิดปกติและยืนยันความสูงการบินที่สม่ำเสมอ ไม่ใช่เพื่อใช้เป็นค่า AGL
{% endhint %}

## จุดหมายภาพ

ภาพแต่ละภาพที่มีข้อมูล GPS จะได้รับจุดหมายที่พิกัดของมัน

### การแสดงจุดหมาย

* จุดหมายจะอยู่ที่พิกัดที่บันทึกไว้อย่างแม่นยำสำหรับภาพแต่ละภาพ
* จุดมาร์กเกอร์ที่อยู่ใกล้กันอาจทับซ้อนกันเมื่อซูมออก — ซูมเข้าเพื่อแยกจุดมาร์กเกอร์ออกจากกัน
* จุดมาร์กเกอร์ที่ถูกเลือกและเน้นจะแสดงอยู่เหนือจุดมาร์กเกอร์อื่น ๆ

### พรีวิวเมื่อนำเมาส์ไปวาง

* **นำเมาส์ไปวาง** บนจุดมาร์กเกอร์ใดก็ได้เพื่อแสดงภาพขนาดย่อของภาพนั้นพร้อมชื่อไฟล์
* **คลิก**ที่มาร์กเกอร์เพื่อเลือกภาพและ**ตรึง** หน้าต่างป๊อปอัพให้เปิดค้างไว้ — หน้าต่างจะคงอยู่จนกว่าคุณจะคลิกที่อื่น ขณะที่หน้าต่างป๊อปอัพถูกตรึง การนำเมาส์ไปวางเหนือมาร์กเกอร์อื่นจะไม่ทำให้หน้าต่างป๊อปอัพนั้นหายไป
* นี่เป็นวิธีที่รวดเร็วในการค้นหาเฟรมเฉพาะในเซสชันขนาดใหญ่โดยไม่ต้องออกจากแผนที่

<figure><img src="../.gitbook/assets/image (36).png" alt=""><figcaption><p>แท็บแผนที่จะแสดงภาพทุกภาพที่มีข้อมูลตำแหน่งทางภูมิศาสตร์ในโครงการ</p></figcaption></figure>

### ซูมขั้นสูง

{% hint style="success" %}
**ซูมขั้นสูง**: เมื่อคุณซูมถึงระดับสูงสุดที่ผู้ให้บริการไทล์มีภาพรองรับ การซูมเข้าเพิ่มเติมจะขยายไทล์แทนที่จะหยุด ทำให้คุณสามารถแยกมาร์กเกอร์ที่อยู่ทับซ้อนกันเกือบสนิทได้
{% endhint %}

* ซูเปอร์ซูมจะทำงานเฉพาะเมื่อคุณ **อยู่ที่** ระดับซูมสูงสุดของผู้ให้บริการสำหรับตำแหน่งนั้น และไทล์ได้โหลดเสร็จสิ้นแล้ว หากอยู่ต่ำกว่าระดับนั้น การซูมจะทำงานตามปกติ
* ช่วงซูมคือ **1× ถึง 32×** เหนือระดับซูมสูงสุดของผู้ให้บริการ
* ตัวบ่งชี้ที่มุมจะแสดงระดับซูเปอร์ซูมปัจจุบันเป็นเปอร์เซ็นต์ และปุ่ม **×** ข้างๆ จะนำคุณกลับสู่การซูมปกติด้วยการคลิกเพียงครั้งเดียว
* การซูมออกจะส่งผ่านไปยังแผนที่โดยตรงเสมอ ดังนั้นคุณจึงไม่สามารถติดอยู่ในโหมดซูเปอร์ซูมได้
* การซูมและเลื่อนแผนที่ขณะอยู่ในโหมดซูมพิเศษจะส่งค่าการเลื่อนที่ได้กลับไปยังแผนที่ ดังนั้นพื้นที่นอกศูนย์กลางที่คุณเคลื่อนย้ายไปจะยังคงร้องขอไทล์แทนที่จะกลายเป็นว่างเปล่า
* จุดมาร์กเกอร์ถูกวาดเป็นองค์ประกอบเวกเตอร์แทนที่จะถูกแปลงเป็นภาพแรสเตอร์ ดังนั้นจึงยังคงคมชัดในทุกระดับซูมพิเศษ

***

## ผู้ให้บริการไทล์แผนที่

{% hint style="success" %}
**การเลือกอัตโนมัติ**: Chloros จะเลือกบริการไทล์ที่ให้ระดับซูมที่ดีที่สุดสำหรับตำแหน่งที่ภาพของคุณอยู่ คุณสามารถเปลี่ยนด้วยตนเองได้ทุกเมื่อ
{% endhint %}

| ผู้ให้บริการ        | หมายเหตุ                                                                                                                                                             |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Google Maps** | ครอบคลุมทั่วโลกอย่างกว้างขวาง; รองรับทั้งสี่ประเภทไทล์                                                                                                            |
| **Esri ArcGIS**| ภาพถ่ายทางอากาศที่มีความละเอียดสูงกว่าในบางภูมิภาคโดยเฉพาะ ประเภทไทล์**Terrain** ไม่ได้รับการเสนอสำหรับ Esri และปุ่มของมันจะถูกปิดใช้งานเมื่อเลือก Esri |***

## ประเภทไทล์แผนที่

เลือกประเภทชั้นแผนที่ด้วยปุ่ม (จากซ้ายไปขวา):

![](&lt;../.gitbook/assets/image (14).png&gt;)

| ประเภท                 | แสดง                                                                |
| -------------------- | -------------------------------------------------------------------- |
| **Terrain**          | การแรเงาความสูงพร้อมรายละเอียดแผนที่ (ถนน, ป้ายชื่อ) — เฉพาะ Google เท่านั้น       |
| **Map**              | แผ่นแผนที่ถนนมาตรฐาน — ตัวเลือกที่ใช้แบนด์วิดท์ต่ำที่สุด              |
| **Satellite**        | ภาพดาวเทียมละเอียด ไม่มีป้ายกำกับ — ตัวเลือกที่ใช้แบนด์วิธสูงที่สุด |
| **Hybrid** (ค่าเริ่มต้น) | ภาพดาวเทียมที่มีถนนและป้ายกำกับแสดงทับอยู่                |

แท็บแผนที่จะเปิดในโหมด **Hybrid** โดยตัวเลือกของคุณจะถูกนำไปใช้เมื่อเปลี่ยนผู้ให้บริการ หากผู้ให้บริการนั้นรองรับ***

## การนำทางบนแผนที่

* **ซูม**: ล้อเลื่อนของเมาส์ หรือปุ่มซูมบนแผนที่
* **เลื่อน**: คลิกและลาก
* **เต็มหน้าจอ**: ปุ่มควบคุมเต็มหน้าจอจะขยายแผนที่ให้เต็มหน้าต่าง***

## ตัวอย่างการใช้งาน

### ตรวจสอบเส้นทางบิน

* ดูพื้นที่การครอบคลุมของเซสชันโดรนได้ในพริบตา
* ระบุจุดที่ขาดการบินผ่าน
* ยืนยันว่าเส้นทางการบินเป็นไปตามแผนที่วางไว้

### การตรวจสอบการสำรวจภาคพื้นดิน

* ดูการกระจายตัวของภาพที่ถ่ายจากภาคพื้นดิน
* ระบุตำแหน่งกรอบเป้าหมายการปรับเทียบสัมพันธ์กับพื้นที่สำรวจ
* ตัดสินใจว่าจุดใดจำเป็นต้องถ่ายภาพเพิ่มเติม

### การควบคุมคุณภาพ

* ค้นหาภาพที่ถ่ายในตำแหน่งที่ไม่คาดคิดและลบออกก่อนการประมวลผล
* จัดเรียงตามความสูงเพื่อระบุเฟรมที่ถ่ายที่ความสูงผิด หรือเฟรมที่สัญญาณ GPS ไม่เสถียร
* ตรวจสอบตำแหน่งภาพเทียบกับบันทึกภาคสนาม

***

## การแก้ไขปัญหา

### ไม่มีเครื่องหมายปรากฏ

**สาเหตุที่อาจเกิดขึ้น**

* ภาพไม่มีข้อมูลเมตาดาต้า GPS
* GPS ถูกปิดบนกล้องขณะถ่ายภาพ
* ข้อมูล EXIF ถูกลบโดยซอฟต์แวร์อื่นก่อนการนำเข้า

**วิธีแก้ไข**: ตรวจสอบให้แน่ใจว่า GPS บนกล้องถูกเปิดใช้งานอยู่ และนำเข้าไฟล์ต้นฉบับใหม่ คุณสามารถตรวจสอบว่าไฟล์เฉพาะมีพิกัดหรือไม่ โดยค้นหาในตารางไฟล์ของแท็บแผนที่ — ภาพที่ไม่มีพิกัดจะไม่มีแถวในตารางนั้น

### จุดมาร์กเกอร์อยู่ผิดตำแหน่ง

**สาเหตุที่อาจเกิดขึ้น**: การจับสัญญาณดาวเทียมไม่ดีในขณะถ่ายภาพ หรือ GPS เกิดการเบี่ยงเบนระหว่างการถ่ายภาพ**วิธีแก้ไข**: นี่เป็นปัญหาที่เกิดขึ้นในขณะถ่ายภาพ ไม่ใช่สิ่งที่Chlorosสามารถแก้ไขได้หลังจากนั้น สำหรับงานที่ต้องการความแม่นยำ ให้ใช้กระบวนการทำงานของ GPS แบบ PPK/RTK — ดูการตั้งค่า**Apply PPK corrections** ใน [Project Settings](../project-settings/project-settings.md).

### แผนที่เป็นสีขาวหรือไทล์หยุดโหลด

ผู้ให้บริการไทล์เป็นบริการออนไลน์ หากไทล์หยุดส่งมา ให้ตรวจสอบการเชื่อมต่อเครือข่ายของเครื่อง แล้วลองเปลี่ยนผู้ให้บริการ หากกำลังซูมระดับสูงมาก ให้กดปุ่ม **×** เพื่อรีเซ็ตกลับสู่ระดับซูมปกติ และให้แผนที่ขอไทล์ใหม่***
