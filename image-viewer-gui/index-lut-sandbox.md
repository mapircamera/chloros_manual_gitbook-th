# Index/LUT Sandbox

Index/LUT Sandbox คือพื้นที่ทำงานแบบโต้ตอบในแถบข้างของโปรแกรมดูภาพChloros คุณสามารถเลือกสูตร เชื่อมต่อช่องสัญญาณของกล้องกับสูตรนั้น ปรับสีด้วยเกรเดียนต์ และปรับช่วงค่า — ภาพจะอัปเดตแบบเรียลไทม์ขณะที่คุณดำเนินการ ตั้งแต่เวอร์ชัน 1.2.0 คุณยังสามารถ **บันทึกสิ่งที่คุณสร้าง** ได้ ทั้งสำหรับภาพเดียวหรือทั้งโครงการ โดยไม่ต้องประมวลผลใหม่

## Sandbox ใช้เพื่ออะไร

| Index/LUT Sandbox (แบบโต้ตอบ)        | การประมวลผลโครงการ (แบบกลุ่ม)       |
| -------------------------------------- | -------------------------------- |
| ภาพละหนึ่งภาพต่อครั้ง, รับผลตอบกลับทันที  | ชุดข้อมูลทั้งหมดในครั้งเดียว     |
| ทดลองและปรับแต่งซ้ำ             | การตั้งค่าที่กำหนดไว้ล่วงหน้า          |
| แสดงผลแบบเรียลไทม์; บันทึกเฉพาะเมื่อคุณต้องการ  | เขียนไฟล์ผลลัพธ์เสมอ      |
| เหมาะสำหรับการค้นหาการตั้งค่าที่เหมาะสม | ดีที่สุดเมื่อการตั้งค่าเสร็จสมบูรณ์ |

{% hint style="success" %}
**ขั้นตอนการทำงานปกติ**: ปรับแต่งใน Sandbox จนกระทั่งภาพแสดงผลตามที่ต้องการ แล้วส่งออกโดยตรงจาก Sandbox หรือคัดลอกการตั้งค่าดัชนีและ LUT เดียวกันไปยัง [Project Settings](../project-settings/project-settings.md) เพื่อให้การประมวลผลครั้งต่อไปนำการตั้งค่าเหล่านี้ไปใช้กับภาพทุกภาพ
{% endhint %}

## การเปิด Sandbox

1. คลิกภาพในตาราง — ภาพจะเปิดในโหมดเต็มหน้าจอในแท็บ **Image Viewer** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line">
2. คลิกไอคอน **Image Viewer** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> เพื่อเลื่อนแถบด้านซ้ายออกมา หากยังไม่ได้เปิด
3. เลือกเลเยอร์หลายแบนด์จากเมนูเลเยอร์แบบดรอปดาวน์ที่มุมขวาบน — **RAW (Reflectance)** เป็นตัวเลือกทั่วไป เนื่องจากค่าดัชนีที่คำนวณจากค่าสะท้อนแสงที่ปรับเทียบแล้วสามารถเปรียบเทียบระหว่างภาพได้

แถบด้านข้างแสดงข้อมูลจากบนลงล่างดังนี้:

* ชื่อภาพและรุ่นกล้อง
* ปุ่ม **Export/Save Image(s)**— จะปรากฏขึ้นเมื่อทำเครื่องหมายที่**Index**หรือ**LUT*** ช่องทำเครื่องหมาย **Index**และ**LUT**
* แผงการตั้งค่าดัชนี
* แผง **ค่าเคอร์เซอร์** พร้อมการอ่านค่า ฮิสโตแกรม และการควบคุม GSD

{% hint style="warning" %}
**ไม่สามารถใช้ได้กับกล้องโมโน** ในภาพ LATTICE M3M แบบแถบเดียว ทั้งสองช่องทำเครื่องหมายจะถูกปิดใช้งาน พร้อมข้อความแสดงข้อมูล _&quot;ไม่สามารถใช้ได้กับเซ็นเซอร์โมโน (M3M)&quot;_ — ดัชนีแบบหลายแถบจะไม่มีค่ากำหนดสำหรับแถบเดียว เพื่อคำนวณดัชนีจากกล้อง M3M ให้รวมภาพสองภาพหรือมากกว่าเป็นชุดภาพหลายแถบที่จัดแนวแล้ว และใช้เครื่องมือคำนวณดัชนี LATTICE
{% endhint %}

## การใช้ดัชนี

1. ทำเครื่องหมายในช่อง **ดัชนี** ที่ด้านบนของแถบด้านข้าง
2. เลือกฟิลเตอร์ของกล้องจากเมนูแบบเลื่อนลงด้านซ้าย (`RGN`, `OCN`, `NGB`, `RGB`, `RE`, `NIR`)
3. เลือกสูตรดัชนีจากเมนูแบบเลื่อนลงด้านขวา — มีสูตรในตัว 27 สูตร พร้อมทั้งสูตรที่คุณสร้างขึ้นเองและบันทึกไว้
4. สูตรจะแสดงผลเป็นสมการคณิตศาสตร์ด้านล่าง พร้อมด้วยวงกลมว่างที่ช่องแต่ละช่อง **ลากวงกลมช่องสีไปยังช่อง** เพื่อผูกมัน
5. เมื่อทุกช่องที่สูตรใช้ถูกผูกแล้ว ภาพจะอัปเดตและแสดงค่าดัชนี
6. นำเคอร์เซอร์ไปวางเหนือภาพเพื่ออ่านค่า; แผง **Cursor Values** จะเพิ่มแถวดัชนีพร้อมค่าที่อยู่ใต้เคอร์เซอร์

คลิกสองครั้งที่ช่องที่ผูกไว้เพื่อล้างข้อมูล สูตรที่ยังไม่สมบูรณ์เป็นสถานะปกติระหว่างการลาก ไม่ใช่ข้อผิดพลาด — ภาพจะไม่อัปเดตจนกว่าสูตรจะสมบูรณ์

วงกลมช่องมีรหัสสีดังนี้: แดง = Red, เขียว = Green, น้ำเงิน = Blue, ส้ม = Orange, สีฟ้า = Cyan, ม่วง = NIR, แมเจนตา = RE. สีเดียวกันนี้ใช้สำหรับจุดช่องและเส้นโค้งฮิสโตแกรมในแผง **ค่าเคอร์เซอร์**

### ตัวอย่างสูตรดัชนีช่องหลายสเปกตรัม (NDVI)

```

Formula: (NIR - Red) / (NIR + Red)

For a Survey3W RGN camera:
  NIR = 850 nm band
  Red = 661 nm band

Result range:          -1.0 to +1.0
Typical vegetation:     0.4 to 0.9
Stressed vegetation:    0.2 to 0.4
Bare soil:              0.0 to 0.2
Water:                 -0.1 to 0.1
```

สำหรับข้อมูลอ้างอิงสูตรที่ครบถ้วน — ทั้งสามรายการค่าตั้งล่วงหน้าและชื่อใดที่ใช้ได้ที่ใด — ดู [สูตรดัชนีมัลติสเปกตรัม](../project-settings/multispectral-index-formulas.md).

### เมื่อเลือก Index แต่ไม่มี LUT

ภาพจะถูกวาดใน **สเกลสีเทา** โดยถูกยืดระหว่างค่าสองค่าเกณฑ์ นี่เป็นการออกแบบโดยเจตนา: ภาพดัชนีเป็นข้อมูลสเกลาร์ และสเกลสีเทาคือการแสดงผลที่ตรงตามความเป็นจริงของมัน ให้เพิ่ม LUT เมื่อต้องการใช้สี***

## การทำงานกับ LUT (Look-Up Tables)**Look-Up Table** (LUT) แปลงค่าดัชนีเป็นสี: ป้อนNDVI0.65, ผลลัพธ์คือสีเขียวเฉพาะเจาะจง มันไม่เปลี่ยนแปลงข้อมูล — แต่เปลี่ยนวิธีที่คุณอ่านข้อมูลนั้น

### การเพิ่ม LUT

1. คลิกปุ่ม **&quot;+ Add LUT&quot;** ของ<img src="../.gitbook/assets/image (1) (1) (1).png" alt="" data-size="line"> ที่อยู่ใต้สูตร
2. เลือกการไล่ระดับสี
3. ตั้งค่าขั้นต่ำและขั้นสูงสุดของการตัดทอน
4. เลือกโหมดการตัดทอน
5. ทำเครื่องหมายในช่อง **LUT** ในแถบด้านข้างเพื่อแสดงผล

ช่องทำเครื่องหมาย LUT จะยังคงถูกปิดใช้งานจนกว่า LUT จะถูกกำหนดค่าจริงบนดัชนี

### การเลือกการไล่ระดับสี

นำเมาส์ไปวางเหนือ **แถบไล่ระดับสี**เพื่อเปิดรายการตั้งค่าล่วงหน้า — Chloros มี**เจ็ด** การตั้งค่าล่วงหน้าสำหรับการไล่ระดับสี:

| # | การไล่ระดับสี                            | รูปแบบ                                                               |
| - | ----------------------------------- | ------------------------------------------------------------------- |
| 1 | Red → Yellow → Green (**ค่าเริ่มต้น**)  | แยกตัว — สอดคล้องกับสัญชาตญาณทั่วไปเกี่ยวกับพืชพรรณ สีเขียว = สุขภาพดี |
| 2 | สีม่วง → สีเหลือง → Green             | แยกตัวออก, มีส่วนปลายต่ำที่ชัดเจน                                  |
| 3 | สีน้ำตาล → สีขาว → Blue                | แยกตัวออกรอบจุดกึ่งกลางที่สว่าง                                   |
| 4 | สีดำ → สีม่วง → สีชมพู → สีเหลืองอ่อน | ลำดับต่อเนื่อง, จากมืดไปสว่าง                                           |
| 5 | Red → Yellow → Blue                 | แยกสีรอบจุดกึ่งกลางที่สว่าง                                   |
| 6 | Purple → Blue → Green → Yellow      | ลำดับจากมืดไปสว่าง                                           |
| 7 | Orange → White → Purple             | แยกสีรอบจุดกึ่งกลางที่สว่าง                                   |

**การไล่ระดับสีแบบแยก**จะวางสีกลางไว้ที่กลางหน้าต่าง ซึ่งอ่านได้ดีเมื่อจุดกึ่งกลางมีความหมาย (เช่น ค่าเกณฑ์, วันที่เริ่มต้น) ส่วน**การไล่ระดับสีแบบต่อเนื่อง** จะไล่ระดับจากมืดไปสว่างอย่างสม่ำเสมอ ซึ่งอ่านได้ดีสำหรับปริมาณที่มีเพียง &quot;มาก&quot; และ &quot;น้อย&quot; เท่านั้น

แต่ละค่าตั้งล่วงหน้ามีจุดสีเจ็ดจุด คลิกที่ค่าตั้งล่วงหน้าและภาพจะอัปเดตทันที (เมื่อกล่อง LUT ถูกทำเครื่องหมาย)

### การแก้ไขจุดสี

ด้านล่างแถบไล่ระดับสีมีแถวตัวอย่างสีหนึ่งตัวอย่างต่อจุด:

* **เปลี่ยนสี**: คลิกตัวอย่างสีเพื่อเปิดเครื่องมือเลือกสี (วงล้อสี, ตัวเลื่อนRGB/HSV หรือรหัส hex เช่น `#FF0000`)
* **เพิ่มจุดสี**: คลิกปุ่ม**+** ที่ปลายแถว — จุดสีขาวจะถูกเพิ่มเข้าไป
* **ลบจุดสี**:**คลิกสองครั้ง** ที่ตัวอย่างสี
* **เก็บการปรับแต่งการไล่ระดับสี**: คลิกไอคอนบันทึกข้างแถบการไล่ระดับสีเพื่อเพิ่มการไล่ระดับสีที่ปรับแต่งแล้วลงในรายการตั้งค่าล่วงหน้า เพื่อให้คุณสามารถเลือกใช้ใหม่ได้

การไล่ระดับสีที่คุณได้กำหนดไว้บนดัชนีจะถูกเก็บไว้พร้อมกับดัชนีนั้นในตั้งค่าของโครงการ ดังนั้นมันจะยังคงอยู่แม้เมื่อปิดและเปิดโครงการใหม่

**จุดหยุดน้อย**จะสร้างโซนที่ชัดเจนซึ่งแสดงเป็นระบบการจัดประเภท;**จุดหยุดมาก** จะสร้างการเปลี่ยนสีที่นุ่มนวลและใกล้เคียงภาพถ่าย สามถึงห้าจุดหยุดเหมาะสำหรับสไลด์นำเสนอและแผนที่การจัดประเภท; หกถึงสิบจุดหยุดเหมาะสำหรับการวิเคราะห์ทั่วไป; สิบห้าจุดหยุดหรือมากกว่าเหมาะสำหรับการตรวจสอบอย่างละเอียดและรูปภาพในสิ่งพิมพ์

### การตั้งค่าช่วงค่า

ตัวควบคุมค่าขีดจำกัดเป็น **สไลเดอร์แบบสองมือจับ**ที่วิ่งจาก −1 ถึง +1 พร้อมกล่องข้อความที่แก้ไขได้อยู่ที่ปลายทั้งสองด้านสำหรับค่าที่แม่นยำ และปุ่ม**AUTO**

* ลากมือจับใดก็ได้ หรือพิมพ์ตัวเลขลงในกล่องข้อความแล้วกด Enter
* **AUTO**ตั้งช่วงค่าเป็น**เปอร์เซ็นไทล์ที่ 2 และ 98** ของค่าดัชนีที่ถูกต้องในภาพ — เป็นจุดเริ่มต้นที่ดีที่ละเว้นค่าผิดปกติ Chloros จะปรับการปัดเศษผลลัพธ์อย่างเหมาะสม เป็น 4 ตำแหน่งทศนิยมสำหรับช่วงที่แคบมาก 3 ตำแหน่งสำหรับช่วงที่แคบ และ 2 ตำแหน่งสำหรับกรณีอื่น
* การปรับแต่งด้วยมือใดๆ จะมีความสำคัญเหนือกว่า AUTO จนกว่าคุณจะกด AUTO อีกครั้ง

ตัวอย่างหน้าต่างNDVI:

| เป้าหมาย                                    | Min  | Max |
| --------------------------------------- | ---- | --- |
| แสดงทั้งหมด                         | −1.0 | 1.0 |
| แสดงเฉพาะพืชพรรณ ไม่รวมดินและน้ำ | 0.2  | 0.9 |
| แสดงเฉพาะพืชพรรณที่สมบูรณ์                 | 0.5  | 0.9 |
| เน้นความเครียด                        | 0.2  | 0.5 |

การลดขนาดหน้าต่างจะเพิ่มความคมชัดภายในพื้นที่ที่คุณสนใจ และผลักส่วนอื่น ๆ ออกไปนอกช่วงค่า — ซึ่ง **โหมดการตัด** จะกำหนดว่าจะเกิดอะไรขึ้นกับส่วนนั้น***

## โหมดการตัด

เมื่อค่าดัชนีของพิกเซลอยู่นอกช่วงของหน้าต่าง min/max โหมด Clipping Mode จะกำหนดวิธีการวาดพิกเซลนั้น

| ชื่อตัวเลือกในเมนูแบบเลื่อนลง                  | ค่าที่เก็บไว้      | พิกเซลที่อยู่นอกช่วงจะถูกวาดเป็น                                                                                                |
| ------------------------------- | ----------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| **Minimum &amp; Maximum** (ค่าเริ่มต้น) | `clip`            | สีปลายสุดที่ใกล้ที่สุดของเกรเดียนต์ — ค่าที่ต่ำกว่าค่าต่ำสุดจะใช้สีแรก ส่วนค่าที่สูงกว่าค่าสูงสุดจะใช้สีสุดท้าย |
| **พื้นหลังโปร่งใส**      | `transparent`     | โปร่งใสอย่างสมบูรณ์ (อัลฟาจริง)                                                                                                  |
| **พื้นหลังแบบดัชนี**| `indexColor`      | เกรย์สเกล ที่ถูกขยายให้ครอบคลุมช่วงดัชนี**ทั้งหมด** ของภาพ ดังนั้นโครงสร้างที่อยู่นอกช่วงดัชนียังคงมองเห็นได้ในสีเทา                |
| **พื้นหลังต้นฉบับ**         | `backgroundColor` | ภาพต้นฉบับเอง ทำให้ชั้นสีทับซ้อนอยู่ด้านบนของฉากจริง                                                |

| โหมด                       | เหมาะที่สุดสำหรับ                               | ลักษณะ                                      |
| -------------------------- | -------------------------------------- | ----------------------------------------- |
| **ขั้นต่ำ &amp; สูงสุด**      | แสดงข้อมูลเต็มรูปแบบ, การวิเคราะห์ทางวิทยาศาสตร์ | ทุกพิกเซลมีสี                      |
| **พื้นหลังโปร่งใส** | การซ้อนทับ GIS, แยกช่วงค่า   | มีสีภายในหน้าต่าง, ไม่มีสีภายนอก |
| **พื้นหลังแบบดัชนี**       | เน้นย้ำข้อมูลโดยรักษาบริบทของข้อมูล    | สีภายใน, สีเทาภายนอก               |
| **พื้นหลังแบบต้นฉบับ**    | รายงานและงานนำเสนอ              | สีภายใน, ภาพถ่ายภายนอก         |

{% hint style="info" %}
**พิกเซลที่ไม่มีข้อมูลจะโปร่งใสเสมอ ในทุกโหมด.** พิกเซลที่มีดัชนีไม่เป็นจำนวนเต็ม (การหารด้วย 0/0) หรือมีค่าเท่ากับ −1.0 หรือ +1.0 (ตัวบ่งชี้ความอิ่มตัว, เมื่อแถบหนึ่งอ่านค่าเป็นศูนย์ในขณะที่อีกแถบหนึ่งไม่เป็นศูนย์) จะถูกพิจารณาเป็นไม่มีข้อมูล แทนที่จะเป็นค่าสุดขั้ว สิ่งนี้ช่วยป้องกันไม่ให้ส่วนที่สว่างเกิน (highlights) และส่วนที่มืดเกิน (shadows) ปรากฏในสเกลสีของคุณ แทนที่จะแสดงผลเป็นค่าอ่านที่สูงสุดในเฟรม กฎเดียวกันนี้กำหนดว่าพิกเซลใดจะถูกใช้เพื่อคำนวณค่าเกณฑ์ AUTO และฮิสโตแกรมดัชนี เพื่อให้ทั้งสามส่วนสอดคล้องกัน
{% endhint %}

ความโปร่งใสจะถูกรักษาไว้เมื่อส่งออกในรูปแบบPNG แต่ไม่สามารถแสดงผลได้ในรูปแบบ JPG

## การอ่านค่าขณะปรับแต่ง

แผง **ค่าเคอร์เซอร์** (Cursor Values) ด้านล่างแผงการตั้งค่าคือเครื่องมือวัดสำหรับ Sandbox:

* เลื่อนเคอร์เซอร์เหนือภาพและอ่านค่าต้นทางของแต่ละช่องสัญญาณ รวมถึงค่าดัชนีในแถวของมันเอง
* เปิดปุ่ม **INDEX** ด้านบนฮิสโตแกรมเพื่อดูการกระจายตัวของค่าดัชนีในเฟรม โดยค่าขีดจำกัดคลิปทั้งสองของคุณจะถูกวาดเป็นเส้นประสีส้ม และค่าของเคอร์เซอร์เป็นเส้นสีขาว — นี่คือวิธีที่เร็วที่สุดในการเลือกหน้าต่างที่จริง ๆ มีข้อมูลของคุณอยู่
* เปิด **CURSOR** เพื่อดูเส้นมาร์กเกอร์ที่ค่าใต้ตัวชี้
* ซูมเกิน 60× (หรือน้อยกว่าหากตั้งค่าขนาดบล็อก GSD) เพื่อเน้นพิกเซลที่แสดงแต่ละพิกเซลด้วยค่าที่ลอยอยู่

ขั้นตอนปฏิบัติ:

1. บันทึกค่าเหนือพืชที่สุขภาพดี พืชที่ได้รับความเครียด ดินเปล่า และน้ำ
2. ดูว่ากลุ่มค่าเหล่านั้นอยู่ตรงไหนบนฮิสโตแกรมดัชนี
3. ตั้งค่า min/max เพื่อกำหนดขอบเขตของกลุ่มค่าที่คุณสนใจ
4. เลือกโหมดตัดภาพ — _Original Background_ จะรักษาภาพฉากโดยรอบให้ยังคงมองเห็นได้

## ส่งออกจาก Sandbox

ทุกสิ่งที่กล่าวมาข้างต้นเป็นตัวอย่างสดจนกว่าคุณจะบันทึกมัน ปุ่ม **Export/Save Image(s)** ที่ด้านบนของแถบข้างจะเปิดหน้าต่างที่เลื่อนมาทับแถบข้าง (แทนที่จะปิดทับภาพ ดังนั้นคุณจึงยังสามารถเห็นสิ่งที่คุณกำลังตัดสินใจได้)

<figure><img src="../.gitbook/assets/image (35).png" alt=""><figcaption></figcaption></figure>### ตัวเลือก

| ตัวเลือก                          | ผล                                                                                                                                            |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Apply to current image**      | บันทึกภาพที่แสดงอยู่ตามการตั้งค่าเหล่านี้อย่างแม่นยำ                                                                                                |
| **Apply to all project images** | ดำเนินการตั้งค่าเดียวกันนี้กับภาพทุกภาพในโครงการ ภาพที่ไม่มีแถบสีที่ดัชนีนี้ต้องการจะถูกข้ามไป ไม่ถือว่าเป็นการผิดพลาด |
| **แถบความชันของดัชนี/LUT**      | ยังเขียนภาพคำอธิบายแยกต่างหากสำหรับการส่งออกแต่ละครั้ง โดยแสดงช่วงค่าที่ติดป้ายกำกับ                                                                     |
| **ฮิสโตแกรมดัชนี**             | ยังเขียนภาพฮิสโตแกรมแยกต่างหากสำหรับการส่งออกแต่ละครั้ง โดยแสดงค่าต่ำสุด/สูงสุดของข้อมูลและเกณฑ์การตัดส่วน                                               |

หาก **GSD block size** ในแท็บภาพมีค่ามากกว่า 1 ช่องแสดงผลจะแจ้งเตือนก่อนที่คุณจะยืนยัน: การส่งออกจะบันทึกภาพที่คุณกำลังดูอยู่ รวมถึงการเฉลี่ยค่าของบล็อกด้วย ให้ตั้งค่า GSD กลับเป็น 1 ก่อน หากต้องการความละเอียดเต็ม

### ตำแหน่งที่ไฟล์ถูกจัดเก็บ

ทุกครั้งที่คลิก **Export**จะจัดสรร**โฟลเดอร์ใหม่ที่ไม่ถูกใช้ซ้ำ**:

```
<project folder>/Sandbox_Exports/<IndexName>_<Index|LUT>_<NNN>/
```

ตัวอย่าง: `Sandbox_Exports/NDVI_LUT_001/`, แล้ว `Sandbox_Exports/NDVI_LUT_002/` สำหรับการรันครั้งต่อไป การกำหนดหมายเลขนี้เกิดจากการสแกนข้อมูลที่มีอยู่บนดิสก์แล้ว ดังนั้นจึงยังคงอยู่แม้จะรีสตาร์ทระบบหรือลบโฟลเดอร์ด้วยมือ ไม่มีข้อมูลใดถูกเขียนทับ — จุดประสงค์หลักของ Sandbox คือการเปรียบเทียบผลลัพธ์ครั้งปัจจุบันกับครั้งล่าสุด

ภายในโฟลเดอร์ สำหรับแต่ละภาพ:

| ไฟล์                                                   | เนื้อหา                                                   |
| ------------------------------------------------------ | ---------------------------------------------------------- |
| `<source name>_<IndexName>_<Index\|LUT>.png`           | ภาพที่เรนเดอร์แล้ว, พิกเซลต่อพิกเซลตามที่โปรแกรมดูภาพแสดง |
| `<source name>_<IndexName>_<Index\|LUT>_legend.png`    | ไฟล์เสริมแถบความชัน (gradient bar sidecar) หากมีการร้องขอ                     |
| `<source name>_<IndexName>_<Index\|LUT>_histogram.png` | ไฟล์เสริมฮิสโตแกรมดัชนี (index histogram sidecar) หากมีการร้องขอ                  |

ทั้งสองส่วนเสริมจะถูกเขียนด้วย **ความละเอียดเต็ม** เสมอ แม้ภาพหลักจะถูกเฉลี่ยแบบบล็อก: ขนาดบล็อกคือความละเอียดของหน้าจอ และทั้งสองส่วนเสริมจะอ่านค่าดัชนีจริงต่อพิกเซล นอกจากนี้ พวกมันยังแสดงข้อมูลมากกว่าเวอร์ชันที่ปรากฏบนหน้าจอ — ทั้งสองจะแสดงทั้งหน้าต่างการขยาย _และ_ ค่าต่ำสุด/สูงสุดที่แท้จริงของข้อมูล ดังนั้นคำอธิบายที่บันทึกไว้จึงยังคงอ่านได้แม้ผ่านไปหลายเดือนโดยไม่ต้องเปิดโครงการนั้นขึ้นใหม่

### ความคืบหน้าและผลลัพธ์

การส่งออกทั้งโครงการใช้เวลาเพียงไม่กี่นาที ดังนั้นระบบจะรายงานความคืบหน้าผ่านช่องความคืบหน้าที่แสดงแบบเรียลไทม์ แทนที่จะบล็อกการทำงาน:

* แถบความคืบหน้าจะแสดง `current / total` และไฟล์ที่กำลังถูกเขียน
* เมื่อเสร็จสิ้น ช่องข้อมูลจะรายงานจำนวนภาพที่ส่งออก จำนวนภาพที่ถูกข้าม และเส้นทางโฟลเดอร์ผลลัพธ์
* ภาพที่ถูกข้ามจะแสดงพร้อมเหตุผล (แสดงสูงสุด 5 ภาพ แล้วตามด้วยบรรทัด &quot;+N more&quot;) เหตุผลทั่วไปคือเลเยอร์ที่ไม่มีช่องสัญญาณที่ดัชนีนี้ต้องการ
* หาก **ไม่มี** ภาพใดในโครงการที่สามารถใช้ดัชนีนี้ได้ การทำงานจะรายงานว่าล้มเหลว แทนที่จะทิ้งโฟลเดอร์ว่างไว้

สามารถส่งออกในแซนด์บ็อกซ์ได้เพียงครั้งเดียวเท่านั้น การเริ่มการทำงานครั้งที่สองในขณะที่การทำงานครั้งแรกยังดำเนินอยู่จะถูกปฏิเสธด้วยข้อความที่ชัดเจน แทนที่จะปล่อยให้การทำงานสองครั้งแข่งขันกันเพื่อใช้ไฟล์โครงการเดียวกัน

### ตารางจะแสดงการรัน

การรันที่เสร็จสิ้นทุกครั้งจะปรากฏเป็นปุ่มแยกต่างหากในแถบเครื่องมือ [ตารางภาพ](image-grid.md) โดยมีป้ายกำกับว่า `<IndexName> <Index|LUT> <NNN>`. นี่คือวิธีเปรียบเทียบการรัน: ส่งออกสองครั้งด้วยค่าความชันหรือค่าเกณฑ์ที่แตกต่างกัน แล้วสลับไปมาระหว่างปุ่มทั้งสองบนกริด

## สูตรดัชนีที่กำหนดเอง (Chloros

+)

{% hint style="info" %}
**สถานที่สร้าง**: ในแถบด้านข้าง Sandbox หรือใน**Project Settings** ก่อนการประมวลผล ทั้งสองวิธีจะบันทึกไปยังรายการระดับโครงการเดียวกัน
{% endhint %}

1. เปิดเครื่องคำนวณสูตรที่กำหนดเองจากเมนูแบบเลื่อนลงของสูตรดัชนี (ต้องเข้าสู่ระบบด้วยบัญชีสมัครสมาชิกChloros

+ ที่ตรงตามเงื่อนไข)
2. เขียนสูตรโดยใช้ **สัญลักษณ์ช่องแถบ** `x`, `y`, `z`, `a`, `b`, `c` — ไม่ใช่ชื่อแบนด์
3. ตัวดำเนินการที่มีอยู่: `+`, `-`, `*`, `/`, `^` และ `()` สำหรับการจัดกลุ่ม
4. ฟังก์ชันที่มีอยู่: `sqrt()`, `log()`, `ln()`, `abs()`, `sign()`, `log1p()`, `log2()`
5. ตั้งชื่อและบันทึก — มันจะปรากฏที่ส่วนล่างของเมนูแบบเลื่อนลงสูตร และคุณสามารถผูกช่องของมันได้โดยการลากวงกลมช่องสัญญาณ เหมือนกับพรีเซ็ตที่ติดตั้งมาในตัว

```

Modified NDVI with an offset:   (y-x)/(y+x+0.5)
Simple ratio:                   y/x
Three-band difference:          (y-x)/(y+x-z)
Squared ratio:                  (y/x)^2
```

{% hint style="warning" %}
**สูตรที่กำหนดเองใช้ได้เฉพาะผ่าน GUI เท่านั้น** ตัวเลือก &quot;CLI

&quot; / &quot;SDK

&quot; `--indices` จะขยายชื่อพรีเซ็ตในตัว 22 ชื่อ และข้ามส่วนอื่น ๆ ไปโดยอัตโนมัติ รวมถึงสูตรที่กำหนดเองของคุณด้วย เพื่อประมวลผลสูตรที่กำหนดเองแบบเป็นชุด ให้กำหนดค่าใน Project Settings แล้วดำเนินการประมวลผล หรือใช้ตัวเลือก &quot;Apply to all project images&quot; ของ Sandbox เพื่อส่งออก
{% endhint %}

## การแก้ไขปัญหา

### &quot;ชั้นนี้ไม่มีช่องที่ดัชนีนี้ต้องการ&quot;

สูตรอ่านตำแหน่งช่องที่ชั้นปัจจุบันไม่มี — เช่น ดัชนีสามช่องบนไฟล์ที่มีหนึ่งหรือสองช่อง เปลี่ยนไปใช้ชั้นภาพหลายแถบ (reflectance หรือ debayered) หรือเลือกดัชนีที่เหมาะกับฟิลเตอร์ของกล้องของคุณ

### &quot;ไม่สามารถติดต่อกับระบบประมวลผลภาพด้านหลังได้&quot;

ระบบด้านหลังไม่ตอบสนอง ตรวจสอบแท็บ Log; หากระบบหลังกำลังรีสตาร์ท Sandbox จะกู้คืนเองเมื่อระบบหลังกลับมาทำงาน

### ภาพไม่เปลี่ยนแปลงเมื่อลากวงกลม

สูตรยังไม่สมบูรณ์ สูตรที่ไม่สมบูรณ์จะถูกพิจารณาเป็นสถานะระหว่างการลากปกติ — ไม่มีการเรนเดอร์ภาพและไม่มีการรายงานข้อผิดพลาด กรอกทุกช่องที่สูตรใช้

### ภาพทั้งหมดมีสีเดียว

หน้าต่างคลิปของคุณอาจอยู่ไกลเกินขอบเขตข้อมูล กด **AUTO**เพื่อปรับให้ตรงกับเปอร์เซ็นไทล์ที่ 2/98 หรือเปิดฮิสโตแกรม**INDEX** เพื่อดูว่าข้อมูลอยู่ตรงไหนจริง ๆ

### สีที่ส่งออกไม่ตรงกับสิ่งที่ผมเห็น

สีควรตรงกัน — เส้นทางส่งออกถูกออกแบบให้สะท้อนภาพตัวอย่างแบบเรียลไทม์อย่างตั้งใจ รวมถึงค่าอัลฟาในโหมดคลิปปิ้ง และการเฉลี่ยบล็อกถูกนำไปใช้ _หลังจาก_ การลงสี ซึ่งตรงกับวิธีที่โปรแกรมดูภาพทำ หากมีความแตกต่าง ให้ตรวจสอบว่าขนาดบล็อก GSD ไม่เปลี่ยนแปลงระหว่างการดูและการส่งออก
