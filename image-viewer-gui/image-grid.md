# ตารางภาพ

หลังจากนำภาพเข้ามาในโครงการ คุณจะเห็นภาพเหล่านั้นจัดเรียงเป็นตารางในพื้นที่หลัก ตารางนี้คือที่ที่คุณสามารถเลือก **เวอร์ชันของภาพแต่ละภาพที่คุณกำลังดู** — ปุ่มด้านบนตารางจะสลับภาพขนาดย่อทั้งหมดพร้อมกันระหว่างไฟล์ต้นฉบับและผลิตภัณฑ์ที่ผ่านการประมวลผลแต่ละชิ้น

## ขนาดภาพย่อ

ใช้แถบเลื่อนซูมที่มุมขวาบนเพื่อปรับขนาดภาพย่อ แถบเลื่อนนี้สามารถปรับได้ตั้งแต่ **64 px ถึง 1200 px*** **Ctrl + ล้อเมาส์** ก็ใช้ปรับขนาดภาพย่อได้เช่นกัน
* **Ctrl + `+`**/**Ctrl + `=`**และ**Ctrl + `−`** ปรับขนาดทีละ 4 px ทุกครั้งที่กด ช่วงการปรับขนาดด้วยคีย์บอร์ดจะหยุดที่ 64 px สำหรับขนาดที่เล็กที่สุด และสำหรับขนาดที่ใหญ่ที่สุด จะหยุดที่ขนาดใดก็ตามที่พอดีกับภาพขนาดย่อสองภาพต่อแถวในหน้าต่างปัจจุบัน
* ขนาดที่คุณเลือกจะถูกบันทึกไว้กับโครงการ (`UI → Grid thumbnail size` ใน `project.json`, ค่าเริ่มต้น `160`) ดังนั้นเมื่อเปิดโครงการใหม่ ขนาดดังกล่าวจะถูกคืนค่าเดิม

<figure><img src="../.gitbook/assets/chloros_grid_zoom.gif" alt=""><figcaption></figcaption></figure>*ความละเอียด* ของภาพย่อเป็นการตั้งค่าที่แยกต่างหากจาก *ขนาด* ของภาพย่อ: ดู **Display → Image Thumbnail Resolution** ใน [Project Settings](../project-settings/project-settings.md) (ค่าเริ่มต้น 512 px ที่ด้านยาว) ขนาดคือความใหญ่ของไทล์ที่วาดขึ้น; ความละเอียดคือระดับรายละเอียดที่ถูกดึงมาเพื่อเติมเต็มไทล์นั้น***

## แถบเครื่องมือกริด

แถวปุ่มด้านบนกริดมีได้สูงสุดสามกลุ่ม จากซ้ายไปขวา:

1. **Per Trigger / Per Camera** — โหมดการจัดกลุ่ม ปรากฏเฉพาะในโครงการที่มีข้อมูลการจับภาพจาก LATTICE
2. **ปุ่มกรองกล้อง** — หนึ่งปุ่มต่อกล้อง LATTICE หนึ่งตัว ปรากฏเฉพาะในโหมด Per Camera
3. **ปุ่มโหมดส่งออก/ดู** — กำหนดว่าภาพย่อแต่ละภาพจะแสดงผลิตภัณฑ์ใด

เมื่อหน้าต่างแคบเกินไปที่จะแสดงทั้งหมด กลุ่มจะยุบลงจากขวาไปซ้ายเป็นเมนูแบบเลื่อนลงเมื่อนำเมาส์ไปวาง: ปุ่มส่งออก/ดูก่อนยุบ ตามด้วยปุ่มกล้อง กลุ่มที่พับลงจะเหลือปุ่มเดียวที่แสดงตัวเลือกที่กำลังใช้งานอยู่ และเมื่อนำเมาส์ไปวางเหนือปุ่มนั้น ชุดปุ่มทั้งหมดจะเลื่อนลงมา **โหมด Per Trigger / Per Camera ไม่เคยพับลง**<!-- SCREENSHOT-NEEDED: Image grid toolbar of a LATTICE array project at full width, showing all three button groups inline: Per Trigger / Per Camera, three camera filter buttons labelled "LATT-M3M (serial)", and the export/view buttons including TIFF, RAW (Original), RAW (Radiance), RAW (Reflectance). -->***

## ปุ่มส่งออก/ดู

ปุ่มเหล่านี้ใช้เพื่อสลับภาพขนาดย่อในตารางระหว่างประเภทภาพ **ปุ่มจะปรากฏทันทีที่ผลิตภัณฑ์ที่ระบุชื่อมีอยู่**— ซึ่งสำหรับไฟล์ต้นทางหมายความว่าทันทีที่นำเข้า ไม่ใช่หลังการประมวลผล ระบบ**Chloros

** จะสแกนผลิตภัณฑ์ของโครงการใหม่ระหว่างที่การประมวลผลกำลังดำเนินอยู่ ดังนั้นปุ่มจะปรากฏระหว่างการประมวลผลเมื่อผลิตภัณฑ์แต่ละชิ้นเริ่มถูกบันทึกลงดิสก์

### ปุ่มหลัก

ปุ่มส่งออกที่อยู่ด้านซ้ายสุดมีชื่อตาม **สิ่งที่คุณนำเข้าจริง**:

| สิ่งที่คุณนำเข้า | ชื่อปุ่ม |
| --- | --- |
|Survey3

RAW+JPG | `JPG` |
| LATTICE captures พร้อมตัวอย่างภาพแสดงผลข้างๆ เฟรม RAW | `PNG` หรือ `TIFF` ขึ้นอยู่กับตัวอย่างภาพที่แสดง |
| LATTICE บันทึกภาพที่ไฟล์ต้น **คือ** ภาพ RAW | *ไม่มีปุ่ม* — `RAW (Original)` แสดงไฟล์นั้นอยู่แล้ว |

ในโครงการแบบผสม ป้ายชื่อจะตามส่วนขยายที่ภาพส่วนใหญ่ใช้

### ปุ่มผลิตภัณฑ์

| ปุ่ม | แสดง | เมื่อปรากฏ |
| --- | --- | --- |
| **Targets** | ภาพที่มีเป้าหมายการปรับเทียบที่ตรวจพบ | หลังการรันที่ตรวจพบเป้าหมาย |
| **Reflectance** | ภาพสะท้อนที่ผ่านการปรับเทียบ | เฉพาะโครงการSurvey3

— โครงการ LATTICE ใช้ `RAW (Reflectance)` แทน ดังนั้นตารางจะไม่แสดงปุ่มสะท้อนสองปุ่ม |
| **ปรับสมดุลสีขาว** | ผลลัพธ์ที่ปรับสมดุลสีขาวแล้ว (กล้องRGB

) | หลังการประมวลผล |
| **แก้ไขวิเนตต์** | ตัวเลือกสำรองที่แก้ไขวิเนตต์แต่ยังไม่ผ่านการปรับเทียบ | หลังการรันที่ไม่สามารถปรับเทียบการสะท้อนแสงได้และ *การแก้ไขวิเนตต์* ถูกเปิด |
| **การตอบสนองของเซ็นเซอร์** | ตัวสำรองการตอบสนองของเซ็นเซอร์ที่ยังไม่ได้รับการปรับเทียบ | เหมือนกัน แต่ปิด *การแก้ไขวิเนตต์* |
| **`RAW (<INDEX> Index)`** | ปุ่มหนึ่งต่อดัชนีที่คำนวณได้ | หลังการประมวลผลที่ตั้งค่าดัชนีแล้ว |
| **`<INDEX> LUT`** | ปุ่มหนึ่งต่อดัชนีที่แมปสี | หลังการรันที่ตั้งค่า LUT |
| **`<Index> <Index\|LUT> <NNN>`** | ปุ่มหนึ่งต่อแต่ละการส่งออก [Index/LUT Sandbox](index-lut-sandbox.md) | เมื่อการส่งออก sandbox เสร็จสิ้น |

### ปุ่มระดับ LATTICE

โครงการที่มีข้อมูลจับภาพ LATTICE จะเพิ่มปุ่มเหล่านี้ โดยใช้ชื่อระดับแทนชื่อผลิตภัณฑ์:

| ปุ่ม | ระดับ |
| --- | --- |
| **RAW (ต้นฉบับ)** | เฟรมดิบต้นฉบับ ตามที่นำเข้า |
| **RAW (Radiance)** | ความส่องผ่านสเปกตรัมแบบ Float32, W/m²/sr/nm |
| **RAW (Reflectance)** | ค่าสะท้อนแบบ uint16, 32768 = ρ 1.0 |

`RAW (Original)` พร้อมใช้งานทันทีตั้งแต่ตอนนำเข้า — ไม่จำเป็นต้องประมวลผลเพิ่มเติม เมื่อการนำเข้า LATTICE ไม่มีปุ่มระดับฐานเลย (ไฟล์ฐานของทุกการจับภาพคือเฟรมดิบของมันเอง) กริดจะย้ายตัวเองไปยังปุ่มระดับแรกที่มีอยู่ เพื่อให้การเน้นบนแถบเครื่องมือตรงกับสิ่งที่คุณกำลังเห็น

การส่งออกระดับสองChloros

**ไม่ได้รับ** **ปุ่มกริดของตัวเอง**:

* **Debayered** — มุมมอง `RAW (Original)` แสดงผลแบบ debayered แล้ว ดังนั้นการเพิ่มปุ่มที่สองบนภาพที่ดูเหมือนกันจะก่อให้เกิดความรบกวน ผลิตภัณฑ์ `RAW (Debayered)` ยังคงถูกบันทึกไปยังดิสก์และสามารถเลือกได้จากเมนูแบบเลื่อนลงของชั้นเต็มหน้าจอ
* **Preview** — บนกล้องRGB

การดูตัวอย่างถูกลงทะเบียนเป็นชั้น `White Balanced` ซึ่งมีปุ่มอยู่ บนกล้องมัลติสเปกตรัม มันถูกลงทะเบียนเป็น `RAW (Preview)` และสามารถเข้าถึงได้จากเมนูแบบเลื่อนลงของเลเยอร์แบบเต็มหน้าจอ

{% hint style="info" %}
ปุ่มระดับเหล่านี้จะแสดงผลเฉพาะสำหรับโครงการที่มีเฟรม LATTICE จริงเท่านั้น โครงการSurvey3

ลงทะเบียนชื่อชั้นภายในบางส่วนที่เหมือนกัน และปุ่มเหล่านี้จะถูกกรองออกสำหรับโครงการดังกล่าว ดังนั้น gridSurvey3

จึงยังคงชุด `JPG / Targets / Reflectance` ที่คุ้นเคยไว้
{% endhint %}

การคลิกภาพย่อของกริดจะเปิด [Image Viewer](opening-an-image-full-screen.md) แบบเต็มหน้าจอ **บนผลิตภัณฑ์เดียวกันที่กริดกำลังแสดง** — หากกริดถูกตั้งค่าเป็น `Targets` ภาพขนาดย่อจะเปิดภาพเป้าหมายที่ส่งออก

## การจัดกลุ่มโครงการ LATTICE: ตามทริกเกอร์ vs ตามกล้อง

การจับภาพแบบอาร์เรย์จะสร้างภาพหลายภาพของช่วงเวลาเดียวกันจากโมดูลกล้องต่าง ๆ การจัดกลุ่มกำหนดวิธีที่กริดจะจัดเรียงภาพเหล่านั้น ทั้งสองโหมดจะแสดงแถบหัวเรื่องที่พับได้เต็มความกว้าง; **ทุกกลุ่มจะเปิดอยู่ตั้งแต่เริ่มต้น** และChloros
จะจดจำกลุ่มที่คุณปิดไว้ สถานะการพับจะถูกติดตามแยกกันตามโหมด ดังนั้นการปิดกลุ่มในโหมด Per Camera จะไม่ส่งผลให้กลุ่มในโหมด Per Trigger ปิดตาม

### Per Camera (ค่าเริ่มต้น)

กลุ่มหนึ่งต่อโมดูลกล้องหนึ่ง ตัวหัวแสดงรุ่นกล้องและหมายเลขซีเรียล (`LATT-M3M — <serial>`) รวมถึงจำนวนภาพ ภาพภายในกลุ่มจัดเรียงตามลำดับเวลาของเหตุการณ์การถ่ายภาพ

ในโหมดนี้ แถบเครื่องมือจะมี **ปุ่มกรองกล้อง** หนึ่งปุ่มต่อกล้องหนึ่งตัว ซึ่งมีป้ายกำกับว่า `MODEL (SERIAL)` กล้องทั้งหมดถูกเลือกไว้ตั้งแต่เริ่มต้น; การคลิกปุ่มจะยกเลิกการเลือกกล้องนั้นและลบกลุ่มของมันออกจากตาราง นี่เป็นวิธีที่รวดเร็วในการตรวจสอบแถบความถี่เดียวตลอดทั้งเที่ยวบิน

### ตามทริกเกอร์

หนึ่งกลุ่มต่อเหตุการณ์การถ่ายภาพ — ชุดเฟรมที่โมดูลทั้งหมดถ่ายภาพด้วยทริกเกอร์เดียวกัน ส่วนหัวแสดงเวลาการถ่ายภาพ จำนวนกล้องที่เข้าร่วม และสัญลักษณ์สำหรับแต่ละรุ่นกล้องในกลุ่ม ไทล์ภายในกลุ่มถูกจัดเรียงตามหมายเลขซีเรียลของกล้อง ดังนั้นแถบเดียวกันจะอยู่ในคอลัมน์เดียวกันสำหรับทุกการทริกเกอร์

## ภาพขนาดย่อในกริดจะตามขนาดบล็อก GSD

หากคุณได้ตั้งค่า **GSD (px)** ในแถบด้านข้างของแท็บภาพ ภาพขนาดย่อแบบกริดจะแสดงด้วยความละเอียดพื้นดินเดียวกัน — ไม่ใช่เพียงในโหมดเต็มหน้าจอเท่านั้น ขนาดบล็อก 8 หมายความว่า พิกเซลที่แสดงแต่ละพิกเซลเป็นค่าเฉลี่ยของบล็อกพิกเซลต้นทางขนาด 8 × 8 ในทุกส่วนภายในแอปที่แสดงภาพ

เนื่องจากไทล์มีความกว้างเพียงไม่กี่ร้อยพิกเซลตั้งแต่แรก ขนาดบล็อกที่หยาบจึงหยุดสร้างความแตกต่างที่มองเห็นได้บนกริดก่อนที่จะเกิดขึ้นในมุมมองเต็มหน้าจอ: กรอบ 4000 px ที่ถูกวาดลงในไทล์ 160 px มีอัตราส่วนประมาณ 25 พิกเซลต้นทางต่อพิกเซลที่แสดง ดู [เปิดภาพแบบเต็มหน้าจอ](opening-an-image-full-screen.md#gsd-block-size) เพื่อดูตัวควบคุมเอง
