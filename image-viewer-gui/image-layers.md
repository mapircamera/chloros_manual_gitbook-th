# ชั้นภาพ

**เมนูแบบดรอปดาวน์ชั้น** ที่มุมขวาบนของ Image Viewer ช่วยให้คุณสลับระหว่างทุกเวอร์ชันของภาพที่คุณกำลังดู — ตั้งแต่ภาพต้นทางที่จับภาพมา ผ่านผลิตภัณฑ์ที่ผ่านการประมวลผลแต่ละชิ้น ไปจนถึงภาพดัชนีที่คำนวณได้ — โดยไม่ต้องออกจากโปรแกรมดูภาพ

## ชั้นภาพคืออะไร?

"ชั้น" ในChloros คือ **ไฟล์ผลิตภัณฑ์**หนึ่งไฟล์ที่ลงทะเบียนกับภาพต้นฉบับหนึ่งภาพ การนำเข้าจะให้ไฟล์ต้นฉบับแก่คุณ; การประมวลผลจะเพิ่มชั้นหนึ่งชั้นสำหรับผลิตภัณฑ์แต่ละชิ้นที่การประมวลผลสร้างขึ้น ไฟล์ที่ส่งออกจะรักษาชื่อไฟล์ต้นฉบับไว้ —**โฟลเดอร์** คือสิ่งที่ระบุผลิตภัณฑ์ และชื่อชั้นคือชื่อที่Chloros ตั้งให้กับโฟลเดอร์นั้น

## รายชื่อชั้น

### มีอยู่เสมอ

| ชั้น | อธิบาย |
| --- | --- |
| **JPG**(หรือ**PNG**/**TIFF**) | ไฟล์พื้นฐานที่มาพร้อมกับการจับภาพ Survey3 นำเข้า `.JPG` ไว้ข้างๆ `.RAW` ทุกครั้ง; การจับภาพ LATTICE จะนำภาพตัวอย่างแสดงผลแบบ PNG หรือ TIFF มาด้วย ติดป้ายกำกับตามสิ่งที่ถูกนำเข้าจริง |
| **RAW (ต้นฉบับ)** | เฟรมดิบต้นทาง ที่ผ่านการแยกพิกเซลเพื่อแสดงผลโดยไม่มีการปรับแต่งใดๆ พร้อมใช้งานทันทีตั้งแต่ขั้นตอนการนำเข้า — ไม่จำเป็นต้องประมวลผลเพิ่มเติม |

การจับภาพ LATTICE ที่ไฟล์ฐาน **คือ** เฟรมดิบของมันเอง จะไม่มีรายการฐานแยกต่างหาก: `RAW (Original)` ได้ครอบคลุมไว้แล้ว

### ผลิตภัณฑ์การประมวลผลของSurvey3



| ชั้น | ถูกเขียนลง | มีอยู่เมื่อ |
| --- | --- | --- |
| **RAW (Target)** | — | เฟรมนี้ถูกระบุว่ามีเป้าหมายการปรับเทียบ |
| **RAW (Reflectance)** | `Reflectance_Calibrated_Images/` | การปรับเทียบการสะท้อนแสงบนเฟรมนี้สำเร็จ |
| **Vignette Corrected**| `Vignette_Corrected_Images/` | ไม่สามารถทำการปรับเทียบการสะท้อนแสงได้**และ** *การแก้ไข Vignette* ถูกเปิด |
| **การตอบสนองของเซ็นเซอร์**| `Sensor_Response_Images/` | ไม่สามารถปรับเทียบการสะท้อนแสงของเฟรมได้**และ** *การแก้ไขวิเนตต์* ถูกปิด |
| **ปรับสมดุลสีขาว** | `White_Balanced_Images/` | ได้สร้างผลิตภัณฑ์ที่ปรับสมดุลสีขาวแล้ว |

{% hint style="info" %}
**การแก้ไขวิเนตต์และการตอบสนองของเซ็นเซอร์เป็นตัวเลือกที่ต่างกัน ไม่สามารถใช้ทั้งสองอย่างพร้อมกันได้** ในแต่ละรอบการประมวลผล จะมีผลิตภัณฑ์สำรองที่ยังไม่ได้รับการปรับเทียบเพียงหนึ่งรายการเท่านั้น สำหรับทุกรุ่นกล้อง และสวิตช์ *การแก้ไขวิเนตต์* จะเลือกว่าจะใช้ผลิตภัณฑ์ใด ดู [การตั้งค่าโครงการ](../project-settings/project-settings.md).
{% endhint %}

### ระดับ LATTICE

LATTICE บันทึกการกระจายสัญญาณ (fan out) ลงในระดับเหล่านี้ในขั้นตอนการประมวลผลครั้งเดียว ระดับใดที่มีอยู่ขึ้นอยู่กับตัวเลือกการส่งออกตามผลิตภัณฑ์ใน [การตั้งค่าโครงการ] และขึ้นอยู่กับสิ่งที่ใช้กับกล้องนั้น

| ชั้น | บันทึกไปยัง | ใช้กับ |
| --- | --- | --- |
| **RAW (Debayered)** | `Debayered_Images/` | RGB และมัลติสเปกตรัม |
| **RAW (Preview)** | `Preview_Images/` | มัลติสเปกตรัม (การขยายสีเท็จ) |
| **White Balanced** | `Preview_Images/` | กล้องหลักแบบ RGB — ภาพตัวอย่าง RGB ถูกลงทะเบียนภายใต้ชื่อนี้เพื่อให้สอดคล้องกับชั้น Survey3 ที่มีชื่อเดียวกัน |
| **RAW (Radiance)** | `Radiance_Images/` | เฉพาะมัลติสเปกตรัม |
| **RAW (Reflectance)** | `Reflectance_Calibrated_Images/` | เฉพาะมัลติสเปกตรัม และเฉพาะเมื่อมีบันทึกการลงแสง (downwelling) ที่ตรงกัน `.daq` หรือเป้าหมายในเฟรมที่ผ่านการตรวจสอบคุณภาพ (QA-passing) ครอบคลุมเฟรม |

กล้องหลักแบบ RGB ไม่มีระบบวัดรังสีตามแต่ละแถบ จึงข้ามการวัดความส่องสว่างและความสะท้อนสำหรับกล้องเหล่านี้โดยระบุว่า **ไม่เกี่ยวข้อง** — บันทึกจะแสดงข้อความนี้แทนที่จะล้มเหลวโดยไม่แจ้งเตือน

{% hint style="info" %}
**ชั้นข้อมูลดิบ (Raw) และชั้นข้อมูลที่ถอดเบย์เออร์ (debayered) จะจัดเรียงให้ตรงกับผลิตภัณฑ์ (คุณสมบัติใหม่ในเวอร์ชัน 1.3.0)**ไฟล์ดิบและไฟล์ที่ถอดเบย์เออร์ของ LATTICE จะถูกบันทึกในทิศทางดั้งเดิมของเซ็นเซอร์ และบันทึกทิศทางที่สอดคล้องกับไฟล์นั้นใน XMP; ส่วนผลิตภัณฑ์อื่น ๆ จะถูกบันทึกโดยที่ทิศทางดังกล่าวถูกนำไปใช้แล้ว โปรแกรมดูภาพและตารางภาพจะปรับ**RAW (Original)**และ**RAW (Debayered)** ตามข้อมูลบันทึกนั้นเพื่อแสดงผล ดังนั้นภาพจะไม่กลับด้านอีกต่อไปเมื่อคุณสลับระหว่างชั้นผลิตภัณฑ์และชั้น raw นี่เป็นการแสดงผลเท่านั้น — ไฟล์จะไม่ถูกเขียนทับใหม่ ไฟล์ที่ไม่มีข้อมูลบันทึกทิศทาง (ถ่ายก่อนเวอร์ชัน 1.3.0 หรือถูกเขียนโดยซอฟต์แวร์อื่น) จะแสดงตามรูปแบบที่เก็บไว้ ดู [รูปแบบภาพออก](../output-image-formats.md#orientation).
{% endhint %}

หน้ากาก Clamp (`*_clampmask.tif` ในโฟลเดอร์ `clamp_masks/`) ไม่ใช่ชั้น: Chloros จะข้ามหน้ากากเหล่านี้ไปเมื่อนำเข้า ดู [รูปแบบภาพออก](../output-image-formats.md#clamp-masks).

### ชั้นดัชนี, LUT และ sandbox

| รูปแบบชั้น | ตัวอย่าง | ที่มา |
| --- | --- | --- |
| **RAW (`<INDEX>` Index)** | `RAW (NDVI Index)` | หนึ่งชั้นต่อดัชนีที่ตั้งค่าใน Project Settings และคำนวณระหว่างการประมวลผล |
| **`<INDEX>` LUT** | `NDVI LUT` | เวอร์ชันที่แมปสีของดัชนี |
| **Sandbox (`<Name>` `<Index\|LUT>` `<NNN>`)** | `Sandbox (NDVI LUT 003)` | หนึ่งรายการต่อ [Index/LUT Sandbox](index-lut-sandbox.md) การส่งออก |

หากชื่อดัชนีเดียวกันถูกกำหนดค่ามากกว่าหนึ่งครั้งด้วยตั้งค่าที่แตกต่างกัน ชื่อของดัชนีที่สองและต่อๆ ไปจะมีตัวเลขเพิ่มเข้าไป (`RAW (NDVI2 Index)`) เพื่อให้สามารถแยกชั้นได้

## การใช้ตัวเลือกชั้น

1. เปิดภาพในโหมดเต็มหน้าจอโดยคลิกที่ภาพขนาดย่อในตาราง
2. คลิก **เมนูแบบเลื่อนลงของชั้น** ที่มุมขวาบนของตัวดูภาพ
3. เลือกชั้น — ภาพจะอัปเดตทันที

เมนูแบบเลื่อนลงจะแสดง **JPG, RAW (Original), RAW (Target), RAW (Reflectance)** เป็นอันดับแรก ตามลำดับนั้น และแสดงรายการอื่นๆ ทั้งหมดหลังจากนั้นตามลำดับที่ผลิตภัณฑ์ถูกลงทะเบียน

### การตั้งค่าชั้นเมื่อนำทาง

การกด **←**/**→** จะย้ายไปยังภาพถัดไปและพยายามรักษาชั้นเดิมไว้:

1. **จับคู่ที่ตรงกันก่อน** — หากภาพถัดไปมีชั้นที่มีชื่อเดียวกัน คุณจะได้รับชั้นนั้น นี่คือสิ่งที่ทำให้คุณอยู่บนเลเยอร์ `RAW (NDVI Index)` ขณะที่คุณกำลังผ่านชุดภาพทั้งหมด
2. **จากนั้นจับคู่ตามประเภท** — เลเยอร์ดัชนีจะค้นหาเลเยอร์ดัชนีใดก็ได้, LUT สำหรับ LUT ใดก็ได้, reflectance สำหรับ reflectance, target สำหรับ target, original สำหรับ original, base สำหรับ base
3. **จากนั้น สำหรับเลเยอร์ส่งออกเท่านั้น** — ชื่อจะถูกเก็บไว้แม้รายการเลเยอร์ยังไม่ได้อัปเดตทัน เพราะไฟล์นั้นอยู่บนดิสก์แล้ว นี่คือสิ่งที่ทำให้คุณสามารถตรวจสอบผลิตภัณฑ์ได้ขณะที่ระบบกำลังเขียนไฟล์เหล่านั้นอยู่
4. **ในกรณีอื่น** — เลเยอร์แรกที่มีอยู่ ซึ่งโดยปกติคือภาพฐาน

ไฟล์ sidecar `.daq` และ `.csv` ในโครงการจะถูกข้ามไปเมื่อใช้ปุ่มลูกศรในการนำทาง ดังนั้นการเลื่อนผ่านภาพจะไม่หยุดที่การบันทึกจากเซ็นเซอร์แสง

การซูมและแพนจะทำงานต่อเนื่องระหว่างภาพด้วย ซึ่งทำให้การเปรียบเทียบก่อน/หลังของตำแหน่งสนามเดียวกันเป็นเรื่องที่ง่าย

## การเข้าใจค่าพิกเซลตามชั้น

[แผงค่าเคอร์เซอร์](opening-an-image-full-screen.md#cursor-values) แสดงค่าจริงต่อช่องสัญญาณใต้เคอร์เซอร์ของคุณ ในหน่วยที่ชั้นนั้นถูกเก็บไว้ คอลัมน์ของมันจะเปลี่ยนไปตามชั้น:

| ชั้น | หน่วยที่แสดง | หมายเหตุ |
| --- | --- | --- |
| Base (JPG / PNG / TIFF preview) | DN, 0–255 | ค่าที่แสดงบนหน้าจอ ซึ่งได้รับการปรับแกมมาบนระบบ RGB ใช้สำหรับการตรวจสอบด้วยตาเปล่าเท่านั้น |
| RAW (ต้นฉบับ) | DN | ค่าตัวเลขดิจิทัลจากเซ็นเซอร์แบบดิบ แกนฮิสโตแกรมจะบอกความลึก: 255 (8 บิต), 4095 (12 บิต) หรือ 65535 (16 บิต) |
| RAW (Debayered) | DN | แบบเชิงเส้น ไม่มีการขยายช่วงการแสดงผล |
| RAW (Preview) / White Balanced | DN | ผลลัพธ์การแสดงผล — ถูกขยายช่วงหรือปรับแกมมาแล้ว ไม่เหมาะสำหรับการวัด |
| RAW (Radiance) | **W/m²/sr/nm** | ค่า radiance ทางกายภาพแบบ Float32 ไม่มีคอลัมน์ DN |
| RAW (Reflectance) | DN **และ %** | เปอร์เซ็นต์ที่คำนวณตามสเกลของไฟล์นั้นเอง — ดูด้านล่าง |
| การส่งออกดัชนี / LUT / sandbox | ค่าดัชนี หรือส่วนประกอบ RGB | ไฟล์ดัชนีช่องเดียวรายงานค่าดัชนี; ไฟล์ LUT ที่แมปสีรายงานส่วนประกอบ Red /Green /Blue |

### การสะท้อนแสง: มาตรวัดเป็นต่อไฟล์

{% hint style="warning" %}
**"หารด้วย 65,535" ถูกต้องเฉพาะสำหรับSurvey3 เท่านั้น** ค่าสะท้อนแสงของ LATTICE ถูกเก็บไว้ในสเกลที่ต่างกัน และการผสมตัวหารทั้งสองเป็นวิธีที่พบบ่อยที่สุดที่ทำให้ค่าสะท้อนแสงที่ได้เป็นครึ่งหนึ่งของค่าที่ควรจะเป็น
{% endhint %}

| แหล่งที่มา | DN ที่เท่ากับค่าสะท้อนแสง 1.0 | ระบุโดย |
| --- | --- | --- |
| **LATTICE**(M3C / M3M) |**32768** | แท็ก XMP `Chloros:PixelScale=32768` ที่ถูกประทับในทุกการส่งออกค่าการสะท้อนแสง LATTICE พื้นที่ว่าง 2× หมายความว่า ρ ที่สูงกว่า 1.0 สามารถแสดงได้แทนที่จะถูกตัด |
| **Survey3**| **65535** | ไม่มีแท็กสเกล XMP ของ Chloros — การปรับเทียบ Survey3 จะเขียนค่า ρ × dtype-max และตัดค่าที่ 1.0 |

สำหรับ GIS และการเขียนสคริปต์: อ่าน `Chloros:PixelScale` จากไฟล์และหารด้วยค่าดังกล่าว หากไม่มีแท็กนี้ ไฟล์จะเป็นSurvey3-scale (65535) โปรแกรมดูไฟล์ กล่องทราย index/LUT และการส่งออก index ทั้งหมดจะกำหนดสเกลด้วยวิธีเดียวกัน ดังนั้นตัวเลขที่แสดงที่เคอร์เซอร์คือตัวเลขที่การคำนวณของ index ใช้

การเก็บข้อมูลตามรูปแบบเฉพาะบนสเกลดังกล่าว:

* **TIFF (32-bit, Percent)** เก็บ DN / 65535 ในรูปแบบ float
* **PNG (8-bit)**และ**JPG (8-bit)** เก็บ DN × 255 / 65535
* **ค่า DN 8-bit จากภาพที่ถ่ายด้วยระบบ 8-bit** หรือไฟล์ reflectance ที่เขียนก่อนเวอร์ชัน 1.3.0 จะถูกตัดให้อยู่ในช่วง 0–255 และไม่มีแท็กสเกล แผงควบคุมจะแสดงค่า DN เท่านั้นสำหรับไฟล์เหล่านั้น โดยไม่มีคอลัมน์เปอร์เซ็นต์

### ช่วงค่าดัชนี

| กลุ่มดัชนี | ช่วงค่าทั่วไป | ค่าอ่าน |
| --- | --- | --- |
| ความแตกต่างที่ปรับมาตรฐาน (NDVI, GNDVI, NDRE, ENDVI…) | −1 ถึง +1 | พืชพรรณที่สมบูรณ์มักอยู่ที่ 0.4–0.9; ดินเปลือยใกล้ 0; น้ำเป็นค่าลบ |
| ปรับตามดิน (SAVI, OSAVI, MSAVI2…) | ประมาณ −1 ถึง +1.5 | ค่าอ่านคล้ายกับ NDVI โดยลดอิทธิพลของพื้นหลังดิน |
| อัตราส่วน (GRVI, GCI, MSR, CIRE…) | ไม่มีขีดจำกัดด้านบน | อัตราส่วนจะเพิ่มขึ้นอย่างไม่มีขีดจำกัดเมื่อแถบตัวหารมีค่าเป็นศูนย์ |
| EVI / LAI | 0 ถึง ~1, 0 ถึง ~3.5 | เมฆและพิกเซลอิ่มตัวอื่นๆ ทำให้ค่าทั้งสองเกินช่วง — ต้องมาสก์พวกมันก่อน |

ดู [สูตรดัชนีมัลติสเปกตรัม](../project-settings/multispectral-index-formulas.md) เพื่อดูสูตรที่แม่นยำเบื้องหลังทุกค่าตั้งล่วงหน้า

## ขั้นตอนการทำงานทั่วไป

### การเปรียบเทียบก่อน / หลัง

1. เลือก **RAW (ต้นฉบับ)** และสังเกตปรากฏการณ์ vignetting และค่าที่ยังไม่ได้รับการปรับเทียบ
2. เปลี่ยนไปใช้ **RAW (Reflectance)**

3. เปรียบเทียบ — วิเนตติ้งถูกลบออก ค่าถูกปรับเทียบแล้ว ซูมและแพนจะคงที่ เพื่อให้คุณกำลังดูพื้นที่เดียวกัน

### ตรวจสอบดัชนีเดียวในชุดภาพทั้งหมด

1. เปิดภาพที่ผ่านการประมวลผลภาพแรกและเลือกชั้นดัชนี
2. กด **→** ซ้ำๆ — ชั้นดัชนีจะติดตามคุณจากภาพหนึ่งไปยังภาพถัดไป
3. สังเกตฮิสโตแกรมในแถบด้านข้างขณะดำเนินการ: เฟรมที่มีการกระจายค่ากระโดดขึ้นลงควรตรวจสอบอย่างละเอียด

### ตรวจสอบเป้าหมายการปรับเทียบ

1. เลือก **RAW (Target)** บนเฟรมเป้าหมาย
2. ตรวจสอบว่าเป้าหมายมองเห็นได้ชัดเจนและถูกตรวจพบ
3. ย้ายไปยังเฟรมเป้าหมายถัดไป — ชั้นเป้าหมายจะตามมา

### ตรวจสอบความแม่นยำของค่าการสะท้อนแสง

1. เลือก **RAW (Reflectance)**

2. อ่านคอลัมน์**%** ในแผง Cursor Values — ค่านี้ได้ปรับสเกลให้ถูกต้องสำหรับไฟล์นั้นแล้ว
3. ตรวจสอบความถูกต้องเทียบกับวัสดุที่รู้จักในเฟรม: พืชพันธุ์ที่สมบูรณ์จะมีค่าสะท้อนแสงสูงในย่านNIR และต่ำในย่านสีแดง; เป้าหมายการปรับเทียบควรมีค่าสะท้อนแสงใกล้เคียงกับค่าที่เผยแพร่ไว้

## การแก้ไขปัญหา

### ชั้นที่คาดไว้ไม่ปรากฏในเมนูแบบเลื่อนลง

**สาเหตุที่อาจเกิดขึ้น**

* ภาพยังไม่ได้รับการประมวลผล — มีเพียงชั้นฐานและ `RAW (Original)` เท่านั้น
* ตัวเลือกการส่งออกของผลิตภัณฑ์ถูกยกเลิกการเลือกใน Project Settings
* ผลิตภัณฑ์นี้ไม่เหมาะสมกับกล้องดังกล่าว (radiance และ reflectance บนมาสเตอร์RGB; ดัชนีใด ๆ บนกล้อง M3M โมโนแบนด์เดียว)
* การปรับเทียบการสะท้อนไม่มีข้อมูลที่จะใช้ — ไม่มีข้อมูลการครอบคลุมแสงลง (downwelling coverage) ของ `.daq` และไม่มีเป้าหมายในเฟรมที่ผ่านการตรวจสอบคุณภาพ (QA) — ดังนั้นเฟรมจึงถูกปรับกลับไปใช้ Vignette Corrected หรือ Sensor Response

**วิธีแก้ไข**

1. ตรวจสอบบันทึกการทำงาน: Chloros จะแจ้งเมื่อผลิตภัณฑ์ส่งออกที่ขอไม่สามารถสร้างได้และเหตุผล
2. ตรวจสอบสวิตช์ส่งออกของแต่ละผลิตภัณฑ์ใน [Project Settings](../project-settings/project-settings.md)
3. ตรวจสอบว่าโฟลเดอร์ผลิตภัณฑ์มีอยู่ในโครงสร้างผลลัพธ์ของโครงการหรือไม่
4. ประมวลผลใหม่โดยเปิดใช้งานผลิตภัณฑ์นั้น

### รายการเลเยอร์ดูเหมือนไม่ทันสมัย

Chloros จะสแกนใหม่โฟลเดอร์ผลิตภัณฑ์ของโครงการระหว่างที่การรันกำลังดำเนินการอยู่ และแก้ไขการลงทะเบียนเลเยอร์ที่ขาดหายไปจากข้อมูลที่จริงบนดิสก์ ดังนั้นเลเยอร์ที่ส่งออกเสร็จสิ้นแล้วจะปรากฏขึ้นด้วยตัวเองในรอบการตรวจสอบ การเปลี่ยนไปจากภาพแล้วกลับมาจะบังคับให้มีการแก้ไขใหม่

### ค่าการสะท้อนแสงดูเหมือนเป็นครึ่งหนึ่งของค่าที่ควรจะเป็น

คุณกำลังแบ่งไฟล์ LATTICE ด้วย 65535 อย่างแน่นอน ใช้ `Chloros:PixelScale` (32768) หรืออ่านคอลัมน์ **%** ซึ่งได้ปรับค่านี้แล้ว

### ชั้นดัชนีมีอยู่ แต่ภาพเป็นสีขาว

ดัชนีต้องการช่องสัญญาณที่ชั้นของคุณไม่มี — เช่น ดัชนีที่อ่านช่องสัญญาณที่สาม แต่ถูกนำไปใช้กับไฟล์ที่มีหนึ่งหรือสองช่องสัญญาณ ให้เปลี่ยนไปใช้ชั้นหลายช่องสัญญาณ (ค่าสะท้อนแสงหรือแบบ debayered) หรือเลือกดัชนีที่เหมาะกับฟิลเตอร์ของกล้อง
