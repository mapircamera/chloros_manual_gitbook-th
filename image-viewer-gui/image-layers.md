# ชั้นภาพ

**เมนูแบบดรอปดาวน์ชั้น** ที่มุมขวาบนของ Image Viewer ช่วยให้คุณสลับระหว่างทุกเวอร์ชันของภาพที่คุณกำลังดู — ตั้งแต่ภาพต้นทางที่ถ่ายมา ผ่านทุกผลิตภัณฑ์ที่ผ่านการประมวลผล ไปจนถึงภาพดัชนีที่คำนวณได้ — โดยไม่ต้องออกจากโปรแกรมดูภาพ

## ชั้นภาพคืออะไร?

&quot;ชั้น&quot; ในChloros

คือ **ไฟล์ผลิตภัณฑ์**หนึ่งไฟล์ที่ลงทะเบียนกับภาพต้นฉบับหนึ่งภาพ การนำเข้าจะให้ไฟล์ต้นฉบับแก่คุณ; การประมวลผลจะเพิ่มชั้นหนึ่งชั้นสำหรับผลิตภัณฑ์แต่ละชิ้นที่การประมวลผลสร้างขึ้น ไฟล์ที่ส่งออกจะรักษาชื่อไฟล์ต้นฉบับไว้ —**โฟลเดอร์** คือสิ่งที่ระบุผลิตภัณฑ์ และชื่อเลเยอร์คือชื่อที่Chloros

ตั้งให้กับโฟลเดอร์นั้น

## การใช้ตัวเลือกชั้น

1. เปิดภาพในโหมดเต็มหน้าจอโดยคลิกที่ภาพขนาดย่อในตาราง
2. คลิก **เมนูแบบเลื่อนลงของเลเยอร์** ที่มุมบนขวาของตัวดูภาพ
3. เลือกเลเยอร์ — ภาพจะอัปเดตทันที

เมนูแบบเลื่อนลงจะแสดง **JPG, RAW (Original), RAW (Target), RAW (Reflectance)** เป็นอันดับแรก ตามลำดับนั้น และแสดงรายการอื่นๆ ทั้งหมดหลังจากนั้นตามลำดับที่ผลิตภัณฑ์ถูกลงทะเบียน

### การตั้งค่าชั้นเมื่อนำทาง

การกด **←**/**→** จะย้ายไปยังภาพถัดไปและพยายามรักษาชั้นภาพเดิมไว้:

1. **จับคู่ที่ตรงกันก่อน** — หากภาพถัดไปมีชั้นภาพที่มีชื่อเดียวกัน คุณจะได้รับชั้นนั้น นี่คือสิ่งที่ช่วยให้คุณอยู่บนเลเยอร์ `RAW (NDVI Index)` ขณะที่คุณกำลังผ่านชุดภาพทั้งหมด
2. **จากนั้นจับคู่ตามประเภท** — เลเยอร์ดัชนีจะค้นหาเลเยอร์ดัชนีใดก็ได้, LUT สำหรับ LUT ใดก็ได้, reflectance สำหรับ reflectance, target สำหรับ target, original สำหรับ original, base สำหรับ base
3. **จากนั้น สำหรับเลเยอร์ส่งออกเท่านั้น** — ชื่อจะถูกเก็บไว้แม้รายการเลเยอร์ยังไม่ทันตามทัน เพราะไฟล์นั้นอยู่บนดิสก์แล้ว นี่คือสิ่งที่ทำให้คุณสามารถตรวจสอบผลิตภัณฑ์ได้ในขณะที่ระบบยังกำลังเขียนไฟล์เหล่านั้นอยู่
4. **ในกรณีอื่น** — เลเยอร์แรกที่มีอยู่ ซึ่งโดยปกติคือภาพ base

ไฟล์ sidecar `.daq` และ `.csv` ในโครงการจะถูกข้ามไปเมื่อใช้ปุ่มลูกศรในการนำทาง ดังนั้นการเลื่อนผ่านภาพจะไม่หยุดที่การบันทึกของเซ็นเซอร์แสง

การซูมและแพนจะทำงานต่อเนื่องระหว่างภาพด้วย ซึ่งทำให้การเปรียบเทียบก่อน/หลังในตำแหน่งสนามเดียวกันเป็นเรื่องที่ง่าย

### การสะท้อนแสง: มาตราส่วนเป็นต่อไฟล์

{% hint style="warning" %}
**&quot;แบ่งด้วย 65,535&quot; ถูกต้องเฉพาะสำหรับSurvey3

เท่านั้น** ค่าสะท้อนแสงของ LATTICE ถูกเก็บไว้ในสเกลที่ต่างกัน และการผสมตัวหารทั้งสองเป็นวิธีที่พบบ่อยที่สุดในการได้ค่าสะท้อนแสงที่เท่ากับครึ่งหนึ่งของค่าที่ควรจะเป็น
{% endhint %}

| แหล่งที่มา | DN ที่เท่ากับค่าสะท้อนแสง 1.0 | ระบุโดย |
| --- | --- | --- |

(65535) โปรแกรมดูไฟล์ (viewer) กล่องทราย (sandbox) ของดัชนี/LUT และการส่งออกดัชนี ทั้งหมดจะกำหนดสเกลด้วยวิธีเดียวกัน ดังนั้นตัวเลขที่คุณอ่านได้ที่เคอร์เซอร์คือตัวเลขที่การคำนวณดัชนีใช้

## ขั้นตอนการทำงานทั่วไป

### การเปรียบเทียบก่อน / หลัง

1. เลือก **RAW (Original)** และสังเกตปรากฏการณ์ vignetting และค่าที่ยังไม่ได้รับการปรับเทียบ
2. เปลี่ยนไปใช้ **RAW (Reflectance)**

3. เปรียบเทียบ — วิเนตติ้งถูกลบออก ค่าถูกปรับเทียบแล้ว ซูมและแพนจะคงที่ เพื่อให้คุณกำลังดูพื้นที่เดียวกัน

### ตรวจสอบดัชนีเดียวในชุดภาพทั้งหมด

1. เปิดภาพที่ผ่านการประมวลผลภาพแรกและเลือกชั้นดัชนี
2. กด **→** ซ้ำๆ — ชั้นดัชนีจะติดตามคุณจากภาพหนึ่งไปยังภาพถัดไป
3. สังเกตฮิสโตแกรมในแถบด้านข้างขณะดำเนินการ: ภาพที่มีการกระจายค่ากระโดดขึ้นลงควรตรวจสอบอย่างละเอียด

### ตรวจสอบเป้าหมายการปรับเทียบ

1. เลือก **RAW (Target)** บนเฟรมเป้าหมาย
2. ตรวจสอบว่าเป้าหมายมองเห็นได้ชัดเจนและถูกตรวจพบ
3. ย้ายไปยังเฟรมเป้าหมายถัดไป — ชั้นเป้าหมายจะตามมา

### ตรวจสอบความแม่นยำของค่าการสะท้อนแสง

1. เลือก **RAW (Reflectance)**

2. อ่านคอลัมน์**%** ในแผง Cursor Values — ค่านี้ถูกปรับสเกลให้ถูกต้องสำหรับไฟล์นั้นแล้ว
3. ตรวจสอบความถูกต้องเทียบกับวัสดุที่รู้จักในเฟรม: พืชพรรณที่สมบูรณ์จะมีค่าNIR

สูงและค่าสีแดงต่ำ; เป้าหมายการปรับเทียบควรมีค่าสะท้อนแสงใกล้เคียงกับค่าที่เผยแพร่

## การแก้ไขปัญหา

### ชั้นที่คาดไว้ไม่ปรากฏในเมนูแบบเลื่อนลง

**สาเหตุที่อาจเกิดขึ้น**

* ภาพยังไม่ได้รับการประมวลผล — มีเพียงชั้นฐานและ `RAW (Original)` เท่านั้น
* ตัวเลือกการส่งออกของผลิตภัณฑ์ถูกยกเลิกการเลือกใน Project Settings
* ผลิตภัณฑ์นี้ไม่เหมาะสมกับกล้องดังกล่าว (radiance และ reflectance บนกล้องมาสเตอร์แบบหลายแถบ (RGB

); ดัชนีใด ๆ บนกล้องโมโน M3M แบบแถบเดียว)
* การปรับเทียบการสะท้อนไม่มีข้อมูลที่จะทำงาน — ไม่มีข้อมูลการครอบคลุมแสงลง (downwelling coverage) ของ `.daq` และไม่มีเป้าหมายในเฟรมที่ผ่านการตรวจสอบคุณภาพ (QA) — ดังนั้นเฟรมจึงกลับไปใช้ Vignette Corrected หรือ Sensor Response

**วิธีแก้ไข**

1. ตรวจสอบบันทึกการทำงาน:Chloros

จะแสดงเมื่อผลิตภัณฑ์ส่งออกที่ขอไม่สามารถสร้างได้และเหตุผล
2. ตรวจสอบสวิตช์ส่งออกตามผลิตภัณฑ์ใน [Project Settings](../project-settings/project-settings.md)
3. ตรวจสอบว่าโฟลเดอร์ผลิตภัณฑ์มีอยู่ในโครงสร้างผลลัพธ์ของโครงการหรือไม่
4. ประมวลผลใหม่โดยเปิดใช้งานผลิตภัณฑ์นั้น

### รายการเลเยอร์ดูเหมือนไม่ทันสมัย

Chloros

จะสแกนโฟลเดอร์ผลิตภัณฑ์ของโครงการใหม่ระหว่างที่การรันกำลังดำเนินอยู่ และแก้ไขการลงทะเบียนเลเยอร์ที่ขาดหายไปจากข้อมูลที่จริงบนดิสก์ ดังนั้น เลเยอร์ที่ส่งออกเสร็จสิ้นแล้วจะปรากฏขึ้นเองในรอบการตรวจสอบ การสลับออกจากภาพแล้วกลับมาจะบังคับให้มีการแก้ไขใหม่

### ค่าการสะท้อนแสงดูเหมือนเป็นครึ่งหนึ่งของค่าที่ควรจะเป็น

คุณกำลังแบ่งไฟล์ LATTICE ด้วย 65535 อย่างแน่นอน ใช้ `Chloros:PixelScale` (32768) หรืออ่านคอลัมน์ **%** ซึ่งได้ปรับค่านี้แล้ว

### ชั้นดัชนีมีอยู่ แต่ภาพเป็นสีขาว

ดัชนีต้องการแถบความยาวคลื่นที่ชั้นของคุณไม่มี — เช่น ดัชนีที่อ่านช่องสัญญาณที่สาม แต่ถูกนำไปใช้กับไฟล์ที่มีหนึ่งหรือสองช่องสัญญาณ ให้เปลี่ยนไปใช้ชั้นหลายแถบ (ชั้นสะท้อนแสงหรือชั้นที่แยกช่องสัญญาณแล้ว) หรือเลือกดัชนีที่เหมาะกับฟิลเตอร์ของกล้อง
