# DAQ Light Sensors

> **กำลังหาอุปกรณ์ฮาร์ดแวร์อยู่ใช่ไหม?**ข้อมูลเกี่ยวกับเซ็นเซอร์เอง — รวมถึงรุ่น วิธีการติดตั้ง ฝาปิด พอร์ต แหล่งจ่ายไฟ และแอป SCANNER — ได้รับการบันทึกไว้ใน**[คู่มือผู้ใช้ DAQ](https://mapir.gitbook.io/daq)**. บทนี้อธิบายวิธีการใช้งานจาก Chloros.**DAQ** light sensors ของ

MAPIRวัดแสงรอบตัวในรูปแบบสเปกตรัมที่ได้รับการปรับเทียบทางรังสีวิทยา ใน Chloros พวกมันมีบทบาทสองอย่าง:

* **เครื่องมือวัดสเปกตรัมแบบสแตนด์อโลน** — แผนภูมิสเปกตรัมแบบเรียลไทม์ ข้อมูลสี และการบันทึก `.daq` ทั้งหมดจาก [แท็บ Light Sensors](gui.md), [CLI](cli-quick-start.md), หรือ Python SDK
* **แหล่งความเข้มแสงลงสำหรับค่าสะท้อน** — ระหว่างการประมวลผล, Chloros จะทำการแทรกค่าการอ่าน `.daq` ของคุณเข้ากับเวลาการเปิดรับแสงของแต่ละการถ่ายภาพ และใช้แสงลงที่วัดได้เพื่อแปลงความส่องสว่างของกล้องเป็นค่าสะท้อน (`--reflectance-source daq`) โดยไม่จำเป็นต้องใช้แผงในฉากสำหรับแถบที่ได้รับการปรับเทียบ

## สามรุ่น, รูปแบบข้อมูลเดียว

| รุ่น | การส่งข้อมูล | การค้นพบ |
| --- | --- | --- |
| **DAQ-U** | USB (ซีเรียล) | สแกนพอร์ตซีเรียล |
| **DAQ-M** | Bluetooth Low Energy | สแกน BLE ตามชื่อ |
| **DAQ-E** | Ethernet (IPv4, PoE-powered) | mDNS `_daq-e._tcp` (hostname `daq-e-<id>.local`) |

ทั้งสามรุ่นใช้โปรโตคอลการสื่อสารผ่านสายเดียวกันและส่งข้อมูลที่เหมือนกัน:

* **สเปกตรัม 135 จุด จาก 340 ถึง 1010 นาโนเมตร ด้วยระยะ 5 นาโนเมตร** พร้อมค่า tristimulus CIE XYZ ในทุกเฟรม
* **ความเข้มรังสีสเปกตรัมที่ผ่านการสอบเทียบทางรังสีวัดในหน่วย W/m²/nm** — ชุดข้อมูลการสอบเทียบจากโรงงานของแต่ละอุปกรณ์ (รวมถึงโปรไฟล์การปรับแก้ cap ที่ใช้งานอยู่) จะถูกนำไปใช้ก่อนที่ข้อมูลจะส่งถึงคุณ
* **รูปแบบการบันทึก `.daq`** ที่เดียวกัน (ไฟล์ SQLite) การประมวลผลต่อจากนั้นจะเหมือนกันไม่ว่าไฟล์ดังกล่าวถูกสร้างขึ้นจากระบบส่งข้อมูลใด

ชุดโปรโตคอลการส่งข้อมูล (USB serial, BLE, mDNS/zeroconf) ถูกรวมไว้ในส่วนหลัง (backend) ของ Chloros — ไม่จำเป็นต้องติดตั้งอะไรเพิ่มเติมเพื่อสื่อสารกับทั้งสามรุ่นผ่าน GUI หรือคำสั่ง `pool-*` ของ CLI

***

## ช่วงที่ได้รับการปรับเทียบ: รายงาน 340–1010 nm, ปรับเทียบ ~374–974 nm

เซ็นเซอร์รายงานช่วงเต็ม 340–1010 nm แต่ช่วงการเพิ่มค่าการวัดรังสีที่สามารถตรวจสอบย้อนกลับได้กับ NIST ครอบคลุมประมาณ **374–974 nm** Chloros ปฏิเสธการแบ่งค่าสะท้อนสัมบูรณ์สำหรับแถบความยาวคลื่นของกล้องใดก็ตามที่มีน้ำหนักสเปกตรัมน้อยกว่าครึ่งหนึ่งภายในช่วงที่ได้รับการปรับเทียบนั้น; แถบที่ถูกข้ามไปจะถูกรายงานพร้อมเหตุผลการข้าม `dls-uncalibrated-band-<nm>`.

ในบรรดา SKU ของฟิลเตอร์ LATTICE ที่จัดส่งอยู่ มีเพียง **F988** เท่านั้นที่ได้รับผลกระทบ:

ค่าสะท้อนแสงของ F988 ได้รับการปรับเทียบโดยใช้แผงสะท้อนแสงในฉาก: ช่วงดังกล่าวอยู่นอกช่วงที่ปรับเทียบของเซ็นเซอร์แสง DAQ ดังนั้น Chloros จะใช้ข้อมูลการจับภาพแผงล่าสุดของคุณและเก็บไว้ระหว่างการตรวจวัดแผงครั้งต่อไป

หากการจับภาพ F988 ถูกประมวลผลโดยมีข้อมูล DAQ เท่านั้น Chloros จะปฏิเสธค่าการสะท้อนแสงที่อิงจาก DAQ สำหรับแถบความยาวคลื่นนั้น พร้อมเหตุผลการข้าม `dls-uncalibrated-band-988` — [ขั้นตอนการทำงานของแผงสะท้อนแสง](../calibration-targets.md) เป็นเส้นทางที่ได้รับการสนับสนุนสำหรับ F988

***

## รหัสตัวรับสัญญาณ

ทุก DAQ จะรายงานรหัสตัวรับสัญญาณที่เสถียร รูปแบบของรหัสจะแตกต่างกันตามรุ่น:

| รุ่น | รูปแบบรหัส | ตัวอย่าง |
| --- | --- | --- |
| DAQ-U | 5-octet hyphenated | `CB-7C-A8-2E-5F` |
| DAQ-M | 5-octet hyphenated | `CB-74-02-30-6B` |
| DAQ-E | `daq-e-<6 hex digits>` | `daq-e-def330` |

ID ของเซ็นเซอร์คือ:

* ถูกบันทึกไว้ในทุกไฟล์ `.daq` ที่มันบันทึก,
* เป็นคีย์ที่ Chloros ใช้เพื่อดึงชุดข้อมูลการปรับเทียบจากโรงงานของอุปกรณ์นั้น,
* ค่าที่คุณส่งไปยัง `--sensor-id` ในคำสั่ง `pool-*` ของ CLI, และ
* สำหรับ DAQ-E ยังรวมถึงชื่อโฮสต์ mDNS ของมัน (`daq-e-def330.local`) — ค่าที่ `--eth-host` รับได้

***

## การสอบเทียบจากโรงงานและระบบคลาวด์

ทุกหน่วย DAQ ได้รับการปรับเทียบจากโรงงานอย่างเป็นรายบุคคลด้วยห่วงโซ่การวัดรังสีที่สามารถตรวจสอบย้อนกลับได้ถึง NIST และ Chloros จะโหลดชุดข้อมูลการปรับเทียบของแต่ละหน่วยโดยใช้ ID ของเซ็นเซอร์เป็นกุญแจ รายงานการปรับเทียบต่อหน่วย (PDF) สามารถดาวน์โหลดได้จากส่วนตั้งค่าของเซ็นเซอร์ใน [แท็บ Light Sensors](gui.md)

{% hint style="warning" %}
**DAQ-U และ DAQ-M จำเป็นต้องมีการเข้าถึงคลาวด์เพื่อทำการปรับเทียบ**ทั้งสองรุ่นไม่เก็บข้อมูลใดๆ บนอุปกรณ์: ชุดข้อมูลการปรับเทียบจากโรงงานถูกเก็บไว้ในคลาวด์ของ MAPIR และถูกดึงมาโดยใช้ ID ของเซ็นเซอร์ (จากนั้นถูกเก็บไว้ในแคชท้องถิ่น) Chloros จำเป็นต้องมีการเชื่อมต่ออินเทอร์เน็ตเพื่อส่งข้อมูล W/m²/nm ที่ผ่านการปรับเทียบจาก DAQ-U หรือ DAQ-M**DAQ-E เป็นข้อยกเว้น** — อุปกรณ์นี้เก็บข้อมูลการปรับเทียบไว้ภายในตัวเครื่อง
{% endhint %}

## สถานที่จัดเก็บข้อมูลบันทึก

| พื้นผิว | จุดหมายปลายทางเริ่มต้นของ `.daq` |
| --- | --- |
| GUI — แท็บ Light Sensors | `<project folder>/light_sensor/` (ข้อมูลที่บันทึกเสร็จแล้วจะถูกเพิ่มเข้าไปในโครงการอัตโนมัติ) |
| CLI — `daq pool-record` | `~/Documents/DAQ Live View/` บนเครื่องที่รันแบ็กเอนด์ |

ทุกชื่อไฟล์ `.daq` จะประกอบด้วย ID ของเซ็นเซอร์และเวลาประทับ
