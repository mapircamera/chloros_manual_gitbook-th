# DAQ Light Sensors

> **กำลังหาอุปกรณ์ฮาร์ดแวร์อยู่ใช่ไหม?**ข้อมูลเกี่ยวกับเซ็นเซอร์เอง — รุ่น, วิธีติดตั้ง, ฝาปิด, พอร์ต, แหล่งจ่ายไฟ และแอป SCANNER — ได้รับการบันทึกไว้ใน**[คู่มือผู้ใช้ DAQ](https://mapir.gitbook.io/daq)**. บทนี้อธิบายวิธีการใช้งานจากChloros เซ็นเซอร์แสง**DAQ** ของ

MAPIR วัดแสงรอบตัวในรูปแบบสเปกตรัมที่ได้รับการปรับเทียบทางรังสีวิทยา ในChloros เซ็นเซอร์เหล่านี้มีสองบทบาท:

* **อุปกรณ์วัดสเปกตรัมแบบอิสระ** — แผนภูมิสเปกตรัมแบบเรียลไทม์ ข้อมูลสี และการบันทึก `.daq` ทั้งหมดจาก [แท็บ Light Sensors](gui.md), [CLI](cli-quick-start.md), หรือ Python SDK
* **แหล่งความส่องลง (downwelling-irradiance) สำหรับค่าสะท้อน** — ระหว่างการประมวลผล, Chloros จะทำการแทรกค่าการอ่าน `.daq` ของคุณเข้ากับเวลาการเปิดรับแสงของแต่ละการถ่ายภาพ และใช้แสงที่ส่องลงที่วัดได้เพื่อแปลงความส่องสว่างของกล้องเป็นค่าการสะท้อน (`--reflectance-source daq`) โดยไม่จำเป็นต้องใช้แผงในฉากสำหรับแถบที่ได้รับการปรับเทียบ

## สามรุ่น หนึ่งรูปแบบข้อมูล

| รุ่น | การส่งข้อมูล | การค้นพบ |
| --- | --- | --- |
| **DAQ-U** | USB (ซีเรียล) | สแกนพอร์ตซีเรียล |
| **DAQ-M** | Bluetooth Low Energy | สแกน BLE ตามชื่อ |
| **DAQ-E** | Ethernet (IPv4, PoE-powered) | mDNS `_daq-e._tcp` (hostname `daq-e-<id>.local`) |**DAQ-E-S (ใหม่ในเวอร์ชัน 1.3.0).** DAQ-E ที่มาพร้อมตัวกระจายแสงแบบถาวรและเซ็นเซอร์วัดมุมเอียง Chloros ระบุอุปกรณ์นี้ด้วยรหัส `DAQ-E-S` และทำงานเหมือนกับ DAQ-E ทุกประการ ยกเว้นว่าไม่มีการปรับค่าความจุ และทุกค่าที่อ่านได้จะรวมข้อมูลมุมเอียง มุมหมุน และมุมก้มของอุปกรณ์ ดู [DAQ-E-S: ตัวกระจายแสงแบบคงที่และเซ็นเซอร์เอียง](caps-and-range.md#daq-e-s-fixed-diffuser-and-tilt).

ทั้งสามรุ่นใช้โปรโตคอลการสื่อสารผ่านสายเดียวกันและส่งข้อมูลที่เหมือนกัน:

* **สเปกตรัม 135 จุด จาก 340 ถึง 1010 นาโนเมตร ด้วยก้าวละ 5 นาโนเมตร** พร้อมค่า tristimulus CIE XYZ ในทุกเฟรม
* **ความเข้มรังสีสเปกตรัมที่ผ่านการสอบเทียบทางรังสีวัดในหน่วย W/m²/nm** — ชุดการสอบเทียบจากโรงงานของแต่ละหน่วย (รวมถึงโปรไฟล์การแก้ไข cap ที่ใช้งานอยู่) จะถูกนำไปใช้ก่อนที่ข้อมูลจะถึงมือคุณ
* **รูปแบบการบันทึก `.daq`** ที่เดียวกัน (ไฟล์ SQLite) การประมวลผลต่อจากนั้นจะเหมือนกันไม่ว่าไฟล์นั้นถูกสร้างขึ้นจากระบบส่งข้อมูลใด

ชุดโปรโตคอลการส่งข้อมูล (USB serial, BLE, mDNS/zeroconf) ถูกรวมไว้ในระบบหลังบ้านของChloros — ไม่จำเป็นต้องติดตั้งอะไรเพิ่มเติมเพื่อสื่อสารกับทั้งสามรุ่นผ่าน GUI หรือคำสั่ง `pool-*` ของCLI

***

## ช่วงที่ได้รับการปรับเทียบ: รายงาน 340–1010 nm, ปรับเทียบ ~374–974 nm

เซ็นเซอร์รายงานช่วงเต็ม 340–1010 nm แต่ช่วงการขยายสัญญาณรังสีที่สามารถตรวจสอบย้อนกลับได้กับ NIST ครอบคลุมประมาณ **374–974 nm** Chloros จะปฏิเสธการแบ่งค่าสะท้อนสัมบูรณ์สำหรับแถบคลื่นของกล้องใดก็ตามที่มีน้ำหนักสเปกตรัมภายในช่วงที่ได้รับการปรับเทียบนั้นน้อยกว่าครึ่งหนึ่ง; แถบที่ถูกข้ามไปจะถูกรายงานพร้อมเหตุผลการข้าม `dls-uncalibrated-band-<nm>`.

ในบรรดา SKU ของฟิลเตอร์ LATTICE ที่จัดส่งอยู่ มีเพียง **F988** เท่านั้นที่ได้รับผลกระทบ:

ค่าการสะท้อนของ F988 ได้รับการปรับเทียบโดยใช้แผงวัดการสะท้อนในฉาก: ช่วงความยาวคลื่นนี้อยู่นอกช่วงที่ปรับเทียบของเซ็นเซอร์แสง DAQ ดังนั้นChloros จึงใช้ข้อมูลการจับภาพแผงล่าสุดของคุณและเก็บไว้ระหว่างการวัดแผงแต่ละครั้ง

หากการจับภาพ F988 ถูกประมวลผลโดยมีข้อมูล DAQ เท่านั้นที่พร้อมใช้งานChloros จะปฏิเสธค่าการสะท้อนแสงที่อิงจาก DAQ สำหรับแถบนั้น พร้อมเหตุผลการข้าม `dls-uncalibrated-band-988` — [ขั้นตอนการทำงานของแผงสะท้อนแสง](../calibration-targets.md) เป็นขั้นตอนที่ได้รับการสนับสนุนสำหรับ F988

## รหัสประจำตัวเซ็นเซอร์

ทุก DAQ รายงาน ID เซนเซอร์ที่เสถียร รูปแบบของ ID แตกต่างกันตามรุ่น:

| รุ่น | รูปแบบ ID | ตัวอย่าง |
| --- | --- | --- |
| DAQ-U | 5-octet hyphenated | `CB-7C-A8-2E-5F` |
| DAQ-M | 5-octet hyphenated | `CB-74-02-30-6B` |
| DAQ-E | `daq-e-<6 hex digits>` | `daq-e-def330` |

ID ของเซ็นเซอร์คือ:

* ถูกบันทึกไว้ในทุกไฟล์ `.daq` ที่มันบันทึก,
* เป็นกุญแจที่Chloros ใช้เพื่อดาวน์โหลดชุดการปรับเทียบจากโรงงานของอุปกรณ์นั้น,
* ค่าที่คุณส่งไปยัง `--sensor-id` ในคำสั่งCLI `pool-*`, และ
* สำหรับ DAQ-E ยังเป็นชื่อโฮสต์ mDNS ของมัน (`daq-e-def330.local`) — ค่าที่ `--eth-host` รับได้

## การปรับเทียบจากโรงงานและระบบคลาวด์

ทุกหน่วย DAQ ได้รับการปรับเทียบจากโรงงานอย่างเป็นรายบุคคลด้วยห่วงโซ่การวัดรังสีที่สามารถตรวจสอบย้อนกลับได้ถึง NIST และChloros จะโหลดชุดข้อมูลการปรับเทียบของแต่ละหน่วยโดยใช้ ID ของเซ็นเซอร์เป็นกุญแจ รายงานการปรับเทียบต่อหน่วย (PDF) สามารถดาวน์โหลดได้จากส่วนตั้งค่าของเซ็นเซอร์ใน [แท็บ Light Sensors](gui.md)

{% hint style="warning" %}
**DAQ-U และ DAQ-M จำเป็นต้องมีการเข้าถึงคลาวด์เพื่อทำการปรับเทียบ**ทั้งสองรุ่นไม่เก็บข้อมูลใดๆ บนอุปกรณ์: ชุดข้อมูลการปรับเทียบจากโรงงานถูกเก็บไว้ในคลาวด์ของMAPIR และถูกเรียกมาโดยใช้ ID ของเซ็นเซอร์ (จากนั้นถูกเก็บไว้ในแคชท้องถิ่น) Chloros จำเป็นต้องมีการเชื่อมต่ออินเทอร์เน็ตเพื่อส่งข้อมูล W/m²/nm ที่ได้รับการปรับเทียบจาก DAQ-U หรือ DAQ-M**DAQ-E เป็นข้อยกเว้น** — มันเก็บข้อมูลการปรับเทียบไว้บนอุปกรณ์
{% endhint %}

## สถานที่บันทึกข้อมูล

| พื้นผิว | จุดหมายปลายทาง `.daq` ตามค่าเริ่มต้น |
| --- | --- |
| GUI — แท็บ Light Sensors | `<project folder>/light_sensor/` (ข้อมูลที่บันทึกเสร็จแล้วจะถูกเพิ่มเข้าไปในโครงการอัตโนมัติ) |
| CLI — `daq pool-record` | `~/Documents/DAQ Live View/` บนเครื่องที่รันแบ็กเอนด์ (`-o` แบบสัมพัทธ์จะชี้ไปยังโฟลเดอร์ที่คุณรันคำสั่งเมื่อ backend อยู่ในเครื่องเดียวกัน) |

ทุกชื่อไฟล์ `.daq` จะประกอบด้วย ID ของเซ็นเซอร์และเวลาบันทึก
