# โปรไฟล์แคปและช่วงการปรับเทียบ

> ตัวฝาครอบเอง — รวมถึงฝาครอบใดที่มาพร้อมกับเซ็นเซอร์ใด วิธีการติดตั้ง และพฤติกรรมทางแสง — ได้รับการบันทึกไว้ใน **[คู่มือผู้ใช้ DAQ](https://mapir.gitbook.io/daq)** หน้านี้อธิบายถึงการ *ประกาศ* ฝาครอบที่ติดตั้งไว้ให้กับChloros

ซึ่งเป็นขั้นตอนที่ทำให้การปรับแก้ถูกต้อง

การปรับเทียบรังสีจากโรงงานของเซ็นเซอร์แสง DAQ ทุกตัวอธิบายถึงเซ็นเซอร์ *เปล่า* (ไม่ติดฝาครอบ) ฝาครอบที่ติดตั้งบนตัวกระจายแสงจะเปลี่ยนประเภทแสงที่เซ็นเซอร์รับได้ ดังนั้นChloros

จึงนำ **โปรไฟล์การปรับแก้ฝาครอบ** ที่วัดจากโรงงานมาใช้เพิ่มเติมบนชุดข้อมูลการปรับเทียบ การระบุฝาครอบที่ถูกต้องเป็นส่วนหนึ่งของการได้รับข้อมูลที่ผ่านการปรับเทียบ — หน้านี้อธิบายว่ามีฝาครอบแบบใดสำหรับแต่ละรุ่น วิธีการระบุ และช่วงสเปกตรัมที่ผ่านการปรับเทียบของเซ็นเซอร์นั้นเป็นอย่างไร

## ความพร้อมใช้งานของฝาครอบตามรุ่น

| โปรไฟล์ฝาครอบ (`cap_id`) | ฝาครอบทางกายภาพ | DAQ-U | DAQ-M | DAQ-E |
| --- | --- | --- | --- | --- |
| `sunshine_cosine` | ฝาครอบแก้ไขโคไซน์แสงแดด (**ค่าเริ่มต้นสำหรับทุกรุ่น**) | มี | มี | มี |
| `fov_15` / `fov_45` / `fov_90` | กรวยจำกัดมุมมอง (15° / 45° / 90°) | มี | — | ใช่ |
| `fov_30` / `fov_60` | กรวยจำกัดมุมมอง (30° / 60°) | ใช่ | — | — |
| `none` | ไม่มีฝาครอบ | — | — | มี |

หมายเหตุเฉพาะรุ่น:

* **DAQ-M มีโปรไฟล์ฝาครอบเพียงแบบเดียว: `sunshine_cosine`.** การกำหนดผลิตภัณฑ์คือ &quot;ตัวเปล่า + ฝา Sunshine&quot; และ DAQ-M ตัวเปล่าไม่ต้องการโปรไฟล์เรขาคณิต
* **DAQ-U ตัวเปล่าคือตัวเปล่าจริง** — ไม่ต้องการโปรไฟล์เรขาคณิตเลย ซึ่งเป็นเหตุผลที่ไม่มีโปรไฟล์ `none` สำหรับรุ่นนี้
* **`none` บน DAQ-E ไม่ใช่ no-op** ตัวกระจายแสงแบบเว้าที่ปิดด้วยกระจกของ DAQ-E มีการแก้ไขเรขาคณิตจริงของตัวเอง ดังนั้น &quot;ไม่มีฝาครอบ&quot; จึงเป็นโปรไฟล์ที่วัดได้บนรุ่นนี้
* **DAQ-E ที่ไม่มีฝาครอบไม่สามารถวัดแสงแดดโดยตรงได้ในทุกมุมสูง** — ฝาครอบ Sunshine คือการตั้งค่าในสนามจริง อย่าวางแผนงานกลางแจ้งโดยใช้ DAQ-E ที่ไม่มีฝาครอบ

ในตั้งค่าต่อเซ็นเซอร์ของ GUI (ไอคอนรูปเกียร์ในแท็บ Light Sensors) เมนูแบบเลื่อนลง **Cap** ยังเสนอตัวเลือก &quot;None (bare sensor)&quot; สำหรับ DAQ-U และ DAQ-M — สำหรับสองรุ่นนี้ &quot;bare&quot; หมายความว่าไม่มีการปรับแก้จากฝาครอบ ตามที่ระบุไว้ข้างต้น เลือกตัวเลือกนี้เฉพาะเมื่อฝาครอบถูกถอดออกทางกายภาพแล้ว

## การกำหนดสถานะของฝาครอบ — และเหตุผลที่มันสำคัญ

**ค่า `cap_id` ที่กำหนดต้องตรงกับฝาครอบที่ติดตั้งอยู่บนเซ็นเซอร์ทางกายภาพ** ทั้งเซ็นเซอร์และซอฟต์แวร์ไม่สามารถตรวจจับตัวแคปที่ติดตั้งได้ การกำหนดค่านี้ส่งผลต่อสองสิ่ง:

1. **การปรับแก้แบบเรียลไทม์** ที่ถูกนำไปใช้กับสเปกตรัมทุกชุด
2. **ข้อมูลตัวแคปที่ถูกบันทึกไว้ในทุกการบันทึก `.daq`** ซึ่งกระบวนการประมวลผลการสะท้อนแสงในขั้นตอนต่อไปจะอ้างอิงข้อมูลนี้

ฝา Sunshine มีค่าการลดทอนตามการออกแบบประมาณ **12×** ดังนั้น การบันทึกโดยระบุฝาผิดจะทำให้สเปกตรัมถูกปรับสเกลผิดพลาดตามปัจจัยดังกล่าวทันที ให้ระบุการเปลี่ยนแปลงฝาทันที

### การตั้งค่าฝา

GUI: แท็บ Light Sensors → ไอคอนรูปเฟืองบนแถวเซ็นเซอร์ → เมนูแบบเลื่อนลง **Cap** ค่าเริ่มต้นสำหรับทุกรุ่นคือ `sunshine_cosine` (เซ็นเซอร์ DAQ ทุกตัวมาพร้อมตัวปรับแก้โคไซน์ติดตั้งไว้แล้ว) และการเลือกนี้จะคงอยู่ตลอดโครงการ



CLI<!-- SCREENSHOT-NEEDED: DAQ tab per-sensor settings modal (gear icon) scrolled to the Cap dropdown, open to show the per-model choices with "Sunshine (cosine corrector)" selected. Use a connected DAQ-E so the Hostname/Firmware/PTP rows are also visible above it. -->

## ประสิทธิภาพของ Sunshine cap (การตั้งค่าสำหรับใช้งานกลางแจ้ง)

ข้อมูลที่สามารถใช้เป็นพื้นฐานในการสร้างขั้นตอนการทำงาน:

| คุณสมบัติ | ค่า |
| --- | --- |
| มุมมอง | 180° ครึ่งทรงกลม |
| ความผิดพลาดในการตอบสนองโคไซน์ | ≤ ±4 % สำหรับมุมตกกระทบถึง 60°; ≤ ±4.5 % สำหรับมุมตกกระทบถึง 70° |
| ขีดจำกัดแสงอาทิตย์ต่ำ | ไม่แนะนำให้ใช้เมื่อมุมสูงของดวงอาทิตย์ต่ำกว่า ~15° |
| การลดทอน | ~12× (ตามการออกแบบ) |
| ความสามารถในการติดตั้งซ้ำของฝาครอบ | ≈ 1.5 % |
| ความเข้มรังสีเชิงปริมาณ | ค่าเฉลี่ย **≥ 15 วินาที** ของการอ่านค่า (เป็นลักษณะเฉพาะของเครื่องมือ ไม่ใช่ข้อบกพร่อง) |

สำหรับค่าความเข้มรังสีเชิงปริมาณใดๆ — รวมถึงข้อมูลอ้างอิงการสะท้อน — ให้ใช้ค่าเฉลี่ยจากการอ่านค่าอย่างน้อย 15 วินาที แทนที่จะใช้ค่าจากเฟรมเดียว

## ช่วงสเปกตรัมที่ได้รับการปรับเทียบ

| คุณสมบัติ | ค่า |
| --- | --- |
| การสุ่มตัวอย่างสเปกตรัม | 340–1010 นาโนเมตร ในขั้นตอนละ 5 นาโนเมตร (135 จุด) |
| ช่วงที่ได้รับการปรับเทียบทางรังสี | **~374–974 nm** (ถูกบังคับใช้ในซอฟต์แวร์) |

เซ็นเซอร์รายงานข้อมูลจากกริดเต็มช่วง 340–1010 nm แต่ค่าการขยายทางรังสีที่ตรวจสอบย้อนกลับได้ถึง NIST ครอบคลุมช่วง ~374–974 nmChloros

**ปฏิเสธการแบ่งค่าสะท้อนสัมบูรณ์** สำหรับแถบความยาวคลื่นของกล้องใดก็ตามที่มีน้ำหนักสเปกตรัมภายในช่วงดังกล่าวน้อยกว่าครึ่งหนึ่ง โดยรายงานเหตุผลการข้ามค่า `dls-uncalibrated-band-<nm>` แทนที่จะสร้างผลลัพธ์ที่ยังไม่ได้รับการปรับเทียบ ในบรรดา SKU ของกล้องที่จัดส่งอยู่ มีเพียงฟิลเตอร์ F988 เท่านั้นที่อยู่นอกช่วงนี้; มันใช้กระบวนการทำงานของแผงสะท้อนแสงแทน — ดู [กระบวนการทำงานของแผงสะท้อนแสง](reflectance.md).

สำหรับรุ่นเซ็นเซอร์, ระบบขนส่ง และ ID เซ็นเซอร์ ดู [ภาพรวม DAQ](README.md) สำหรับวิธีการใช้ cap stamp ระหว่างการประมวลผล ดู [การบันทึกและรูปแบบ .daq](recording.md)
