# โปรไฟล์แคปและช่วงการปรับเทียบ

> ฝาครอบเอง — รวมถึงข้อมูลว่าฝาครอบใดมาพร้อมกับเซ็นเซอร์ใด วิธีการติดตั้ง และพฤติกรรมทางแสง — ได้รับการบันทึกไว้ใน **[คู่มือผู้ใช้ DAQ](https://mapir.gitbook.io/daq)** หน้านี้อธิบายถึงการ *แจ้ง* ฝาครอบที่ติดตั้งไว้ให้กับChloros
ซึ่งเป็นขั้นตอนที่ทำให้การปรับแก้ถูกต้อง

การปรับเทียบรังสีจากโรงงานของเซ็นเซอร์แสง DAQ ทุกตัวอธิบายถึงเซ็นเซอร์ *ในสภาพเปล่า* ฝาครอบทางกายภาพที่ติดตั้งบนตัวกระจายแสงจะเปลี่ยนประเภทแสงที่เซ็นเซอร์รับได้ ดังนั้นChloros
จึงนำ **โปรไฟล์การปรับแก้ฝาครอบ** ที่วัดจากโรงงานมาใช้เพิ่มเติมบนชุดข้อมูลการปรับเทียบ การระบุฝาครอบที่ถูกต้องเป็นส่วนหนึ่งของการได้รับข้อมูลที่ผ่านการปรับเทียบ — หน้านี้อธิบายว่ามีฝาครอบแบบใดสำหรับแต่ละรุ่น วิธีระบุฝาครอบ และช่วงสเปกตรัมที่ผ่านการปรับเทียบของเซ็นเซอร์นั้นเป็นอย่างไร

## ความพร้อมใช้งานของฝาครอบตามรุ่น

| โปรไฟล์ฝาครอบ (`cap_id`) | ฝาครอบทางกายภาพ | DAQ-U | DAQ-M | DAQ-E |
| --- | --- | --- | --- | --- |
| `sunshine_cosine` | ฝาครอบแก้ไขโคไซน์แสงแดด (**ค่าเริ่มต้นสำหรับทุกรุ่น**) | ใช่ | ใช่ | ใช่ |
| `fov_15` / `fov_45` / `fov_90` | กรวยจำกัดมุมมอง (15° / 45° / 90°) | มี | — | ใช่ |
| `fov_30` / `fov_60` | กรวยจำกัดมุมมอง (30° / 60°) | ใช่ | — | — |
| `none` | ไม่มีฝาครอบ | — | — | มี |

หมายเหตุเฉพาะรุ่น:

* **DAQ-M มีโปรไฟล์ฝาครอบเพียงแบบเดียว: `sunshine_cosine`.** การกำหนดผลิตภัณฑ์คือ &quot;ตัวเปล่า + ฝา Sunshine&quot; และ DAQ-M ตัวเปล่าไม่ต้องการโปรไฟล์เรขาคณิต
* **DAQ-U ตัวเปล่าคือตัวเปล่าจริง** — ไม่ต้องการโปรไฟล์เรขาคณิตเลย ซึ่งเป็นเหตุผลที่ไม่มีโปรไฟล์ `none` สำหรับรุ่นนี้
* **`none` บน DAQ-E ไม่ใช่ no-op** ตัวกระจายแสงแบบเว้าที่ปิดด้วยกระจกของ DAQ-E มีการแก้ไขเรขาคณิตจริงในตัว ดังนั้น &quot;no cap&quot; เองจึงเป็นโปรไฟล์ที่วัดได้บนรุ่นนี้
* **DAQ-E ที่ไม่มีฝาครอบไม่สามารถวัดแสงแดดโดยตรงได้ไม่ว่าที่มุมสูงใด** — ฝาครอบ Sunshine คือการตั้งค่าในสนามจริง อย่าวางแผนทำงานกลางแจ้งโดยใช้ DAQ-E ที่ไม่มีฝาครอบ

ในตั้งค่าต่อเซ็นเซอร์ของ GUI (ไอคอนรูปเกียร์ในแท็บ Light Sensors) เมนูแบบเลื่อนลง **Cap** ยังเสนอตัวเลือก &quot;None (bare sensor)&quot; สำหรับ DAQ-U และ DAQ-M — สำหรับสองรุ่นนี้ &quot;bare&quot; หมายถึงเพียงว่าไม่มีการปรับแก้จากฝาครอบ ตามหมายเหตุด้านบน เลือกตัวเลือกนี้เฉพาะเมื่อฝาครอบถูกถอดออกทางกายภาพแล้ว

## การระบุฝาครอบ — และเหตุผลที่มันสำคัญ

**ค่า `cap_id` ที่ระบุต้องตรงกับฝาครอบที่ติดตั้งอยู่บนเซ็นเซอร์ทางกายภาพ** ทั้งเซ็นเซอร์และซอฟต์แวร์ไม่สามารถตรวจจับตัวแคปที่ติดตั้งได้ การกำหนดค่านี้ส่งผลต่อสองสิ่ง:

1. **การปรับแก้แบบเรียลไทม์** ที่ถูกนำไปใช้กับสเปกตรัมทุกชุด
2. **ข้อมูลตัวแคปที่ถูกบันทึกไว้ในทุกการบันทึก `.daq`** ซึ่งกระบวนการประมวลผลการสะท้อนแสงในขั้นตอนต่อไปจะอ้างอิงข้อมูลนี้

ฝา Sunshine มีค่าการลดทอนตามการออกแบบประมาณ **12×** ดังนั้น การบันทึกข้อมูลโดยระบุฝาผิดจะทำให้สเปกตรัมถูกปรับสเกลผิดพลาดตามปัจจัยดังกล่าวทันที ให้ระบุการเปลี่ยนแปลงฝาทันที

### การตั้งค่าฝา

GUI: แท็บ Light Sensors → ไอคอนรูปเกียร์บนแถวเซ็นเซอร์ → เมนูแบบเลื่อนลง **Cap** ค่าเริ่มต้นสำหรับทุกรุ่นคือ `sunshine_cosine` ซึ่งเป็นสมมติฐาน (DAQ-U, DAQ-M และ DAQ-E มาพร้อมโดยไม่มีการตั้งค่า cap และการบันทึกจะระบุว่า cap ถูกสมมติไว้จนกว่าคุณจะเลือกค่าหนึ่ง) และการเลือกนี้จะคงอยู่ตลอดโครงการ



CLI<!-- SCREENSHOT-NEEDED: DAQ tab per-sensor settings modal (gear icon) scrolled to the Cap dropdown, open to show the per-model choices with "Sunshine (cosine corrector)" selected. Use a connected DAQ-E so the Hostname/Firmware/PTP rows are also visible above it. -->
(ระบบหลังต้องกำลังทำงาน):

```bash

# Swap at runtime (after physically changing the cap)
chloros-cli daq pool-set-cap --sensor-id daq-e-def330 --cap-id fov_45
```

CLI

ขั้นสูง: โปรไฟล์ถูกส่งมาภายในติดตั้งChloros
ที่ `daq/cap_profiles/<u|m|e>/<cap_id>.json` และสามารถถูกแทนที่ตามผู้ใช้ได้ที่ `~/.chloros/daq_cap_profiles/<u|m|e>/<cap_id>.json`.

นอกเหนือจากค่าจำกัดแล้ว เซนเซอร์ที่ยังไม่เคยถูกปรับเทียบใหม่จะได้รับการปรับปรุงค่าออฟเซ็ตมืดเล็กน้อยที่คำนวณจากข้อมูลของกลุ่มอุปกรณ์ — โดยไม่จำเป็นต้องมีการดำเนินการจากผู้ใช้

## DAQ-E-S: ตัวกระจายแสงและมุมเอียงคงที่

**DAQ-E-S** เป็น DAQ-E ที่มีสองจุดแตกต่างสำคัญต่อChloros
ส่วนอื่น ๆ (การค้นพบ, การเชื่อมต่อ, PTP, การบันทึก, การตั้งค่าอุปกรณ์) ทำงานเหมือน DAQ-E ทุกประการ

* **ดิฟฟิวเซอร์ของมันเป็นแบบถาวร จึงไม่ต้องการการปรับแก้ค่าแคป** ดิฟฟิวเซอร์ถูกติดตั้งบนอุปกรณ์เมื่อทำการวัดการปรับเทียบจากโรงงาน ดังนั้นการปรับเทียบดังกล่าวจึงแสดงค่าความเข้มแสงที่ตกกระทบจริงแล้วChloros
ไม่ใช้โปรไฟล์การจำกัดค่าสูงสุดกับมันไม่ว่าจะมีการร้องขออย่างไร: การจำกัดค่าสูงสุดที่ตั้งชื่อสำหรับมันจะถูกเพิกเฉยพร้อมข้อความแจ้งเตือน การบันทึกข้อมูลจะระบุว่าค่าจำกัดนั้นมาจากโมเดล และคำเตือนเกี่ยวกับการสมมติค่าจำกัดจะไม่ปรากฏขึ้นสำหรับมัน ใน Project Settings → DAQ Light Sensor แถวของมันไม่แสดง cap และการแทนที่ cap ระดับโครงการทั้งหมดไม่ส่งผลต่อมัน อย่าใช้ cap กับข้อมูลของมันด้วยมือ: การแก้ไข Sunshine ที่อยู่ด้านบนจะแสดงค่าสูงประมาณ 11 เท่า
* **มันมีเครื่องวัดความเร่ง 3 แกน** การตอบสนองแบบโคไซน์ของตัวกระจายแสงมีผลเฉพาะเมื่ออยู่ในระดับราบเท่านั้น ดังนั้นเซ็นเซอร์ที่เอียงจะรายงานค่าความเข้มของแสงผิดพลาดโดยไม่มีอาการอื่นใด ดังนั้นการอ่านค่า DAQ-E-S แต่ละครั้งจึงมีข้อมูลการเอียง (tilt), การหมุน (roll) และการก้ม (pitch) ของมัน และข้อมูลที่บันทึกจาก `.daq` จะเก็บข้อมูลเหล่านี้ไว้ข้างๆ ทุกสเปกตรัม (`imu_tilt_deg`, `imu_roll_deg`, `imu_pitch_deg`, …), ทำให้คุณสามารถแยกแยะระหว่างเมฆกับฐานติดตั้งที่เอียงได้

สำหรับทุกฟิลด์ท่าทางและวิธีการรายงานข้อผิดพลาดในสตรีมท่าทาง ดู [DAQ-E-S ในคู่มืออ้างอิงCLI
](../reference/cli-reference.md#daq-e-s--fixed-diffuser-and-tilt-sensor).

## ประสิทธิภาพของ Sunshine cap (การตั้งค่ากลางแจ้ง)

ค่าที่สามารถใช้เป็นพื้นฐานในการสร้างขั้นตอนการทำงาน:

| คุณสมบัติ | ค่า |
| --- | --- |
| มุมมอง | 180° ครึ่งทรงกลม |
| ความผิดพลาดในการตอบสนองโคไซน์ | ≤ ±4 % สำหรับมุมตกกระทบถึง 60°; ≤ ±4.5 % สำหรับมุมตกกระทบถึง 70° |
| ขีดจำกัดแสงอาทิตย์ต่ำ | ไม่แนะนำให้ใช้เมื่อมุมสูงของดวงอาทิตย์ต่ำกว่า ~15° |
| การลดทอน | ~12× (ตามการออกแบบ) |
| ความแม่นยำในการติดตั้งซ้ำของฝาครอบ | ≈ 1.5 % |
| ความเข้มรังสีเชิงปริมาณ | ค่าเฉลี่ย **≥ 15 วินาที** ของการอ่านค่า (เป็นลักษณะเฉพาะของเครื่องมือ ไม่ใช่ข้อบกพร่อง) |

สำหรับค่าความเข้มรังสีเชิงปริมาณใดๆ — รวมถึงข้อมูลอ้างอิงการสะท้อนแสง — ให้ใช้ค่าเฉลี่ยของการอ่านค่าอย่างน้อย 15 วินาที แทนที่จะใช้ค่าจากเฟรมเดียว

## ช่วงสเปกตรัมที่ได้รับการปรับเทียบ

| คุณสมบัติ | ค่า |
| --- | --- |
| การสุ่มตัวอย่างสเปกตรัม | 340–1010 nm ในขั้น 5 nm (135 จุด) |
| ช่วงที่ได้รับการปรับเทียบทางรังสี | **~374–974 nm** (ถูกบังคับใช้ในซอฟต์แวร์) |

เซ็นเซอร์รายงานข้อมูลจากกริดเต็มช่วง 340–1010 nm แต่ค่าการขยายทางรังสีที่สามารถตรวจสอบย้อนกลับได้ถึง NIST ครอบคลุมช่วง ~374–974 nm Chloros
**ปฏิเสธการแบ่งตามค่าสะท้อนสัมบูรณ์** สำหรับแถบคลื่นของกล้องใดก็ตามที่มีน้ำหนักสเปกตรัมภายในช่วงดังกล่าวน้อยกว่าครึ่งหนึ่ง โดยจะรายงานเหตุผลการข้ามค่า `dls-uncalibrated-band-<nm>` แทนที่จะสร้างผลลัพธ์ที่ยังไม่ได้รับการปรับเทียบ ในบรรดา SKU ของกล้องที่จัดส่งออก มีเพียงฟิลเตอร์ F988 เท่านั้นที่อยู่นอกช่วงนี้; มันใช้ขั้นตอนการทำงานของแผงสะท้อนแสงแทน — ดู [ขั้นตอนการทำงานของแผงสะท้อนแสง](reflectance.md).

สำหรับรุ่นเซ็นเซอร์, ระบบขนส่ง และ ID เซ็นเซอร์ ดู [ภาพรวม DAQ](README.md) สำหรับวิธีการใช้ cap stamp ระหว่างการประมวลผล ดู [การบันทึกและรูปแบบ .daq](recording.md)
