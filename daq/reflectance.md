# กระบวนการทำงานด้านค่าสะท้อนแสง

เซ็นเซอร์แสง DAQ จะแปลงภาพรังสีเป็นค่าสะท้อนแสง มีสองกระบวนการทำงานที่แตกต่างกัน:

1. **เซ็นเซอร์เดียว** — DAQ หนึ่งตัววัดความเข้มรังสีที่ส่องลง ในขณะที่กล้องถ่ายภาพ และChloros จะแบ่งความสว่างของกล้องด้วยค่าอ้างอิงนั้น
2. **เซ็นเซอร์คู่** — เซ็นเซอร์ DAQ สองตัว โดยตัวหนึ่งวัดท้องฟ้าและอีกตัวหนึ่งวัดวัตถุ สร้างเส้นโค้งการสะท้อนแสงตามสเปกตรัมแบบเรียลไทม์โดยไม่ต้องใช้กล้อง

## เซ็นเซอร์ตัวเดียว + กล้อง (ค่าอ้างอิงแสงลง)

DAQ ทำหน้าที่เป็นเซ็นเซอร์วัดแสงลง (DLS): กล้องถ่ายภาพวัดความส่องสว่างที่ขึ้น **L**(W/m²/sr/nm), DAQ วัดความส่องสว่างที่ลง**E** (W/m²/nm), และChloros คำนวณค่าการสะท้อนแสงต่อแถบความยาวคลื่นตามสูตร:

> ρ = π · L / E

ค่าที่ DAQ อ่านได้จะ **ตรงกับเวลาการเปิดรับแสง** เสมอ — นี่คือเหตุผลที่ DAQ และกล้องใช้สัญญาณนาฬิกาที่ควบคุมด้วย PTP ร่วมกัน (ดู [DAQ-E Networking & Time Sync](ethernet-ptp.md)) ปรับใช้ Sunshine cosine cap สำหรับการทำงานกลางแจ้งและกำหนดค่าให้ถูกต้อง; การกำหนดค่า cap จะปรับขนาด E โดยตรง (ดู [Cap Profiles & Calibrated Range](caps-and-range.md)). สำหรับงานเชิงปริมาณ ให้จำไว้ว่าคุณสมบัติของเครื่องมือคือ: ค่าความเข้มแสงเชิงปริมาณได้มาจากการเฉลี่ยค่าการอ่านอย่างน้อย 15 วินาที

### การจับภาพแบบเรียลไทม์

ผูก DAQ กับกล้องในแท็บ Cameras: แผงตั้งค่าของกล้องแต่ละตัวมีเมนูแบบเลื่อนลง **Light Sensor** ที่แสดงรายการ DAQ ที่เชื่อมต่อทั้งหมด (DAQ-U/M/E) จากแท็บ Light Sensors; สำหรับอาร์เรย์ที่ซิงโครไนซ์ การเลือก Light Sensor สำหรับทั้งอาร์เรย์จะส่งต่อไปยังสมาชิกทุกตัว (กล้องแต่ละตัวสามารถตั้งค่าทับได้) เมื่อเชื่อมต่อแล้ว สเปกตรัมของเซ็นเซอร์จะถูกส่งไปยังช่อง DLS ของกล้อง และค่าการสะท้อนที่ส่งออกจะถูกหารด้วยค่าการอ่านที่ตรงกัน ในอาร์เรย์ สมาชิกที่มีเซ็นเซอร์ของตัวเองจะใช้ค่าอ่านของตัวเอง — สำหรับแถบสเปกตรัมในภาพรวมแบบเรียลไทม์ การส่งออกข้อมูล และการปรับค่าแสงอัตโนมัติ — ส่วนสมาชิกอื่น ๆ จะใช้อาร์เรย์ของอาร์เรย์นั้น

สองพฤติกรรมที่ควรทราบ:

* **ไม่มีการผูกกับ DAQ → ค่าสะท้อนแสงถูกปฏิเสธ ไม่ใช่ถูกสร้างขึ้น** Chloros จะปฏิเสธผลิตภัณฑ์ค่าสะท้อนแสงและบันทึกเหตุผลการข้ามไป แทนที่จะส่งคืนผลิตภัณฑ์ที่มีค่าน้อยลงอย่างเงียบๆ
* **ค่าที่ใช้งานอยู่จะถูกรักษาไว้** สำหรับทุกเฟรมการสะท้อนแสง ค่าการอ่าน DAQ ที่ถูกนำไปใช้จริงจะถูกบันทึกเป็นไฟล์ `.daq` ในโฟลเดอร์ `daq/` ของการจับภาพ ดังนั้นการจับภาพนี้จึงสามารถประมวลผลใหม่ได้ในภายหลัง ([การบันทึกและรูปแบบ .daq](recording.md)). ไฟล์ `.daq.cameras.json` ที่อยู่ข้างๆ จะระบุชื่อกล้องที่มันอธิบาย และเมื่อประมวลผลใหม่ ระบบจะจับคู่กับภาพจากกล้องเหล่านั้นเท่านั้น

### การประมวลผลภาพที่บันทึกไว้

สำหรับการประมวลผลหลังการบิน ให้บันทึกไฟล์ `.daq` ระหว่างเซสชันและเก็บไว้พร้อมกับภาพ — ระบบจะแก้ไขข้อมูลการส่องลงที่ตรงกับเวลาอัตโนมัติ และดึงข้อมูลการปรับเทียบจากโรงงานที่ขาดหายไปจากคลาวด์ของMAPIR เมื่อใช้งานครั้งแรก การบันทึกผ่าน GUI จะถูกเพิ่มเข้าไปในโครงการที่เปิดอยู่โดยอัตโนมัติเมื่อการบันทึกหยุดลง

สามารถเลือกค่าอ้างอิงการสะท้อนแสงได้ขณะประมวลผล — `--reflectance-source` บน `chloros-cli process` หรือการตั้งค่าแหล่งที่มาของการสะท้อนแสงในส่วน Project Settings ของ GUI:

| ค่า | พฤติกรรม |
| --- | --- |
| `auto` (ค่าเริ่มต้น) | เป้าหมายการปรับเทียบในเฟรมที่ผ่านการตรวจสอบคุณภาพ (QA) เป็นค่าอ้างอิงสัมบูรณ์; การปรับเทียบแบบลงสู่พื้น (ρ = π·L/E) จาก DAQ เป็นตัวเลือกสำรอง เป้าหมายที่ผ่านการตรวจสอบคุณภาพ (QA) พร้อมด้วยธงเตือน (เช่น แผงที่หลุดออก หรือแถบที่ผิดปกติ) จะไม่ได้รับการเลือกใช้โดยอัตโนมัติ: ระบบจะลองใช้ลำดับเป้าหมาย, เป้าหมาย+DAQ และ DAQ เท่านั้น ตามลำดับคะแนนที่วัดได้บนแผงที่เก็บไว้ |
| `daq` | DAQ เป็นหลัก |
| `target` | เป้าหมายในเฟรมที่เคร่งครัด; ไม่มีการแทนที่ด้วย DAQ |

ดู [Calibration Targets](../calibration-targets.md) สำหรับขั้นตอนการทำงานของเป้าหมายและ [บท LATTICE](../lattice/README.md) พร้อมทั้ง [คู่มือ CLI](../reference/cli-reference.md) เพื่อดูกระบวนการประมวลผลแบบครบวงจร เมื่ออ่านพิกเซลการสะท้อนที่ส่งออก ให้ใช้มาตราส่วนที่ประทับ (LATTICE: 32768 = ρ 1.0, XMP `Chloros:PixelScale`; Survey3: 65535) — ดู [รูปแบบภาพผลลัพธ์](../output-image-formats.md).

### แบนด์ที่อยู่นอกช่วงที่ปรับเทียบของ DAQ

ช่วงที่ DAQ ได้รับการปรับเทียบทางรังสีวัดได้คือ ~374–974 nmChloros
จะปฏิเสธค่าการสะท้อนแสงจาก DAQ สำหรับแถบกล้องใดก็ตามที่มีน้ำหนักสเปกตรัมภายในช่วงดังกล่าวน้อยกว่าครึ่งหนึ่ง และจะรายงานเหตุผลการข้ามค่าเป็น `dls-uncalibrated-band-<nm>` ในบรรดา SKU ที่จัดส่งอยู่ ขณะนี้มีผลเฉพาะกับ F988 เท่านั้น: ค่าสะท้อนแสงของ F988 ได้รับการปรับเทียบโดยใช้แผงสะท้อนแสงในฉาก: ช่วงความยาวคลื่นดังกล่าวอยู่นอกช่วงที่ปรับเทียบของเซ็นเซอร์แสง DAQ ดังนั้นChloros จะใช้ข้อมูลการจับภาพแผงล่าสุดของคุณและเก็บไว้ระหว่างการตรวจวัดแผงครั้งต่อไป หากกล้อง F988 ทำงานในโหมด DAQ เท่านั้นChloros จะปฏิเสธค่าการสะท้อนแสงที่อิงจาก DAQ สำหรับแถบนั้นด้วยเหตุผลการข้าม `dls-uncalibrated-band-988` — กระบวนการทำงานของแผงสะท้อนแสงเป็นวิธีที่ได้รับการสนับสนุน

## เซ็นเซอร์คู่ (แสงรอบตัว + วัตถุ)

เซ็นเซอร์ DAQ สองตัว — คู่ใดก็ได้ ไม่ว่าจะอยู่ในระบบขนส่งใด — จะให้สเปกตรัมการสะท้อนแบบเรียลไทม์โดยไม่ต้องใช้กล้อง: เซ็นเซอร์หนึ่งตัวหันหน้าไปทางท้องฟ้า (**แหล่งแสงแวดล้อม**), อีกตัวหันหน้าไปทางวัตถุ (**เครื่องสแกนวัตถุ**), และChloros จะคำนวณตามความยาวคลื่น:

> R(λ) = object(λ) / ambient(λ)

(เป็นศูนย์เมื่อ ambient ≤ 0).

### ใน GUI

เมื่อต่อเซ็นเซอร์ทั้งสองไว้ในแท็บ Light Sensors ให้เปิดหน้าต่างเพิ่มเซ็นเซอร์ (ปุ่ม "+" บนไทล์กราฟในโหมด grid view) และเลือก **Combine Ambient + Object**. เลือกเซ็นเซอร์ทั้งสองจากเมนูแบบเลื่อนลง**Ambient Light Source**และ**Object Scanner**แล้วคลิก**Create**กลุ่มนี้จะปรากฏเป็นกราฟแยกต่างหาก และเป็นแถวในแถบด้านข้างที่มีป้าย**REF** สีเขียว

ใต้กราฟการสะท้อนแสง (มุมมองแบบรายการ) **ตารางดัชนีพืชพรรณ** แบบเรียลไทม์จะคำนวณดัชนีจากเส้นโค้งโดยใช้ศูนย์กลางแถบที่สีฟ้า 450 / สีเขียว 550 / สีแดง 670 / NIR 800 นาโนเมตร ดัชนีแบบอัตราส่วนที่หักล้างมาตราส่วนสัมบูรณ์ (NDVI, GNDVI, ENDVI, WDRVI, GRVI, CVI, GCI, MSR) จะแสดงอยู่เสมอ; ส่วนดัชนีที่ต้องการค่าการสะท้อนแสงแบบสัมบูรณ์ (EVI, SAVI, OSAVI, GSAVI, GOSAVI, MSAVI2, RDVI, TDVI, LAI, NLI, MNLI, FCI, GEMI) จะแสดงขึ้นเฉพาะเมื่อเซ็นเซอร์ทั้งสองเป็นรุ่นที่ผ่านการปรับเทียบกำลังแล้ว

### ค่าสะท้อนที่ปรากฏ vs. ค่าสะท้อนสัมพัทธ์ — กฎการตั้งชื่อ

Chloros ตั้งชื่อผลลัพธ์จากเซ็นเซอร์คู่ตามสิ่งที่คู่เซ็นเซอร์นั้นสามารถอ้างได้จริง:

| คู่เซ็นเซอร์ | ชื่อ |
| --- | --- |
| เซ็นเซอร์ทั้งสองผ่านการปรับเทียบ — ชุดปรับเทียบจากโรงงานถูกโหลด | **ค่าสะท้อนที่ปรากฏ** |
| เซนเซอร์ใดก็ตามที่ยังไม่ได้รับการปรับเทียบ | **ค่าสะท้อนสัมพัทธ์** |

ทั้งสามรุ่นเป็นแบบเรดิโอเมตริก: เมื่อชุดข้อมูลการปรับเทียบจากโรงงานของเซนเซอร์ถูกโหลดแล้ว สเปกตรัมของมันจะเป็นค่าสัมบูรณ์ W/m²/nm ดังนั้น คู่เซนเซอร์ที่ได้รับการปรับเทียบจะให้อัตราส่วนที่นำไปสู่ค่าสะท้อนสัมพัทธ์สัมบูรณ์ — การขนส่งข้อมูลไม่ได้กำหนดค่านี้ หากเซ็นเซอร์ใดยังคงส่งข้อมูลนับดิบ (ไม่สามารถเข้าถึงชุดข้อมูลได้) ผลลัพธ์จะถูกลดระดับเป็นเส้นโค้งสัมพัทธ์ (รูปทรงสเปกตรัมยังคงถูกต้อง) เซ็นเซอร์ทั้งสองควรมีค่าขีดจำกัดที่ประกาศไว้อย่างถูกต้อง ([Cap Profiles & Calibrated Range](caps-and-range.md)).
