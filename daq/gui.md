# แท็บ DAQ ใน Chloros

แท็บ DAQ — ที่มีชื่อ **Light Sensors** ในแถบข้างของ Chloros — เป็นหน้าควบคุมแบบเรียลไทม์สำหรับ [เซ็นเซอร์แสง DAQ-U, DAQ-M และ DAQ-E](README.md): เชื่อมต่อเซ็นเซอร์ผ่านช่องทางส่งข้อมูลใดก็ได้, ดูสเปกตรัมที่ได้รับการปรับเทียบแบบเรียลไทม์, คำนวณค่าการสะท้อนแบบเรียลไทม์จากคู่เซ็นเซอร์ และบันทึกไฟล์ `.daq` ลงในโครงการของคุณโดยตรง

แท็บนี้จะใช้งานได้เมื่อระบบหลังบ้านของ Chloros เริ่มทำงานเสร็จสิ้นแล้ว แผนภูมิในแท็บนี้ได้รับข้อมูลจากบริการ DAQ ของ Chloros ผ่านการเชื่อมต่อแบบเรียลไทม์ ซึ่งจะเชื่อมต่อใหม่โดยอัตโนมัติ (ระยะเวลาพัก 2–10 วินาที) หากการเชื่อมต่อถูกขัดจังหวะ; เมื่อไม่สามารถเข้าถึงบริการได้ แถวสถานะของเซ็นเซอร์จะแสดง **No Server**การจัดวางประกอบด้วย**แถบด้านข้างของเซ็นเซอร์**(หนึ่งแถวต่อเซ็นเซอร์ที่เชื่อมต่อ) และ**พื้นที่กราฟ** (หนึ่งไทล์กราฟต่อเซ็นเซอร์หรือกลุ่ม)

## การเชื่อมต่อเซ็นเซอร์

คลิก **Connect Sensor** ที่ส่วนบนของแถบด้านข้าง กล่องโต้ตอบการเชื่อมต่อจะเปิดขึ้นในพื้นที่หลัก (หรือเป็นชั้นทับเมื่อเพิ่มเซ็นเซอร์อีกตัว — ในกรณีนั้นจะมีปุ่ม Cancel ปรากฏขึ้น)

| การควบคุม | พฤติกรรม |
| --- | --- |
| **ประเภทอุปกรณ์** | `DAQ-U (USB)` (ค่าเริ่มต้น), `DAQ-M (Bluetooth)` หรือ `DAQ-E (Ethernet)` การเปลี่ยนประเภทจะเริ่มสแกนใหม่สำหรับโปรโตคอลการส่งข้อมูลที่เลือกใหม่ |
| **พอร์ต / อุปกรณ์ BLE / ชื่อโฮสต์ / IP** | แสดงรายการอุปกรณ์ที่ค้นพบเป็น `device - description`; รายการแรกที่ระบบระบุว่าเป็นเซ็นเซอร์จะถูกเลือกอัตโนมัติ ระหว่างการสแกน จะแสดง `Scanning...` (USB), `Scanning (N)...` พร้อมการนับถอยหลัง 8 วินาที (BLE), หรือ `Discovering ethernet sensors (N)...` พร้อมการนับถอยหลัง 5 วินาที (Ethernet). ผลลัพธ์ที่ว่างจะแสดงเป็น `No ports` / `No BLE devices` / `No ethernet sensors found`. |
| **↻ Refresh** | สแกนใหม่ทันทีสำหรับวิธีการส่งข้อมูลที่เลือก (ถูกปิดใช้งานระหว่างการสแกน BLE/Ethernet) |
| **Connect** | เปิดใช้งานเมื่อเลือกอุปกรณ์แล้ว; เปลี่ยนชื่อเป็น `Connecting...` ระหว่างการเชื่อมต่อ |

การค้นหาจะทำงาน **เฉพาะเมื่อหน้าต่างการเชื่อมต่อปรากฏบนหน้าจอ** และทำซ้ำทุก 15 วินาที สำหรับการขนส่งที่เลือกไว้เท่านั้น — การเปิดแท็บเพียงอย่างเดียวจะไม่ทำการสแกน หากเกิดข้อผิดพลาด หน้าต่างจะแสดงข้อความ: *&quot;การเชื่อมต่อล้มเหลว โปรดลองถอดและเสียบเซ็นเซอร์ใหม่ แล้วคลิก &#x27;เชื่อมต่อ&#x27; อีกครั้ง&quot;*

แถบด้านข้างจะเปิดขึ้นอัตโนมัติเมื่อเซ็นเซอร์ตัวแรกของคุณเชื่อมต่อสำเร็จ

{% hint style="info" %}
**DAQ-E ไม่ปรากฏขึ้น?** DAQ-E ไม่มีไฟ LED แสดงสถานะ — ตรวจสอบไฟแสดงสถานะ PoE/link บนสวิตช์หรือพอร์ตอินเจกเตอร์ที่มันถูกเสียบอยู่ และรอสักไม่กี่วินาทีหลังเปิดเครื่องเพื่อให้มันบูตเสร็จ เครื่องที่ติดตั้ง Chloros ต้องอยู่ในโดเมนการกระจายสัญญาณเดียวกัน (mDNS ไม่สามารถผ่านเราเตอร์ได้) บน Windows ให้ยอมรับคำเตือนจากไฟร์วอลล์ Defender ในครั้งแรกที่ Chloros ผูกซ็อกเก็ตมัลติคาสต์ (mDNS UDP 5353, ข้อมูล DAQ-E UDP 5002, PTP UDP 319/320) อุปกรณ์ DAQ-E สองเครื่องใน LAN เดียวกันจะถูกค้นพบแยกกัน โดยแต่ละเครื่องใช้ชื่อโฮสต์ `daq-e-<id>.local` ของตัวเอง
{% endhint %}

## แถบด้านข้างของเซ็นเซอร์

เซ็นเซอร์ที่เชื่อมต่อแต่ละตัวจะมีแถวหนึ่ง (บวกอีกหนึ่งแถวต่อกลุ่ม Ambient+Object) แถวสามารถจัดเรียงใหม่ได้ด้วยการลาก และลำดับของแถวจะส่งผลให้ลำดับของไทล์กราฟเปลี่ยนไปด้วย คลิกที่แถวเพื่อทำให้เซ็นเซอร์/กลุ่มนั้นเป็นกราฟที่ใช้งานอยู่ในมุมมองรายการ

| องค์ประกอบ | ความหมาย |
| --- | --- |
| ขอบซ้ายที่มีสี | สีของกราฟเซ็นเซอร์ |
| สัญลักษณ์การส่งข้อมูล | `DAQ-U` / `DAQ-M` / `DAQ-E` หรือป้าย `REF` สีเขียวสำหรับกลุ่มการสะท้อนแสง Ambient+Object |
| ชื่ออุปกรณ์ | ตั้งค่าเริ่มต้นเป็นหมายเลขซีเรียลของเซ็นเซอร์ (ซึ่งเป็นเอกลักษณ์ที่คงที่สำหรับการปรับเทียบ ชื่อไฟล์ `.daq` และการจับคู่การนำเข้า); ชื่อที่กำหนดเองจะคงอยู่ตามแต่ละโครงการ |
| **Calibrated** (สีเขียว) | แสดงขึ้นเมื่อชุดข้อมูลการปรับเทียบจากโรงงานของเซ็นเซอร์ถูกโหลดแล้ว คือ สเปกตรัมเป็นค่าจริง W/m²/nm |
| **Update Available** (สีเหลืองอำพัน, DAQ-E เท่านั้น) | เฟิร์มแวร์ที่กำลังทำงานอยู่มีเวอร์ชันเก่ากว่าภาพที่รวมอยู่ในชุดสร้างChloros

นี้ | ระหว่างการอัปเดต จะแสดงความคืบหน้าแบบเรียลไทม์ (`Flashing… N%`, `Restarting sensor…`, แล้ว `Updated X → Y` หรือ `Failed`) |
| ตา | สลับการแสดงผลของเซ็นเซอร์นี้บนแผนภูมิ |
| เฟือง | เปิดหน้าต่างตั้งค่าสำหรับเซ็นเซอร์แต่ละตัว (ด้านล่าง) |
| ✕ (สีแดง) | ตัดการเชื่อมต่อเซ็นเซอร์ หรือลบกลุ่ม Ambient+Object |

ด้านบนแถวมีปุ่มสองปุ่ม:

* **Connect Sensor** — เปิดหน้าต่างการเชื่อมต่อ (เปลี่ยนชื่อเป็น `Connecting...` เมื่อกำลังทำงาน)
* **บันทึกทั้งหมด / หยุดทั้งหมด**— เริ่มหรือหยุดการบันทึก `.daq` บน**ทุก**เซนเซอร์ที่เชื่อมต่ออยู่ ต้องมีเซนเซอร์อย่างน้อยหนึ่งตัว**และโครงการที่เปิดอยู่** (คำอธิบาย: &quot;เปิดโครงการเพื่อบันทึก&quot;); ปุ่มจะเปลี่ยนเป็นสีแดงเมื่อการบันทึกกำลังทำงาน

เมื่อไม่มีเซ็นเซอร์ที่เชื่อมต่อ จะแสดงข้อความ &quot;No sensors connected&quot;

## การตั้งค่าสำหรับเซ็นเซอร์แต่ละตัว (หน้าต่างโมดัลรูปเฟือง)

เปิดโดยคลิกไอคอนรูปเฟืองบนแถวเซ็นเซอร์ เนื้อหาเรียงตามลำดับ:

* **แถวข้อมูล** — ประเภทอุปกรณ์ (DAQ-U/M/E), การเชื่อมต่อ (`Serial (USB)` / `Bluetooth` / `Ethernet`), พอร์ต (พอร์ต COM, ที่อยู่ BLE หรือโฮสต์) และหมายเลขซีเรียล
* **รายงานการสอบเทียบ: ดาวน์โหลด** — ดาวน์โหลดใบรับรองการสอบเทียบที่ติดตามได้ถึง NIST (PDF) ของอุปกรณ์นี้ และเปิดในโปรแกรมดู PDF ของคุณ สามารถใช้งานได้เมื่อทราบหมายเลขซีเรียลแล้ว; ใบรับรองจะถูกเก็บไว้ในแคชเมื่อเชื่อมต่อครั้งแรก
* **ชื่ออุปกรณ์** — คลิกไอคอนดินสอเพื่อเปลี่ยนชื่อ; การตั้งค่าจะคงอยู่ตามโครงการ
* **สีเส้นกราฟ** — ตัวอย่างสี; เก็บค่าไว้ตามแต่ละโครงการ
* **เวลาการรวม (ms)**— ตัวเลื่อน + ตัวเลข,**1–500 ms**, ค่าเริ่มต้น**32 ms**. ถูกปิดใช้งานเมื่อ AE เปิดอยู่
* **ค่าเฉลี่ยเฟรม**— ตัวเลื่อน + ตัวเลข,**1–50 เฟรม**, ค่าเริ่มต้น**20**.
* **AE: ON/OFF**— สวิตช์เปิด/ปิดการปรับแสงอัตโนมัติ;**ค่าเริ่มต้น ON** เมื่อเชื่อมต่อ. ปิดสวิตช์นี้เพื่อตั้งค่าเวลาการรวมสัญญาณด้วยตนเอง
* **หยุดการสตรีม / เริ่มการสตรีม** — หยุดชั่วคราวหรือต่อต่อการสตรีมสด
* **บันทึก / หยุดการบันทึก** — การบันทึก `.daq` ตามเซ็นเซอร์แต่ละตัว (ต้องมีโครงการที่เปิดอยู่)
* **Cap** — โปรไฟล์การปรับแก้ cap (ส่วนถัดไป)
* **แถวข้อมูลสด** — เวลาการรวมสัญญาณ (ms), FPS, จำนวนตัวอย่าง, การบันทึก (สีแดง `REC` หรือ `Off`), และสถานะ (`Streaming` / `Paused` / `SATURATED` / `No Server`).

### เฉพาะ DAQ-E: แถวเครือข่าย, เฟิร์มแวร์ และ PTP

* **Hostname / IP** — ที่อยู่ปัจจุบันของอุปกรณ์
* **เฟิร์มแวร์** — เวอร์ชันเฟิร์มแวร์ปัจจุบัน พร้อมด้วยเซลล์การดำเนินการ:<version\>

ปุ่ม</version\>

**อัปเดตเป็น \<version\>** จะปรากฏขึ้นเมื่อเวอร์ชันChloros

นี้รวมภาพเฟิร์มแวร์ DAQ-E ที่ใหม่กว่า การอัปเดตจะดำเนินการผ่านเครือข่ายภายในประมาณ 30 วินาที; เซนเซอร์จะรีสตาร์ทและเชื่อมต่อใหม่โดยอัตโนมัติ และการถ่ายโอนที่ถูกขัดจังหวะจะไม่ส่งผลต่อเฟิร์มแวร์ปัจจุบัน ความคืบหน้าแสดงแบบเรียลไทม์ (`Flashing… N%` → `Restarting sensor…` → `Updated X → Y`) และเซลล์จะแสดง `Up to date` เมื่อเป็นเวอร์ชันปัจจุบัน
* **PTP Sync** — สถานะ PTP แบบเรียลไทม์ (กลับสู่ `unknown`) เฟิร์มแวร์ DAQ-E เวอร์ชัน 1.2.0 ขึ้นไปเข้าร่วมใน IEEE 1588 PTPv2 ในฐานะนาฬิกาแบบสเลฟเท่านั้น; ส่วน backend ของโฮสต์Chloros

เป็น PTP grandmaster และกล้อง DAQ-E และ LATTICE ทุกตัวใน LAN จะทำงานเป็น slave ต่อมันใน domain 0 โดยรักษาความคลาดเคลื่อนของ timestamp ให้อยู่ภายในประมาณ 1 ms

สำหรับกลุ่ม Ambient+Object โหมดเกียร์จะแสดงเฉพาะเซ็นเซอร์ต้นทางของกลุ่ม ชื่ออุปกรณ์ และสีเส้นกราฟเท่านั้น

### การเลือกฝาครอบ

เมนูแบบเลื่อนลง **Cap** บอกให้Chloros

ทราบว่าฝาครอบทางกายภาพใดถูกติดตั้งบนตัวกระจายแสงของเซ็นเซอร์ และนำโปรไฟล์การปรับแก้ที่วัดจากโรงงานของฝาครอบนั้นมาใช้กับทุกสเปกตรัม ตัวเลือกขึ้นอยู่กับรุ่น:

| รุ่น | ตัวเลือกฝาครอบ |
| --- | --- |
| DAQ-U | ไม่มี (เซ็นเซอร์เปล่า), FOV 15°, FOV 30°, FOV 45°, FOV 60°, FOV 90°, Sunshine (ตัวปรับโคไซน์) |
| DAQ-M | ไม่มี (เซ็นเซอร์เปล่า), Sunshine (ตัวปรับโคไซน์) |
| DAQ-E | ไม่มี (เซ็นเซอร์เปล่า), FOV 15°, FOV 45°, FOV 90°, Sunshine (ตัวปรับโคไซน์) |

**ค่าเริ่มต้นสำหรับทุกรุ่นคือ Sunshine (ตัวปรับคอสีน)** —MAPIR

จัดส่ง DAQ ทุกเครื่องพร้อมติดตั้งฝา Sunshine และนี่คือรูปแบบมาตรฐานสำหรับการใช้งานกลางแจ้ง: มุมมองครึ่งทรงกลม 180° ด้วยความผิดพลาดโคไซน์ ≤ ±4 % จนถึง 60° และ ≤ ±4.5 % จนถึง 70° (ไม่แนะนำให้ใช้เมื่อมุมสูงของดวงอาทิตย์ต่ำกว่า ~15°), มีการลดทอนตามการออกแบบ (~12×). การเลือกของคุณจะถูกเก็บไว้ในโครงการ

**การเลือกฝาครอบต้องตรงกับฝาครอบจริง**ทั้งเซ็นเซอร์และซอฟต์แวร์ไม่สามารถตรวจจับได้ว่าฝาครอบใดถูกติดตั้งอยู่ การเลือกนี้จะกำหนดทั้งการปรับแก้แบบเรียลไทม์และข้อมูลที่ถูกบันทึกไว้ในทุกไฟล์ `.daq` — ด้วยการลดทอน ~12× ของฝาครอบ Sunshine, การเปลี่ยนฝาปิดโดยไม่แจ้งให้ทราบจะทำให้การปรับแก้สเปกตรัมผิดพลาดประมาณด้วยปัจจัยนั้น (การถอดและติดตั้งฝาปิดเดิมใหม่จะทำให้ค่าผิดพลาดประมาณ 1.5 %.) เลือก**None (เซ็นเซอร์เปล่า)** เฉพาะเมื่อถอดตัวเก็บประจุออกทางกายภาพแล้วเท่านั้น; บน DAQ-E, &quot;None&quot; ยังคงใช้โปรไฟล์เรขาคณิตจากโรงงานสำหรับตัวกระจายแสงแก้วที่ฝังอยู่ — นี่ไม่ใช่การไม่ดำเนินการ — และ DAQ-E ที่ไม่มีตัวเก็บประจุเป็นเพียงการตั้งค่าบนโต๊ะทดลอง ไม่ใช่การตั้งค่าภาคสนามที่ได้รับการสนับสนุน
{% endhint %}

{% hint style="info" %}
การอัปเกรดจากคู่มือเวอร์ชันเก่า: สวิตช์ &quot;Sunshine Diffuser Installed&quot; ทางด้านเบราว์เซอร์จากเวอร์ชัน 1.1.0 ได้ถูกยกเลิกแล้ว การจัดการฝาครอบตอนนี้ใช้โปรไฟล์ Cap ตามเซ็นเซอร์แต่ละตัว ซึ่งถูกนำไปใช้ทางด้านเซิร์ฟเวอร์
{% endhint %}

## พื้นที่กราฟ

แถบด้านบนที่ติดอยู่มี **ปุ่มสลับระหว่างมุมมองรายการ ⇄ มุมมองตาราง**และ**แถบเลื่อนซูมกราฟ** (ขนาดไทล์ 200–2000 px) มุมมองจะเปลี่ยนเป็นแบบตารางโดยอัตโนมัติเมื่อมีกลุ่มกราฟมากกว่าหนึ่งกลุ่ม และกลับเป็นแบบรายการเมื่อมีหนึ่งกลุ่มหรือน้อยกว่านั้น โหมดมุมมองและขนาดกราฟจะคงอยู่ตามแต่ละโครงการ**กราฟสเปกตรัม** สำหรับแต่ละเซ็นเซอร์แสดง:

* **แกน X** — ความยาวคลื่น (nm). กริดเซ็นเซอร์มีช่วง 340–1010 nm ด้วยความละเอียด 5 nm (135 จุด) และถูกอินเตอร์โพลเลตเป็น 1 nm เพื่อแสดงผล
* **แกน Y** — กำลัง (W/m²), พร้อมด้วยคำนำหน้า SI อัตโนมัติ (m/µ/n) ที่เลือกจากจุดสูงสุด สเปกตรัมเป็นความเข้มรังสีสเปกตรัมที่ได้รับการปรับเทียบทางรังสีวัด (W/m²/nm) บนทั้งสามระบบการขนส่ง
* การเติมสีสเปกตรัมแบบรุ้งใต้เส้นติดตามเดียว; เซนเซอร์หลายตัวบนกราฟเดียวกันจะทับซ้อนกันเป็นเส้นสีพร้อมการเติมสีที่จางลง
* **เมื่อนำเมาส์ไปวาง**— เคอร์เซอร์แนวตั้งที่แสดงความยาวคลื่นและค่าต่อเซนเซอร์;**ลาก** เพื่อซูม (ปุ่มซูมออกจะปรากฏขึ้นเมื่อซูมอยู่)
* ปุ่ม **+** (เฉพาะในโหมดแสดงกริด) เพื่อเพิ่มเซ็นเซอร์ลงในกราฟนี้หรือสร้างกลุ่ม (ด้านล่าง)
* ชื่ออุปกรณ์อยู่ตรงกลางด้านบน และมีตัวหมุนจนกว่าเฟรมแรกจะมาถึง
* **Saturation** ไม่ถูกแสดงบนกราฟเอง: เซ็นเซอร์ที่อิ่มตัวจะแสดงข้อความสถานะ `SATURATED` สีแดง และ `Saturated: Yes` สีแดง**การอิ่มตัว** ไม่ถูกแสดงบนกราฟเอง: เซนเซอร์ที่อิ่มตัวจะแสดงข้อความสถานะ `SATURATED` สีแดง และแถว `Saturated: Yes` สีแดงในตารางข้อมูลสด ลดเวลาการรวมข้อมูลหรือเปิด AE ใหม่เพื่อล้างสถานะนี้

## กลุ่มการสะท้อนแสง (แสงรอบตัว + วัตถุ)

เซ็นเซอร์สองตัวที่เชื่อมต่อกันสามารถรวมกันเพื่อแสดงการสะท้อนแสงแบบเรียลไทม์ — โดยไม่ต้องใช้กล้อง:

1. ในมุมมองกริด (grid view), คลิก **+**บนไทล์กราฟและเลือก**Combine Ambient + Object**.
2. เลือกเซ็นเซอร์ **แหล่งแสงรอบตัว**และเซ็นเซอร์**เครื่องสแกนวัตถุ**(เซ็นเซอร์สองตัวที่ต่างกัน) แล้วคลิก**สร้าง**

Chloros

จะคำนวณ R(λ) = object(λ) / ambient(λ) สำหรับแต่ละความยาวคลื่นจากสองสตรีมแบบเรียลไทม์ (0 เมื่อแสงรอบตัว ≤ 0) ชื่อกลุ่มจะขึ้นอยู่กับประเภทการปรับเทียบของเซ็นเซอร์:

* เซ็นเซอร์ทั้งสองได้รับการปรับเทียบ (แพ็กเกจถูกโหลด) → **&quot;Apparent Reflectance&quot;**.
* หากเซ็นเซอร์ใดก็ตามยังไม่ได้รับการปรับเทียบ → **&quot;Relative Reflectance&quot;**.

กลุ่มนี้จะปรากฏเป็นแถวสีเขียว `REF` ในแถบด้านข้างและในกราฟของตัวเอง (พื้นหลังสีรุ้ง, ค่าที่แสดงเมื่อนำเมาส์ไปวางจะแสดงถึง 4 ตำแหน่งทศนิยม, สามารถลากเพื่อซูมได้).

เมนู **+**ยังมีตัวเลือก**เพิ่มเซ็นเซอร์ใหม่** พร้อมสามตำแหน่ง: *รวมเซ็นเซอร์ใหม่* (เพิ่มลงในกราฟนี้), *ย้ายเซ็นเซอร์ที่มีอยู่มาที่นี่*, หรือ *ดูเซ็นเซอร์ใหม่* (กราฟแยกต่างหาก).

## การบันทึกไฟล์ `.daq`

* การบันทึกจำเป็นต้องมี **โครงการที่เปิด** — หากไม่มีโครงการที่เปิด ทั้งปุ่ม Record All (ในแถบด้านข้าง) และปุ่ม Record ของแต่ละเซ็นเซอร์จะถูกปิดใช้งาน
* ไฟล์จะถูกบันทึกเป็น **`<project folder>/light_sensor/`**; ชื่อไฟล์จะประกอบด้วย ID ของเซ็นเซอร์และเวลาบันทึก และชื่ออุปกรณ์จะถูกเก็บไว้พร้อมกับไฟล์บันทึก
* เมื่อการบันทึกหยุดลง (Stop, Stop All หรือการตัดการเชื่อมต่อระหว่างการบันทึก) ไฟล์ `.daq` ที่เสร็จสิ้นจะถูก **เพิ่มเข้าไปในโครงการที่เปิดอยู่โดยอัตโนมัติ** — ไฟล์ดังกล่าวจะปรากฏในรายการไฟล์ของโครงการโดยไม่ต้องเพิ่มด้วยมือ พร้อมที่จะใช้เป็นข้อมูลลงสู่พื้นน้ำสำหรับ [การประมวลผลค่าสะท้อน](README.md).
* ตัวบ่งชี้สีแดง `REC` จะปรากฏในแถวแบบเรียลไทม์ของหน้าต่างการตั้งค่าขณะบันทึกข้อมูล

สำหรับค่าความเข้มรังสีเชิงปริมาณ ให้คำนวณค่าเฉลี่ยจากข้อมูลอย่างน้อย 15 วินาที — นี่เป็นลักษณะเฉพาะของอุปกรณ์ ไม่ใช่ข้อบกพร่อง
