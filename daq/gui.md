# แท็บ DAQ ใน Chloros

แท็บ DAQ — ที่มีชื่อ **Light Sensors** ในแถบด้านข้างของ Chloros — เป็นหน้าควบคุมแบบเรียลไทม์สำหรับ [เซ็นเซอร์แสง DAQ-U, DAQ-M และ DAQ-E](README.md): เชื่อมต่อเซ็นเซอร์ผ่านช่องทางส่งข้อมูลใดก็ได้, ดูสเปกตรัมที่ปรับเทียบแล้วแบบเรียลไทม์, คำนวณค่าการสะท้อนแบบเรียลไทม์จากคู่เซ็นเซอร์, และบันทึกไฟล์ `.daq` ลงในโครงการของคุณโดยตรง

แท็บนี้จะใช้งานได้เมื่อระบบหลังบ้านของChloros เริ่มทำงานเสร็จสิ้นแล้ว แผนภูมิในแท็บนี้ได้รับข้อมูลจากบริการ DAQ ของChloros ผ่านการเชื่อมต่อแบบเรียลไทม์ ซึ่งจะเชื่อมต่อใหม่โดยอัตโนมัติ (ระยะเวลาพัก 2–10 วินาที) หากการเชื่อมต่อถูกขัดจังหวะ; เมื่อไม่สามารถเข้าถึงบริการได้ แถวสถานะของเซ็นเซอร์จะแสดง **No Server**การจัดวางประกอบด้วย**แถบด้านข้างของเซ็นเซอร์**(หนึ่งแถวต่อเซ็นเซอร์ที่เชื่อมต่อ) และ**พื้นที่กราฟ** (หนึ่งช่องกราฟต่อเซ็นเซอร์หรือกลุ่ม)

## การเชื่อมต่อเซ็นเซอร์

คลิก **Connect Sensor**ที่ด้านบนของแถบด้านข้าง กล่องโต้ตอบการเชื่อมต่อจะเปิดขึ้นในพื้นที่หลัก (หรือเป็นชั้นทับซ้อนเมื่อเพิ่มเซ็นเซอร์อีกตัว — ในกรณีนั้นจะมีปุ่ม**Cancel** ปรากฏขึ้น)

| การควบคุม | พฤติกรรม |
| --- | --- |
| **ประเภทอุปกรณ์** | `DAQ-U (USB)` (ค่าเริ่มต้น), `DAQ-M (Bluetooth)` หรือ `DAQ-E (Ethernet)` การเปลี่ยนประเภทจะเริ่มการสแกนใหม่สำหรับโปรโตคอลการส่งข้อมูลที่เลือก |
| **พอร์ต / อุปกรณ์ BLE / ชื่อโฮสต์ / IP** | แสดงรายการอุปกรณ์ที่ค้นพบเป็น `device - description`; รายการแรกที่ระบบระบุว่าเป็นเซ็นเซอร์จะถูกเลือกอัตโนมัติ ระหว่างการสแกน จะแสดง `Scanning...` (USB), `Scanning (N)...` พร้อมการนับถอยหลัง 8 วินาที (BLE), หรือ `Discovering ethernet sensors (N)...` พร้อมการนับถอยหลัง 5 วินาที (Ethernet). หากผลการสแกนเป็นว่าง จะแสดง `No ports` / `No BLE devices` / `No ethernet sensors found`. |
| **↻ Refresh** | สแกนการขนส่งที่เลือกใหม่ทันที (ถูกปิดใช้งานระหว่างการสแกน BLE/Ethernet) |
| **Connect Sensor** | เปิดใช้งานเมื่อเลือกอุปกรณ์แล้ว; เปลี่ยนชื่อเป็น `Connecting...` ระหว่างการเชื่อมต่อ |

การค้นหาจะทำงาน **เฉพาะเมื่อหน้าต่างการเชื่อมต่อปรากฏบนหน้าจอ** และทำซ้ำทุก 15 วินาที สำหรับการขนส่งที่เลือกเท่านั้น — การเปิดแท็บเพียงอย่างเดียวจะไม่ทำการสแกน หากเกิดข้อผิดพลาด หน้าต่างจะแสดงข้อความ: *&quot;การเชื่อมต่อล้มเหลว โปรดลองถอดและเสียบเซ็นเซอร์ใหม่ แล้วคลิก &#x27;เชื่อมต่อ&#x27; อีกครั้ง&quot;*

แถบด้านข้างจะเปิดขึ้นอัตโนมัติเมื่อเซ็นเซอร์ตัวแรกของคุณเชื่อมต่อสำเร็จ

{% hint style="info" %}
**DAQ-E ไม่ปรากฏ?**DAQ-E ไม่มีไฟ LED แสดงสถานะ — ตรวจสอบไฟแสดงสถานะ PoE/link บนสวิตช์หรือพอร์ตอินเจกเตอร์ที่มันถูกเสียบอยู่ และรอสักไม่กี่วินาทีหลังเปิดเครื่องเพื่อให้มันบูตเสร็จ เครื่องChloros ต้องอยู่ในโดเมนการส่งสัญญาณเดียวกัน (mDNS ไม่สามารถผ่านเราเตอร์ได้) กฎไฟร์วอลล์**Chloros Backend (UDP-In)** ของโปรแกรมติดตั้งจะอนุญาต mDNS (UDP 5353), ข้อมูล DAQ-E (UDP 5002) และ PTP (UDP 319/320); ไฟร์วอลล์ของบุคคลที่สามจำเป็นต้องอนุญาตพอร์ตเดียวกันนี้ด้วย อุปกรณ์ DAQ-E สองเครื่องในเครือข่าย LAN เดียวกันจะถูกค้นพบแยกกัน โดยแต่ละเครื่องใช้ชื่อโฮสต์ `daq-e-<id>.local` ของตัวเอง
{% endhint %}

## แถบด้านข้างของเซ็นเซอร์

เซ็นเซอร์ที่เชื่อมต่อแต่ละตัวจะมีแถวหนึ่ง (บวกอีกหนึ่งแถวต่อกลุ่ม Ambient+Object) แถวสามารถจัดเรียงใหม่ได้โดยการลาก และลำดับของแถวจะส่งผลให้ลำดับของไทล์กราฟเปลี่ยนไปด้วย คลิกแถวเพื่อทำให้เซ็นเซอร์/กลุ่มนั้นเป็นกราฟที่ใช้งานอยู่ในมุมมองรายการ

| องค์ประกอบ | ความหมาย |
| --- | --- |
| ขอบซ้ายที่มีสี | สีของกราฟเซ็นเซอร์ |
| สัญลักษณ์การส่งข้อมูล | `DAQ-U` / `DAQ-M` / `DAQ-E` หรือสัญลักษณ์ `REF` สีเขียวสำหรับกลุ่มการสะท้อนแสง Ambient+Object |
| ชื่ออุปกรณ์ | ตั้งค่าเริ่มต้นเป็นหมายเลขซีเรียลของเซ็นเซอร์ (ซึ่งเป็นเอกลักษณ์ที่คงที่สำหรับการสอบเทียบ ชื่อไฟล์ `.daq` และการจับคู่การนำเข้า); ชื่อที่กำหนดเองจะคงอยู่ตามแต่ละโครงการ |
| **Calibrated** pill (สีเขียว) | แสดงขึ้นเมื่อโหลดชุดข้อมูลการสอบเทียบจากโรงงานของเซ็นเซอร์แล้ว คือ สเปกตรัมเป็นค่า W/m²/nm ที่ถูกต้อง |
| **มีอัปเดต** (สีเหลืองอำพัน, เฉพาะ DAQ-E) | เฟิร์มแวร์ที่กำลังทำงานอยู่เก่ากว่าภาพที่รวมมาในเวอร์ชันChloros

นี้ ระหว่างการอัปเดตจะแสดงความคืบหน้าแบบเรียลไทม์ (`Flashing… N%`, `Restarting sensor…`, แล้ว `Updated X → Y` หรือ `Failed`) |
| Eye | เปิด/ปิดการแสดงเซ็นเซอร์นี้บนกราฟ |
| Gear | เปิดหน้าต่างตั้งค่าสำหรับเซ็นเซอร์แต่ละตัว (ด้านล่าง) |
| ✕ (สีแดง) | ตัดการเชื่อมต่อเซ็นเซอร์ หรือลบกลุ่ม Ambient+Object |

ด้านบนแถวข้อมูลมีปุ่มสองปุ่ม:

* **Connect Sensor** — เปิดหน้าต่างเชื่อมต่อ (เปลี่ยนชื่อเป็น `Connecting...` เมื่อกำลังทำงาน).
* **บันทึกทั้งหมด / หยุดทั้งหมด**— เริ่มหรือหยุดการบันทึก `.daq` บน**ทุก**เซนเซอร์ที่เชื่อมต่ออยู่ จำเป็นต้องมีเซ็นเซอร์อย่างน้อยหนึ่งตัว**และโครงการที่เปิดอยู่** (ข้อความแสดงเมื่อนำเมาส์ไปวาง: &quot;เปิดโครงการเพื่อบันทึก&quot;); ปุ่มจะเปลี่ยนเป็นสีแดงเมื่อการบันทึกกำลังทำงาน

ในสถานะว่างจะแสดงข้อความ &quot;ไม่มีเซ็นเซอร์ที่เชื่อมต่อ&quot;

## การตั้งค่าสำหรับเซ็นเซอร์แต่ละตัว (หน้าต่างโมดัลรูปเกียร์)

เปิดโดยคลิกไอคอนรูปเกียร์บนแถวเซ็นเซอร์ เนื้อหาตามลำดับ:

* **แถวข้อมูล** — ประเภทอุปกรณ์ (DAQ-U/M/E), การเชื่อมต่อ (`Serial (USB)` / `Bluetooth` / `Ethernet`), พอร์ต (พอร์ต COM, ที่อยู่ BLE หรือโฮสต์) และหมายเลขซีเรียล
* **รายงานการสอบเทียบ: ดาวน์โหลด** — ดาวน์โหลดใบรับรองการสอบเทียบที่ติดตามได้ถึง NIST (PDF) ของอุปกรณ์นี้ และเปิดในโปรแกรมดู PDF ของคุณ ใช้งานได้เมื่อทราบหมายเลขซีเรียลแล้ว; ใบรับรองจะถูกเก็บไว้ในแคชเมื่อเชื่อมต่อครั้งแรก
* **ชื่ออุปกรณ์** — คลิกไอคอนดินสอเพื่อเปลี่ยนชื่อ; การตั้งค่าจะคงอยู่ตามโครงการ
* **สีเส้นกราฟ** — ตัวอย่างสี; การตั้งค่าจะคงอยู่ตามโครงการ
* **เวลาการรวม (ms)**— ตัวเลื่อน + ตัวเลข,**1–500 ms**, ค่าเริ่มต้น**32 ms**. ถูกปิดใช้งานเมื่อ AE เปิดอยู่
* **ค่าเฉลี่ยเฟรม**— ตัวเลื่อน + ตัวเลข,**1–50 เฟรม**, ค่าเริ่มต้น**20**.
* **AE: ON/OFF**— สวิตช์เปิด/ปิดการปรับแสงอัตโนมัติ;**ค่าเริ่มต้นคือ ON** เมื่อเชื่อมต่อ. ปิดสวิตช์นี้เพื่อตั้งเวลาการรวมสัญญาณด้วยมือ
* **หยุดการสตรีม / เริ่มการสตรีม** — หยุดชั่วคราวหรือต่อต่อการสตรีมสด
* **บันทึก / หยุดบันทึก** — การบันทึก `.daq` ตามเซ็นเซอร์แต่ละตัว (ต้องมีโครงการที่เปิดอยู่)
* **Cap** — โปรไฟล์การปรับค่า Cap (ส่วนถัดไป)
* **แถวข้อมูลสด** — เวลาการรวม (ms), FPS, จำนวนตัวอย่าง, การบันทึก (สีแดง `REC` หรือ `Off`), และสถานะ (`Streaming` / `Paused` / `SATURATED` / `No Server`).

### เฉพาะ DAQ-E: แถวเครือข่าย, เฟิร์มแวร์ และ PTP

* **Hostname / IP** — ที่อยู่ปัจจุบันของอุปกรณ์
* **เฟิร์มแวร์** — เวอร์ชันเฟิร์มแวร์ปัจจุบัน พร้อมด้วยเซลล์การดำเนินการ:<version\>

ปุ่ม</version\>

**อัปเดตเป็น \<version\>** จะปรากฏขึ้นเมื่อเวอร์ชันChloros

นี้รวมภาพเฟิร์มแวร์ DAQ-E ที่ใหม่กว่า การอัปเดตจะดำเนินการผ่านเครือข่ายภายในประมาณ 30 วินาที; เซนเซอร์จะรีสตาร์ทและเชื่อมต่อใหม่โดยอัตโนมัติ และการถ่ายโอนที่ถูกขัดจังหวะจะไม่ส่งผลต่อเฟิร์มแวร์ปัจจุบัน ความคืบหน้าแสดงแบบเรียลไทม์ (`Flashing… N%` → `Restarting sensor…` → `Updated X → Y`), และเซลล์จะแสดง `Up to date` เมื่อเป็นเวอร์ชันปัจจุบัน
* **PTP Sync** — สถานะ PTP แบบเรียลไทม์ (กลับสู่ `unknown`) เฟิร์มแวร์ DAQ-E เวอร์ชัน 1.2.0 ขึ้นไปเข้าร่วมใน IEEE 1588 PTPv2 ในฐานะนาฬิกาแบบสเลฟเท่านั้น; ระบบหลังของโฮสต์Chloros

เป็น PTP grandmaster และกล้อง DAQ-E และ LATTICE ทุกตัวใน LAN จะทำงานเป็น slave ต่อมันในโดเมน 0 โดยรักษาความคลาดเคลื่อนของ timestamp ให้อยู่ภายในประมาณ 1 ms.
* **เครือข่าย**— ที่อยู่ IP ที่อุปกรณ์ใช้งานและวิธีที่ได้รับ (DHCP, link-local หรือ static) รวมถึงการตั้งค่าที่บันทึกไว้ซึ่งจะมีผลหลังการรีสตาร์ท**Change…**เปิดแบบฟอร์ม:**Automatic (DHCP)**หรือ**Static IP**พร้อมด้วยที่อยู่ IP, หน้ากากซับเน็ต และเกตเวย์ (หากต้องการ)**Apply and restart** จะบันทึกการตั้งค่า, รีสตาร์ทเซ็นเซอร์ และเชื่อมต่อใหม่ ที่อยู่ IP แบบคงที่นอกเครือข่ายของคอมพิวเตอร์นี้จะถูกปฏิเสธ เนื่องจากChloros

ไม่สามารถติดต่อกับเซ็นเซอร์ได้หลังการรีสตาร์ท; กล่องตัวเลือกเพื่ออนุญาตให้ใช้ที่อยู่ดังกล่าวจะปรากฏขึ้น สำหรับคอมพิวเตอร์ที่จะได้รับการกำหนดที่อยู่ใหม่หรือถูกส่งต่อไปยังเครือข่ายนั้น **สตรีมเมื่อเปิดเครื่อง**กำหนดว่าเซ็นเซอร์จะเริ่มสตรีมทันทีที่เปิดเครื่อง ก่อนที่ซอฟต์แวร์ใดจะเชื่อมต่อ**รีสตาร์ทเซ็นเซอร์** จะรีสตาร์ทเซ็นเซอร์และเชื่อมต่อใหม่ด้วยตั้งค่าปัจจุบัน การรีสตาร์ทจะถูกปฏิเสธขณะที่เซ็นเซอร์กำลังบันทึกข้อมูล ฟีเจอร์ใหม่ในเวอร์ชัน 1.3.0

สำหรับกลุ่ม Ambient+Object หน้าต่างโมดัลรูปเฟืองจะแสดงเฉพาะเซ็นเซอร์ต้นทางของกลุ่ม ชื่ออุปกรณ์ และสีเส้นกราฟเท่านั้น

### การเลือกฝาครอบ

เมนูแบบเลื่อนลง **Cap** บอกให้Chloros

ทราบว่าฝาครอบทางกายภาพใดถูกติดตั้งบนตัวกระจายแสงของเซ็นเซอร์ และนำโปรไฟล์การปรับแก้ที่วัดจากโรงงานของฝาครอบนั้นมาใช้กับทุกสเปกตรัม ตัวเลือกขึ้นอยู่กับรุ่น:

| รุ่น | ตัวเลือกฝาครอบ |

**ค่าเริ่มต้นสำหรับทุกรุ่นคือ Sunshine (ตัวปรับคอสีน)** — MAPIR

จัดส่ง DAQ ทุกเครื่องพร้อมติดตั้งฝา Sunshine และนี่คือค่ากำหนดมาตรฐานสำหรับการใช้งานกลางแจ้ง: มุมมองครึ่งทรงกลม 180° ด้วยความผิดพลาดโคไซน์ ≤ ±4 % จนถึง 60° และ ≤ ±4.5 % จนถึง 70° (ไม่แนะนำให้ใช้เมื่อมุมสูงของดวงอาทิตย์ต่ำกว่า ~15°), มีการลดทอนตามการออกแบบ (~12×). การเลือกของคุณจะถูกเก็บไว้ในโครงการ

{% hint style="warning" %}
**การเลือกฝาครอบต้องตรงกับฝาครอบที่ติดตั้งจริง**ทั้งเซ็นเซอร์และซอฟต์แวร์ไม่สามารถตรวจจับได้ว่าฝาครอบใดถูกติดตั้ง การเลือกนี้จะกำหนดทั้งการปรับแก้แบบเรียลไทม์และข้อมูลที่ถูกบันทึกไว้ในทุกไฟล์ `.daq` — ด้วยการลดทอน ~12× ของฝาครอบ Sunshine, การเปลี่ยนแปลงฝาปิดที่ไม่ได้แจ้งจะทำให้การปรับแก้สเปกตรัมผิดพลาดประมาณด้วยปัจจัยนั้น (การถอดและติดตั้งฝาปิดเดิมใหม่จะให้ค่าซ้ำประมาณ 1.5 %.) ให้เลือก**None (เซ็นเซอร์เปล่า)** เฉพาะเมื่อฝาปิดถูกถอดออกทางกายภาพแล้วเท่านั้น; บน DAQ-E, &quot;None&quot; ยังคงใช้โปรไฟล์เรขาคณิตจากโรงงานสำหรับตัวกระจายแสงแก้วที่ฝังอยู่ — นี่ไม่ใช่การไม่ดำเนินการ — และ DAQ-E ที่ไม่มีตัวกระจายแสงเป็นรูปแบบการตั้งค่าบนโต๊ะทดลอง ไม่ใช่รูปแบบการตั้งค่าในสนามที่ได้รับการสนับสนุน
{% endhint %}

{% hint style="info" %}
การอัปเกรดจากคู่มือเวอร์ชันเก่า: สวิตช์ &quot;Sunshine Diffuser Installed&quot; ทางด้านเบราว์เซอร์จากเวอร์ชัน 1.1.0 ได้ถูกยกเลิกแล้ว การจัดการฝาครอบตอนนี้ใช้โปรไฟล์ฝาครอบต่อเซ็นเซอร์ ซึ่งถูกนำไปใช้ทางด้านเซิร์ฟเวอร์
{% endhint %}

## พื้นที่กราฟ

แถบด้านบนที่ติดอยู่มี **ปุ่มสลับระหว่างมุมมองรายการ ⇄ มุมมองตาราง**และ**แถบเลื่อนซูมแผนภูมิ** (ขนาดไทล์ 200–2000 px) มุมมองจะสลับอัตโนมัติเป็นมุมมองตารางเมื่อมีกลุ่มแผนภูมิมากกว่าหนึ่งกลุ่ม และกลับเป็นมุมมองรายการเมื่อมีหนึ่งกลุ่มหรือน้อยกว่า โหมดแสดงผลและขนาดแผนภูมิจะถูกเก็บไว้ตามแต่ละโครงการ**แผนภูมิสเปกตรัม** สำหรับแต่ละเซ็นเซอร์แสดง:

* **แกน X** — ความยาวคลื่น (nm) ตารางเซนเซอร์มีช่วง 340–1010 nm ด้วยความละเอียด 5 nm (135 จุด) และถูกปรับค่าให้ละเอียดเป็น 1 nm เพื่อแสดงผล
* **แกน Y**— สำหรับเซนเซอร์ที่ได้รับการปรับเทียบ (ปุ่ม**Calibrated**สีเขียว),**กำลัง (W/m²/nm)**— ความเข้มสเปกตรัมที่ผ่านการสอบเทียบทางรังสีวิทยาบนทั้งสามการขนส่ง — พร้อมด้วยคำนำหน้า SI อัตโนมัติ (m/µ/n) ที่เลือกจากจุดสูงสุด เซนเซอร์ที่ชุดสอบเทียบยังไม่ถูกโหลดจะแสดงค่าดิบเป็น**ความเข้ม (counts)** โดยไม่ปรับสเกล เมื่อกราฟแสดงทั้งสองประเภทพร้อมกัน พลังงานจะอยู่บนแกนซ้าย และจำนวนนับจะอยู่บนแกนขวา
* การเติมสีสเปกตรัมแบบรุ้งอยู่ใต้เส้นติดตามเดียว; เซนเซอร์หลายตัวบนกราฟเดียวกันจะแสดงเป็นเส้นสีต่างกันพร้อมการเติมสีที่จางลง
* **Hover**— เคอร์เซอร์แนวตั้งที่แสดงความยาวคลื่นและค่าต่อเซ็นเซอร์ (W/m²/nm สำหรับเซ็นเซอร์ที่ได้รับการปรับเทียบ, หรือจำนวนนับทั้งหมดในกรณีอื่น);**ลาก** เพื่อซูม (ปุ่มซูมออกจะปรากฏขึ้นขณะซูม)
* ปุ่ม **+** (เฉพาะโหมดมุมมองกริด) เพื่อเพิ่มเซ็นเซอร์ลงในกราฟนี้หรือสร้างกลุ่ม (ด้านล่าง)
* ชื่ออุปกรณ์อยู่ตรงกลางด้านบน และมีตัวหมุนจนกว่าเฟรมแรกจะมาถึง

**การอิ่มตัว** ไม่ถูกแสดงบนกราฟเอง: เซนเซอร์ที่อิ่มตัวจะแสดงข้อความสถานะ `SATURATED` สีแดง และแถว `Saturated: Yes` สีแดงในตารางข้อมูลสด ลดเวลาการรวมข้อมูลหรือเปิด AE ใหม่เพื่อแก้ไข

/Blue

## กลุ่มการสะท้อนแสง (แสงรอบตัว + วัตถุ)

เซ็นเซอร์สองตัวที่เชื่อมต่อกันสามารถรวมกันเพื่อแสดงค่าการสะท้อนแบบเรียลไทม์ — โดยไม่ต้องใช้กล้อง:

1. ในมุมมองตาราง (grid view), คลิก **+**บนช่องกราฟและเลือก**รวมแสงรอบตัว + วัตถุ**.
2. เลือกเซ็นเซอร์ **แหล่งแสงรอบตัว**และเซ็นเซอร์**เครื่องสแกนวัตถุ**(เซ็นเซอร์สองตัวที่ต่างกัน) แล้ว**สร้าง**

Chloros

จะคำนวณ R(λ) = object(λ) / ambient(λ) สำหรับแต่ละความยาวคลื่นจากสองสตรีมแบบเรียลไทม์ (0 เมื่อแสงรอบตัว ≤ 0) ชื่อกลุ่มจะขึ้นอยู่กับระดับการปรับเทียบของเซ็นเซอร์:

* เซ็นเซอร์ทั้งสองได้รับการปรับเทียบ (แพ็กเกจถูกโหลด) → **&quot;ค่าสะท้อนที่ปรากฏ&quot;**.
* หากเซ็นเซอร์ใดก็ตามยังไม่ได้รับการปรับเทียบ → **&quot;Relative Reflectance&quot;**.

กลุ่มนี้จะปรากฏเป็นแถวสีเขียว `REF` ในแถบด้านข้าง และในกราฟของตัวเอง (พื้นหลังสีรุ้ง, ค่าที่แสดงเมื่อนำเมาส์ไปวางจะแสดงถึง 4 ตำแหน่งทศนิยม, สามารถลากเพื่อซูมได้).

เมนู **+**ยังมีตัวเลือก**เพิ่มเซ็นเซอร์ใหม่** พร้อมตำแหน่งวางสามแบบ: *รวมเซ็นเซอร์ใหม่* (เพิ่มลงในกราฟนี้), *ย้ายเซ็นเซอร์ที่มีอยู่มาที่นี่*, หรือ *ดูเซ็นเซอร์ใหม่* (กราฟแยกต่างหาก).

## การบันทึกไฟล์ `.daq`

* การบันทึกจำเป็นต้องมี **โครงการที่เปิด** — หากไม่มีโครงการที่เปิด ปุ่ม Record All (ในแถบด้านข้าง) และปุ่ม Record ของแต่ละเซ็นเซอร์จะถูกปิดใช้งาน
* ไฟล์จะถูกบันทึกไปยัง **`<project folder>/light_sensor/`**; ชื่อไฟล์จะประกอบด้วย ID ของเซ็นเซอร์และเวลาบันทึก และชื่ออุปกรณ์จะถูกเก็บไว้พร้อมกับข้อมูลการบันทึก
* เมื่อการบันทึกหยุดลง (Stop, Stop All หรือการตัดการเชื่อมต่อระหว่างการบันทึก) ไฟล์ `.daq` ที่เสร็จสิ้นแล้วจะ **ถูกเพิ่มเข้าไปในโครงการที่เปิดอยู่โดยอัตโนมัติ** — มันจะปรากฏในรายการไฟล์ของโครงการโดยไม่ต้องเพิ่มด้วยมือ พร้อมที่จะใช้เป็นข้อมูลการส่องลงสำหรับ [การประมวลผลความสะท้อน](README.md).
* ตัวบ่งชี้ `REC` สีแดงจะปรากฏในแถวแบบเรียลไทม์ของหน้าต่างการตั้งค่าขณะบันทึก

สำหรับค่าความเข้มรังสีเชิงปริมาณ ให้เฉลี่ยข้อมูลอย่างน้อย 15 วินาที — นี่เป็นลักษณะเฉพาะของอุปกรณ์ ไม่ใช่ข้อบกพร่อง

## การจัดวางเซ็นเซอร์หลายตัวและการเก็บรักษาข้อมูลโครงการ

* รวมเซ็นเซอร์หลายตัวลงในกราฟเดียว (แกนร่วม), เก็บกราฟแยกกัน (การจัดวางกริดอัตโนมัติ), ย้ายเซ็นเซอร์ระหว่างกราฟ, ลากเพื่อจัดเรียงแถว/ไทล์ใหม่, และซ่อนเซ็นเซอร์แต่ละตัวด้วยปุ่มสลับรูปตา
* Chloros

จะเก็บรักษาข้อมูลตามโครงการ: ชื่ออุปกรณ์, สีของกราฟ, ขนาดกราฟ, โหมดแสดงผล และการตั้งค่าของแต่ละเซ็นเซอร์ (เวลาการรวมค่า, การเฉลี่ยเฟรม, สถานะ AE, การเลือกตัวจำกัด)
* **เมื่อเปิดโครงการใหม่ ระบบจะเชื่อมต่อเซ็นเซอร์ของโครงการนั้นโดยอัตโนมัติ** ตามที่อยู่ — พอร์ต COM สำหรับ DAQ-U, อุปกรณ์ BLE สำหรับ DAQ-M, ชื่อโฮสต์ mDNS สำหรับ DAQ-E (ถูกแก้ไขแม้ IP ของอุปกรณ์จะเปลี่ยนไป) — และนำโปรไฟล์ cap ที่บันทึกไว้ การเฉลี่ยเฟรม สถานะ AE และเวลาการรวมข้อมูลแบบมือของแต่ละเซ็นเซอร์มาใช้ใหม่***

## การจับคู่กล้อง (DLS)

ไม่มีอะไรต้องจับคู่เลย ต่างจากขั้นตอนการทำงาน DLS ของโดรนที่ผูกเซ็นเซอร์แสงกับกล้องตั้งแต่ต้นChloros

จะจับคู่ข้อมูล DAQ กับภาพในขั้นตอนถัดไป: ในเวลาที่นำเข้า/ประมวลผล ค่าอ่านของ `.daq` จะถูกคำนวณค่าโดยประมาณให้ตรงกับเวลาเปิดรับแสงของแต่ละภาพที่ถ่าย บันทึกข้อมูลด้วยเซ็นเซอร์ที่เชื่อมต่ออยู่ใดก็ได้ (ค่า `.daq` จะถูกเพิ่มเข้าโครงการอัตโนมัติ) และกระบวนการประมวลผลค่าสะท้อนแสงจะหาค่าอ่านที่ถูกต้องตามเวลา — ดู [เซ็นเซอร์แสง DAQ](README.md) เพื่อทราบวิธีการใช้ข้อมูลแสงที่ส่องลง สำหรับการจับภาพ LATTICE **แบบสด**ให้เลือกเซ็นเซอร์จากเมนูแบบเลื่อนลง**Light Sensor** ในแท็บ Cameras แทน; การบันทึกแต่ละครั้งจะบันทึกค่าที่มันใช้ ซึ่งตรงกับกล้องเฉพาะของการบันทึกนั้นเท่านั้น (ดู [Reflectance Workflows](reflectance.md))</version\>
