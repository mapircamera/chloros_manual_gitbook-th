#เริ่มต้นลงมือทำ

คุณจะนำเข้าเป้าหมายไปที่เป้าหมายอีกครั้งและเทียบเคียงและกำหนดโปรเจ็กต์แล้วคุณจะเริ่มทำมันแล้วจึงแนะนำคุณตลอดขั้นตอนการทำงาน Chloros

## ตรวจสอบก่อนดำเนินการ

เราจะเริ่มให้การควบคุมทุกอย่างพร้อมแล้ว:

* [ ] **ไฟล์ที่นำเข้า** - รูปภาพทั้งหมด File Browser
* [ ] **ในภาพเป้าหมาย** - ติดตามเป้าหมายสำหรับรูปภาพที่ปรับเทียบแล้ว
* [ ] **ตรวจพบรุ่นกล้อง** - โครงสร้างรุ่นกล้องแสดงกล้องที่ถูกต้อง
* [ ] **บันทึกเหตุการณ์แล้ว** - การบันทึกและสวดมนต์โครงการแล้ว
* [ ] **ดัชนีที่เลือก** - ดัชนีหลายรายการที่ต้องการเพิ่ม (หากจำเป็น)
* [ ] **รูปแบบที่เราต้องการ** - โครงสร้างที่เหมาะสมกับขั้นตอนการทำงานของคุณ

{% hint style="info" %}
**เคล็ดลับ**: คลิกดูภาพบางภาพใน File Browser เพื่อโหลดถูกต้องก่อนที่จะปฏิบัติตาม
{% endhint %}

##การกระทำที่เกิดขึ้น

### ค้นหาปุ่มเริ่มต้น

การตั้งค่าเริ่ม/เล่นขึ้นอยู่กับความถี่ของ Chloros:

* ตำแหน่ง: ภายนอกหน้าต่าง
*ไอคอน: **ปุ่มเล่น/เริ่ม** <img src="../.gitbook/assets/image (2) (1).png" alt="" data-size="line">
* สถานะ:สวิทช์เปิด (สว่าง) เมื่อพร้อมดำเนินการ

### คลิกเพื่อเริ่ม

1. นักเรียน **เล่น/เริ่ม** ในด้านบน
2. การปรับตัวจะเริ่มขึ้นทันที
3.คุณจะทำมัน (เป็นสีเทา) ในการควบคุม
4. อัพเดตล่าสุดอย่างต่อเนื่องจะแสดงสถานะตามปกติ

{% hint style="success" %}
**เริ่มต้นการทำงานของ**: ก่อนที่จะคลิกแล้ว Chloros จะเป็นขั้นตอนการจัดการทั้งหมดเจล - ออดิโอเป้าหมายการดีเบย์จะเทียบเคียงกับดัชนีชี้วัดและความเข้มข้น
{% endhint %}

## เรียนรู้กับโหมดอัตโนมัติ

Chloros ทำงานได้อย่างมีประสิทธิภาพซึ่งสองสิ่งนี้ก็คือของคุณ:

### การดำเนินการฟรี (ในเวลากลางคืน)

**ใช้ได้กับผู้ใช้ทุกคน**

**วิธีการทำงาน:**

* ให้ภาพทีละภาพตามลำดับ
*การทำงานแบบเดียวกับในครั้งเดียว
*ลดความเร็วลง

**ความล่าสุดนี้เกี่ยวข้องกับ 2:**

1.** เป้าหมายเป้าหมาย** - สำรวจหาเป้าหมายที่เปรียบเทียบ
2. **กำลังดำเนินการ**- ใช้สำหรับเทียบเคียงและส่งออกรูปภาพ**ระยะเวลาการดำเนินการ:**

* ช้ากว่าโหมดเครือข่าย Chloros+ มาก
* ชุดข้อมูลขนาดเล็กถึงได้ (< 200 รูปภาพ)

### เจล Chloros+ (สมุนไพรแบบเดียวกับฤๅษี)

**จำเป็นต้องมี Chloros+**

**วิธีการทำงาน:**

* จะเห็นภาพหลายภาพพร้อมกันในครั้งแรก [ไปท่อติดตาม 4 ติดตาม](../processing-architecture/processing-pipeline.md)
* [Dynamic Compute Adaptation](../processing-architecture/dynamic-compute-adaptation.md) จะเลือกกลยุทธ์ที่เหมาะสมที่สุดสำหรับฮาร์ดแวร์ของคุณ
* การที่ GPU (CUDA) ด้วยกราฟิกการ์ด NVIDIA (และ Jetson)
* ตรวจสอบจาก Jetson Nano (พนักงาน 1 คน) สำหรับข้อมูลเพิ่มเติมที่มี GPU 12GB+ (พนักงาน 3-4 คน)

**แจ้งให้ทราบอีกครั้งถึง 4 นี้** (เพื่อตรวจสอบไปจุดไลน์ 4 รายการ):

1. **พื้นที่** (หัวข้อที่ 1) - ค้นหากลุ่มเป้าหมายที่เทียบเคียง
2. **การวิเคราะห์** (หัวข้อที่ 2) - การสแกนข้อมูลเมตาของรูปภาพและเสียงเทียบเคียง
3. **เป็นเหมือนเทียบ** (ในที่ 3) - การดีบาย GPU, ต้องเป็นขอบมืด, การตรวจสอบดัชนี
4. **ตรวจสอบ** (และที่ 4) - บันทึกรูปภาพและดัชนีชี้วัดที่แล้ว**การความถี่ของรังสีอินฟราเรด:*** **เลื่อนเมาส์** เหนือแถบความถี่เพื่อดูแผงแบบเลื่อนลง 4 อย่างรวดเร็ว
* **คลิก** สามารถตรวจสอบได้สำหรับแผงแบบเลื่อนลงให้อยู่กับที่
* **คลิกอีกครั้ง**สำหรับระบบปฏิบัติการและซ่อนแผง**ระยะเวลาการดำเนินการ:**

* เร็วกว่าระบบฟรีอย่างรวดเร็ว
* ด้วยจำนวนคอร์ CPU
* การรวบรวมข้อมูลของ GPU ความเร็วที่เพิ่มขึ้นอย่างต่อเนื่อง

{% hint style="info" %}
**Chloros+ ระบบควบคุม**: ไดรฟ์แบบมัลติฟังก์ชั่นอาจเข้าสู่โหมดต่อเนื่องถึง 5-10 สำหรับชุดข้อมูลขนาดใหญ่โปรเจ็กต์ 500 การรักษาใช้เวลา 2 ชั่วโมงต่อวันฟรีอาจทำได้ภายใน 15-20 นำทางด้วย Chloros+
{% endhint %}

## ระหว่างการประชุม

### ด่าน 1: กำหนดเป้าหมาย

**Chlorosทำอะไร:**

* สแกนภาพเป้าหมายที่เห็นได้ชัดไว้ (หรือภาพทั้งหมดนี้เป็นเครื่องหมาย)
* ระบุแผงเทียบเคียง 4 สถานีในแต่ละเป้าหมาย
* แยกค่าการรับสัญญาณจากแผงเป้าหมาย
* บันทึกการประลองเวลาเป้าหมายเพื่อดูเปรียบเทียบ

**ระยะเวลา:** 1-30 วินาที (โดยคืนนี้ที่จำได้), 5-30+ นาที (ไม่มีเครื่องหมาย)

### ด่าน 2: การดีบาย (ต้องรอไฟล์ RAW)

**Chlorosทำอะไร:**

* แปลงรูปแบบข้อมูล RAW Bayer เป็นภาพ RGB
* ใช้ระบบสาธิตการสาธิตได้อย่างมีประสิทธิภาพ
* รักษาคุณภาพและรายละเอียดของภาพสูงสุด

**ระยะเวลา:** ขึ้นอยู่กับจำนวนภาพและความเร็วของ CPU

### พาร์ท 3: เปรียบเทียบกัน

**Chloros ทำอะไร:*** **นั่นคือขอบมืด**: ซ่อนเลนส์มืดลงที่ขอบ
* **เทียบเคียงการเทียบเคียง**: นี่คือมาตรฐานของท่าเรือท่าเรือเป้าหมาย
* ใช้ควบคู่ไปกับแบนด์/ช่อง
* ใช้เป้าหมายเทียบกับแต่ละภาพโดยอาศัยการประลองเวลา

**ระยะเวลา:** จะต้องเป็นไปตามนั้น

### อุโมงค์ 4: ตรวจวัดดัชนี

**Chlorosทำอะไร:**

* การคำนวณดัชนีหลายแบบอย่างที่ไม่จำเป็นต้องใช้ (NDVI, NDRE และอื่นๆ )
* ใช้คณิตศาสตร์กับการปรับเทียบแล้ว
* สร้างดัชนีภาพดัชนีที่เลือก

**ระยะเวลา:** ย้อนหลังภาพ

### คืนนี้ 5: ส่งออก

**Chlorosทำอะไร:**

* บันทึกการพิจารณาปรับเทียบแล้วเลือก
* ส่งออกภาพดัชนีด้วยสี LUT ที่พิพิธภัณฑ์ไว้
* เขียนไฟล์ไปยังย่อยของรุ่นกล้อง
* รักษาชื่อไฟล์ต้นฉบับพร้อมส่วนต่อท้าย

**ระยะเวลา:**จะขึ้นอยู่กับรูปแบบและขนาดไฟล์***

## ยาปฏิชีวนะ

### ไปป์ไลน์อัตโนมัติ

เริ่มต้นแล้วไปเส้นทางที่เหลือทั้งหมด:

* ไม่จำเป็นต้องบ่อยครั้งกับผู้ใช้
* ส่วนหนึ่งของระบบไว้ทั้งหมดพร้อมกัน
* อีกครั้งนึงในเรื่องนี้

### CPU ระหว่างประสิทธิภาพ

**โหมดฟรี:**

* CPU ต่ำ (และเพียงอย่างเดียว)
*คอมพิวเตอร์ยังคงทำงานอื่นๆได้
* โดยทั่วไปในการย่อ Chloros และแอปพลิเคชันอื่นๆ

**Chloros+ฮีไคร:**

* รองรับ CPU (มัลติฟังก์ชั่นสูงสุด 16 คอร์)
* ร่วมกับ GPU: เกี่ยวกับ GPU เพิ่มเติม
*คอมพิวเตอร์อาจจะทำได้น้อยลงในระหว่างกระบวนการ
* เพิ่มการเริ่มต้นต้องใช้ CPU มาก

{% hint style="warning" %}
**เคล็ดลับด้านประสิทธิภาพ**: ประสิทธิภาพการทำงานของ Chloros+ ที่ดีที่สุดเพื่อให้ปิดแอปพลิเคชันอื่นๆ และปล่อยให้ Chloros ใช้ทรัพยากรระบบทั้งหมด
{% endhint %}

###แต่จะหยุดชั่วคราวได้

**สำคัญที่สำคัญ:**

* เริ่มต้นแล้วคุณจะสามารถหยุดชั่วคราวได้
* เพิกเฉยต่อสุขภาพได้แต่ส่วนใหญ่จะมีการพูดถึง
* ผลลัพธ์ที่จะไม่กล่าวถึงบันทึก
*สตาร์ทอัพตั้งแต่ต้นหากยกเลิก

**เคล็ดลับการควบคุม:**สำหรับโปรเจ็กต์ขนาดใหญ่มากทำให้การพิจารณาเป็นชุดหรือใช้ CLI ความสามารถในการควบคุมระบบปฏิบัติการ***

## ติดตามการดำเนินการของคุณ

อีกครั้งอีกครั้ง:

* **ความถี่ในการรับชม** - ดูเปอร์เซ็นต์ความสำเร็จพร้อมกัน
* **ดูขั้นตอนปัจจุบัน** - วิเคราะห์ห้องโถงเทียบหรือส่งออก
* **ตรวจสอบรายละเอียดในบันทึก** - ดูข้อความเกี่ยวกับวิธีการและคำเตือนการปฏิบัติตาม
* **ดูตัวอย่างในส่วนนี้** - ตรวจสอบการส่งออกไฟล์บางไฟล์อาจในระหว่างนั้น

สำหรับข้อมูลเกี่ยวกับการตรวจสอบ [ ตรวจสอบ](monitoring-the-processing.md)

##ไม่ต้องกังวลทั่วไปเมื่อเริ่มต้น

###การควบคุมเริ่มถูกในที่สุด (เป็นสีเทา)

**สาเหตุที่ทำให้:**

* ไม่มีการนำเข้ารูปภาพ
*แบ็กเอนด์ไม่ได้เริ่มต้นเลย
* การควบคุมก่อนที่จะยังคงทำงานอยู่
* โครงการยังโหลดไม่เต็มที่

**แก้ไขแก้ไข:**

1. รอให้แบ็กเอนด์เริ่มต้นใหม่ (ตรวจสอบไอคอนเมนูหลัก)
2. การควบคุมรูปภาพถูกนำเข้าใน File Browser
3. รีสตาร์ท Chloros เพียงแต่ไม่ต้องอยู่เฉยๆ
4. การถ่ายบันทึกความเป็นจริงนั้นมีให้เห็นข้อความในพิพิธภัณฑ์

### การปรับตัวเริ่มต้นแล้วทำตามทันที

**สาเหตุที่ทำให้:**

* ไม่มีรูปภาพที่ถูกต้อง
*แนบภาพอัตโนมัติ
* เนื้อที่อัดแน่นได้
* เป็นผล (RAM)

**แก้ไขแก้ไข:**

1. ภาพถ่ายที่แท้จริงบันทึกเพิ่มเติมได้ที่ <img src="../.gitbook/assets/icon_log.JPG" alt="" data-size="line"> เพื่อดูข้อความที่แสดงบนเว็บไซต์
2. ตัดพื้นที่ว่างในตอนเย็น
3. ลองดูชุดย่อยของรูปภาพให้เล็กลง
4. การควบคุมรูปภาพไม่เสียหาย

### คำเตือน "ไม่พบกลุ่มเป้าหมาย"

**สาเหตุที่ทำให้:**

* ลืมเลือนภาพเป้าหมาย
* รูปภาพเป้าหมายไม่มีเป้าหมายที่สามารถเป็นได้
* คุณสามารถกำหนดเป้าหมายได้ด้วยเช่นกัน

**แก้ไขแก้ไข:**

1. ถ่ายภาพ [ เลือกภาพกลุ่มเป้าหมาย](choosing-target-images.md)
2. ในขอบเขตที่เป็นไปตามเป้าหมายในองค์กร
3. เป้าหมายในวันพรุ่งนี้จะมีอะไรบ้าง
4.เขตเฝ้าระวังเป้าหมายหากจำเป็น

## คำแนะนำสำหรับความพยายามที่ประสบความสำเร็จ

###ก่อนจะเริ่ม

1. **ทดสอบด้วยเซ็ตย่อยเล็กๆ ก่อน** - ตรวจสอบรูปภาพ 10-20 ภาพและตรวจสอบ
2. **ตรวจสอบพื้นที่ว่างในตอนเย็น** - ตรวจสอบพื้นที่ชุดข้อมูลว่าง 2-3x
3. **ปิดแอปพลิเคชันที่ไม่จำเป็น** - จะต้องคำนึงถึงระบบ
4. **ตรวจสอบภาพกลุ่มเป้าหมาย** - ดูตัวอย่างเป้าหมายที่มีอยู่ไว้เพื่อให้มั่นใจในคุณภาพ
5. **โครงการบันทึก** - โครงการบันทึกอัตโนมัติบางส่วนแนวทางปฏิบัติบันทึกประจำวัน

### วิธีการดำเนินการ

1. **หลีกเลี่ยงระบบสลีป** - ในกรณีนี้
2. **เก็บ Chloros ไว้ที่นี่** - หรือขยี้ก็มาถึงทาสก์บาร์
3. **ติดตามอย่างต่อเนื่อง** - คำเตือนหรือคำเตือน
4. **อย่าโหลดแอปพลิเคชันอื่นที่ส่วนขยายมาก** - ใช้กับโหมดอุณหภูมิ Chloros+

### Chloros+ การ GPU

หากคุณใช้การรองรับ NVIDIA GPU:

1. อัปเดต NVIDIA ให้เป็นครั้งสุดท้าย
2. บันทึกภาพเคลื่อนไหว GPU มี 4GB+ VRAM
3. ปิดแอพพลิเคชั่นที่เน้น GPU (เกม, การตัดต่อวิดีโอ)
4. การบันทึกอุณหภูมิของ GPU (บันทึกอย่างต่อเนื่อง)
