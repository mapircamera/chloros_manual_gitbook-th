#วิธีการปฏิบัติ

หากต้องการ Chloros โปรดตรวจสอบทุกครั้งก่อนตรวจสอบผลลัพธ์การควบคุมคุณภาพและการเตรียมการอย่างละเอียดแล้วค่อยประมวลผลในขั้นตอนการทำงานของคุณแนะนำคุณตลอดขั้นตอนสุดท้ายและขั้นตอนถัดไป

## การพิจารณาในเรื่องอื่นๆ ของสภา

เพื่อดูการตรวจสอบอย่างละเอียดอีกครั้ง:

* ✅ **ความเฉียบแหลม**: จิตวิญญาณผลสำเร็จ 100%
* ✅ **บันทึกนี้ยังมีข้อเท็จจริง**: แสดงข้อความ "การดำเนินการวิจัย"
* ✅ **ปุ่มเริ่ม**: ต้องเปิดใช้งานอีกครั้ง (พร้อมสำหรับการดำเนินการครั้งถัดไป)
* ✅ **ไฟล์นี้มี**: รูปภาพที่ฮาร์ดดิสก์ทั้งหมดจะบันทึกลงในเมนบอร์ดรุ่นย่อยของกล้อง***

## ค้นหารูปภาพที่เกี่ยวข้องแล้วของคุณ

### เป็นส่วนช่วยในการพุต

1. คลิก **เมนูหลัก** <img src="../.gitbook/assets/image (1) (1) (1) (1).png" ไอคอน alt="" data-size="line"> (ซ้ายบน)
2. เลือก **"เปิดโครงการ"**

3. คนที่สำรวจไฟล์ของคุณมักจะขึ้นไปยังไดรีโปรเจ็กต์
4. ค้นหาโครงการของคุณตามชื่อ

## การตรวจสอบที่เกี่ยวข้องแล้ว

### ดูตัวอย่างด่วนใน File Explorer

**Windows หรืออธิบายใน:**

1. คุณสามารถดูย่อยรุ่นกล้อง
2. เลือกไฟล์รูปภาพ
3. ภาพยนตร์ตัวอย่างในบานหน้าต่างแสดงตัวอย่าง Windows Explorer
4. ใช้ปุ่มความสว่างเพื่อดูภาพ

### ดูตัวอย่างในโปรแกรมดูรูปภาพภายนอก

**ผู้ดูแล:*** **QGIS** - GIS ฟรี (ดีที่สุดสำหรับการอ้างอิงหลายที่อ้างอิงถึง)
* **IrfanView** - การดูรูปภาพอย่างละเอียดและต่อเนื่อง ( รองรับ TIFF)
* **Adobe Photoshop** - อย่างมืออาชีพ ( รองรับ TIFF)
* **GIMP** - ตัวเลือกฟรีสำหรับ Photoshop
* **Windows Photos** - การรองรับขั้นพื้นฐาน (รองรับไม่ได้ TIFF 16 คอนโซล)

### ดูตัวอย่างใน Chloros Image Viewer

ใช้ Image Viewer ใน Chloros สำหรับการแสดงภาพขั้นสูง:

1. คลิกภาพขนาดย่อของรูปภาพใน File Browser
2. รูปภาพการเปิดขึ้นในพื้นที่แสดงตัวอย่างหลัก
3. คลิก **โปรแกรมดูรูปภาพ** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> ตามปกติในตอนกลางคืนอีกครั้งด้านซ้าย
4. ใช้ [Index/LUT Sandbox](../image-viewer-gui/index-lut-sandbox.md) สำหรับเซิร์ฟเวอร์เชิงเขา

ดู [โปรแกรมดูภาพ](../image-viewer-gui/opening-an-image-full-screen.md) สำหรับคำแนะนำต่างๆ

2. บันทึกเป็นไฟล์ข้อความในโปรเจ็กต์ต่างๆ
3. รวมไปกับเอกสารประกอบโครงการ
4. ส่งไปที่ฝ่ายสนับสนุน MAPIR หากพบปัญหา

##การแก้ปัญหาและการแก้ปัญหาทั่วไปของผลลัพธ์

###ไม่ต้องกังวล:เราจะทำได้โดยที่

**สาเหตุที่ทำให้:**

*ไม่มีการปฏิบัติตามกฎระเบียบ
* รูปภาพเฉพาะกลุ่มเป้าหมาย (ไม่รวมจากที่นี่)
* มุมมองทั้งหมดระหว่างนั้น
*จะช่วยแก้ปัญหาร่วมกัน

**แก้ไขแก้ไข:**

1. การถ่ายบันทึกจริงๆ นั้นมีให้เห็นข้อความที่ข้าม/อาณาจักร
2. การควบคุมพื้นที่ในคืนนี้
3. ประเภทไฟล์: ขึ้นอยู่กับ (จำนวนเดิม - จำนวนเป้าหมาย) × (ดัชนี + 1)
4. นำเข้าอีกครั้งในไฟล์อีกครั้งอีกครั้ง

###ไม่ต้องกังวล: ล้อมืดหรือสว่าง (วิกเนตรยังสามารถได้)

**สาเหตุที่ทำให้:**

* บทความก่อนหน้านี้สั้นแล้ว
* กล้อง/เลนส์ไม่อยู่ในแกลเลอรี่ Chloros
*มองภาพมืดมากเกินกว่าการแก้ไข

**แก้ไขแก้ไข:**

1. ในเวลาเดียวกันนั้นจะมีการเผยแพร่บทความสั้นแล้วในโปรเจ็กต์
2. ถ่ายภาพรุ่นกล้องที่ตรวจพบอย่างสม่ำเสมอ
3. ติดต่อฝ่ายสนับสนุน MAPIR หากต้องการค้นหาภาพมืดอยู่

###ไม่ต้องกังวล: สีหรือค่าอะไร

**สาเหตุที่ทำให้:**

* ไม่พบกลุ่มเป้าหมายเปรียบเทียบ
* เลือกรุ่นเป้าหมายที่เทียบเคียงได้
* ตรวจสอบเปรียบเทียบการเปรียบเทียบ
*ภาพเป้าหมายคุณภาพต่ำ

**แก้ไขแก้ไข:**

1. การควบคุมได้ทำให้มันเหมือนกับการเทียบเทียมแล้ว
2. ถ่ายภาพข้อความ "Target found" ใน Debug Log
3. ถ่ายภาพคุณภาพภาพเป้าหมาย
4. ทำซ้ำอีกครั้งโดยถูกต้อง

###ไม่ต้องกังวล: ค่า NDVI ไม่ต้องกังวล

**ช่วง NDVI ที่มีความสำคัญ:*** **น้ำดินดิน**: -0.1 ถึง 0.2
* **พืชพรรณเบาบาง/ไม่แข็งแรง**: 0.2 ถึง 0.4
* **พืชพรรณปานกลาง**: 0.4 ถึง 0.6
* **พืชผักตามความต้องการและบ่อยครั้ง**: 0.6 ถึง 0.9**หากค่าอยู่นอกช่วงดังกล่าว:**

1. การพิจารณาคดีเป็นเรื่องเทียบเทียมแล้ว
2. บันทึกเสียงบันทึกในขณะที่วัดแสงรวมอยู่ด้วย
3. การตรวจวัดเป้าหมายเปรียบเทียบ
4. การตรวจวิเคราะห์กล้องตรวจจับรุ่นกล้องที่ถูกต้อง
5. การตัดระยะเวลาและเงื่อนไขในการจับภาพเป้าหมาย

##รูปภาพที่ตรงกับของคุณ

### สำหรับโฟโตแกรมเมทรี / สุดยอดออร์โธโมซาอิก

**ขั้นตอนการทำงานที่สำคัญ:**

1.** การนำเข้าภาพที่ปรับเทียบแล้ว** ในระบบปฏิบัติการโฟโตแกรมเมทรี:
   * Pix4Dmapper
   * Agisoft เมตาเชป
   * โดรนดีพลอย
   * เว็บโอดีเอ็ม
2. **ในเมตา EXIF**: การบันทึกข้อมูล GPS ของส่วนไว้เพื่อติดแท็กตำแหน่ง
3. **ขั้นตอนการทำงานที่ปรับเทียบแล้ว**: ใช้ภาพสะท้อนเพื่อการรับสัญญาณอย่างมาก
4. **ตรวจสอบดัชนีความเชื่อมั่น**: สร้าง NDVI orthomosaics จากภาพดัชนีแต่ละภาพ
5. **ส่งออกการอ้างอิงถึง GeoTIFF**: สำหรับใช้ในแอปพลิเคชัน GIS

### สำหรับการวิเคราะห์ GIS

**ขั้นตอนการทำงานที่สำคัญ:**

1.**โหลดลงใน QGIS, ArcGIS หรืออื่นๆ**

2.**ใช้ภาพสะท้อน TIFF 16 สำหรับการเล่นแบบหลายแบนด์
3. **ใช้ภาพดัชนี** (NDVI, NDRE) เป็นชั้นพืชพรรณที่พร้อมใช้งาน
4. **ตรวจแรสเตอร์**: รวมแบนด์เพื่อตรวจดูคลีนิก
5. **ส่งออก**: สร้างแผนที่ประเภทต่างๆ การเปลี่ยนแปลงแผนที่สุขภาพพืชผัก

### สำหรับกีฬา / รายงานโดยตรง

**ขั้นตอนการทำงานที่สำคัญ:**

1.**ใช้ดัชนีภาพที่มีสี LUT** สำหรับรายงานภาพ
2. **แยกสถิติ**: NDVI ต่อการควบคุม/การควบคุม
3. **เหตุการณ์เวลา**: การวิเคราะห์ดัชนีระหว่างหลายเหตุการณ์
4. **สร้างรายงาน**: รวมแผนที่สถิติและการแสดงภาพ***

## การเก็บถาวรและส่วนที่เหลือ

### กลยุทธ์ที่เป็นกลาง

**สิ่งที่ต้องประหยัด:***✅**ภาพ RAW/JPG ต้นฉบับ** - เก็บรักษาถาวรในไดรฟ์/สำนักงานใหญ่
* ✅ **ผลลัพธ์ที่เห็นได้ชัดแล้ว** - เก็บภาพและดัชนีที่ปรับเทียบแล้วไว้
* ✅ **ไฟล์โครงการ** - มีจำนวนมากทั้งหมดสำหรับการทำซ้ำหากจำเป็น
* ✅ **บันทึกที่แท้จริง** - รายละเอียดบันทึกเอกสาร
* ✅ **ภาพเป้าหมายเป็นเหมือนเทียบ**- สำหรับการตรวจสอบและการควบคุมใหม่**คำแนะนำในการตรวจสอบ:*** **สังเกตการณ์ทันที**: ส่วนประกอบภายนอก
* **การเก็บถาวรในระยะยาว**: รูปแบบต่างๆ บนคลาวด์ (Google Drive, Dropbox และอื่นๆ)
* **ข้อมูลสำคัญ**: เก็บเหล็ก 2-3 ชุดที่ต่างกัน***

## จะดำเนินการในครั้งถัดไป

###จะนำโครงการกลับมาใช้ใหม่

การแสดงชุดระบบควบคุมกันหลายสี:

1. **บันทึกแผนผังโครงการ** (หากยังไม่ได้ดำเนินการ)
2. **สร้างโครงการใหม่** ไม่จำเป็นต้องเป็นไปตามนั้น
3. **นำเข้ารูปภาพใหม่**

4.** สิ่งสำคัญ**ด้วยทุกสิ่งที่จะเกิดขึ้น

### การปรับตัวเป็นชุดหลายตัว

สำหรับหลาย ๆ คน/ชุดข้อมูล:**ตัวเลือกที่ 1: GUI - ตรวจสอบโครงการ**

* สร้างโครงการแยกกันอัจฉริยะ
* ใช้สภาพอากาศที่ป้อมปราการ
* ดำเนินการครั้งละครั้ง

**ส่วนที่ 2: Chloros CLI (Chloros+ เท่านั้น)**

* เฝ้าสังเกตแบ๊ดอัตโนมัติ
* แจ้งหลาย ๆ อย่างพร้อมกันด้วย
* ดู [เอกสาร CLI](../CLI.md)

**ส่วนที่ 3: Python SDK (Chloros+ เท่านั้น)**

* ควบคุมทางโปรแกรม
* อะไรที่ไปกับไปเยี่ยมชมไลน์
* ดู [เอกสาร API](../api-python-sdk.md)
