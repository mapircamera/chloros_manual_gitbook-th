# การปรับตั้งค่าโครงการ

ก่อนที่จะประมวลผลภาพของคุณ การตั้งค่าโครงการให้สอดคล้องกับความต้องการของกระบวนการทำงานของคุณเป็นสิ่งสำคัญ แผงควบคุม Project Settings <img src="../.gitbook/assets/icon_project-settings.JPG" alt="" data-size="line"> ให้คุณควบคุมได้อย่างครบถ้วนเกี่ยวกับการปรับเทียบ ตัวเลือกการประมวลผล ดัชนีมัลติสเปกตรัม และรูปแบบการส่งออก

## การเข้าถึงการตั้งค่าโครงการ

1. เปิดโครงการของคุณใน Chloros
2. คลิกไอคอน **Project Settings** <img src="../.gitbook/assets/icon_project-settings.JPG" alt="" data-size="line"> ในแถบด้านซ้าย
3. แผง Project Settings จะแสดงตัวเลือกการตั้งค่าทั้งหมด

<figure><img src="../.gitbook/assets/image (28).png" alt=""><figcaption><p>แผง **Project Settings** — การแสดงผล, การตรวจจับเป้าหมาย และการประมวลผล</p></figcaption></figure>

{% hint style="info" %}
**การตั้งค่าจะถูกบันทึกอัตโนมัติ** พร้อมกับโครงการของคุณ เมื่อคุณเปิดโครงการอีกครั้ง การตั้งค่าทั้งหมดจะถูกกู้คืน
{% endhint %}

***

## การตั้งค่าอย่างรวดเร็วสำหรับขั้นตอนการทำงานทั่วไป

### การตั้งค่าเริ่มต้น (แนะนำสำหรับผู้ใช้ส่วนใหญ่)

การตั้งค่าเริ่มต้นทำงานได้ดีสำหรับขั้นตอนการทำงานทั่วไปของSurvey3
และ LATTICE:

* ✅ **การแก้ไขวิเนตต์**: เปิดใช้งาน
* ✅ **การปรับเทียบการสะท้อนแสง / สมดุลสีขาว**: เปิดใช้งาน (ใช้เป้าหมายMAPIR
และ/หรือข้อมูลเซ็นเซอร์แสง DAQ)
* ✅ **วิธีเดเบเยอร์**: มาตรฐาน (เร็ว, คุณภาพปานกลาง)
* ✅ **รูปแบบการส่งออก**:TIFF
(16-bit)
* ✅ **ผลิตภัณฑ์ส่งออกทั้งหมด**: เปิดใช้งาน (LATTICE จะจับภาพ fan out เป็น debayered, preview, radiance และ reflectance โดยอัตโนมัติ)

เพียงนำเข้าภาพของคุณและเริ่มประมวลผลด้วยค่าเริ่มต้นเหล่านี้

***

## ภาพรวมการตั้งค่าโครงการ

แผงการตั้งค่าโครงการถูกจัดแบ่งเป็นส่วนต่าง ๆ ดังต่อไปนี้ ส่วนเพิ่มเติมอีกสองส่วน — **เซ็นเซอร์แสง DAQ**และ**การจัดแนวอาร์เรย์** — จะปรากฏขึ้นโดยอัตโนมัติเมื่อโครงการของคุณมีไฟล์ที่เกี่ยวข้อง สำหรับเอกสารประกอบที่ครบถ้วน โปรดดู [การตั้งค่าโครงการ](../project-settings/project-settings.md).

### การแสดงผล

* **ความละเอียดของภาพขนาดย่อ**: ความละเอียดของภาพขนาดย่อในตารางภาพ ตัวเลือก:**ค่าเริ่มต้น (512 px)**,**1024 px**,**2048 px**,**ความละเอียดเต็ม**. ใช้สำหรับการแสดงผลเท่านั้น — ไม่ส่งผลต่อการประมวลผลเลย ค่าที่สูงขึ้นจะดูคมชัดขึ้นเมื่อซูมเข้า แต่โหลดช้าลง

### การตรวจจับเป้าหมาย

ควบคุมวิธีที่Chloros
ใช้เพื่อระบุเป้าหมายการปรับเทียบในภาพของคุณ

**การตั้งค่าหลัก:*** **พื้นที่ตัวอย่างการปรับเทียบขั้นต่ำ (px)**: ค่าเกณฑ์ขนาดสำหรับการตรวจจับเป้าหมาย (ค่าเริ่มต้น:**25**, ช่วง 0–10000)
* **ค่าความคล้ายคลึงขั้นต่ำสำหรับการจัดกลุ่มเป้าหมาย (0-100)**: ค่าเกณฑ์ความคล้ายคลึงสำหรับการจัดกลุ่มพื้นที่เป้าหมาย (ค่าเริ่มต้น:**60**)**เมื่อใดควรปรับ:**

* เพิ่มพื้นที่ตัวอย่างหากเกิดการตรวจจับผิด
* ลดลงหากไม่ตรวจพบเป้าหมาย
* ปรับค่าการกลุ่มเป้าหมายหากเป้าหมายถูกแบ่งออกเป็นหลายจุดตรวจจับ

{% hint style="info" %}
การตั้งค่าเหล่านี้จะถูกทำให้เป็นสีเทาเมื่อ **การปรับเทียบการสะท้อน / สมดุลสีขาว** ถูกปิด — เมื่อปิดการตั้งค่านี้ การตรวจจับเป้าหมายจะไม่ทำงานเลย
{% endhint %}

### การประมวลผล

ตัวเลือกหลักสำหรับการประมวลผลภาพและการปรับเทียบ

**การตั้งค่าหลัก:*** **การแก้ไข vignette**: ชดเชยความมืดของเลนส์ที่ขอบภาพ ✅ แนะนำ
* **การปรับเทียบการสะท้อน / สมดุลสีขาว**: ปรับเทียบภาพโดยใช้เป้าหมายที่ตรวจพบ (Survey3
) และ/หรือข้อมูลจากเซ็นเซอร์แสง DAQ (LATTICE) ✅ แนะนำ
* **วิธี Debayer**: อัลกอริทึมสำหรับการแปลงไฟล์ RAW เป็นภาพมัลติสเปกตรัม 3 ช่อง
* **ช่วงเวลาปรับเทียบขั้นต่ำ**: เวลาขั้นต่ำเป็นวินาทีระหว่างการใช้เป้าหมายการปรับเทียบ (ค่าเริ่มต้น:**0** = ใช้ทั้งหมด, ช่วง 0–3600)**ผลิตภัณฑ์สำรองเมื่อไม่มีการปรับเทียบ:**เมื่อไม่สามารถปรับเทียบการสะท้อนแสงของเฟรมได้ (ไม่มีเป้าหมายให้ใช้ หรือการปรับเทียบถูกปิดใช้งาน) เฟรมนั้นจะถูกส่งออกเป็นหนึ่งในสองผลิตภัณฑ์สำรอง —**มีเพียงหนึ่งผลิตภัณฑ์จากคู่ดังกล่าวต่อการรัน** ซึ่งถูกเลือกโดยสวิตช์การแก้ไข Vignette:

* **ส่งออกการตอบสนองของเซ็นเซอร์**: เขียน `Sensor_Response_Images` — ใช้เมื่อการแก้ไข Vignette**ปิด*** **ส่งออกภาพที่แก้ไข vignette**: เขียนเป็น `Vignette_Corrected_Images` — ใช้เมื่อการแก้ไข vignette**เปิด**ช่องทำเครื่องหมายที่ไม่ได้ใช้งานจะถูกทำให้เป็นสีเทา การยกเลิกการเลือกช่องที่ใช้งานอยู่จะหยุดการเขียนไฟล์นั้นโดยสิ้นเชิง**ผลิตภัณฑ์ส่งออก LATTICE** (แสดงสำหรับทุกโครงการ; ใช้ได้กับการจับภาพ LATTICE):

* **ส่งออกภาพที่ถอดเบย์เออร์**: ภาพที่ถอดเบย์เออร์แบบเชิงเส้น (`Debayered_Images`) ใช้ได้กับโมดูลRGB
และ multispectral
* **ส่งออกภาพตัวอย่าง**: ภาพตัวอย่างที่แสดงบนหน้าจอ (`Preview_Images`)RGB
= การปรับสมดุลสีขาว (ใช้แหล่งแสง DAQ หากมี มิฉะนั้นใช้ gray-world) + gamma; multispectral = การขยายสีเท็จ
* **ส่งออก radiance**: ความส่องผ่านสเปกตรัมแบบ float32 (`Radiance_Images`, W/m²/sr/nm). เฉพาะโมดูลมัลติสเปกตรัม — ไม่ใช้กับมาสเตอร์แบบRGB

* ****ส่งออกค่าสะท้อน**: ค่าสะท้อนแบบ uint16 (`Reflectance_Calibrated_Images`, DN 32768 = ρ 1.0) เมื่อมีค่าการอ่านแบบลงสู่พื้นผิว (downwelling) ของ `.daq` หรือเป้าหมายภายในเฟรมที่ครอบคลุมเฟรมนั้น ใช้ได้เฉพาะกับโมดูลมัลติสเปกตรัมเท่านั้น

ทั้งสี่ตัวเลือก **เปิดโดยค่าเริ่มต้น**— เฟรมดิบ LATTICE ที่นำเข้าหนึ่งเฟรมจะถูกกระจายไปยังทุกผลิตภัณฑ์ที่เปิดใช้งานและเหมาะสมในรอบการประมวลผลครั้งเดียว ช่องทำเครื่องหมาย**ส่งออกค่าสะท้อน** จะถูกทำให้เป็นสีเทาเมื่อการปรับเทียบค่าสะท้อนถูกปิด การตั้งค่าที่สวิตช์หลักทำให้ไม่สามารถใช้งานได้ จะถูกทำให้เป็นสีเทาเสมอ พร้อมด้วยข้อความแสดงข้อมูล (tooltip) ที่ระบุชื่อสวิตช์ที่ต้องปรับเปลี่ยน**การตั้งค่าขั้นสูง:*** **การปรับเวลาโซนของเซ็นเซอร์แสง**: จำนวนชั่วโมงจาก UTC สำหรับการปรับเวลาของเซ็นเซอร์แสงให้ตรงกัน (ค่าเริ่มต้น: 0, ช่วง −12 ถึง +12)
* **ใช้การแก้ไข PPK**: ใช้ข้อมูล GPS/จุดกำหนดการเปิดรับแสงจากไฟล์ `.daq` (ค่าเริ่มต้น: ปิด)
* **จุดกำหนดการเปิดรับแสง 1/2**: กำหนดกล้องไปยังจุดกำหนดการเปิดรับแสงสำหรับการตั้งค่ากล้องคู่

{% hint style="info" %}
**ระดับการป้อนข้อมูล LATTICE เป็นอัตโนมัติ** การบันทึกของ LATTICE จะเก็บระดับการประมวลผลไว้ในเมตาดาต้า XMP และการประมวลผลจะเข้าสู่กระบวนการเสมอที่เฟรมดิบ — ไม่มีอะไรต้องตั้งค่าใน GUI (มีแฟล็ก &quot;CLI
&quot; `--input-level` สำหรับผู้ใช้ขั้นสูงเพื่อแทนที่การตั้งค่าสำหรับการบันทึกที่สูญเสียข้อมูลเมตาดาต้า; ดู [CLI
Reference](../reference/cli-reference.md).)
{% endhint %}

### วิธีเดเบเยอร์

ปัจจุบันเรามี 2 วิธีเดเบเยอร์ในChloros
:

#### มาตรฐาน (เร็ว, คุณภาพปานกลาง)

เดเบเยอร์แบบมาตรฐานทำงานได้รวดเร็ว แต่แสดงสัญญาณรบกวนสีจากการเดเบเยอร์ ซึ่งส่งผลให้ภาพมีความแม่นยำน้อยลงและมีสัญญาณรบกวนมากขึ้น

#### Texture Aware (ช้า, คุณภาพสูงสุด) \[Chloros
+ เท่านั้น]

Texture Aware ใช้การเดเบเยอร์คุณภาพสูงที่คำนึงถึงขอบภาพ ร่วมกับโมเดลลดสัญญาณรบกวนด้วย AI/ML ซึ่งสามารถกำจัดสัญญาณรบกวนจากการเดเบเยอร์ได้เกือบทั้งหมด โมเดลนี้ต้องการหน่วยความจำ GPU (VRAM) เพื่อทำงาน: ด้วย **VRAM 7 GB หรือมากกว่า** สามารถประมวลผลภาพหลายภาพพร้อมกันได้; หากต่ำกว่า 7 GB จะประมวลผลภาพทีละภาพ (ช้าลงอย่างเห็นได้ชัด) ดู [Dynamic Compute Adaptation](../processing-architecture/dynamic-compute-adaptation.md).

{% hint style="info" %}
**ภาพที่ถ่ายด้วย LATTICE จะใช้การเดโมซิกแบบมาตรฐานเสมอ** เนื่องจากไม่มีโมเดล Texture Aware ที่ได้รับการฝึกอบรมสำหรับ LATTICE ดังนั้นตัวเลือกนี้จึงไม่ปรากฏสำหรับภาพ LATTICE — แต่ภาพSurvey3
ในโครงการเดียวกันยังสามารถใช้ตัวเลือกนี้ได้
{% endhint %}

### ดัชนี (ดัชนีมัลติสเปกตรัม)

กำหนดดัชนีพืชพรรณที่จะคำนวณและส่งออก เมนูแบบเลื่อนลงใน GUI มี **สูตรดัชนีที่กำหนดไว้ล่วงหน้า 27 สูตร**

**วิธีเพิ่มดัชนี:**

1. คลิกปุ่ม**&quot;Add index&quot;**

2. เลือกดัชนีจากเมนูแบบเลื่อนลง (NDVI
,NDRE
,GNDVI
, เป็นต้น)
3. ตั้งค่าการแสดงผล (สี LUT, ช่วงค่า)
4. เพิ่มดัชนีหลายตัวตามความต้องการ

**ดัชนียอดนิยม:*** **NDVI**: สุขภาพพืชทั่วไป (ใช้บ่อยที่สุด)
* **NDRE**: การตรวจจับความเครียดในระยะเริ่มต้นด้วยRedEdge
* **GNDVI**: ความไวต่อความเข้มข้นของคลอโรฟิลล์
* **OSAVI**: ทำงานได้ดีกับดินที่มองเห็นได้
* **EVI**: พื้นที่ที่มีดัชนีพื้นที่ใบสูง (LAI
)

**สูตรกำหนดเอง:**

* สร้างสูตรดัชนีมัลติสเปกตรัมกำหนดเองด้วยการคำนวณทางคณิตศาสตร์ระหว่างช่องสัญญาณภาพทั้งหมด
* บันทึกสูตรกำหนดเองเพื่อใช้ซ้ำ
* สูตรที่กำหนดเองเป็นคุณสมบัติของChloros
+; ความพร้อมใช้งานขึ้นอยู่กับระดับแผนบริการของคุณ

สำหรับดัชนีและสูตรทั้งหมดที่มีอยู่ — รวมถึงชื่อใดที่ใช้ได้เฉพาะใน GUI และชื่อใดที่ใช้งานได้ในCLI
/SDK
— ดู [สูตรดัชนีมัลติสเปกตรัม](../project-settings/multispectral-index-formulas.md).

### ส่งออก

ควบคุมรูปแบบไฟล์ผลลัพธ์

**รูปแบบที่มีอยู่**(การตั้งค่า:**รูปแบบภาพที่ปรับเทียบ**, ค่าเริ่มต้น**TIFF
(16-bit)**):

* **TIFF
(16-bit)**: แนะนำสำหรับ GIS และการวิเคราะห์ทางวิทยาศาสตร์
* **TIFF
(32-bit, Percent)**: ค่าทศนิยม
* **PNG
(8-bit)**: การบีบอัดแบบไม่สูญเสียข้อมูลสำหรับการแสดงผล
* **JPG (8-bit)**: ไฟล์ขนาดเล็กที่สุด, การบีบอัดแบบสูญเสียข้อมูล

ไฟล์ผลลัพธ์จะถูกบันทึกไว้ในโฟลเดอร์โครงการ โดยจัดกลุ่มตามกล้องและรูปแบบ: `<project>/<camera>/<format>/<Product>_Images/` ค่า Radiance จะ **ถูกบันทึก**เป็น float32 ในโฟลเดอร์ `tiff32`**เสมอ** ไม่ว่าการตั้งค่านี้จะเป็นอย่างไร ไฟล์ที่ส่งออกจะรักษาชื่อไฟล์ต้นฉบับ — โฟลเดอร์จะระบุผลิตภัณฑ์ ดู [การเสร็จสิ้นการประมวลผล](finishing-the-processing.md) เพื่อดูโครงสร้างโฟลเดอร์ผลลัพธ์ทั้งหมด

### เซ็นเซอร์แสง DAQ

ส่วนนี้แสดงรายการไฟล์ DAQ downwelling ทุกไฟล์ (`.daq` / `.csv`) ในโครงการของคุณ โดยแต่ละไฟล์มีหนึ่งแถว แสดงรุ่นเซ็นเซอร์ ชื่อไฟล์ และการปรับ **cap** ของตัวกระจายแสงที่ใช้กับไฟล์นั้น

* **การแทนที่ค่า cap (ทุกไฟล์)**: เมนูแบบเลื่อนลงเดียวที่ใช้ได้กับทั้งโครงการ**Auto** (ค่าเริ่มต้น) ใช้ค่า cap ที่บันทึกไว้ในแต่ละไฟล์ — หากไม่มีการบันทึกค่า cap ใดๆ จะถือว่าอยู่ในสภาพแสงแดด เนื่องจาก DAQMAPIR
ทุกเครื่องมาพร้อมตัวปรับค่าแสงแดด การเลือกค่า cap จะแทนที่ค่าของทุกไฟล์: การบันทึกแบบดิบจะถูกปรับแก้ด้วยค่านี้ และการบันทึกที่มีค่า cap อยู่แล้วจะถูกอ้างอิงใหม่ (การปรับแก้ที่บันทึกไว้จะถูกยกเลิก และค่า cap ที่เลือกจะถูกนำไปใช้)
* แถวจะแสดงคำเตือนเมื่อค่าขีดจำกัดที่บันทึกไว้เป็นค่าเริ่มต้นที่ฮับสมมติขึ้นแทนที่จะได้รับการยืนยันจากผู้ใช้งาน และเมื่อค่าขีดจำกัดที่เลือกไม่มีโปรไฟล์สำหรับรุ่นอุปกรณ์นั้น (การแทนที่จะถูกปฏิเสธสำหรับไฟล์นั้น)

ข้อมูลบันทึก DAQ ที่สร้างในแท็บ Light Sensors จะถูกเพิ่มเข้าไปในโครงการที่เปิดอยู่โดยอัตโนมัติ และไฟล์ `.daq` / `.csv` ที่นำเข้าจะปรากฏที่นี่ทันทีที่เพิ่มเข้าไป

<figure><img src="../.gitbook/assets/image (32).png" alt=""><figcaption><p>การตั้งค่าโครงการส่วนล่าง — ดัชนี, รูปแบบการส่งออก, ส่วน DAQ Light Sensor, และการควบคุมแม่แบบ/โฟลเดอร์โครงการ</p></figcaption></figure>### การจัดแนวอาร์เรย์

ส่วนนี้จะปรากฏ **เฉพาะ** เมื่อมีภาพอย่างน้อยหนึ่งภาพในโครงการที่มีการแปลงการจัดแนวระหว่างโมดูล ซึ่งอาร์เรย์ LATTICE บันทึกไว้ขณะจับภาพ (`Chloros:Alignment*` XMP) ส่วนนี้แสดงจำนวนภาพที่มีแท็กและกล้องใดเป็นกล้องอ้างอิง พร้อมด้วยตัวเลือกควบคุมต่อไปนี้:

* **ใช้การจัดแนวอาร์เรย์** (ค่าเริ่มต้น: เปิด): ปรับรูปทรงของผลิตภัณฑ์ที่ประมวลผลทุกชนิด (debayered / preview / radiance / reflectance / index) ให้สอดคล้องกับรูปทรงอ้างอิงร่วมของอาร์เรย์ ปิด = ส่งออกในรูปแบบรูปทรงเซนเซอร์ต้นฉบับ
* **ตัดให้เหลือพื้นที่ทับซ้อนร่วมกัน** (ค่าเริ่มต้น: เปิด): ตัดส่วนที่ส่งออกที่จัดแนวแล้วให้เหลือเฉพาะพื้นที่ที่ทุกโมดูลมีร่วมกัน เพื่อให้ทุกแบนด์มีพื้นที่ทับซ้อนเท่ากัน การปิดจะรักษาพื้นที่เซนเซอร์เต็ม (เติมสีดำนอกพื้นที่ต้นทาง)
* **การสุ่มตัวอย่างใหม่**:**Bilinear (เรียบเนียน, ค่าเริ่มต้น)**,**Nearest (รักษาค่าที่แม่นยำ)**— ไม่มีการผสมระหว่างพิกเซล สำหรับการวิเคราะห์รังสีอย่างเคร่งครัด — หรือ**Cubic (คมชัดที่สุด)**.***

## การตั้งค่า PPK (Post-Processed Kinematic)

หากใช้เครื่องบันทึก DAQMAPIR

ที่มี GPS เพื่อกำหนดตำแหน่งทางภูมิศาสตร์อย่างแม่นยำ:

### ข้อกำหนดเบื้องต้น

* เครื่องบันทึก DAQMAPIR

ที่มีโมดูล GPS (GNSS)
* ไฟล์บันทึก .daq ที่มีข้อมูลพินการเปิดรับแสง
* กล้องที่เชื่อมต่อกับพินการเปิดรับแสงของ DAQ ระหว่างการบันทึก

### ขั้นตอนการตั้งค่า

1. วางไฟล์บันทึก .daq ในโฟลเดอร์โครงการของคุณ
2. ใน Project Settings (การตั้งค่าโครงการ), ทำเครื่องหมายในช่อง **&quot;Apply PPK corrections&quot;**

3. ตั้งค่า**&quot;Light sensor timezone offset&quot;** หากจำเป็น (ค่าเริ่มต้น: 0 สำหรับ UTC)
4. กำหนดกล้องให้ตรงกับพินการเปิดรับแสง:
   * **กล้องเดียว**: กำหนดอัตโนมัติให้พิน 1
   * **กล้องสองตัว**: กำหนดกล้องแต่ละตัวให้พินที่ถูกต้องด้วยตนเอง**การกำหนดพินการเปิดรับแสง:*** **พินการรับแสง 1**: เลือกรุ่นกล้องจากเมนูแบบเลื่อนลง
* **พินการรับแสง 2**: เลือกกล้องตัวที่สอง หรือ &quot;ไม่ใช้&quot;
* ไม่สามารถกำหนดกล้องตัวเดียวกันให้กับพินทั้งสองได้

{% hint style="warning" %}
**สำคัญ**: ต้องกำหนดพินการรับแสงให้ถูกต้องกับกล้องแต่ละตัว การกำหนดที่ผิดจะส่งผลให้ข้อมูลตำแหน่งทางภูมิศาสตร์ไม่ถูกต้อง
{% endhint %}
