#เราจะพบกับโครงการ

ก่อนตรวจสอบภาพเพื่อตรวจสอบคือต้องกำหนดความถี่โปรเจ็กต์ให้เป็นหลักข้อกำหนดขั้นตอนการทำงานของคุณตรวจสอบโปรเจ็กต์ <img src="../.gitbook/assets/icon_project-settings.JPG" alt="" data-size="line"> ให้เราทราบเกี่ยวกับการพิจารณาคดีที่สภาหลายกรณีและรูปแบบอย่างเป็นทางการ

##สำหรับโครงการเฝ้าระวัง

1.เปิดโปรเจ็กต์สำหรับ Chloros
2. คลิกไอคอน **บางครั้งโครงการ** <img src="../.gitbook/assets/icon_project-settings.JPG" alt="" data-size="line"> ในบางครั้งส่วนที่เหลือด้านซ้าย
3. การแสดงสดโครงการนี้ยังมีให้เห็นทั้งหมด

{% hint style="info" %}
**คุณจะได้ทราบถึงบันทึก** กับโปรเจ็กต์ของคุณโดยไม่ต้องเปิดโปรเจ็กต์อีกครั้งทั้งหมดในนั้นทั้งหมด...
{% endhint %}

## คุณรู้ด่วนสำหรับคืนนี้โฟลว์ทั่วไป

### จะเริ่มต้น (แนะนำไม่มีอะไรเลย)

สำหรับขั้นตอนกล้อง MAPIR Survey3 โดยทั่วไปทั่วไปจะเริ่มต้นจะ:

* ✅ **เป็นขอบมืด**: เปิดให้แล้ว
* ✅ **ตรงกับการเทียบเทียม**: เปิดใช้งาน (ต้องใช้รูปภาพของกลุ่มเป้าหมาย MAPIR)
* ✅ **วิธี Debayer**: มาตรฐาน (ความเข้มงวดในระดับปานกลาง)
* ✅ **รูปแบบการแสดง**: TIFF (16 เต้น)

เพียงนำเข้าภาพของคุณเท่านั้นด้วยเหตุนี้

##เฝ้าระวังโครงการ

เพื่อให้ทราบถึงโครงการที่จะช่วยให้สามารถสรุปเป็นส่วนสำหรับเอกสารประกอบฉบับสมบูรณ์ได้ [การติดตามโครงการ](../project-settings/project-settings.md)

### กำหนดเป้าหมาย

หลักการวิธีการ Chloros ระบุเป้าหมายที่เทียบเท่ากับของคุณ

**หมายเหตุหลัก:*** **พื้นที่ตัวอย่างเปรียบเทียบขั้นต่ำ**: เกณฑ์ขนาดสำหรับกลุ่มเป้าหมายหลัก (: 25 ฮาร์ดแวร์)
* **ภาพรวมของกลุ่มเป้าหมายขั้นต่ำ**: เมื่อพิจารณาถึงความสังเกตของกลุ่มภูมิภาคเป้าหมาย (60)**เมื่อใดควรสังเกต:**

*ขยายพื้นที่ตัวอย่างหากตรวจพบเท็จ
* หากตรวจไม่พบกลุ่มเป้าหมาย
*ชุดเกราะหากเป้าหมายถูกมองว่ามีหลายรูปแบบ

### ขึ้นอยู่กับการตัดสินใจ

ตรวจสอบและตรวจเทียบภาพหลัก

**เพิ่มเติมหลัก:*** **ต้องการขอบมืด**: กำหนดให้เลนส์มืดลงที่ขอบ ✅ โปรโมชั่น
* **เป็นจุดเทียบเคียงการประท้วง**: หอคอยให้เป็นมาตรฐานของกลุ่มเป้าหมายที่รองรับ ✅ ตรวจสอบ
* **วิธี Debayer**: ปกติสำหรับการควบคุม RAW โดยทั่วไปตามปกติ 3 แชนเนล
* **ช่วงที่เท่ากันเทียบใหม่ขั้นต่ำ**: เวลาระหว่างการใช้กลุ่มเป้าหมายเป็นจุดเทียบ (0 = ใช้ทั้งหมด)**เป็นจุดที่ยอดเยี่ยม:*** **ออฟเซ็ตเขตเวลาของไฮดรอลิกวัดแสง**: สำหรับการซิงโครไนซ์เวลา PPK (: 0)
* **ใช้ PPK**: ใช้ข้อมูล GPS/พินการรับแสงจากไฟล์ .daq
* **พินการรับแสง 1/2**: กำหนดกล้องให้กับการรับแสงสำหรับกล้องคู่

### วิธีการชำระหนี้

เราจะมีวิธีดีบาย 2 วิธีใน Chloros:

#### มาตรฐาน (ความเร็วเพียงเล็กน้อยปานกลาง)

การดีบายมาตรฐานจะดำเนินการอย่างรวดเร็วแต่แสดงสัญญาณรบกวนสีที่ลดแสงเพื่อให้ภาพมีน้อยลงและมีสัญญาณรบกวนมากขึ้น

#### Texture Aware (ช้าพบกับสุด) \[Chloros+ อย่าลืม]

Texture Aware ใช้ตัวดีบายที่ต้องใช้ถึงขอบในส่วนหัวของเซิร์ฟเวอร์โมดูลการควบคุมสัญญาณรบกวนของ AI/ML คำสั่งขจัดสัญญาณรบกวนจากสัญญาณรบกวนสัญญาณรบกวนรุ่น Texture Aware ต้องใช้ CPU (VRAM) เพื่อทำงานของเราไม่จำเป็นต้องใช้ VRAM >4GB เพื่อประสิทธิภาพที่ติดตาม

### ดัชนี (ดัชนีหลาย ๆ ครั้ง)

ดัชนีดัชนีพืชพรรณที่จะคำนวณและส่งออก

**วิธีเพิ่มดัชนี:**

1. พิพิธภัณฑ์**"เพิ่มดัชนี"**

2. เลือกดัชนีจากเมนูแบบเลื่อนลง (NDVI, NDRE, GNDVI ฯลฯ)
3. บันทึกการแสดงภาพ (สี LUT, ช่วงค่า)
4.และดัชนีหลายรายการตามความต้องการ

**ดัชนียอดนิยม:*** **NDVI**: สุขภาพพืชทั่วไป (พบมากที่สุด)
* **NDRE**: ความเครียดตั้งแต่เนิ่นๆด้วย RedEdge
* **GNDVI**:ไวต่อรังสีของคลอโรฟิลล์
* **OSAVI**: การควบคุมกับดินที่เก็บข้อมูลได้
* **EVI**: ดัชนีพื้นที่เพจสูง (LAI)**สูตรของการตอบสนอง (Chloros+ เท่านั้น):**

* สร้างสูตรดัชนีหลายอย่างพร้อมกัน
* ใช้ band math กับทุกช่องภาพ
* หมายเหตุสูตรนี้เพื่อเป็นการสร้างซ้ำ

สำหรับดัชนีและสูตรทั้งหมดทั้งหมด [สูตรดัชนีหลายเหตุการณ์](../project-settings/multispectral-index-formulas.md)

###ส่งออก

ศึกษารูปแบบและคุณภาพไฟล์ดังกล่าว

**รูปแบบที่มี:*** **TIFF (16)**: แนะนำสำหรับ GIS และการออกกำลังกาย (ช่วง 0-65,535)
* **TIFF (32 คืนนี้, คืนนี้)**: ค่าการสะท้อนแสงจุดทศนิยม (ช่วง 0.0-1.0)
* **PNG (8 กระท่อม)**: ไม่จำเป็นต้องใช้คุณภาพสำหรับการแสดงภาพ (ช่วง 0-255)
* **JPG (8 เครื่องเล่น)**: รองรับที่เล็กที่สุดแบบเก็บข้อมูล (ช่วง 0-255)***

## การวิจัยและการอ่านเรื่องราว

### บันทึกกำหนดการโครงการ

สร้างรูปแบบที่นำมาใช้ซ้ำได้สำหรับขั้นตอนการทำงานที่สำคัญ:

1. บันทึกเพิ่มเติมต้องการแผงเพิ่มเติมโครงการ
2. เลื่อนไปที่ส่วน **" บันทึกแผนที่โครงการ"** ที่ด้านล่าง
3. ป้อนชื่อเทมเพลตสื่อที่มีความหมาย (เช่น "Survey3N\_RGN\_Agriculture")
4. คลิกไอคอนบันทึก

**ประโยชน์:**

* ใช้งานได้หลายอย่างกับหลายโครงการ
*บางทีกับสมาชิกในทีม
* รักษาความยิ่งใหญ่อีกครั้งอีกครั้ง

### ดาวน์โหลดแผนการตรวจสอบใหม่

ที่กำลังสร้างโครงการใหม่:

1. เลือก **"โครงการใหม่"** จากเมนูหลัก
2. เลือก **ตัวเลือก "โหลดจากเทมเพลต"**

3. เลือกไปที่จุดหมายปลายทางของคุณ
4. พวกเขาทั้งหมดจะใช้ระบบปฏิบัติการ

### รองรับการทำงาน

**"บันทึกการติดตามโครงการ"** ระบุตำแหน่งโครงการใหม่ตามข้อมูล:

* **ตำแหน่งเริ่มต้น**: `C:\Users\[Username]\Chloros Projects`
* **เปลี่ยนตำแหน่ง**: คลิกไอคอนแก้ไขข้อมูลข่าวสารใหม่
* **เมื่อใดควรเปลี่ยน**:
  * ไดรฟ์เครือข่ายสำหรับระบบเป็นทีม
  * ไดรฟ์พร้อมกันพร้อมพื้นที่ส่วนใหญ่ที่มากขึ้น
  * โครงสร้างโครงสร้างตามปี/ลูกค้า

## หลังจากนั้น PPK (จลนศาสตร์หลังๆ)

หากใช้เครื่องบันทึก MAPIR DAQ พร้อม GPS สำหรับผู้บริหารระดับสูง:

### เบื้องต้น

* MAPIR DAQ พร้อม GPS (GNSS)
*ตรวจสอบบันทึก .daq พร้อมรายการพินการเปิดรับ
* ตรวจสอบการรับแสง DAQ บันทึกการจับภาพ

###ในครั้งต่อไป

1. สามารถไฟล์บันทึก .daq สามารถติดตามโครงการของคุณได้
2. ในโปรเจ็กต์นี้สามารถตรวจสอบช่องได้ทันที **"ใช้ PPK"**

3. ติดตั้ง**"การจัดเก็บข้อมูลเขตเวลาของฟังก์ชั่นวัดแสง"** จำเป็นต้องมี (: 0 สำหรับ UTC)
4. กำหนดกล้องให้กับหมุดรับแสง:
   * **กล้องตัวเดียว**: กำหนดให้กับพิน 1
   * **กล้องคู่**: กำหนดกล้องแต่ละตัวเพิ่มเติมเพื่อแก้ไขพิน**สำหรับเพนซิล:*** **Exposure Pin 1**: เลือกรุ่นกล้องจากเมนูแบบเลื่อนลง
* **Exposure Pin 2**: ไปที่กล้องตัวที่สองหรือ "ห้ามใช้"
* กล้องตัวเดียวกันสามารถกำหนดร่วมกับพินได้

{% hint style="warning" %}
**ข้อสำคัญ**: โต๊ะกำหนดหมุดรับแสงให้กับกล้องที่อ้างถึงการที่คนส่วนใหญ่จะทราบข้อมูลตำแหน่งของระบบปฏิบัติการ
{% endhint %}

## สภาพอากาศขั้นสูง

### โครงการกล้องหลายตัว

เมื่อตรวจสอบภาพจากกล้อง MAPIR ตรวจสอบตัวในโปรเจ็กต์เดียว:

1. Chloros กล้องแต่ละตัวรุ่นต่างๆ
2. วิดีโอของเธอได้รับโปรไฟล์ที่ดีของเธอ
3. PPK: กำหนดกล้องแต่ละตัวเพิ่มเติมเพื่อแก้ไขการรับแสง
4. กล้องทั้งหมดใช้รูปแบบนี้และดัชนีเดียวกัน

**ตัวอย่าง**: Survey3W RGN + Survey3N OCN อุปกรณ์กล้องคู่

### แบบสำรวจในวันนี้หรือหลายวัน

อีกครั้งอีกครั้งในเวลาเดียวกันอีกครั้งหนึ่ง:

1. สร้างแผนภูมิด้วยมาตรฐานของคุณ
2. ใช้เป้าหมายที่เป็นจุดสังเกตอย่างต่อเนื่อง
3. รายละเอียดแต่ละวันเป็นโครงการวิจัย
4. ใช้หลายๆ อย่างเพื่อให้ได้ผลลัพธ์ที่เปรียบเทียบได้
5. ส่งออกพร้อมกันเพื่อวิเคราะห์ชั่วคราว

### ชุดข้อมูลขนาดใหญ่

สำหรับโปรเจ็กต์ที่มีรูปภาพจำนวนมาก (500+):

* พิจารณาแยกโครงการอื่นๆตามวันที่หรือพื้นที่
* ใช้ความเย็นแบบฤดูหนาว Chloros+ เพื่อให้ผลลัพธ์ที่เป็นผลสืบเนื่อง
* พิจารณา CLI หรือ API สำหรับระบบอัตโนมัติแบบแบตช์
*ช่วงที่เท่ากันจะเทียบใหม่ขั้นต่ำตามเวลาที่กำหนดเป้าหมาย
