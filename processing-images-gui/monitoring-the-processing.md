#การควบคุมอัตโนมัติ

ไปที่จุดเริ่มต้นขึ้น Chloros มีห้องอาหารในร้านอาหารหลายแห่งในคลินิกปัญหาและเข้าใจว่าเป็นกับชุดข้อมูลของคุณที่นี่ อธิบายวิธีติดตามการปฏิบัติตามกฎระเบียบตีความ Chloros ไปที่

## อย่างต่อเนื่องคืนนี้

ที่โดดเด่นในด้านบนสุดของสถานะการรับชมและเปอร์เซ็นต์ความสำเร็จ

### โหมดทึบโหมดฟรี

ไม่เคยเลย Chloros+:

**การแสดงอีกครั้ง 2 พบกับ:**

1.** เป้าหมายเป้าหมาย** - ค้นหาเป้าหมายในสถานที่ดังกล่าว
2. **การแสดง** - รายงานและล่าสุด**ส่วนใหญ่จะแสดง:**

*ประสบความสำเร็จร่วมกัน (0-100%)
* ชื่อปัจจุบัน
* เพิ่มเติมภาพอย่างรวดเร็วอย่างรวดเร็วอย่างง่าย

### Chloros+ อาจจะไม่

เอกสารที่มี Chloros+:

**การแสดงอีกครั้ง 4 พบกับ:**

1.**พื้นที่** - ค้นหาเป้าหมายเทียบเคียง
2. **วิเคราะห์** - ถ่ายภาพและเตรียมไปป์ไลน์
3. **มีการเทียบเคียง** - บทความสั้นและตรงการเคารพ
4. **การแสดง** - บันทึกไฟล์ที่เห็นได้ชัด**คุณสมบัติแบบมัลติมีเดีย:*** **วางเมาส์เหนือ** แผงควบคุมที่แข็งแกร่ง 4 ขั้นตอนที่ขยาย
* **คลิก** สามารถตรวจสอบได้เพื่อตรวจสอบ/ปักหมุดแผงที่ขยาย
* **คลิกอีกครั้ง** สำหรับระบบปฏิบัติการและซ่อนอัตโนมัติเมื่อปล่อยเมาส์
* จะมีด่านตรวจเจอของคืนนี้ (0-100%)

## เรียนรู้ขั้นตอนในแต่ละวัน

**ติดตามไปป์ไลน์**: GUI ทั้ง 4 ในกรณีนี้คือ [ไปป์ไลน์ในการควบคุมแบบ 4](../processing-architecture/processing-pipeline.md) บนระบบและประสิทธิภาพของ GPU Thread 3 (เทียบเท่ากับคู่แข่ง) จะควบคุมจาก [Dynamic Compute Adaptation](../processing-architecture/dynamic-compute-adaptation.md) ตรวจสอบปรับให้เหมาะสมสำหรับฮาร์ดแวร์เฉพาะของคุณ
{% endhint %}

### ห้องโถง 1: สังเกตการณ์ (เป้าหมาย)

**ส่วน:**

* Chloros สแกนดูภาพด้วยช่องเป้าหมาย
* อัลกอริธึมในตำนานของคอมพิวเตอร์ระบุแผงเทียบกับ 4 ประตู
* ค่าสะท้อนที่ดึงมาจากแต่ละแผง
* การประชันเวลาเป้าหมายที่เป็นจุดอ้างอิงของการสนับสนุน

**ระยะเวลา:**

* โดยที่วันพรุ่งนี้ไว้: 10-60 วินาที
* ไม่มีเป้าหมายที่จะเกิดขึ้นไว้: 5-30+ นาที ( สแกนภาพทั้งหมด)

**ในเวลานี้:**

* แผ่น: 0% → 100%
* ประเภทของมุมมอง
* จำนวนกลุ่มเป้าหมายที่พบ

**สิ่งที่ต้องระวัง:**

* ขั้นตอนการดำเนินการให้เร็วขึ้นหากจำเป็นอย่างถูกต้อง
* หากตรวจพบมากเกินไปอาจจะไม่ถูกเลย
* บันทึกความเข้าใจที่แท้จริงสำหรับข้อความ "พบเป้าหมาย"

### การบำบัด 2: ยุง

**ส่วน:**

* ผู้สำรวจข้อมูลเมตา EXIF ของรูปภาพ (การเก็บข้อมูลเวลาเพื่อรับแสง)
* กลยุทธ์ที่สอดคล้องกับการประกบเวลาเป้าหมาย
*ตามที่คุณต้องการคิวอัตโนมัติภาพ
* การเตรียมผู้ปฏิบัติงานที่เป็นไปตามแบบอนุกรม (Chloros+ พิเศษสำหรับ)

**ระยะเวลา:**5-30 วินาที**ยังคงเป็น:**

* กราฟ: 0% → 100%
*ด่านเร็วอาจจะจบเร็ว

**สิ่งที่ต้องระวัง:**

* มีความก้าวหน้าอย่างมั่นคงไม่มีหยุดชั่วคราว
* คำเตือนเกี่ยวกับข้อมูลเมตาที่หายไปในบันทึกที่ละเอียด

### พาร์ท 3: เป็นเรื่องเทียบ

**ส่วน:*** **Debayering**: ในรูปแบบ RAW Bayer เป็น 3 ช่อง
* **ต้องการขอบความมืด**: อย่าลืมโหลดขอบมืดลง
* **เป็นเหมือนเทียบเทียม**: เป็นมาตรฐานด้วยค่ากลุ่มเป้าหมาย
* **ดัชนีดัชนี**: ดัชนีดัชนีหลายเหตุการณ์
* ติดตามภาพแต่ละภาพผ่านทางไปเส้นทางแบบเต็ม

**ระยะเวลา:**ระยะเวลาปกติ (60-80%)**ยังคงเหมือนเดิม:**

* เทียบเท่า: 0% → 100%
*ภาพปัจจุบันนี้ถูกกฎหมายเช่นกัน
* รูปภาพที่อัปเดต / รูปภาพทั้งหมด

**วิธีการปฏิบัติ:*** **โหมดอิสระ**: กำหนดภาพแต่ละภาพตามลำดับ
* **โหมด Chloros+**: ความละเอียดของภาพสูงสุด 16 ภาพพร้อมกัน
* **การฝึกฝน GPU**: ความเร็วที่เพิ่มขึ้นขั้นนี้**สิ่งที่ต้องระวัง:**

* ต่อเนื่องตลอดเวลานับภาพ
* บันทึกจริงๆ เพื่อดูข้อความที่ไม่ต้องต่อภาพ
* คำเตือนเกี่ยวกับคุณภาพภาพหรือปัญหาในเรื่องเทียบเคียง

### คืนนี้ 4: ในกรุงเวียนนา

**ส่วน:**

* เนื้อหาประกอบการปรับเทียบแล้วลงมติในการเลือกตั้ง
* ส่งออกภาพดัชนีหลายเหตุการณ์ด้วยสี LUT
* กำหนดการย่อยรุ่นกล้อง
* รักษาชื่อไฟล์ต้นฉบับพร้อมส่วนต่อท้าย

**ระยะเวลา:**10-20% ของเวลาทั้งหมด**ส่วนที่เหลือ:**

* เพียงเล็กน้อย: 0% → 100%
*กำลังเขียนอยู่ครับ
*แม้จะเป็นเช่นนั้นและปลายทาง

**สิ่งที่ต้องระวัง:**

* คำเตือนพื้นที่ไม่อนุญาตให้
* มีเนื้อหาในเนื้อหาไฟล์
* และอื่น ๆ ทั้งหมด

## ในส่วนบันทึกที่แท้จริงนั้น

บันทึกเหตุผลโดยละเอียดเกี่ยวกับเรื่องนี้ในกฎระเบียบและปัญหาใดๆ ทราบ

### ในส่วนลึกของบันทึกนั้น

1. คลิก **และมีบันทึกบางส่วน** <img src="../.gitbook/assets/icon_log.JPG" alt="" data-size="line"> ในกระแสเรียกร้องด้านซ้าย
2. บันทึกเรื่องราวต่างๆ จะขึ้นอยู่กับเรื่องราวต่างๆ ในเรื่องนั้น
3. เลื่อนอัตโนมัติในข้อความล่าสุด

### เข้าใจกับข้อความบันทึก

#### บอกข้อมูล (ขาว/เทา)

การควบคุมปกติปกติ:

```
[INFO] Processing started
[INFO] Target detected in IMG_0015.RAW - 4 panels found
[INFO] Calibrating IMG_0234.RAW
[INFO] Exported NDVI image: IMG_0234_NDVI.tif
[INFO] Processing complete
```

####เตือนเตือน (สีเหลือง)

ไม่สำคัญอย่างยิ่งที่ไม่หยุด:

```
[WARN] No GPS data found in IMG_0145.RAW
[WARN] Target image timestamp gap > 30 minutes
[WARN] Low contrast in calibration panel - results may vary
```

**การดำเนินการ:** คำเตือนคำเตือนหลัง แต่อย่าขัดจังหวะ

#### การเข้าพักของเรา (Red)

สิ่งสำคัญที่ส่งผลต่อระบบ:

```
[ERROR] Cannot write file - disk full
[ERROR] Corrupted image file: IMG_0299.RAW
[ERROR] No targets detected - enable reflectance calibration or mark target images
```

**การดำเนินการ:** คุณสามารถดูการถ่ายทอดสดของ...

###บันทึกธรรมชาติทั่วไป

| สิ่ง | ความหมาย | เป็นเพียง |
| -------------------------------- | -------------------------------------- | ----------------------------------------------------------------- |
| " ค้นพบเป้าหมายใน \[ชื่อไฟล์]" | พบกับเป้าหมายที่จะสำเร็จเทียบเท่าแล้ว | ไม่มี - ปกติ |
| "กำลังติดตามรูปภาพ X จาก Y" | อัพเดทล่าสุดในปัจจุบัน | ไม่มี - ปกติ |
| "ไม่พบเป้าหมาย" | ไม่พบกลุ่มเป้าหมายที่เทียบเคียง | ต่อไปนี้เป็นเป้าหมายของเป้าหมายหรือเทียบเท่ากับการจำลอง |
| "พื้นที่สำหรับรวบรวมข้อมูล" | เหตุใดสิ่งนี้สำหรับเหตุผลที่ | ยังว่างอยู่ในที่โล่ง |
| "ข้ามไฟล์ที่เฟิร์มแวร์" | นี่คือภาพของโลก | ไฟล์ไฟล์จากการ์ด SD อีกครั้ง |
| "ใช้ข้อมูล PPK" | ใช้ GPS จากไฟล์ .daq | ไม่มี - ปกติ |

### อ่านเพิ่มเติมเกี่ยวกับข้อมูลบันทึก

เรื่องของบันทึกเพื่อการแก้ปัญหาหรือสนับสนุน:

1. เปิดแผงอย่างละเอียดบันทึกรายละเอียด
2. บันทึก **"บันทึกการเดินทาง"** (หรือคลิกขวา → เลือกทั้งหมด)
3. ลงไปที่ไฟล์ข้อความหรืออีเมล
4. ส่งไปที่ฝ่ายสนับสนุน MAPIR จำเป็นต้องมี

## ตรวจสอบทรัพยากรระบบ

### รองรับซีพียู

**โหมดฟรี:**

* 1 CPU คอร์ที่ \~100%
* และอื่นๆ อีกมากมายที่ใช้งานได้หรือพร้อมใช้งาน
* ยังคงเป็นอย่างนั้น

**Chloros+ฮีไคร:**

* ควบคุมคอร์ที่ 80-100% (สูงสุด 16 คอร์)
* CPU โดยรวมสูง
* ระบบอาจรู้สึกได้น้อยลง

**เพื่อติดตาม:**

* Windows พนักงานจัดการงาน (Ctrl+Shift+Esc)
* ประสิทธิภาพ → ส่วน CPU
* ค้นหาที่ต้องการ "Chloros" หรือ "chloros-backend"

### เหตุผลประการนี้ (RAM)

**การใช้งานทั่วไป:**

* โครงการขนาดเล็ก (< 100 ภาพ): 2-4 GB
* โปรเจ็กต์สำเร็จ (100-500 ภาพ): 4-8 GB
* โปรเจ็กต์ขนาดใหญ่ (500+ ภาพ): 8-16 GB
* Chloros+ ฮีฮีฮีใช้ RAM อย่างเป็นทางการ

**หากยังมีเหลือน้อย:**

* แจ้งเตือนแบ๊ดแลนดฌที่มีขนาดเล็กลง
* ปิดโปรแกรมอื่นๆ
* การอัพเกรด RAM โปรดดูชุดข้อมูลขนาดใหญ่เป็นประจำ

### รองรับ GPU (Chloros+ พร้อม CUDA)

ในขณะนี้การทำงานร่วมกับ GPU:

* NVIDIA GPU แสดงการใช้งานสูง (60-90%)
* อย่าลืม VRAM (ต้องใช้ 4GB+ VRAM)
* ตรวจสอบเทียบเคียงกับภายนอกได้

**เพื่อติดตาม:**

*ไอคอนถาดระบบ NVIDIA
* คนจัดการงาน → ประสิทธิภาพ → GPU
* GPU-Z หรือเครื่องมือตรวจสอบสามารถตรวจสอบได้

### คืนนี้ I/O

**สิ่งที่สำคัญ:**

* อ่านเรื่องราวสูงขั้นตอนการวิเคราะห์
* เขียนรายละเอียดสูงในขั้นตอนนี้
* SSD เดล HDD เดล

**เคล็ดลับด้านประสิทธิภาพ:**

* ใช้ SSD สำหรับโครงการเมื่อเร็วๆนี้
* ดูสตรีมมิ่งเครือข่ายสำหรับชุดข้อมูลขนาดใหญ่
* บันทึกประจำวันไม่ใกล้ความจุ (บันทึกลงไป)

## สีดำและสีขาวระหว่างปัญหา

###บัลเล่ต์

**ไม่จำเป็นต้องแผงลอย (ไม่มีการเปลี่ยนแปลงเป็นเวลา 5+ นาที):**

* บันทึกการบันทึกจริงๆ ด้วยความที่สามารถดูได้
* ตัดพื้นที่ว่างในคืนนี้
* การตัด Task Manager ใน Chloros กำลังทำงานอยู่

**ข้อความแสดงทุกวันเป็นประจำ:**

*เราจะพบกับพวกเราได้
* เหตุผลทั่วไป: เหตุผลหลักๆ ของฉันเองที่เป็นสาเหตุ
* ดูส่วนในส่วนด้านล่าง

**ระบบไม่ทำให้กังวล:**

* Chloros+รีจิสทรีใช้ทรัพยากรที่นี่
* พิจารณางานอย่างต่อเนื่องตลอดเวลาหรืออัปเกรดฮาร์ดแวร์
*ทรัพยากรฟรีนำมาใช้ทรัพยากร

### ไม่ว่าอย่างไรก็ตามจะมีการหยุดอย่างไร

ความเย็นสบายเห็น:

* ❌ ความเชื่อเต็ม" หรือ "ไม่สามารถเขียนไฟล์"
* ❌ไฟล์รูปภาพดังกล่าวมักจะซ้ำๆ
* ❌ระบบไม่ต้องทำอะไรเลย (ไม่ต้องกลัว)
* ❌ รายงานเพิ่มเติมเกี่ยวกับเหตุการณ์ที่เกิดขึ้น
* ❌ นำเข้ารูปภาพผิด

**วิธีหยุด:**

1. คลิก**ปุ่มหยุด/ยกเลิก** (เพิ่มปุ่มเริ่ม)
2. เหตุผลหยุดลงและอื่นๆ อีกมากมาย
3. การแก้ไขปัญหาและเริ่มต้นตั้งแต่ต้น

## ในเรื่องระหว่างการทำงานร่วมกัน

### ใจเย็นช้ามาก

**สาเหตุที่ทำให้:**

*ภาพเป้าหมายที่ไม่เกิดขึ้น (สแกนภาพทั้งหมด)
* HDD แทนการจัดเก็บข้อมูล SSD
* ทรัพยากรระบบนั้น
* ดัชนีดัชนีจำนวนมาก
* สตรีมมิ่งเครือข่าย

**แก้ไขแก้ไข:**

1. เมื่อเพิ่งเริ่มต้นและอยู่ในขั้นตอนการเปิดใช้งาน: ยกเลิกถึงเป้าหมายแล้วเริ่มต้นใหม่
2. สำหรับอนาคต: ใช้ SSD ลดฐานข้อมูลอัพเกรดฮาร์ดแวร์
3. พิจารณา CLI สำหรับชุดข้อมูลขนาดใหญ่เป็นชุด

### คำเตือน "พื้นที่สาธารณะ"

**แก้ไขแก้ไข:**

1. เพิ่มพื้นที่ในเวลาว่างทันที
2. ก่อตั้งโครงการเพื่อเพิ่มพื้นที่ด้วยพื้นที่มากขึ้น
3. ลดดัชนีจำนวนที่จะส่งออก
4. ใช้รูปแบบ JPG แทน TIFF (ไฟล์ขนาดเล็ก)

### นั่นเป็น "ไฟล์ความเสียหาย" บ่อยครั้ง

**แก้ไขแก้ไข:**

1. ภาพยนตร์รูปภาพจากการ์ด SD อีกครั้งยังมีสมบูรณ์
2. ทดสอบการ์ด SD เป็นครั้งแรก
3. การลบไฟล์ที่เสียหายจากโครงการ
4. ดูภาพที่เหลือต่อไป

### ระบบร้อนเกินไป / ควบคุมปริมาณ

**แก้ไขแก้ไข:**

1. คืนนี้วิญญาณที่ความเชื่อนั้น
2. ฝุ่นจากช่องเรื่องของคอมพิวเตอร์
3. การลดอุณหภูมิของความเย็น (ใช้โหมดฟรีแทน Chloros+)
4. ดำเนินการอีกครั้งที่อากาศเย็นกว่าวัน
