#การเลือกรูปภาพเป้าหมาย

การพิจารณาว่ารูปภาพใดๆ เป็นครั้งแรกที่เทียบเคียงเป็นขั้นตอนสำคัญที่ช่วยเร่งให้เกิดการตรวจสอบ Chloros ได้ด้วยการเลือกใช้ภาพกลุ่มเป้าหมายและเปรียบเทียบ Chloros ในการตรวจสอบทุกภาพในข้อมูลของคุณโดยตรงเป้าหมายจะเทียบเคียง

##วันพรุ่งนี้เป้าหมายคืออะไร?

### ส่วนในเรื่องอื่นๆ

หากไม่มีการกล่าวถึงเป้าหมาย Chloros การเขียน:

* สแกนทุกภาพในกรณีของคุณ
* จำเป็นต้องอัลกรีธึมเป้าหมายในแต่ละภาพ
* การตัดภาพนับร้อยหรือรูปภาพโดยไม่จำเป็น

**ผลลัพธ์**: ชุดนี้อาจอาจมีมากกว่าข้อมูลขนาดใหญ่มากมาย

### พร้อมรูปภาพเป้าหมายที่วันพรุ่งนี้ไว้

ตรวจสอบการตรวจสอบเป้าหมายสำหรับรูปภาพเฉพาะ:

* Chloros สแกนเฉพาะรูปภาพที่เลือกไว้สำหรับกลุ่มเป้าหมาย
* เป้าหมายที่เป็นไปได้โดยตรงมาก
* เวลาที่คุณสามารถดูได้อย่างใกล้ชิด

{% hint style="success" %}
**ความเร็ว**: การสอบสวนภาพเป้าหมาย 2-3 ภาพในข้อมูล 500 ภาพสามารถลดประสิทธิภาพของเป้าหมายจาก 30+ นาทีเหลือ 1 นาที
{% endhint %}

***

## วิธีจัดการกับเป้าหมายเป้าหมาย

### มาตรการ 1: ระบุสถานที่เป้าหมายของคุณ

ดูวีดีโอนำเข้า File Browser และภาพใดๆ เพื่อดูตัวอย่างเทียบ

**สถานการณ์ทั่วไป:*** **กลุ่มเป้าหมายการจับภาพล่วงหน้า**: จับภาพก่อนเริ่มดำเนินการ
* **เป้าหมายหลังการจับภาพ**: จับภาพหลังจากนี้
* **เป้าหมายในสนาม**: กลุ่มเป้าหมายที่วางพื้นที่ยึด
* **หลายกลุ่มเป้าหมาย**: 2-3 รูปภาพเป้าหมายต่อการรับรู้ (แนะนำ)

### มาตรการ 2: มาตรการเฝ้าระวังเป้าหมาย

เรามีระบบจำลองเสมือน:

1. ค้นหารูปภาพในตาราง File Browser
2. ค้นหารับชม **เป้าหมาย** (ดูวิดีโอที่เหมาะสมสุด)
3. คลิกช่องในพบกับเป้าหมายของรูปภาพนั้น
4. การแสดงสำหรับรูปภาพอื่นๆ ทั้งหมด

### คืนนี้ 3: ยืนยันการเลือกของคุณ

และจะแจ้งให้ทราบอีกครั้ง:

* [ ] มีการตรวจสอบภาพเสมอเหมือนเช่นเทียบ
* [ ] ไม่มีการตรวจสอบรูปภาพของกลุ่มเป้าหมายโดยไม่มีอะไร
* [ ] กลุ่มเป้าหมายได้ชัดเจนในการเลือกรูปภาพ

***

## การปฏิบัติที่ดีที่สุดสำหรับรูปภาพเป้าหมาย

### การปฏิบัติตามเป้าหมาย

**ระยะเวลา:**

* จับกลุ่มเป้าหมายทันทีก่อนและตลอดการจับภาพของคุณ
* มีสภาพแสงเช่นเดียวกับที่วัดแสง DAQ ของคุณ
* การจับภาพเป้าหมายให้บ่อยที่สุดเพื่อให้ได้ผลลัพธ์ที่ดีที่สุดมิฉะนั้นข้อมูลของแสงจะสามารถตรวจสอบเพื่อปรับเทียบเคียงได้

**ตำแหน่งกล้อง:**

* ถือกล้องไว้เหนือเป้าหมายโดยให้อยู่ตรงกลางและเติมเต็มให้ครอบคลุม 40-60% ของกึ่งกลางภาพ
* หมายถึงกล้องคุณภาพ/ขีดตกต่ำสุดกับเป้าหมายเป้าหมาย

**ในเวลานี้:**

* แสงสว่างแบบเดียวกับที่วัดแสง DAQ ของคุณ
* มุมมองเงาของเป้าหมาย
* อย่าสำคัญด้วยร่างกายหรือพืชพรรณ
*ที่มืดครึ้มให้ผลลัพธ์ที่เป็นที่รู้จักมากที่สุด

**เงื่อนไขกลุ่มเป้าหมาย:**

* รักษาแผงเป้าหมายให้สะอาดและแห้ง
* คุณสมบัติแผงทั้ง 4 กระจกได้ชัดเจนในเรื่องสิ่งกีดขวาง
* เหตุการณ์ที่เห็นได้ชัดในฉาก/จุดตกต่ำสุดสู่เหตุการณ์สำคัญ

### มีภาพเป้าหมายกี่ภาพ?

**ขั้นต่ำ:**1 รูปภาพเป้าหมายต่อผู้บริหาร**แนะนำ:** รูปภาพเป้าหมาย 3-5 ภาพต่อผู้บริหาร**ระดับการปกครองปฏิบัติที่ดีที่สุด:**

* ถ่ายภาพ 3-5 ภาพหลังจากบันทึกความทรงจำของแสง
* หมุนกล้องระหว่างการจับภาพเพื่อให้ได้ผลลัพธ์ที่ดีที่สุด
* ติดตามเพิ่มเติม: การปรับปรุงอย่างต่อเนื่องๆ หากสภาพแสงปรับปรุงตลอดเวลา

***

##การเชื่อมต่อกับกล้องหลายตัว

### จะเป็นกล้องคู่

ถ้าใช้กล้อง MAPIR เหมือนเดิม (เช่น Survey3W RGN + Survey3N OCN):

1. จับภาพเป้าหมายด้วย **กล้องสายตาตัว** ตอนนี้
2. ใช้ **เป้าหมายเดียวกันในเวลาเดียวกัน** สำหรับกล้องที่รองรับตัว
3. ภาพเป้าหมายสำหรับ **กล้องยังคงมีประเภท** ใน File Browser
4. Chloros มีเป้าหมายที่ชัดเจนเทียบเท่ากล้องแต่ละตัว

### รองรับรุ่นกล้อง

**รองรับรุ่นกล้อง** รองรับการมองเห็นรูปภาพใดๆ ที่มาจากกล้องตัวใดๆ:

* Survey3W\_RGN
* Survey3N\_OCN
* Survey3W\_RGB
*อื่นๆ

ใช้ความสามารถในการทำเช่นนี้ได้ในเป้าหมายสำหรับกล้องแต่ละประเภทตามความเหมาะสมของคุณ

***

##เพื่อใช้เป้าหมาย

### ในรูปแบบการเล่นในนั้น

หาก Chloros ตรวจไม่พบเป้าหมายของคุณบ่อยครั้งที่ปรับให้เห็นได้ใน [โครงการ](adjusting-project-settings.md):**พื้นที่ตัวอย่างจะแสดงขั้นต่ำ:*** **พบ**: 25
* **เพิ่มขึ้น** หากตรวจพบขนาดเล็กที่ผิดพลาด
* **ลดลง** หากตรวจไม่พบกลุ่มเป้าหมาย**ถึงกลุ่มเป้าหมาย ขั้นต่ำ:*** **ทั้งหมด**: 60
* **เพิ่มขึ้น** หากเป้าหมายถูกมองว่ามีหลายเป้าหมาย
* **ลดลง** หากตรวจไม่พบเป้าหมายที่มีขนาดเล็กของสีทั้งหมด***

##กระทบเป้าหมายทั่วไป

### อดทน: ไม่พบเป้าหมาย

**สาเหตุที่ทำให้:**

* การกระทำดังกล่าวไม่ได้หมายความว่าใน File Browser
* กลุ่มเป้าหมายเล็กเกินไปในการขนส่ง (< 30% ของภาพ)
* มองเห็นแสงไม่ดี ( เงาแสงสะท้อน)
* คุณสามารถกำหนดเป้าหมายได้ด้วยเช่นกัน

**แก้ไขแก้ไข:**

1. มาตรการติดตามเป้าหมายเพื่อตรวจสอบรูปภาพที่ถูกต้อง
2. ถ่ายทำคุณภาพภาพเป้าหมายในตัวอย่าง
3. ยึดเป้าหมายคืนให้ดีภาพไม่ดี
4.เขตเฝ้าระวังเป้าหมายหากจำเป็น

###ไม่ต้องกังวล: เกราะเป้าหมายเท็จ

**สาเหตุที่ทำให้:**

* อาคารสีขาวหรือสิ่งที่ดินที่เข้าใจผิดว่าเป็นเป้าหมาย
* รอยสดใสในพืชพรรณ
* เพดานในอาคารต่ำเกินไป

**แก้ไขแก้ไข:**

1. เฉพาะภาพเป้าหมายจริงเพื่อจำกัดขอบเขตขอบเขต
2. ขยายพื้นที่ตัวอย่างเพื่อดูขั้นต่ำ
3. โดยคำนึงถึงกลุ่มเป้าหมายขั้นต่ำ
4. ถ่ายทำภาพรวมภาพเป้าหมายแสดงเฉพาะกลุ่มเป้าหมาย (ความมุ่งหมายยิงของปรากฏการณ์นี้)

***

## รายการตรวจสอบตรวจสอบ

เริ่มดำเนินการตรวจสอบการตรวจสอบรูปภาพเป้าหมายของคุณ:

* [ ] ทันทีที่ภาพกลุ่มเป้าหมายขยี้ตา 1 ภาพต่อการรับรู้
* [ ] ช่องที่กล่าวถึงเป้าหมายที่เป็นไปได้สำหรับรูปภาพเป้าหมายทั้งหมด
* [ ] เพื่อดูการถ่ายภาพภายในกรอบเวลาเดียวกับแบบสำรวจ
* [ ] เป้าหมายที่สามารถเห็นได้ชัดเจนในตัวอย่างเมื่อคลิก
* [ ] ยืนเทียบเทียมทั้ง 4 วัดได้ในแต่ละภาพกลุ่มเป้าหมาย
* [ ] ไม่มีเงาหรือสิ่งกีดขวางบนเป้าหมาย
* [ ] สำหรับกล้องคู่: เป้าหมายที่มองเห็นไว้สำหรับกล้องบางชนิด

***

## ทำตามแบบไร้เป้าหมาย

### โดยไม่มีเป้าหมายที่จะเปรียบเทียบ

การดำเนินการนี้จะแนะนำอีกครั้งถึงความเป็นไปได้ที่สามารถทำได้โดยปราศจากเป้าหมาย:

1. ปล่อยให้ช่องเป็นไปตามเป้าหมายทั้งหมดที่ถูกกฎหมายเลือก
2. **อีกครั้ง** "สมมุติว่าเทียบเทียม" ในโปรเจ็กต์
3. เชื่อว่าขอบความมืดนี้จะยังคงอยู่
4. เราจะนำเสนอการปรับเทียบเคียงแบบสัมบูรณ์

{% hint style="warning" %}
**ไม่แนะนำ**: อีกครั้งลองดูเทียบเคียงการเทียบเคียงกับประสิทธิภาพที่เห็นได้ชัดถึงสัมพัทธ์เท่านั้นที่เป็นจุดสังเกตการสอบสวนใช้กลุ่มเป้าหมายที่เทียบเคียงกับผลลัพธ์ของการสำรวจและการสำรวจได้
{% endhint %}
