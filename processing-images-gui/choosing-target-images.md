# การเลือกภาพเป้าหมาย

การระบุภาพที่มีเป้าหมายการปรับเทียบจะช่วยให้ Chloros รู้ได้อย่างแม่นยำว่าควรค้นหาเป้าหมายเหล่านั้นที่ใด เมื่อมีภาพอย่างน้อยหนึ่งภาพที่ถูกทำเครื่องหมายในคอลัมน์ Target (เป้าหมาย) Chloros จะสแกน **เฉพาะภาพที่ถูกทำเครื่องหมายเท่านั้น** — ดังนั้น การทำเครื่องหมายเป้าหมายจึงเป็นวิธีทั้งในการเร่งความเร็วการประมวลผลและป้องกันไม่ให้ภาพสำรวจถูกเข้าใจผิดว่าเป็นเป้าหมาย

<figure><img src="../.gitbook/assets/image (40).png" alt=""><figcaption></figcaption></figure>

## ทำไมต้องทำเครื่องหมายภาพเป้าหมาย?

### การทำเครื่องหมายควบคุมการสแกน

เมื่อคุณทำเครื่องหมายในคอลัมน์ Target สำหรับภาพเฉพาะ:

* Chloros จะสแกนหาเป้าหมายเฉพาะในภาพที่ถูกทำเครื่องหมายเท่านั้น
* การตรวจจับเป้าหมายเสร็จสิ้นได้เร็วขึ้นมาก
* ภาพสำรวจจะไม่ก่อให้เกิดการตรวจจับเป้าหมายที่ผิดพลาด

หาก **ไม่มี** ภาพใดถูกทำเครื่องหมาย Chloros จะกลับสู่การสแกนภาพทุกภาพในโครงการ:

* อัลกอริทึมการตรวจจับเป้าหมายจะทำงานบนภาพทุกภาพ
* ภาพหลายร้อยหรือหลายพันภาพถูกตรวจสอบโดยไม่จำเป็น
* การประมวลผลใช้เวลานานขึ้นอย่างมีนัยสำคัญ โดยเฉพาะอย่างยิ่งสำหรับชุดข้อมูลขนาดใหญ่

{% hint style="success" %}
**การปรับปรุงความเร็ว**: การทำเครื่องหมายภาพเป้าหมาย 2-3 ภาพในชุดข้อมูล 500 ภาพสามารถลดเวลาการตรวจจับเป้าหมายจาก 30+ นาทีลงเหลือน้อยกว่า 1 นาที
{% endhint %}

***

## วิธีทำเครื่องหมายภาพเป้าหมาย

### ขั้นตอนที่ 1: ระบุภาพเป้าหมายของคุณ

ดูภาพที่นำเข้าใน File Browser และระบุภาพใดที่มีเป้าหมายการปรับเทียบ

**สถานการณ์ทั่วไป:*** **เป้าหมายก่อนการถ่ายภาพ**: ถ่ายภาพก่อนเริ่มเซสชัน
* **เป้าหมายหลังการถ่ายภาพ**: ถ่ายภาพหลังจากเสร็จสิ้นเซสชัน
* **เป้าหมายในสนาม**: เป้าหมายที่วางไว้ภายในพื้นที่ถ่ายภาพ
* **เป้าหมายหลายภาพ**: 2-3 ภาพเป้าหมายต่อเซสชัน (แนะนำ)

### ขั้นตอนที่ 2: ตรวจสอบคอลัมน์ **Target** <img src="../.gitbook/assets/image (33).png" alt="" data-size="original">

สำหรับภาพแต่ละภาพที่มีเป้าหมายการปรับเทียบ:

1. ค้นหาภาพในตารางของ File Browser
2. ค้นหาคอลัมน์ **Target** (คอลัมน์ด้านขวาสุด)
3. คลิกช่องทำเครื่องหมายในคอลัมน์ **Target** ของภาพนั้น
4. ทำซ้ำสำหรับภาพทั้งหมดที่มีเป้าหมาย

### ขั้นตอนที่ 3: ตรวจสอบการเลือก

ก่อนดำเนินการ ให้ตรวจสอบอีกครั้ง:

* [ ] ภาพทั้งหมดที่มีเป้าหมายการปรับเทียบถูกทำเครื่องหมายแล้ว
* [ ] ไม่มีภาพที่ไม่ใช่เป้าหมายถูกทำเครื่องหมายโดยไม่ได้ตั้งใจ
* [ ] เป้าหมายปรากฏชัดเจนในภาพที่ทำเครื่องหมายแล้ว

## LATTICE: เป้าหมายเป็นตัวเลือกเมื่อ DAQ กำลังบันทึก

สำหรับกล้องมัลติสเปกตรัม LATTICE เป้าหมายการปรับเทียบในเฟรมเป็น **หนึ่งในสอง** ตัวอ้างอิงการสะท้อนที่เป็นไปได้:

* **เป้าหมายในกรอบภาพ**: เมื่อภาพเป้าหมายที่ได้รับการทำเครื่องหมายผ่านเกณฑ์การตรวจสอบคุณภาพ (QA) ของChloros เป้าหมายนั้นจะกลายเป็น**ค่าอ้างอิงการสะท้อนแสงแบบสัมบูรณ์** สำหรับภาพรอบข้าง
* **การวัดแสงลงจาก DAQ**: เมื่อไม่มีเป้าหมาย (หรือ QA ไม่ผ่าน) Chloros จะคำนวณค่าสะท้อนแสงจากความเข้มแสงลงจากเซ็นเซอร์แสงของ DAQ แทน (ρ = π·L/E) หากการบันทึก `.daq` หรือ DAQ-M `.csv` ครอบคลุมภาพที่ถ่ายได้ คุณจะได้รับค่าการสะท้อนที่ปรับเทียบ**โดยไม่ต้องใช้ภาพเป้าหมายใดๆ เลย**พฤติกรรมอัตโนมัตินี้เป็นค่าเริ่มต้น ใน CLI / SDK สิ่งนี้สอดคล้องกับ `--reflectance-source auto`; คุณยังสามารถบังคับใช้ `target` (แบบเคร่งครัด — ไม่มีการแทนที่ด้วย DAQ) หรือ `daq` (ให้ DAQ เป็นหลัก) ได้ ดู [CLI Reference](../reference/cli-reference.md#per-product-export-toggles-lattice-multispectral).**รูปทรงเป้าหมาย LATTICE**: นอกเหนือจากการตรวจจับแผงแบบคลาสสิกที่ใช้สำหรับ Survey3 การประมวลผล LATTICE ยังรองรับ**เป้าหมายที่มีเครื่องหมาย ArUco**,**เป้าหมาย ROI คงที่**และ**เป้าหมายแบบแถบ**ซึ่งสามารถกำหนดค่าได้ตามแต่ละโครงการ การสแกนค่าการสะท้อนของเป้าหมาย**ที่วัดได้** ต่อหน่วยสามารถจัดหาได้โดยใช้หมายเลขซีเรียล (CLI: `--target-reflectance-dir`, `<serial>.csv` หนึ่งชุดต่อหน่วยเป้าหมาย), โดยใช้สเปกตรัม T3/T4P ตามค่ามาตรฐานเป็นทางเลือกสำรอง

{% hint style="info" %}
**โมดูล F988**: ค่าสะท้อนแสงของ F988 ได้รับการปรับเทียบโดยใช้แผงสะท้อนแสงในฉาก: เนื่องจากแถบความยาวคลื่นนี้อยู่นอกช่วงที่ปรับเทียบของเซ็นเซอร์แสง DAQ ดังนั้น Chloros จึงใช้ข้อมูลการจับภาพแผงล่าสุดของคุณและเก็บไว้ระหว่างการตรวจวัดแผงครั้งต่อไป หากโมดูล F988 ได้รับการประมวลผลด้วย DAQ เท่านั้น Chloros จะปฏิเสธค่าการสะท้อนแสงที่อิงจาก DAQ สำหรับแถบความยาวคลื่นนั้น (เหตุผลการข้าม `dls-uncalibrated-band-988`) — กระบวนการทำงานของแผงสะท้อนแสงคือวิธีที่ได้รับการสนับสนุน
{% endhint %}

## แนวทางปฏิบัติที่ดีที่สุดสำหรับภาพเป้าหมาย

### แนวทางในการถ่ายภาพเป้าหมาย

**เวลา:**

* ถ่ายภาพเป้าหมายทันทีก่อนและตลอดช่วงการถ่ายภาพ
* ในสภาพแสงเดียวกันกับเซ็นเซอร์แสง DAQ ของคุณ
* เพื่อผลลัพธ์ที่ดีที่สุด ควรถ่ายภาพเป้าหมายบ่อยที่สุดเท่าที่จะทำได้ หากไม่ทำเช่นนั้น ข้อมูลจากเซ็นเซอร์แสงจะถูกใช้เพื่อปรับการสอบเทียบตามเวลา

**ตำแหน่งกล้อง:**

* ถือกล้องอยู่เหนือเป้าหมายให้อยู่ตรงกลางและครอบคลุมประมาณ 40-60% ของศูนย์กลางภาพ
* รักษาให้กล้องอยู่ในแนวขนาน/แนวตั้งฉากกับพื้นผิวเป้าหมาย

**แสง:**

* ใช้แสงแวดล้อมที่เหมือนกับเซ็นเซอร์แสง DAQ ของคุณ
* หลีกเลี่ยงการเกิดเงาบนพื้นผิวเป้าหมาย
* อย่าบังแหล่งกำเนิดแสงด้วยร่างกาย ยานพาหนะ หรือพืชพรรณ
* สภาพอากาศที่มีเมฆครึ้มจะให้ผลลัพธ์ที่สม่ำเสมอที่สุด

**สภาพเป้าหมาย:**

* รักษาแผงเป้าหมายให้สะอาดและแห้ง
* แผงทั้งหมดของเป้าหมาย (เช่น ทั้ง 4 แผงบน T4) ต้องมองเห็นได้ชัดเจนและไม่มีสิ่งกีดขวาง
* วางเป้าหมายให้ตั้งฉาก/ตรงกับแหล่งแสง หากเป็นไปได้

### จำนวนภาพเป้าหมาย?

**ขั้นต่ำ:**1 ภาพเป้าหมายต่อเซสชัน**แนะนำ:** 3-5 ภาพเป้าหมายต่อเซสชัน**ตารางเวลาที่แนะนำ:**

* ถ่ายภาพ 3-5 ภาพทันทีหลังจากเซ็นเซอร์แสงเริ่มบันทึก
* หมุนกล้องระหว่างการถ่ายภาพเพื่อผลลัพธ์ที่ดีที่สุด
* ตัวเลือกเสริม: ถ่ายภาพเป้าหมายเป็นระยะๆ ระหว่างเซสชัน หากสภาพแสงเปลี่ยนแปลงอย่างต่อเนื่อง

## การทำงานกับกล้องหลายตัว

### การตั้งค่ากล้องคู่

หากใช้กล้อง MAPIR สองตัวพร้อมกัน (เช่น Survey3W RGN + Survey3N OCN):

1. ถ่ายภาพเป้าหมายด้วย **กล้องทั้งสองตัว** พร้อมกัน
2. ใช้ **เป้าหมายทางกายภาพเดียวกัน** สำหรับทั้งสองกล้อง
3. ทำเครื่องหมายภาพเป้าหมายสำหรับ **ทั้งสองประเภทกล้อง** ใน File Browser
4. Chloros จะใช้เป้าหมายที่เหมาะสมสำหรับการปรับเทียบของแต่ละกล้อง

### คอลัมน์ Camera Model

คอลัมน์ **Camera Model** ช่วยระบุภาพใดมาจากกล้องใด:

* Survey3W\_RGN
* Survey3N\_OCN
* LATT-M3M-L41-F550
* LATT-M3C-L87-FRGN
* เป็นต้น

ใช้คอลัมน์นี้เพื่อตรวจสอบว่าคุณได้ทำเครื่องหมายเป้าหมายสำหรับแต่ละประเภทกล้องในโครงการของคุณแล้วหรือไม่

***

## การตั้งค่าการตรวจจับเป้าหมาย

### การปรับความไวในการตรวจจับ

หาก Chloros ไม่ตรวจจับเป้าหมายของคุณได้อย่างถูกต้อง ให้ปรับการตั้งค่าเหล่านี้ใน [Project Settings](adjusting-project-settings.md):**พื้นที่ตัวอย่างการปรับเทียบขั้นต่ำ (px):*** **ค่าเริ่มต้น**: 25 พิกเซล
* **เพิ่ม** หากเกิดการตรวจจับผิดพลาดกับวัตถุขนาดเล็ก
* **ลด** หากเป้าหมายไม่ถูกตรวจจับ**ค่ากลุ่มเป้าหมายขั้นต่ำ (0-100):*** **ค่าเริ่มต้น**: 60
* **เพิ่ม** หากเป้าหมายถูกแบ่งออกเป็นหลายการตรวจจับ
* **ลด** หากเป้าหมายที่มีความแตกต่างของสีไม่ถูกตรวจจับอย่างครบถ้วน

{% hint style="info" %}
**เคล็ดลับ CLI**: `chloros-cli process` รองรับตัวปรับค่าเดียวกัน (`--min-target-size`, `--target-clustering`) และธง `--target`/`--targets` ของมันจะกำหนดให้โฟลเดอร์อินพุตทั้งโฟลเดอร์เป็น &quot;เป้าหมายเฉพาะบนแผงควบคุม&quot; เท่านั้น ดู [CLI Reference](../reference/cli-reference.md).
{% endhint %}

## ปัญหาทั่วไปเกี่ยวกับภาพเป้าหมาย

### ปัญหา: ไม่พบเป้าหมาย

**สาเหตุที่อาจเกิดขึ้น:**

* ภาพเป้าหมายไม่ถูกทำเครื่องหมายใน File Browser
* เป้าหมายในกรอบภาพเล็กเกินไป (&lt; 30% ของภาพ)
* แสงไม่ดี (เงา, แสงสะท้อน)
* การตั้งค่าการตรวจจับเป้าหมายเข้มงวดเกินไป

**วิธีแก้ไข:**

1. ตรวจสอบให้แน่ใจว่าคอลัมน์ Target ถูกทำเครื่องหมายสำหรับภาพที่ถูกต้อง
2. ตรวจสอบคุณภาพภาพเป้าหมายในโหมดดูตัวอย่าง
3. ถ่ายภาพเป้าหมายใหม่หากคุณภาพไม่ดี
4. ปรับการตั้งค่าการตรวจจับเป้าหมายหากจำเป็น

### ปัญหา: การตรวจจับเป้าหมายผิด

**สาเหตุที่อาจเกิดขึ้น:**

* อาคารสีขาว ยานพาหนะ หรือพื้นดินถูกเข้าใจผิดว่าเป็นเป้าหมาย
* จุดสว่างในพืชพรรณ
* ความไวในการตรวจจับต่ำเกินไป

**วิธีแก้ไข:**

1. ทำเครื่องหมายเฉพาะภาพเป้าหมายที่แท้จริง — ภาพที่ถูกทำเครื่องหมายเท่านั้นที่จะถูกสแกน
2. เพิ่มพื้นที่ตัวอย่างการปรับเทียบขั้นต่ำ
3. เพิ่มค่าการรวมกลุ่มเป้าหมายขั้นต่ำ
4. ตรวจสอบให้แน่ใจว่าภาพเป้าหมายแสดงเฉพาะเป้าหมายเท่านั้น (มีสิ่งรบกวนในพื้นหลังน้อยที่สุด)

## รายการตรวจสอบ

ก่อนเริ่มการประมวลผล ให้ตรวจสอบการเลือกภาพเป้าหมายของคุณ:

* [ ] มีภาพเป้าหมายที่ถูกทำเครื่องหมายอย่างน้อย 1 ภาพต่อเซสชัน (หรือ สำหรับ LATTICE ให้มีการบันทึก `.daq`/`.csv` ที่ครอบคลุมเซสชันนั้น)
* [ ] ช่องทำเครื่องหมายในคอลัมน์เป้าหมายถูกทำเครื่องหมายสำหรับภาพเป้าหมายทั้งหมด
* [ ] ภาพเป้าหมายถูกถ่ายในช่วงเวลาเดียวกันกับการสำรวจ
* [ ] เป้าหมายมองเห็นได้ชัดเจนในหน้าตัวอย่างเมื่อคลิก
* [ ] แผงการปรับเทียบทั้งหมดมองเห็นได้ในภาพเป้าหมายแต่ละภาพ
* [ ] ไม่มีเงาหรือสิ่งกีดขวางบนเป้าหมาย
* [ ] สำหรับกล้องคู่: เป้าหมายถูกทำเครื่องหมายสำหรับทั้งสองประเภทกล้อง

## การประมวลผลแบบไม่มีเป้าหมาย

### LATTICE: พร้อมการบันทึก DAQ

หากเซ็นเซอร์แสง DAQ ได้บันทึกความเข้มรังสีที่ตกสู่พื้นดิน (downwelling irradiance) ระหว่างการถ่ายภาพ LATTICE ของคุณ ก็ไม่จำเป็นต้องใช้เป้าหมาย:

1. นำเข้าไฟล์ `.daq` (หรือ DAQ-M `.csv`) พร้อมภาพ
2. ปล่อยให้คอลัมน์ Target ไม่ถูกทำเครื่องหมาย
3. ค่าการสะท้อนแสงจะถูกคำนวณจากค่าอ้างอิงความเข้มแสงลงของ DAQ โดยอัตโนมัติ
4. ค่าความส่องสว่าง (Radiance) ไม่จำเป็นต้องใช้เป้าหมายหรือ DAQ — ค่านี้มาจากการปรับเทียบรังสีจากโรงงานของกล้องเพียงอย่างเดียว

### การประมวลผลโดยไม่ใช้ข้อมูลอ้างอิงใดๆ

คุณยังสามารถประมวลผลได้โดยไม่ต้องใช้เป้าหมายหรือ DAQ:

1. ปล่อยให้ช่องทำเครื่องหมายในคอลัมน์ &quot;เป้าหมาย&quot; ทั้งหมดไม่ถูกทำเครื่องหมาย
2. **ปิด** &quot;การปรับเทียบการสะท้อน / สมดุลสีขาว&quot; ใน Project Settings — การตรวจจับเป้าหมายจะถูกข้ามไปทั้งหมด
3. การแก้ไข vignette จะยังคงถูกนำไปใช้
4. ผลลัพธ์จะไม่ถูกปรับเทียบสำหรับการสะท้อนแบบสัมบูรณ์ (LATTICE multispectral ยังคงส่งออกผลิตภัณฑ์แบบ debayered, preview และ radiance)

{% hint style="warning" %}
**ไม่แนะนำสำหรับงานวิทยาศาสตร์แบบSurvey3**: หากไม่มีการปรับเทียบค่าสะท้อนแสง ค่าพิกเซลของ Survey3 จะแสดงเพียงความสว่างสัมพัทธ์เท่านั้น ไม่ใช่การวัดค่าสะท้อนแสงทางวิทยาศาสตร์ ให้ใช้เป้าหมายการปรับเทียบ (หรือสำหรับ LATTICE ให้ใช้เซ็นเซอร์แสง DAQ) เพื่อผลลัพธ์ที่แม่นยำและสามารถทำซ้ำได้
{% endhint %}
