# การเพิ่มไฟล์ลงในโครงการ

หลังจากที่คุณสร้างหรือเปิดโครงการใน Chloros แล้ว ขั้นตอนต่อไปคือการเพิ่มภาพมัลติสเปกตรัมเพื่อเริ่มการประมวลผล แท็บ File Browser <img src="../.gitbook/assets/icon_file-browser.JPG" alt="" data-size="line"> ช่วยให้การนำเข้าภาพและการจัดการชุดข้อมูลของคุณเป็นเรื่องง่าย

## การเข้าถึง File Browser

1. เปิดหรือสร้างโครงการใน Chloros
2. คลิกไอคอน **File Browser** <img src="../.gitbook/assets/icon_file-browser.JPG" alt="" data-size="line"> ในแถบด้านซ้าย
3. แผง File Browser จะแสดงรายชื่อไฟล์ของโครงการของคุณ

{% hint style="info" %}
**ประเภทไฟล์ที่รองรับ**:

* **Survey3W / Survey3N**: คู่ไฟล์ RAW+JPG และภาพ JPG (แนะนำให้ใช้ RAW+JPG)
* **LATTICE**: การบันทึก `.tif` / `.tiff` — ที่เขียนโดยระบบควบคุมกล้อง Chloros หรือโดย LATTICE hub
* **ข้อมูลเซ็นเซอร์แสง**: การบันทึก `.daq` (DAQ-U/M/E) และบันทึกการส่องลงของ DAQ-M `.csv` — นำเข้าพร้อมกับภาพเพื่อใช้ในการปรับเทียบการสะท้อนแสง
{% endhint %}

***

## การเพิ่มภาพลงในโครงการของคุณ

มีสองวิธีหลักในการเพิ่มภาพลงในโครงการของคุณ:

### วิธีที่ 1: เพิ่มไฟล์

ใช้ตัวเลือกนี้เพื่อนำเข้าไฟล์ภาพแต่ละไฟล์หรือกลุ่มไฟล์จำนวนน้อย

1. คลิกปุ่ม **&quot;Add Files&quot;** <img src="../.gitbook/assets/image (3).png" alt="" data-size="line"> ที่ด้านบนของแผง File Browser
2. ไปยังโฟลเดอร์ที่เก็บภาพของคุณ
3. เลือกไฟล์ภาพหนึ่งหรือหลายไฟล์ (กด **Ctrl** ค้างไว้เพื่อเลือกหลายไฟล์)
4. คลิก **&quot;Open&quot;** เพื่อนำเข้าไฟล์ที่เลือก

### วิธีที่ 2: เพิ่มโฟลเดอร์

ใช้ตัวเลือกนี้เพื่อนำเข้าภาพทั้งหมดจากโฟลเดอร์ในครั้งเดียว คุณสามารถเลือก **หลายโฟลเดอร์** ในหน้าต่างสนทนาเดียว

1. คลิกปุ่ม **&quot;Add Folder&quot;** <img src="../.gitbook/assets/image (1) (1).png" alt="" data-size="line"> ที่ด้านบนของแผง File Browser
2. ไปยังและเลือกโฟลเดอร์ที่เก็บภาพจากเซสชันการถ่ายภาพของคุณ
3. คลิก **&quot;Select Folder&quot;** เพื่อนำเข้าภาพทั้งหมดที่ระบบรองรับ

{% hint style="info" %}
**ไฟล์ที่โหลดไม่สำเร็จจะได้รับการแจ้งเตือน** หากโฟลเดอร์ใดมีไฟล์ที่Chlorosสามารถระบุได้แต่ไม่สามารถโหลดได้ ระบบจะแสดงคำเตือน — ภาพจะไม่หายไปจากกริดโดยไม่มีคำเตือน
{% endhint %}

***

## การนำเข้าโฟลเดอร์ LATTICE Capture

ข้อมูล LATTICE Capture ถูกบันทึกด้วย **โฟลเดอร์ย่อยหนึ่งโฟลเดอร์ต่อระดับการส่งออก** — เช่น `raw/`, `debayered/`, `radiance/`, `reflectance/`, `preview/` — พร้อมกับไฟล์ลงสู่พื้นน้ำ `.daq` ที่สอดคล้องกันในโฟลเดอร์หลัก:

```
output/
├── raw/           capture_<timestamp>_SN<serial>_raw.tif
├── debayered/     capture_<timestamp>_SN<serial>_debayered.tif
├── preview/       capture_<timestamp>_SN<serial>_display.tif
└── *.daq          the downwelling reading matched to the capture
```

**ตั้งค่า &quot;Add Folder&quot; ให้ชี้ไปยังโฟลเดอร์รากของภาพ** (`output/` ข้างต้น). เมื่อโฟลเดอร์ที่เลือกไม่มีภาพอยู่ภายใน แต่มีโฟลเดอร์ย่อย Chloros จะเข้าไปในโฟลเดอร์ย่อยเหล่านั้นโดยอัตโนมัติ — โฟลเดอร์ย่อยระดับต่าง ๆ และโฟลเดอร์ราก `.daq` จะถูกนำเข้ามาทั้งหมดในครั้งเดียว**วิธีการนำเข้าภาพที่จับได้:*** ภาพที่จับได้แต่ละภาพจะถูกนำเข้าเป็น **ภาพเดียว** โดยจัดกลุ่มตามการจับภาพ (ไม่ใช่หนึ่งรายการต่อระดับ) ระดับอื่น ๆ ของการจับภาพเดียวกันจะปรากฏเป็นโหมดการดูของภาพนั้น
* **การประมวลผลจะเริ่มจากเฟรมดิบเสมอ** ระดับอื่น ๆ สามารถดูได้ แต่มีเพียง `raw` เท่านั้นที่ถูกส่งผ่านกระบวนการ — การประมวลผลซ้ำผลิตภัณฑ์ที่ผ่านการประมวลผลแล้วจะทำให้การแก้ไขถูกนำไปใช้สองครั้ง ดังนั้น Chloros จึงปฏิเสธ ไฟล์ที่ส่งออกแล้วนำเข้ามาใหม่ไม่สามารถใช้ช่อง raw ของการจับภาพได้
* โฟลเดอร์การจับภาพที่บันทึก **โดยไม่** นำเข้า raw จะแสดงผลตามปกติ แต่กระบวนการประมวลผลจะข้ามมันไปและแจ้งในบันทึก (ธง CLI `--input-level` สามารถบังคับจุดเข้าสำหรับกรณีนี้ได้ — ดู [คู่มืออ้างอิง CLI](../reference/cli-reference.md#what-a-captures-folder-looks-like).)**เซสชัน LATTICE hub** นำเข้าด้วยวิธีเดียวกัน: คลิก &quot;Add Folder&quot; (เพิ่มโฟลเดอร์) เพื่อชี้ไปยังโฟลเดอร์เซสชันที่คัดลอกจาก hub (โฟลเดอร์นี้ประกอบด้วย `raw/` และ `previews/`) พร้อมทั้งไฟล์บันทึกข้อมูลแบบลงสู่พื้น (downwelling log) ของ DAQ-M `.csv` ใดๆ ที่มีอยู่ หากการปรับเทียบของกล้องหรือ DAQ ยังไม่ถูกเก็บไว้ในแคชบนเครื่องของคุณ Chloros จะดึงข้อมูลมาโดยอัตโนมัติตามหมายเลขซีเรียลเมื่อนำเข้า (ต้องมีการเชื่อมต่ออินเทอร์เน็ตเพียงครั้งเดียว)***

## การเข้าใจตารางใน File Browser

เมื่อภาพถูกนำเข้าแล้ว จะปรากฏในตารางที่มีคอลัมน์ดังต่อไปนี้:

### ชื่อไฟล์

* ชื่อไฟล์ต้นฉบับจากกล้อง
* รักษาตามกฎการตั้งชื่อของกล้อง (เช่น IMG\_0001.RAW หรือ capture\_20260816\_101500\_SN213800234\_raw.tif)

### เวลา

* วันที่และเวลาที่ถ่ายภาพ
* สกัดจากข้อมูลเมตาดาต้า EXIF ของภาพ
* ใช้สำหรับการจับคู่เซ็นเซอร์แสง การซิงโครไนซ์ PPK และการจัดตารางเป้าหมายการปรับเทียบ

### รุ่นกล้อง

* ตรวจจับการตั้งค่ากล้องและฟิลเตอร์อัตโนมัติ
* ตัวอย่างของSurvey3: Survey3W\_RGN, Survey3N\_OCN, Survey3W\_RGB
* ตัวอย่างของLATTICE: LATT-M3M-L41-F550, LATT-M3C-L87-FRGN
* ใช้เพื่อประยุกต์โปรไฟล์การประมวลผลที่ถูกต้อง

### คอลัมน์เป้าหมาย (ช่องทำเครื่องหมาย)

* ทำเครื่องหมายในช่องนี้สำหรับภาพที่มีเป้าหมายการปรับเทียบ
* เมื่อมีภาพอย่างน้อยหนึ่งภาพถูกทำเครื่องหมาย **ระบบจะสแกนหาเป้าหมายเฉพาะในภาพที่ถูกทำเครื่องหมายเท่านั้น*** ดู [การเลือกภาพเป้าหมาย](choosing-target-images.md) สำหรับรายละเอียด

### การดูข้อมูลเมตาดาต้าของภาพ

การคลิกปุ่มสลับที่มุมขวาบนเหนือตารางจะแสดงข้อมูลเมตาดาต้าของภาพที่เลือกไว้ในพื้นที่กริดภาพ

## ไฟล์เซ็นเซอร์แสงในโครงการของคุณ

* ไฟล์ `.daq` และ `.csv` จะปรากฏในรายการ File Browser แต่ไม่ใช่ภาพที่สามารถคลิกได้ — ไฟล์เหล่านี้ให้ค่าความเข้มแสงที่ตกกระทบ (downwelling irradiance) สำหรับการปรับเทียบค่าการสะท้อนแสง
* ทุกไฟล์ `.daq`/`.csv` ที่นำเข้าจะถูกแสดงใน **Project Settings → DAQ Light Sensor** ซึ่งคุณสามารถตรวจสอบการปรับแก้ฝาครอบตัวกระจายแสงที่ใช้กับแต่ละไฟล์ได้ ดู [การปรับการตั้งค่าโครงการ](adjusting-project-settings.md).
* การบันทึกที่คุณทำในแท็บ **Light Sensors** จะถูกเพิ่มเข้าไปในโครงการที่เปิดอยู่โดยอัตโนมัติ — ไม่จำเป็นต้องนำเข้าด้วยมือ***

## การจัดการไฟล์ในโครงการของคุณ

### การลบไฟล์

เพื่อลบภาพที่ไม่ต้องการออกจากโครงการของคุณ:

1. เลือกภาพหนึ่งหรือหลายภาพในตาราง File Browser
2. คลิกปุ่ม **&quot;Remove Selected&quot;** <img src="../.gitbook/assets/image (2) (1).png" alt="" data-size="line">
3. ยืนยันการลบ (ไฟล์จะไม่ถูกลบจากดิสก์ แต่เพียงถูกลบออกจากโครงการเท่านั้น)

### การจัดเรียงและกรอง

* **จัดเรียงตามคอลัมน์**: คลิกหัวคอลัมน์ใดก็ได้เพื่อจัดเรียงภาพ
* **จัดเรียงตามเวลา**: มีประโยชน์สำหรับการจัดเรียงลำดับการถ่ายภาพตามเวลา
* **กรองตามรุ่นกล้อง**: จัดกลุ่มภาพตามประเภทกล้องหากใช้กล้องหลายตัว***

## การดูตัวอย่างภาพ

### การดูภาพเต็ม

คลิกภาพขนาดย่อใดก็ได้ใน File Browser เพื่อแสดงภาพในพื้นที่ดูตัวอย่างหลัก:

1. ภาพจะปรากฏในแผงดูตัวอย่างตรงกลาง
2. ใช้ปุ่มควบคุมการซูมเพื่อตรวจสอบรายละเอียดภาพ
3. ย้ายระหว่างภาพโดยใช้ปุ่มลูกศร

### การนำทางอย่างรวดเร็ว

* **ภาพก่อนหน้า**: คลิกปุ่มลูกศรซ้ายหรือกดปุ่ม ←
* **ภาพถัดไป**: คลิกปุ่มลูกศรขวาหรือกดปุ่ม →
* **ซูมเข้า/ออก**: ใช้ล้อเมาส์หรือปุ่มซูม
* **เลื่อนภาพ**: คลิกและลากบนภาพเมื่อซูมเข้า***

## การจัดการไฟล์ซ้ำ

Chloros จะตรวจจับและเพิกเฉยไฟล์ซ้ำโดยอัตโนมัติ:

* ไฟล์ที่มีชื่อไฟล์เหมือนกันจะถูกข้ามไป
* ป้องกันการประมวลผลซ้ำโดยไม่ตั้งใจ
* แสดงข้อความเตือนเมื่อตรวจพบไฟล์ซ้ำ

{% hint style="warning" %}
**สำคัญ**: อย่าเปลี่ยนชื่อหรือแก้ไขไฟล์ภาพต้นฉบับก่อนการนำเข้า Chloros ใช้ชื่อไฟล์ต้นฉบับและข้อมูลเมตาเพื่อดำเนินการอย่างถูกต้อง
{% endhint %}

***

## ชุดข้อมูลจากกล้องหลายรุ่น

หากโครงการของคุณมีภาพจากกล้องหลายรุ่นของMAPIR:

1. Chloros จะตรวจจับรุ่นกล้องแต่ละรุ่นโดยอัตโนมัติ — Survey3, LATTICE หรือการผสมผสาน
2. แต่ละรุ่นกล้องจะได้รับการประมวลผลด้วยโปรไฟล์การปรับเทียบที่เหมาะสม
3. ตัวเลือกไฟล์ (File Browser) จะแสดงรุ่นกล้องในคอลัมน์ Camera Model
4. แต่ละกล้องจะได้รับโครงสร้างโฟลเดอร์ผลลัพธ์ของตัวเองเมื่อได้รับการประมวลผล

**ตัวอย่างสถานการณ์**: Survey3W RGN + Survey3N OCN การตั้งค่ากล้องคู่ หรืออาร์เรย์ LATTICE ที่มี RGB เป็นมาสเตอร์และโมดูลแถบแคบหลายตัว***

## แนวทางปฏิบัติที่ดีที่สุด

### จัดระเบียบก่อนนำเข้า

* เก็บภาพเป้าหมายการปรับเทียบไว้ในโฟลเดอร์เดียวกันกับภาพสำรวจ
* เก็บไฟล์เซ็นเซอร์แสง `.daq` / `.csv` ของแต่ละเซสชันการถ่ายภาพไว้พร้อมกับภาพของเซสชันนั้น
* รักษาโครงสร้างโฟลเดอร์ต้นฉบับจากกล้อง/การ์ด SD/ฮับของคุณ
* อย่าผสมชุดข้อมูลจากเซสชันต่างกันในโครงการเดียวกัน

### การตั้งชื่อไฟล์

* รักษาชื่อไฟล์ต้นฉบับของกล้อง (IMG\_0001.RAW, capture\_..., เป็นต้น)
* อย่าเปลี่ยนชื่อไฟล์ก่อนนำเข้า
* ชื่อต้นฉบับมีข้อมูลเมตาดาต้าสำคัญ

### ภาพเป้าหมายการปรับเทียบ

* ให้รวมภาพเป้าหมายการปรับเทียบ 1-2 ภาพต่อเซสชันเสมอ (Survey3; สำหรับ LATTICE สามารถใช้บันทึก DAQ แทนได้ — ดู [การเลือกภาพเป้าหมาย](choosing-target-images.md))
* ถ่ายภาพเป้าหมายก่อนและหลังการถ่ายภาพ
* วางเป้าหมายในสภาพแสงเดียวกันกับพื้นที่ถ่ายภาพ
* ทำเครื่องหมายภาพเป้าหมายโดยใช้ช่องทำเครื่องหมาย Target

***

## ปัญหาทั่วไปและวิธีแก้ไข

### ภาพไม่ปรากฏหลังการนำเข้า

**สาเหตุที่อาจเกิดขึ้น:**

* รูปแบบไฟล์ไม่ได้รับการสนับสนุน (ดูรายชื่อรูปแบบที่ได้รับการสนับสนุนที่ส่วนบนของหน้านี้)
* ภาพถ่ายมาจากกล้องที่ไม่ใช่MAPIR (ดู [กล้องที่ได้รับการสนับสนุน](../supported-cameras.md))
* ไฟล์เสียหายหรือการถ่ายโอนจากบัตร SD ไม่สมบูรณ์

**วิธีแก้ไข**: ตรวจสอบความเข้ากันได้ของรูปแบบไฟล์และรุ่นกล้อง และตรวจสอบคำเตือนการโหลดไฟล์สำหรับไฟล์ที่ล้มเหลวอย่างเฉพาะเจาะจง

### ไม่ตรวจพบรุ่นกล้อง

**สาเหตุที่อาจเกิดขึ้น:**

* ข้อมูลเมตาดาต้า EXIF ถูกแก้ไข
* รูปภาพถูกแก้ไขในซอฟต์แวร์ภายนอก
* การถ่ายโอนไฟล์ไม่สมบูรณ์

**วิธีแก้ไข**: นำเข้าไฟล์ต้นฉบับที่ไม่ถูกแก้ไขจากกล้อง/การ์ด SD ใหม่

### ขาดข้อมูลเวลา

**สาเหตุที่อาจเกิดขึ้น:**

* นาฬิกาของกล้องไม่ถูกตั้งค่าอย่างถูกต้อง
* ข้อมูล EXIF ถูกลบโดยซอฟต์แวร์ภายนอก

**วิธีแก้ไข**: ตรวจสอบว่าการตั้งค่าเวลาของกล้องถูกต้องขณะถ่ายภาพ

### รายงานโครงการที่เปิดใหม่แสดงว่ามีไฟล์ขาดหาย

หากไฟล์ต้นฉบับถูกย้ายหรือลบไปตั้งแต่ครั้งสุดท้ายที่เปิดโครงการ Chloros จะแจ้งให้ทราบว่า **ไฟล์ใด** ที่หายไป แทนที่จะเปิดขึ้นเป็นตารางว่างเปล่า นำไฟล์กลับไปยังเส้นทางเดิม หรือลบรายการที่ขาดหายไปและนำเข้าใหม่***

## ขั้นตอนต่อไป

เมื่อไฟล์ถูกนำเข้าแล้ว:

1. **ตรวจสอบรายชื่อไฟล์** - ตรวจสอบให้แน่ใจว่าภาพทั้งหมดถูกโหลดอย่างถูกต้อง
2. **ตรวจสอบรุ่นกล้อง** - ตรวจสอบการตรวจจับกล้องให้ถูกต้อง
3. **ทำเครื่องหมายภาพเป้าหมาย** - ดู [การเลือกภาพเป้าหมาย](choosing-target-images.md)
4. **ปรับการตั้งค่า** - กำหนดตัวเลือกการประมวลผลใน [การตั้งค่าโครงการ](adjusting-project-settings.md)
5. **เริ่มการประมวลผล** - ดู [การเริ่มการประมวลผล](starting-the-processing.md)

สำหรับข้อมูลรายละเอียดเกี่ยวกับการตั้งค่าโครงการ ดู [การปรับตั้งค่าโครงการ](adjusting-project-settings.md).
