# ไฟล์แนบ

อีกครั้งหรือเปิดโปรเจ็กต์ใน Chloros แล้วพบกันต่อไปคือไม่จำเป็นต้องมีเนื้อหาหลาย ๆ ครั้งเพื่อเริ่มการทำงานของ การปรับแต่ง File Browser<img src="../.gitbook/assets/icon_file-browser.JPG" alt="" data-size="line"> เพียงเล็กน้อยการรวบรวมข้อมูลและจัดการชุดข้อมูลของคุณนำเข้าได้ง่าย

## สำหรับไฟล์แนบ

1.เปิดหรือสร้างโปรเจ็กต์ใน Chloros
2. คลิก **ไฟล์การปรับแต่ง** <img src="../.gitbook/assets/icon_file-browser.JPG" alt="" data-size="line">ไอคอนในคืนนี้อีกครั้ง
3. ทึบ File Browser จะถือเป็นไฟล์ของโครงการของคุณ

{% hint style="info" %}
**ประเภทไฟล์ที่รองรับ**: Chloros รองรับไฟล์ภาพ RAW+JPG และ JPG MAPIR Survey3W และ Survey3N รองรับเฉพาะ RAW+JPG เท่านั้น
{% endhint %}

***

## เพิ่มเติมรูปภาพของคุณ

วิธีการหลักในนั้นก็คือรูปภาพของคุณ:

### ขั้นตอนที่ 1: ไม่ต้องมีไฟล์

ใช้ตัวเลือกนี้เพื่อนำเข้าไฟล์รูปภาพแต่ละไฟล์หรือไฟล์ที่เลือกจำนวนน้อย

1. คืนนี้ **"Add Files"** <img src="../.gitbook/assets/image.png" alt="" data-size="line"> คืนนี้ File Browser
2. บันทึกไปยังเดสก์ท็อปที่มีรูปภาพของคุณ
3. เลือกไฟล์รูปภาพหนึ่งไฟล์ขึ้นไป (กด **Ctrl** ที่สำคัญหลายไฟล์)
4. คลิก **"เปิด"** เพื่อนำเข้าไฟล์ที่เลือก

###วิธีที่ 2: ยังคงเป็นอย่างนั้น

ใช้ส่วนประกอบนี้เพื่อนำเข้าภาพทั้งหมดจากที่นี่ในครั้งเดียว

1. โทรศัพท์ **"Add Folder"** <img src="../.gitbook/assets/image (1).png" alt="" data-size="line"> เพดาน File Browser
2. บันทึกไปยังที่มาของภาพที่มีการบันทึกการจับภาพของคุณ
3. คลิก **"เลือกดู"**ไฟล์นำเข้าไฟล์ที่รองรับทั้งหมดจากไฟล์นั้น***

## เข้าใจกับระดับไฟล์

รูปภาพที่นำเข้าแล้วรูปภาพจะแสดงให้เห็นในระดับสูงที่มีดังต่อไปนี้:

### ชื่อไฟล์

* ชื่อไฟล์ต้นฉบับจากกล้อง
* รักษารูปแบบการรองรับกล้อง (เช่น IMG\_0001.RAW)

### ประติเวลา

* วันที่และช่วงเวลาถ่ายภาพ
* แยกมาจากข้อมูลเมตา EXIF ของรูปภาพ
* เพื่อใช้ในการซิงโครไนซ์ PPK และเป้าหมายที่ชัดเจน

###รุ่นกล้อง

* พบกับกล้องและความโปร่งใส
* อธิบาย: Survey3W\_RGN, Survey3N\_OCN, Survey3W\_RGB
* ใช้บันทึกความทรงจำของเหตุผล

### ติดตามเป้าหมาย (ช่องวันพรุ่งนี้)

* เป็นที่ช่องนี้สำหรับรูปภาพที่มีเป้าหมายเทียบเคียง
*ตามด้วยเป้าหมายเพื่อดูตัวอย่าง
* ดูรายละเอียดใน [ เลือกภาพเป้าหมาย](choosing-target-images.md)

### การดูข้อมูลเมตาของรูปภาพ

การสังเกตที่จะเห็นบนเหนือพื้นดินจะเห็นข้อมูลเมตาของพื้นที่ที่เลือกในพื้นที่พื้นที่รูปภาพ

## ไฟล์แนบของคุณ

###แนบไฟล์

ท้ายที่สุดแล้วไม่จำเป็นต้องออกจากโปรเจ็กต์ของคุณ:

1. เลือกรูปภาพหนึ่งภาพขึ้นไปในระดับ File Browser
2. สุขภาพ **"ลบรายการที่เลือก"** <img src="../.gitbook/assets/image (2).png" alt="" data-size="line">
3. ยืนยันอีกครั้ง ( ไฟล์จะไม่ถูกลบจากเดิมลบจากโปรเจ็กต์เท่านั้น)

### การเรื่องของเรื่องนี้และกรอง

* **ผู้ผลิตตามโรงงาน**: คลิกเพื่อดูเพื่อดูรูปภาพ
* **การแสดงให้เห็นการประลองเวลา**: มีประโยชน์สำหรับการจับภาพการจับภาพในเวลา
* **รองรับรุ่นกล้อง**: จัดกลุ่มรูปภาพตามประเภทกล้องหากใช้กล้องหลายตัว***

## ดูตัวอย่างรูปภาพ

###ดูภาพเต็ม

คลิกรูปขนาดย่อของรูปภาพใดๆ ใน File Browser ภายในพื้นที่แสดงตัวอย่างหลัก:

1. รูปภาพในแผงแสดงตัวอย่างตรงกลาง
2. ใช้การซูมในรายละเอียดภาพ
3. การทำงานร่วมกันระหว่างรูปภาพปุ่มความสว่าง

### สามารถด่วน

* **ภาพก่อนหน้า**: คลิกเครื่องหมายซ้ายหรือกดปุ่ม ←
* **รูปภาพถัดไป**: คลิกขวาหรือกดปุ่ม →
* **ซูมเข้า/ออก**: ใช้ล้อเลื่อนของเมาส์หรือปุ่มซูม
* **แพน**: คลิกและลากบนรูปภาพเมื่อซูมเข้า***

##จะต้องไฟล์ที่ซ้ำกัน

Chloros ในบ้านและละเว้นไฟล์ที่ซ้ำกันอีกครั้ง:

*มีคุณสมบัติที่มีชื่อไฟล์เหมือนกันที่จะข้ามไป
*การกระทำซ้ำอีกครั้งโดยทำซ้ำ
* ประกาศเตือนเมื่อตรวจพบรายการซ้ำกัน

{% hint style="warning" %}
**ข้อสำคัญ**: พยายามเปลี่ยนชื่อหรือแก้ไขไฟล์ภาพต้นฉบับของคุณนำเข้า Chloros ต้องใช้ไฟล์ชื่อต้นฉบับและข้อมูลเมตาเพื่อประสิทธิภาพที่ดี
{% endhint %}

***

##ชุดข้อมูลกล้องผสมแบบ

ถ้าโปรเจ็กต์ของคุณมีรูปภาพจากกล้อง MAPIR เพื่อตรวจสอบตัว:

1. Chloros กล้องแต่ละตัวรุ่นต่างๆ
2. ผู้ผลิตแต่ละประเภทได้รับบันทึกด้วยโปรไฟล์ที่เคารพ
3. File Browser จะเป็นรุ่นของกล้องในโครงสร้างรุ่นของกล้อง
4. การปฏิบัติตามกฎระเบียบสำหรับกล้องแต่ละประเภท

**สถานการณ์ตัวอย่าง**: Survey3W RGN + Survey3N OCN กล้องคู่***

## ปฏิบัติตามสิ่งที่ดีที่สุด

###จัดระเบียบก่อนนำเข้า

* เก็บภาพเป้าหมายเทียบเท่ากับภาพที่สำรวจได้
* รักษาอาคารแบบดั้งเดิมจากกล้อง/ การ์ด SD ของคุณ
* อย่าผสมชุดอัจฉริยะในโปรเจ็กต์เดียว

###การรองรับไฟล์

* รักษาชื่อไฟล์กล้องดั้งเดิม (IMG\_0001.RAW และอื่นๆ)
* เพื่อเปลี่ยนชื่อไฟล์ก่อนนำเข้า
* ชื่อดั้งเดิมมีข้อมูลเมตาที่สำคัญ

### รูปภาพเป้าหมายเทียบเคียง

* รวมรูปภาพเป้าหมายเทียบกับ 1-2 ภาพต่อความสมดุลเสมอ
* จับกลุ่มเป้าหมายก่อนและหลังการจับภาพ
* อาจกำหนดเป้าหมายในสภาพแสงได้เช่นเดียวกับพื้นที่จับภาพ
* เป้าหมายเป้าหมายของช่องเป้าหมายไปจนถึงเป้าหมายเพิ่มเติม

***

##ไม่ต้องกังวลทั่วไปและการกระทำแก้ไข

### รูปภาพไม่ได้เป็นเพียงการนำเข้า

**สาเหตุที่ทำให้:**

* รองรับไฟล์รูปแบบไม่ (เฉพาะ RAW+JPG และ JPG จากกล้อง MAPIR)
*ภาพมาจากกล้องที่เราเห็น MAPIR (ดู [กล้องที่รองรับ](../supported-cameras.md))
*ความโดดเด่นหรือประสิทธิภาพของการ์ด SD ที่มีความสำคัญ

**วิธีแก้ไข**: การบันทึกรูปแบบไฟล์และคำอธิบายของรุ่นกล้อง

###ตรวจไม่พบรุ่นกล้อง

**สาเหตุที่ทำให้:**

*ประกาศข้อมูลเมตา EXIF
* รูปภาพที่แก้ไขด้วยภายนอก
* บันทึกไฟล์ของคุณ

**วิธีการ**: นำเข้าไฟล์ต้นฉบับที่ยังไม่ได้แก้ไขอีกครั้งจากกล้อง/การ์ด SD

###การประลองเวลาที่หายไป

**สาเหตุที่ทำให้:**

* นาฬิกาในกล้องไม่ได้ตั้งค่าดังกล่าว
* ข้อมูล EXIF ​​ถูกปล้นโดยซอฟต์แวร์ภายนอก

**คำแนะนำ**: ระบบควบคุมเวลาของกล้องถูกต้องระหว่างทิศทาง***

##ต่อไปจะต้องเจอ.

เมื่อไฟล์ของคุณถูกนำเข้าแล้ว:

1. **ตรวจสอบรายการไฟล์** - บันทึกการดาวน์โหลดรูปภาพทั้งหมดโดยตรง
2. **ตรวจสอบรุ่นกล้อง** - จับภาพกล้องที่ถูกต้อง
3. **เป้าหมายที่แท้จริง** - ดู [การเลือกรูปภาพเป้าหมาย](choosing-target-images.md)
4. **ปรับเพิง** - ทำตามวิธีการใน [หลายๆ โครงการ](adjusting-project-settings.md)
5. **เริ่มดำเนินการ** - ดู [การเริ่มดำเนินการ](starting-the-processing.md)

สำหรับข้อมูลเพิ่มเติมเกี่ยวกับโปรเจ็กต์ต่อเนื่อง [ เราจะเขียนโปรเจ็กต์](adjusting-project-settings.md)
